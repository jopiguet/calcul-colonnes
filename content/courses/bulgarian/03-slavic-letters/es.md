# 3. Las letras eslavas

Las nueve últimas letras escriben sonidos que el griego no tenía: ж, ц, ч, ш, щ, ъ, ь, ю, я. Entre ellas está ъ, una vocal para la que pocos alfabetos tienen letra. Esta lección completa las 30 letras y da las palabras de cortesía de cada día.

## Nueve letras para sonidos eslavos

| Letra | Sonido | Transliteración |
|---|---|---|
| Ж ж | j del francés *jour* | zh |
| Ц ц | ts de *tsunami* | ts |
| Ч ч | ch de *chico* | ch |
| Ш ш | sh del inglés *ship* | sh |
| Щ щ | sht del inglés *ashtray* | sht |
| Ъ ъ | una a breve y oscura | a |
| Ь ь | y delante de о | y |
| Ю ю | yu de *yugo* | yu |
| Я я | ya de *yate* | ya |

- Щ se lee *sht* en búlgaro, no el *shch* del ruso: щастие *shtastie*, «felicidad».
- Ъ es una vocal plena, una *a* breve y oscura, como la *a* del inglés «about»: добър *dobar*, «bueno». La transliteración oficial la escribe *a*, como а; también puede escribir *ă* o *ǎ*.
- Ь solo aparece delante de о, para palatalizar la consonante: шофьор *shofyor*, «conductor».
- Ж se escribe *zh*, Ч *ch*, Ш *sh*: también puede escribir *ž*, *č*, *š*.

## La cortesía

| Búlgaro | Transliteración | Significado |
|---|---|---|
| добър ден | *dobar den* | buenos días |
| благодаря | *blagodarya* | gracias |
| довиждане | *dovizhdane* | adiós |
| чай | *chay* | té |
| хляб | *hlyab* | pan |
| жена | *zhena* | mujer |
| къща | *kashta* | casa |

- Добър ден se dice durante el día; добро утро *dobro utro* por la mañana, добър вечер *dobar vecher* por la tarde.
- Благодаря también se dice мерси *mersi*, del francés.
- Довиждане es «hasta vernos»: до «hasta», виждане «el ver».
