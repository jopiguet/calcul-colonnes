# 3. Les lettres slaves

Les neuf dernières lettres notent des sons que le grec n'avait pas : ж, ц, ч, ш, щ, ъ, ь, ю, я. Parmi elles, ъ, une voyelle pour laquelle peu d'alphabets ont une lettre. Cette leçon complète les 30 lettres et donne les mots de politesse de tous les jours.

## Neuf lettres pour des sons slaves

| Lettre | Son | Translittération |
|---|---|---|
| Ж ж | j de *jour* | zh |
| Ц ц | ts de *tsar* | ts |
| Ч ч | tch de *tchèque* | ch |
| Ш ш | ch de *chat* | sh |
| Щ щ | cht de *ch'timi* | sht |
| Ъ ъ | e de *le*, plus ouvert | a |
| Ь ь | y devant о | y |
| Ю ю | you de *youpi* | yu |
| Я я | ya de *yack* | ya |

- Щ se lit *cht* en bulgare, pas le *chtch* du russe : щастие *shtastie*, « bonheur ».
- Ъ est une vraie voyelle, entre le *e* de « le » et le *a* : добър *dobar*, « bon ». La translittération officielle l'écrit *a*, comme а ; vous pouvez aussi taper *ă* ou *ǎ*.
- Ь ne se trouve que devant о, pour mouiller la consonne : шофьор *shofyor*, « chauffeur ».
- Ж s'écrit *zh*, Ч *ch*, Ш *sh* : vous pouvez aussi taper *ž*, *č*, *š*.

## La politesse

| Bulgare | Translittération | Sens |
|---|---|---|
| добър ден | *dobar den* | bonjour |
| благодаря | *blagodarya* | merci |
| довиждане | *dovizhdane* | au revoir |
| чай | *chay* | thé |
| хляб | *hlyab* | pain |
| жена | *zhena* | femme |
| къща | *kashta* | maison |

- Добър ден se dit dans la journée ; добро утро *dobro utro* le matin, добър вечер *dobar vecher* le soir.
- Благодаря se dit aussi мерси *mersi*, du français.
- Довиждане, c'est « jusqu'à se revoir » : до « jusqu'à », виждане « le fait de voir ».

- ж zh, ц ts, ч ch, ш sh, щ sht, ъ a, ь y (devant о), ю yu, я ya.
- Ъ est une voyelle, proche du *e* de « le » ; щ se lit *cht*.
- добър ден, благодаря, довиждане ; чай, хляб, жена, къща.
