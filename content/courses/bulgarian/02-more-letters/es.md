# 2. Las letras que vienen del griego

Nueve letras más vienen del griego o parecen nuevas: Б, Г, Д, З, И, Й, Л, П, Ф. Con ellas y las doce primeras puede leer la mayoría de las palabras búlgaras, y saludar.

## Nueve letras

| Letra | Sonido | Nota |
|---|---|---|
| Б б | b | distinta de В |
| Г г | g | siempre suave, como en *gato* |
| Д д | d | |
| З з | z | una s sonora; parece el número 3 |
| И и | i | |
| Й й | y | como en *hoy*, junto a una vocal |
| Л л | l | |
| П п | p | la pi griega |
| Ф ф | f | la fi griega |

- Б y В son dos letras: б es *b*, в es *v*, como la v francesa o inglesa. Бира se lee *bira*, «cerveza»; вода *voda*, «agua».
- И es una vocal, *i*; Й, la «i breve», es la consonante *y*: здравей *zdravey*.
- A mano y en cursiva algunas letras cambian de forma: т parece una m latina, п una n, и una u. La letra impresa, como aquí, guarda las formas de la tabla.

## Palabras y un saludo

| Búlgaro | Transliteración | Significado |
|---|---|---|
| вода | *voda* | agua |
| бира | *bira* | cerveza |
| лимон | *limon* | limón |
| град | *grad* | ciudad |
| ден | *den* | día |
| здравей | *zdravey* | hola |

- Здравей se dice a una persona a quien se tutea; a varias, o de usted, se dice здравейте *zdraveyte*.
- Град es el *-grad* de Belgrado y de nombres de ciudades antiguos: «lugar cercado».
