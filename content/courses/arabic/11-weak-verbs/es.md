# 11. Los verbos débiles

Cuando una de las tres letras de la raíz es و o ي, una hamza, o cuando las dos últimas son iguales, el verbo se dobla: la letra débil se vuelve vocal larga, se acorta o desaparece. Estos verbos están entre los más frecuentes de la lengua: قَالَ «dijo», كَانَ «era», جَاءَ «vino», رَأَى «vio». Cada clase sigue su regla, y la raíz sigue ahí bajo la superficie.

## Las clases

| Clase | Raíz | Perfectivo | Imperfectivo | Sentido |
|---|---|---|---|---|
| cóncavo (و/ي en medio) | ق و ل | قَالَ *qāla*, قُلْتُ *qultu* | يَقُولُ *yaqūlu* | decir |
| cóncavo | ك و ن | كَانَ *kāna*, كُنْتُ *kuntu* | يَكُونُ *yakūnu* | ser |
| cóncavo | س ي ر | سَارَ *sāra*, سِرْتُ *sirtu* | يَسِيرُ *yasīru* | caminar, viajar |
| defectivo (و/ي final) | د ع و | دَعَا *daʿā* | يَدْعُو *yadʿū* | llamar, rezar |
| defectivo | م ش ي | مَشَى *mashā* | يَمْشِي *yamshī* | andar |
| asimilado (و inicial) | و ص ل | وَصَلَ *waṣala* | يَصِلُ *yaṣilu* | llegar |
| asimilado | و ج د | وَجَدَ *wajada* | يَجِدُ *yajidu* | encontrar |
| hamzado | أ خ ذ | أَخَذَ *akhadha* | يَأْخُذُ *yaʾkhudhu* | tomar |
| sordo (geminado) | م د د | مَدَّ *madda*, مَدَدْتُ *madadtu* | يَمُدُّ *yamuddu* | extender |

En los cóncavos, la vocal larga de قَالَ se acorta ante una desinencia consonántica: قُلْتُ «dije». En los asimilados, la و de la raíz desaparece en el imperfectivo: يَصِلُ. El imperativo de قَالَ es قُلْ *qul* «¡di!», que abre cuatro suras del Corán: قُلْ هُوَ اللَّهُ أَحَدٌ (112:1).

## Encontrar la raíz

| Forma | Raíz |
|---|---|
| قُلْتُ | ق و ل |
| يَجِدُ | و ج د |
| يَدْعُو | د ع و |
| كُنْتُ | ك و ن |

Cuando una forma solo muestra dos consonantes, busque una و, una ي o una hamza que falte.

::: exercise write
Escriba en árabe.

- «dije» → [[قلت]]
- «¡di!» → [[قل]]
- «llegó» → [[وصل]]
- «era, estaba» (yo) → [[كنت]]
:::

::: exercise class
¿Qué clase?

- قَالَ → ((cóncavo* / defectivo / asimilado))
- يَمْشِي → ((cóncavo / defectivo* / sordo))
- يَصِلُ → ((hamzado / asimilado* / cóncavo))
- مَدَّ → ((sordo* / defectivo / cóncavo))
:::

::: exercise root
¿Qué raíz?

- يَقُولُ → ((ق ل ل / ق و ل* / ق ي ل))
- يَجِدُ → ((ج د د / و ج د* / ج ي د))
- دَعَا → ((د ع و* / د ع ي / د ع ع))
- كُنْتُ → ((ك ن ت / ك و ن* / ك ي ن))
:::

::: exercise translate
Traduzca.

- قَالَ لِي: أَهْلًا وَسَهْلًا. → {{Me dijo: bienvenido.}}
- كُنْتُ فِي القَاهِرَةِ. → {{Estaba en El Cairo.}}
- وَجَدْتُ الكِتَابَ. → {{Encontré el libro.}}
- قُلْ هُوَ اللَّهُ أَحَدٌ → {{Di: Él es Dios, Uno. / Di: Él, Dios, es Uno.}}
:::

::: summary
- Cóncavos: قال، قلت، يقول; كان، كنت، يكون. Defectivos: دعا يدعو، مشى يمشي.
- Asimilados: وصل يصل، وجد يجد. Hamzados: أخذ يأخذ. Sordos: مدّ، مددت، يمدّ.
- Dos consonantes visibles: busque و، ي o hamza; قُلْ «¡di!».
:::
