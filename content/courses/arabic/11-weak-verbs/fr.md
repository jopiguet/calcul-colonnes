# 11. Les verbes faibles

Quand l'une des trois lettres de la racine est و ou ي, une hamza, ou quand les deux dernières sont identiques, le verbe se plie : la lettre faible devient une voyelle longue, s'abrège ou disparaît. Ces verbes sont parmi les plus fréquents de la langue : قَالَ « il a dit », كَانَ « il était », جَاءَ « il est venu », رَأَى « il a vu ». Chaque classe suit sa règle, et la racine reste là sous la surface.

## Les classes

| Classe | Racine | Accompli | Inaccompli | Sens |
|---|---|---|---|---|
| concave (و/ي au milieu) | ق و ل | قَالَ *qāla*, قُلْتُ *qultu* | يَقُولُ *yaqūlu* | dire |
| concave | ك و ن | كَانَ *kāna*, كُنْتُ *kuntu* | يَكُونُ *yakūnu* | être |
| concave | س ي ر | سَارَ *sāra*, سِرْتُ *sirtu* | يَسِيرُ *yasīru* | marcher, voyager |
| défectueux (و/ي final) | د ع و | دَعَا *daʿā* | يَدْعُو *yadʿū* | appeler, prier |
| défectueux | م ش ي | مَشَى *mashā* | يَمْشِي *yamshī* | marcher |
| assimilé (و initial) | و ص ل | وَصَلَ *waṣala* | يَصِلُ *yaṣilu* | arriver |
| assimilé | و ج د | وَجَدَ *wajada* | يَجِدُ *yajidu* | trouver |
| hamzé | أ خ ذ | أَخَذَ *akhadha* | يَأْخُذُ *yaʾkhudhu* | prendre |
| sourd (redoublé) | م د د | مَدَّ *madda*, مَدَدْتُ *madadtu* | يَمُدُّ *yamuddu* | étendre |

Dans les verbes concaves, la voyelle longue de قَالَ s'abrège devant une terminaison consonantique : قُلْتُ « j'ai dit ». Dans les assimilés, le و de la racine disparaît à l'inaccompli : يَصِلُ. L'impératif de قَالَ est قُلْ *qul* « dis ! », qui ouvre quatre sourates du Coran : قُلْ هُوَ اللَّهُ أَحَدٌ (112:1).

## Retrouver la racine

| Forme | Racine |
|---|---|
| قُلْتُ | ق و ل |
| يَجِدُ | و ج د |
| يَدْعُو | د ع و |
| كُنْتُ | ك و ن |

Quand une forme ne montre que deux consonnes, cherchez un و, un ي ou une hamza manquants.

::: exercise write
Écrivez en arabe.

- « j'ai dit » → [[قلت]]
- « dis ! » → [[قل]]
- « il est arrivé » → [[وصل]]
- « j'étais » → [[كنت]]
:::

::: exercise class
Quelle classe ?

- قَالَ → ((concave* / défectueux / assimilé))
- يَمْشِي → ((concave / défectueux* / sourd))
- يَصِلُ → ((hamzé / assimilé* / concave))
- مَدَّ → ((sourd* / défectueux / concave))
:::

::: exercise root
Quelle racine ?

- يَقُولُ → ((ق ل ل / ق و ل* / ق ي ل))
- يَجِدُ → ((ج د د / و ج د* / ج ي د))
- دَعَا → ((د ع و* / د ع ي / د ع ع))
- كُنْتُ → ((ك ن ت / ك و ن* / ك ي ن))
:::

::: exercise translate
Traduisez.

- قَالَ لِي: أَهْلًا وَسَهْلًا. → {{Il m'a dit : bienvenue.}}
- كُنْتُ فِي القَاهِرَةِ. → {{J'étais au Caire.}}
- وَجَدْتُ الكِتَابَ. → {{J'ai trouvé le livre.}}
- قُلْ هُوَ اللَّهُ أَحَدٌ → {{Dis : Il est Dieu, Un. / Dis : Lui, Dieu est Un.}}
:::

::: summary
- Concaves : قال، قلت، يقول ; كان، كنت، يكون. Défectueux : دعا يدعو، مشى يمشي.
- Assimilés : وصل يصل، وجد يجد. Hamzés : أخذ يأخذ. Sourds : مدّ، مددت، يمدّ.
- Deux consonnes visibles : cherchez un و، ي ou une hamza manquants ; قُلْ « dis ! ».
:::
