# 14. Las oraciones de relativo y las preguntas

El último versículo de la Fátiha contiene una relativa: صِرَاطَ الَّذِينَ أَنْعَمْتَ عَلَيْهِمْ «el camino de aquellos a quienes has agraciado», literalmente «aquellos que has agraciado sobre ellos». Los pronombres relativos árabes concuerdan con su sustantivo, solo se usan tras un sustantivo definido, y la relativa repite el sustantivo con un pronombre. Las preguntas son más sencillas: una palabra interrogativa o هَلْ delante de una oración corriente.

## Los pronombres relativos

| | Singular | Plural |
|---|---|---|
| masculino | الَّذِي *alladhī* | الَّذِينَ *alladhīna* |
| femenino | الَّتِي *allatī* | اللَّاتِي *allātī* |

| Árabe | Sentido |
|---|---|
| الرَّجُلُ الَّذِي يَكْتُبُ | el hombre que escribe |
| الكِتَابُ الَّذِي قَرَأْتُهُ | el libro que leí (lit. que lo leí) |
| المَدِينَةُ الَّتِي سَكَنْتُ فِيهَا | la ciudad en la que viví (lit. en ella) |
| رَأَيْتُ رَجُلًا يَكْتُبُ | vi a un hombre que escribía |

Tras un sustantivo indefinido no hay relativo. El pronombre ـهُ، ـهَا، ـهِمْ dentro de la relativa, el *ʿāʾid*, remite al sustantivo siempre que no sea sujeto. مَنْ «el que, quienquiera» y مَا «lo que» no necesitan sustantivo: مَنْ جَدَّ وَجَدَ «quien se esfuerza, encuentra» (proverbio).

## Las palabras interrogativas

| Palabra | Sentido | Ejemplo |
|---|---|---|
| مَا / مَاذَا *mā / mādhā* | qué | مَاذَا تُرِيدُ؟ ¿qué quieres? |
| مَنْ *man* | quién | مَنْ أَنْتَ؟ ¿quién eres? |
| أَيْنَ *ayna* | dónde | أَيْنَ تَسْكُنُ؟ ¿dónde vives? |
| مَتَى *matā* | cuándo | مَتَى وَصَلْتَ؟ ¿cuándo llegaste? |
| كَيْفَ *kayfa* | cómo | كَيْفَ حَالُكَ؟ ¿cómo estás? |
| لِمَاذَا *limādhā* | por qué | لِمَاذَا تَدْرُسُ العَرَبِيَّةَ؟ ¿por qué estudias árabe? |
| كَمْ *kam* | cuántos (+ singular en acusativo) | كَمْ كِتَابًا عِنْدَكَ؟ ¿cuántos libros tienes? |
| أَيّ *ayy* | cuál | أَيُّ كِتَابٍ؟ ¿qué libro? |
| هَلْ / أَ *hal / a-* | (pregunta de sí o no) | هَلْ أَنْتَ طَالِبٌ؟ ¿eres estudiante? |

مَا ante un sustantivo es «cuál es»: مَا اسْمُكَ؟ «¿cómo te llamas?». Ante un verbo en perfectivo, مَا es una negación (lección 9).

Escriba en árabe.

- «cuándo» → [[متى]]
- «que, el cual» (relativo, m. sg.) → [[الذي]]
- «los que» (m. pl.) → [[الذين]]
:::

::: exercise relative
¿Qué relativo?

- المَدْرَسَةُ … بَنَوْهَا «la escuela que construyeron» → ((الَّذِي / الَّتِي* / الَّذِينَ))
- الطُّلَّابُ … نَجَحُوا «los estudiantes que aprobaron» → ((الَّذِي / الَّتِي / الَّذِينَ*))
- رَأَيْتُ رَجُلًا … يَكْتُبُ «vi a un hombre que escribía» → ((الَّذِي / sin relativo*))
:::

::: exercise question
¿Qué palabra interrogativa?

- … أَنْتَ؟ «¿quién eres?» → ((مَا / مَنْ* / أَيْنَ))
- … كِتَابًا عِنْدَكَ؟ «¿cuántos libros?» → ((كَمْ* / كَيْفَ / أَيّ))
- … أَنْتَ طَالِبٌ؟ «¿eres estudiante?» → ((هَلْ* / مَاذَا / مَتَى))
- … اسْمُكَ؟ «¿cómo te llamas?» → ((مَا* / مَنْ / كَمْ))
:::

::: exercise translate
Traduzca.

- الكِتَابُ الَّذِي قَرَأْتُهُ جَمِيلٌ. → {{El libro que leí es bonito. / El libro que he leído es hermoso.}}
- صِرَاطَ الَّذِينَ أَنْعَمْتَ عَلَيْهِمْ → {{el camino de aquellos a quienes has agraciado / la senda de los que has favorecido}}
- لِمَاذَا تَدْرُسُ العَرَبِيَّةَ؟ → {{¿Por qué estudias árabe?}}
- هَلْ أَنْتَ طَالِبٌ؟ → {{¿Eres estudiante?}}
:::

::: summary
- الذي، التي، الذين، اللاتي tras un sustantivo definido; nada tras un indefinido; un pronombre repite el sustantivo (قرأتُهُ).
- مَن quienquiera, ما lo que; ماذا، مَن، أين، متى، كيف، لماذا، كم، أيّ.
- هل / أ para preguntas de sí o no; كم + singular en acusativo.
:::
