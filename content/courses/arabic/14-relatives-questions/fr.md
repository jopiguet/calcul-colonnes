# 14. Les relatives et les questions

Le dernier verset de la Fâtiha contient une relative : صِرَاطَ الَّذِينَ أَنْعَمْتَ عَلَيْهِمْ « le chemin de ceux que Tu as comblés », littéralement « ceux que Tu as comblés sur eux ». Les pronoms relatifs arabes s'accordent avec leur nom, ne s'emploient qu'après un nom défini, et la relative reprend le nom par un pronom. Les questions sont plus simples : un mot interrogatif ou هَلْ devant une phrase ordinaire.

## Les pronoms relatifs

| | Singulier | Pluriel |
|---|---|---|
| masculin | الَّذِي *alladhī* | الَّذِينَ *alladhīna* |
| féminin | الَّتِي *allatī* | اللَّاتِي *allātī* |

| Arabe | Sens |
|---|---|
| الرَّجُلُ الَّذِي يَكْتُبُ | l'homme qui écrit |
| الكِتَابُ الَّذِي قَرَأْتُهُ | le livre que j'ai lu (litt. que je l'ai lu) |
| المَدِينَةُ الَّتِي سَكَنْتُ فِيهَا | la ville où j'ai habité (litt. dans elle) |
| رَأَيْتُ رَجُلًا يَكْتُبُ | j'ai vu un homme qui écrivait |

Après un nom indéfini, il n'y a pas de relatif. Le pronom ـهُ، ـهَا، ـهِمْ dans la relative, le *ʿāʾid*, renvoie au nom chaque fois qu'il n'est pas sujet. مَنْ « celui qui, quiconque » et مَا « ce que » se passent de nom : مَنْ جَدَّ وَجَدَ « qui cherche trouve » (proverbe).

## Les mots interrogatifs

| Mot | Sens | Exemple |
|---|---|---|
| مَا / مَاذَا *mā / mādhā* | quoi, que | مَاذَا تُرِيدُ؟ que veux-tu ? |
| مَنْ *man* | qui | مَنْ أَنْتَ؟ qui es-tu ? |
| أَيْنَ *ayna* | où | أَيْنَ تَسْكُنُ؟ où habites-tu ? |
| مَتَى *matā* | quand | مَتَى وَصَلْتَ؟ quand es-tu arrivé ? |
| كَيْفَ *kayfa* | comment | كَيْفَ حَالُكَ؟ comment vas-tu ? |
| لِمَاذَا *limādhā* | pourquoi | لِمَاذَا تَدْرُسُ العَرَبِيَّةَ؟ pourquoi étudies-tu l'arabe ? |
| كَمْ *kam* | combien (+ singulier à l'accusatif) | كَمْ كِتَابًا عِنْدَكَ؟ combien de livres as-tu ? |
| أَيّ *ayy* | quel | أَيُّ كِتَابٍ؟ quel livre ? |
| هَلْ / أَ *hal / a-* | (question fermée) | هَلْ أَنْتَ طَالِبٌ؟ es-tu étudiant ? |

مَا devant un nom signifie « quel est » : مَا اسْمُكَ؟ « quel est ton nom ? ». Devant un verbe à l'accompli, مَا est une négation (leçon 9).

Écrivez en arabe.

- « pourquoi » → [[لماذا]]
- « quand » → [[متى]]
- « qui » (relatif, m. sg.) → [[الذي]]
- « ceux qui » (m. pl.) → [[الذين]]
:::

::: exercise relative
Quel relatif ?

- المَدْرَسَةُ … بَنَوْهَا « l'école qu'ils ont construite » → ((الَّذِي / الَّتِي* / الَّذِينَ))
- الطُّلَّابُ … نَجَحُوا « les étudiants qui ont réussi » → ((الَّذِي / الَّتِي / الَّذِينَ*))
- رَأَيْتُ رَجُلًا … يَكْتُبُ « j'ai vu un homme qui écrivait » → ((الَّذِي / pas de relatif*))
:::

::: exercise question
Quel mot interrogatif ?

- … أَنْتَ؟ « qui es-tu ? » → ((مَا / مَنْ* / أَيْنَ))
- … كِتَابًا عِنْدَكَ؟ « combien de livres ? » → ((كَمْ* / كَيْفَ / أَيّ))
- … أَنْتَ طَالِبٌ؟ « es-tu étudiant ? » → ((هَلْ* / مَاذَا / مَتَى))
- … اسْمُكَ؟ « quel est ton nom ? » → ((مَا* / مَنْ / كَمْ))
:::

::: exercise translate
Traduisez.

- الكِتَابُ الَّذِي قَرَأْتُهُ جَمِيلٌ. → {{Le livre que j'ai lu est beau.}}
- صِرَاطَ الَّذِينَ أَنْعَمْتَ عَلَيْهِمْ → {{le chemin de ceux que Tu as comblés / la voie de ceux que Tu as comblés de bienfaits}}
- لِمَاذَا تَدْرُسُ العَرَبِيَّةَ؟ → {{Pourquoi étudies-tu l'arabe ?}}
- هَلْ أَنْتَ طَالِبٌ؟ → {{Es-tu étudiant ?}}
:::

::: summary
- الذي، التي، الذين، اللاتي après un nom défini ; rien après un indéfini ; un pronom reprend le nom (قرأتُهُ).
- مَن quiconque, ما ce que ; ماذا، مَن، أين، متى، كيف، لماذا، كم، أيّ.
- هل / أ pour les questions fermées ; كم + singulier à l'accusatif.
:::
