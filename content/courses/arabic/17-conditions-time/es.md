# 17. Las condicionales y las oraciones temporales

El árabe tiene tres palabras para «si»: إِنْ para una posibilidad real, إِذَا para lo que se espera (a menudo «cuando»), y لَوْ para lo irreal. Las tres llevan normalmente el **perfectivo**, sea cual sea el tiempo: la condición se ve como cumplida. La sura 110 empieza con una: إِذَا جَاءَ نَصْرُ اللَّهِ وَالْفَتْحُ «cuando llegue el auxilio de Dios y la victoria».

## Los tres «si»

| Palabra | Uso | Verbo | Ejemplo |
|---|---|---|---|
| إِنْ *in* | posibilidad real | perfectivo o yusivo | إِنْ دَرَسْتَ نَجَحْتَ si estudias, aprobarás |
| إِذَا *idhā* | esperado, «cuando» | perfectivo | إِذَا جَاءَ فَقُلْ لَهُ cuando venga, dile |
| لَوْ *law* | irreal | perfectivo; principal con لَـ | لَوْ كُنْتُ غَنِيًّا لَسَافَرْتُ si fuera rico, viajaría |

La principal lleva فَـ *fa-* «entonces» cuando no es un simple verbo: imperativo, oración nominal, negación, futuro: إِذَا جَاءَ فَقُلْ لَهُ. Tras لَوْ, la principal suele llevar لَـ: لَسَافَرْتُ. «A menos que» es إِلَّا إِذَا; «si no fuera por» con لَوْ es لَوْلَا + sustantivo: لَوْلَا المَطَرُ «si no fuera por la lluvia».

## Las oraciones temporales

| Palabra | Sentido | Ejemplo |
|---|---|---|
| عِنْدَمَا *ʿindamā* | cuando | عِنْدَمَا وَصَلْتُ، نَامَ cuando llegué, dormía (lit. se durmió) |
| حِينَ *ḥīna* | cuando, en el momento en que | حِينَ سَمِعَ الخَبَرَ cuando oyó la noticia |
| بَعْدَ أَنْ *baʿda an* | después de que | بَعْدَ أَنْ أَكَلْنَا después de comer |
| قَبْلَ أَنْ *qabla an* | antes de que (+ subjuntivo) | قَبْلَ أَنْ تَذْهَبَ antes de que te vayas |
| مُنْذُ *mundhu* | desde, hace | أَسْكُنُ هُنَا مُنْذُ سَنَتَيْنِ vivo aquí desde hace dos años |
| حَتَّى *ḥattā* | hasta que (+ subjuntivo) | انْتَظِرْ حَتَّى أَرْجِعَ espera hasta que vuelva |

Escriba en árabe.

- «si, cuando» (esperado) → [[إذا]]
- «cuando» (ʿindamā) → [[عندما]]
- «después de que» → [[بعد أن]]
- «desde» → [[منذ]]
:::

::: exercise which
¿Qué «si»?

- «si fuera rico» (irreal) → ((إِنْ / إِذَا / لَوْ*))
- «cuando venga» (esperado) → ((إِنْ / إِذَا* / لَوْ))
- «si estudias» (posible) → ((إِنْ* / لَوْ))
- «si no fuera por la lluvia» → ((لَوْلَا المَطَرُ* / إِنْ المَطَرُ))
:::

::: exercise fa
¿Con فَـ o sin él?

- إِذَا جَاءَ … قُلْ لَهُ (imperativo) → ((con فَـ* / sin))
- إِنْ دَرَسْتَ … نَجَحْتَ (simple perfectivo) → ((con فَـ / sin*))
- لَوْ كُنْتُ غَنِيًّا … سَافَرْتُ → ((con لَـ* / con فَـ))
:::

::: exercise translate
Traduzca.

- إِذَا جَاءَ نَصْرُ اللَّهِ وَالْفَتْحُ → {{Cuando llegue el auxilio de Dios y la victoria. / Cuando vengan la ayuda de Dios y la victoria.}}
- لَوْ كُنْتُ غَنِيًّا لَسَافَرْتُ. → {{Si fuera rico, viajaría.}}
- أَسْكُنُ هُنَا مُنْذُ سَنَتَيْنِ. → {{Vivo aquí desde hace dos años.}}
- قَبْلَ أَنْ تَذْهَبَ، اتَّصِلْ بِي. → {{Antes de irte, llámame. / Antes de que te vayas, llámame.}}
:::

::: summary
- إنْ (posible), إذا (esperado, «cuando»), لو (irreal), normalmente + perfectivo.
- فَـ ante una principal que no es un simple verbo; لَـ tras لو; لولا «si no fuera por».
- عندما، حين، بعد أن، قبل أن، منذ، حتى.
:::
