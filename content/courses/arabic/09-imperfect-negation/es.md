# 9. El imperfectivo y la negación

El perfectivo sirve para acciones acabadas; el **imperfectivo** para todo lo que no lo está: el presente, lo habitual y, con un prefijo, el futuro. Donde el perfectivo añade sufijos, el imperfectivo añade prefijos: يَكْتُبُ *yaktubu* «escribe». La primera sura del Corán tiene dos: إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ «A Ti solo adoramos y a Ti solo pedimos ayuda».

## El imperfectivo

| Persona | Forma | Persona | Forma |
|---|---|---|---|
| yo | أَكْتُبُ *aktubu* | nosotros | نَكْتُبُ *naktubu* |
| tú (m.) | تَكْتُبُ *taktubu* | vosotros | تَكْتُبُونَ *taktubūna* |
| tú (f.) | تَكْتُبِينَ *taktubīna* | ellos | يَكْتُبُونَ *yaktubūna* |
| él | يَكْتُبُ *yaktubu* | ellas | يَكْتُبْنَ *yaktubna* |
| ella | تَكْتُبُ *taktubu* | | |

Los prefijos son أَ *a-* yo, تَ *ta-* tú y ella, يَ *ya-* él y ellos, نَ *na-* nosotros. La vocal tras la segunda radical se aprende con el verbo: يَكْتُبُ *u*, يَشْرَبُ *yashrabu a*, يَجْلِسُ *yajlisu i* «se sienta». سَـ *sa-* o سَوْفَ *sawfa* ante el imperfectivo forma un futuro: سَأَكْتُبُ «escribiré».

## La negación

| Negación | Con | Sentido | Ejemplo |
|---|---|---|---|
| لَا *lā* | imperfectivo | no | لَا أَعْرِفُ no sé |
| مَا *mā* | perfectivo | no (pasado) | مَا ذَهَبَ no fue |
| لَمْ *lam* | yusivo (lección 12) | no (pasado, escrito) | لَمْ يَذْهَبْ no fue |
| لَنْ *lan* | subjuntivo (lección 12) | no (futuro) | لَنْ يَذْهَبَ no irá |
| لَيْسَ *laysa* | oración nominal | no es | لَيْسَ هُنَا no está aquí |

لَيْسَ se conjuga como un perfectivo: لَسْتُ *lastu* «no soy», لَسْتَ, لَيْسَتْ, لَسْنَا, لَيْسُوا. Su atributo va en acusativo: لَسْتُ طَالِبًا «no soy estudiante».

::: exercise neg
¿Qué negación?

- «no sé» → ((لَا أَعْرِفُ* / مَا أَعْرِفُ / لَيْسَ أَعْرِفُ))
- «no fue» (perfectivo) → ((لَا ذَهَبَ / مَا ذَهَبَ* / لَنْ ذَهَبَ))
- «no irá» → ((لَمْ يَذْهَبْ / لَنْ يَذْهَبَ* / لَا ذَهَبَ))
- «no soy estudiante» → ((لَسْتُ طَالِبًا* / لَا طَالِب / مَا طَالِب))
:::

::: exercise tense
¿Perfectivo o imperfectivo?

- يَشْرَبُ → ((perfectivo / imperfectivo*))
- شَرِبَتْ → ((perfectivo* / imperfectivo))
- نَسْتَعِينُ → ((perfectivo / imperfectivo*))
- سَأَكْتُبُ → ((perfectivo / imperfectivo con futuro sa-*))
:::

- لَا أَعْرِفُ. → {{No sé. / No lo sé.}}
- إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ → {{A Ti solo adoramos y a Ti solo pedimos ayuda. / Solo a Ti adoramos y solo a Ti pedimos ayuda.}}
- سَأَذْهَبُ غَدًا. → {{Iré mañana.}}
:::

::: summary
- Imperfectivo: prefijos أَ تَ يَ نَ + tema + -u; plurales -ūna; يَكْتُبُ، يَشْرَبُ، يَجْلِسُ.
- Futuro: سَـ / سَوْفَ + imperfectivo.
- لَا + imperfectivo, مَا + perfectivo, لَمْ + yusivo, لَنْ + subjuntivo, لَيْسَ «no es» + acusativo.
:::
