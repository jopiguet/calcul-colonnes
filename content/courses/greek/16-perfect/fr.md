# 16. Le parfait

Le parfait grec ne signifie pas « je fis ». Il décrit un **état présent** qui résulte d'une action passée : τέθνηκε, c'est « il est mort » ; πέπεικα « j'ai persuadé (et la personne est maintenant convaincue) ». Sa marque est le **redoublement** : la première consonne du radical est répétée, suivie de ε, devant lui : λύω → λέ-λυ-κα.

## Le parfait actif et moyen-passif

| Personne | Actif | Moyen-passif |
|---|---|---|
| 1re sg. | λέλυκα | λέλυμαι |
| 2e sg. | λέλυκας | λέλυσαι |
| 3e sg. | λέλυκε(ν) | λέλυται |
| 1re pl. | λελύκαμεν | λελύμεθα |
| 2e pl. | λελύκατε | λέλυσθε |
| 3e pl. | λελύκασι(ν) | λέλυνται |
| infinitif | λελυκέναι | λελύσθαι |
| participe | λελυκώς, -υῖα, -ός | λελυμένος, -η, -ον |

L'actif ajoute κα au radical redoublé ; le moyen-passif ajoute ses terminaisons directement, sans voyelle thématique. Le redoublement reste à tous les modes : ce n'est pas un augment.

## Le redoublement

| Le verbe commence par | Redoublement | Exemple |
|---|---|---|
| une consonne | cette consonne + ε | λύω → λέλυκα ; παιδεύω → πεπαίδευκα |
| une aspirée θ φ χ | la consonne simple + ε | θύω → τέθυκα ; φιλέω → πεφίληκα |
| une voyelle | allongée, comme un augment | ἀγγέλλω → ἤγγελκα ; ὁπλίζω → ὥπλικα |
| deux consonnes, ζ, ξ, ψ | ἐ- seulement | στέλλω → ἔσταλκα ; γιγνώσκω → ἔγνωκα |

Certains parfaits n'ont pas de κ (*parfait second*) : γράφω → γέγραφα ; λείπω → λέλοιπα ; et de φαίνω, πέφηνα « je suis apparu ». οἶδα « je sais » est un parfait sans redoublement : « j'ai vu », donc « je sais ».

## Le plus-que-parfait

Augment + redoublement + -η : ἐλελύκη « j'avais délié ». Il décrit un état dans le passé : ἐτεθνήκει « il était mort ».

::: summary
- Parfait : redoublement + κα : λέλυκα, -κας, -κε(ν), -καμεν, -κατε, -κασι(ν) ; moyen λέλυμαι, -σαι, -ται.
- λε-λυ, πε-παίδευκα ; aspirée → simple : τέθυκα ; voyelle allongée ; ἐ- devant deux consonnes : ἔγνωκα.
- Un état présent issu d'un acte passé : τέθνηκε il est mort ; plus-que-parfait ἐλελύκη ; οἶδα je sais.
:::
