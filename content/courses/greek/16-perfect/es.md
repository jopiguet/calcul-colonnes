# 16. El perfecto

El perfecto griego no significa «hice». Describe un **estado presente** que resulta de una acción pasada: τέθνηκε es «ha muerto», es decir, «está muerto»; πέπεικα «he persuadido (y la persona está ahora convencida)». Su marca es la **reduplicación**: la primera consonante del tema se repite, seguida de ε, delante de él: λύω → λέ-λυ-κα.

## El perfecto activo y medio-pasivo

| Persona | Activo | Medio-pasivo |
|---|---|---|
| 1.ª sg. | λέλυκα | λέλυμαι |
| 2.ª sg. | λέλυκας | λέλυσαι |
| 3.ª sg. | λέλυκε(ν) | λέλυται |
| 1.ª pl. | λελύκαμεν | λελύμεθα |
| 2.ª pl. | λελύκατε | λέλυσθε |
| 3.ª pl. | λελύκασι(ν) | λέλυνται |
| infinitivo | λελυκέναι | λελύσθαι |
| participio | λελυκώς, -υῖα, -ός | λελυμένος, -η, -ον |

El activo añade κα al tema reduplicado; el medio-pasivo añade sus desinencias directamente, sin vocal temática. La reduplicación se mantiene en todos los modos: no es un aumento.

## La reduplicación

| El verbo empieza por | Reduplicación | Ejemplo |
|---|---|---|
| una consonante | esa consonante + ε | λύω → λέλυκα; παιδεύω → πεπαίδευκα |
| una aspirada θ φ χ | la consonante simple + ε | θύω → τέθυκα; φιλέω → πεφίληκα |
| una vocal | alargada, como un aumento | ἀγγέλλω → ἤγγελκα; ὁπλίζω → ὥπλικα |
| dos consonantes, ζ, ξ, ψ | solo ἐ- | στέλλω → ἔσταλκα; γιγνώσκω → ἔγνωκα |

Algunos perfectos no tienen κ (*perfecto segundo*): γράφω → γέγραφα; λείπω → λέλοιπα; y de φαίνω, πέφηνα «he aparecido». οἶδα «sé» es un perfecto sin reduplicación: «he visto», luego «sé».

## El pluscuamperfecto

Aumento + reduplicación + -η: ἐλελύκη «había desatado». Describe un estado en el pasado: ἐτεθνήκει «estaba muerto».

::: summary
- Perfecto: reduplicación + κα: λέλυκα, -κας, -κε(ν), -καμεν, -κατε, -κασι(ν); medio λέλυμαι, -σαι, -ται.
- λε-λυ, πε-παίδευκα; aspirada → simple: τέθυκα; vocal alargada; ἐ- ante dos consonantes: ἔγνωκα.
- Un estado presente fruto de un acto pasado: τέθνηκε está muerto; pluscuamperfecto ἐλελύκη; οἶδα sé.
:::
