# 11. L'aoriste second

Beaucoup des verbes les plus fréquents ne forment pas leur aoriste avec σα. Ils emploient un radical plus court et plus ancien, avec les terminaisons de l'imparfait : λαμβάνω « je prends », aoriste ἔλαβον « je pris ». Cet **aoriste second** a le même sens que le premier ; seule la forme diffère. Son radical s'apprend avec le verbe, comme on apprend *prendre, je pris*.

## Les formes

| Personne | Imparfait de λαμβάνω | Aoriste second |
|---|---|---|
| 1re sg. | ἐλάμβανον je prenais | ἔλαβον je pris |
| 2e sg. | ἐλάμβανες | ἔλαβες |
| 3e sg. | ἐλάμβανε(ν) | ἔλαβε(ν) |
| 1re pl. | ἐλαμβάνομεν | ἐλάβομεν |
| 2e pl. | ἐλαμβάνετε | ἐλάβετε |
| 3e pl. | ἐλάμβανον | ἔλαβον |

Les terminaisons sont identiques ; le radical les distingue : λαμβαν- pour le présent et l'imparfait, λαβ- pour l'aoriste. L'infinitif est accentué sur la terminaison, λαβεῖν « prendre », et l'impératif est λαβέ « prends ! ».

## Aoristes seconds courants

| Présent | Aoriste | Infinitif aoriste | Sens |
|---|---|---|---|
| λαμβάνω | ἔλαβον | λαβεῖν | prendre |
| βάλλω | ἔβαλον | βαλεῖν | jeter, lancer |
| μανθάνω | ἔμαθον | μαθεῖν | apprendre |
| φεύγω | ἔφυγον | φυγεῖν | fuir |
| πάσχω | ἔπαθον | παθεῖν | souffrir, éprouver |
| ἔχω | ἔσχον | σχεῖν | avoir, saisir |
| εὑρίσκω | ηὗρον | εὑρεῖν | trouver |
| ὁράω | εἶδον | ἰδεῖν | voir |
| λέγω | εἶπον | εἰπεῖν | dire |
| ἔρχομαι | ἦλθον | ἐλθεῖν | venir, aller |

Certains verbes tirent leur aoriste d'une tout autre racine : ὁράω, εἶδον ; ἔρχομαι, ἦλθον ; λέγω, εἶπον. Le grec a réuni d'anciens verbes en un seul paradigme, comme le français *aller* avec *je vais* et *j'irai*.

Un mot qu'Hérodote prête à Crésus joue sur παθεῖν et μαθεῖν : τὰ παθήματα μαθήματα, « les souffrances sont des leçons ».

::: summary
- Aoriste second : augment + radical court + terminaisons de l'imparfait : ἔλαβον ; infinitif λαβεῖν.
- Le radical le distingue de l'imparfait : ἐλάμβανον / ἔλαβον.
- ἔβαλον, ἔμαθον, ἔφυγον, ἔπαθον, ἔσχον, ηὗρον ; εἶδον, εἶπον, ἦλθον d'autres racines.
:::
