# 12. Le moyen et le passif

Le grec a une troisième voix entre l'actif et le passif, le **moyen** : le sujet agit pour lui-même ou sur lui-même. λύω τὸν ἵππον « je délie le cheval » ; λύομαι τὸν υἱόν « je délivre mon fils pour moi », c'est-à-dire « je le rachète ». Au présent et à l'imparfait, le passif a les mêmes formes que le moyen : λύεται, c'est « il rachète » ou « il est délié », et le contexte tranche.

## Présent et imparfait, moyen et passif

| Personne | Présent | Imparfait |
|---|---|---|
| 1re sg. | λύομαι | ἐλυόμην |
| 2e sg. | λύῃ, λύει | ἐλύου |
| 3e sg. | λύεται | ἐλύετο |
| 1re pl. | λυόμεθα | ἐλυόμεθα |
| 2e pl. | λύεσθε | ἐλύεσθε |
| 3e pl. | λύονται | ἐλύοντο |

Infinitif λύεσθαι. Le futur moyen ajoute σ : λύσομαι ; l'aoriste premier moyen est ἐλυσάμην, -σω, -σατο, -σάμεθα, -σασθε, -σαντο.

## Ce que signifie le moyen

| Actif | Moyen | La différence |
|---|---|---|
| λύω délier | λύομαι racheter | pour soi |
| λούω laver (quelqu'un) | λούομαι se laver | sur soi |
| παύω arrêter (quelqu'un) | παύομαι cesser | sur soi |
| πείθω persuader | πείθομαι obéir (+ dat.) | se laisser persuader |

## Les déponents

Certains verbes n'existent qu'au moyen, avec un sens actif : βούλομαι « je veux », γίγνομαι « je deviens », μάχομαι « je combats », ἔρχομαι « je viens ». On les appelle **déponents**.

## Le complément d'agent

Avec un passif, la personne par qui l'action se fait est ὑπό + génitif ; l'instrument est au datif seul : ἡ πόλις ὑπὸ τῶν πολεμίων λύεται « la cité est détruite par les ennemis » ; βάλλεται λίθῳ « il est frappé d'une pierre ».

::: summary
- Moyen-passif : -ομαι, -ῃ, -εται, -όμεθα, -εσθε, -ονται ; imparfait -όμην, -ου, -ετο, -όμεθα, -εσθε, -οντο.
- Moyen : pour soi ou sur soi (λύομαι racheter, παύομαι cesser) ; passif : mêmes formes au système du présent.
- Déponents βούλομαι, γίγνομαι, μάχομαι ; agent ὑπό + gén., instrument au datif.
:::
