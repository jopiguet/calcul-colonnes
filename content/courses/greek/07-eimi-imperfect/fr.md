# 7. « Être » et l'imparfait

Deux choses dans une leçon : le verbe εἰμί « je suis », irrégulier comme dans toutes les langues, et le premier temps du passé, l'**imparfait**, qui décrit une action en cours, répétée ou tentée dans le passé. L'imparfait introduit l'**augment**, le ε- qui marque le passé de l'indicatif et que vous verrez désormais devant chaque temps du passé.

## εἰμί, « je suis »

| Personne | Présent | Imparfait |
|---|---|---|
| 1re sg. | εἰμί je suis | ἦ, ἦν j'étais |
| 2e sg. | εἶ | ἦσθα |
| 3e sg. | ἐστί(ν) | ἦν |
| 1re pl. | ἐσμέν | ἦμεν |
| 2e pl. | ἐστέ | ἦτε |
| 3e pl. | εἰσί(ν) | ἦσαν |

L'infinitif est εἶναι « être ». En tête de phrase, ἔστι signifie « il y a » ou « il est possible » : ἔστι θεός « il existe un dieu ». L'attribut, nom ou adjectif, est au nominatif : Σωκράτης σοφός ἐστιν « Socrate est sage ».

## L'imparfait

| Personne | Terminaison | λύω |
|---|---|---|
| 1re sg. | -ον | ἔλυον je déliais |
| 2e sg. | -ες | ἔλυες |
| 3e sg. | -ε(ν) | ἔλυε(ν) |
| 1re pl. | -ομεν | ἐλύομεν |
| 2e pl. | -ετε | ἐλύετε |
| 3e pl. | -ον | ἔλυον |

L'imparfait se construit sur le radical du présent : augment + radical + voyelle thématique + terminaison.

## L'augment

| Le verbe commence par | Augment | Exemple |
|---|---|---|
| une consonne | ε- devant elle (*syllabique*) | γράφω → ἔγραφον |
| une voyelle | la voyelle allongée (*temporel*) : α, ε → η ; ο → ω | ἄγω → ἦγον ; ἐθέλω → ἤθελον |
| un préverbe | l'augment après le préverbe | ἀποπέμπω → ἀπέπεμπον |

L'imparfait est le temps de la description et du déroulement : ἔγραφεν « il écrivait », « il avait l'habitude d'écrire », « il essayait d'écrire ». Pour un acte unique et accompli, le grec emploie un autre passé, l'aoriste (leçon 10).

::: summary
- εἰμί, εἶ, ἐστί(ν), ἐσμέν, ἐστέ, εἰσί(ν) ; imparfait ἦ, ἦσθα, ἦν, ἦμεν, ἦτε, ἦσαν ; εἶναι.
- Imparfait : augment + radical du présent + -ον, -ες, -ε(ν), -ομεν, -ετε, -ον.
- Augment : ε- devant consonne, première voyelle allongée, après le préverbe ; l'imparfait dure ou se répète.
:::
