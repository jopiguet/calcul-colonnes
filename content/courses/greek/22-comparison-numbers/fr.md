# 22. La comparaison et les nombres

Le grec compare par des terminaisons : σοφός, σοφώτερος, σοφώτατος, « sage, plus sage, très sage ». Les adjectifs les plus courants sont irréguliers, comme en français (*bon, meilleur*), et plusieurs nous ont donné des mots : ἄριστος dans *aristocratie*, μέγιστος, πλεῖστος. Les nombres terminent la leçon ; les premiers se déclinent.

## La comparaison régulière

| Positif | Comparatif | Superlatif |
|---|---|---|
| σοφός sage | σοφώτερος | σοφώτατος |
| δίκαιος juste | δικαιότερος | δικαιότατος |
| ἀληθής vrai | ἀληθέστερος | ἀληθέστατος |

Après une syllabe longue, le ο reste (δικαιό-τερος) ; après une brève, il devient ω (σοφώ-τερος). « Que » se dit ἤ, ou par le seul génitif : σοφώτερος ἢ ἐγώ, σοφώτερος ἐμοῦ « plus sage que moi ». ὡς avec le superlatif signifie « le plus… possible » : ὡς τάχιστα « le plus vite possible ».

## La comparaison irrégulière

| Positif | Comparatif | Superlatif |
|---|---|---|
| ἀγαθός bon | ἀμείνων, βελτίων | ἄριστος, βέλτιστος |
| κακός mauvais | κακίων, χείρων | κάκιστος, χείριστος |
| καλός beau | καλλίων | κάλλιστος |
| μέγας grand | μείζων | μέγιστος |
| πολύς nombreux | πλείων | πλεῖστος |
| ταχύς rapide | θάττων | τάχιστος |

Les comparatifs en -ων se déclinent comme εὐδαίμων : μείζων, μείζονος.

## Les nombres

| Nombre | Cardinal | Ordinal |
|---|---|---|
| 1 | εἷς, μία, ἕν | πρῶτος |
| 2 | δύο | δεύτερος |
| 3 | τρεῖς, τρία | τρίτος |
| 4 | τέτταρες, τέτταρα | τέταρτος |
| 5 | πέντε | πέμπτος |
| 10 | δέκα | δέκατος |
| 100 | ἑκατόν | ἑκατοστός |
| 1000 | χίλιοι | χιλιοστός |

À partir de cinq, les cardinaux ne se déclinent pas. εἷς donne οὐδείς, οὐδεμία, οὐδέν « personne, rien » : οὐδεὶς ἦλθεν « personne n'est venu ».

::: exercise than
Comment s'exprime « que » ?

- σοφώτερος … τοῦ πατρός → ((rien de plus : le génitif dit « que »* / il manque ἤ))
- μείζων ἢ ἐκεῖνος → ((ἤ + le même cas* / le génitif))
- ὡς τάχιστα → ((très vite / le plus vite possible* / plus vite que))
- ἀμείνων → ((bon / meilleur* / le meilleur))
:::

::: exercise numbers
Quel nombre ?

- τρεῖς → ((2 / 3* / 4))
- πέντε → ((5* / 6 / 10))
- ἑκατόν → ((10 / 100* / 1000))
- τρίτος → ((trois / troisième* / trente))
:::

::: exercise translate
Traduisez.

- οὐδεὶς ἀνθρώπων σοφώτερος Σωκράτους. → {{Aucun homme n'est plus sage que Socrate. / Personne n'est plus sage que Socrate.}}
- ἄριστον μὲν ὕδωρ. → {{L'eau est ce qu'il y a de meilleur. / Le meilleur, c'est l'eau.}}
- τρεῖς ἡμέρας ἐμένομεν. → {{Nous restâmes trois jours. / Nous avons attendu trois jours.}}
- ἡ μεγίστη πόλις → {{la plus grande cité / la plus grande ville}}
:::

::: summary
- -τερος, -τατος : σοφώτερος, δικαιότερος ; « que » ἤ ou le génitif ; ὡς + superlatif.
- ἀγαθός ἀμείνων ἄριστος ; κακός κακίων κάκιστος ; μέγας μείζων μέγιστος ; πολύς πλείων πλεῖστος.
- εἷς μία ἕν, δύο, τρεῖς, τέτταρες, πέντε, δέκα, ἑκατόν, χίλιοι ; οὐδείς personne.
:::
