# 22. La comparación y los números

El griego compara con desinencias: σοφός, σοφώτερος, σοφώτατος, «sabio, más sabio, el más sabio». Los adjetivos más comunes son irregulares, como en español (*bueno, mejor, óptimo*), y varios nos han dado palabras: ἄριστος en *aristocracia*, μέγιστος, πλεῖστος. Los números cierran la lección; los primeros se declinan.

## La comparación regular

| Positivo | Comparativo | Superlativo |
|---|---|---|
| σοφός sabio | σοφώτερος | σοφώτατος |
| δίκαιος justo | δικαιότερος | δικαιότατος |
| ἀληθής verdadero | ἀληθέστερος | ἀληθέστατος |

Tras sílaba larga, la ο se mantiene (δικαιό-τερος); tras breve, pasa a ω (σοφώ-τερος). «Que» se dice ἤ, o con el genitivo solo: σοφώτερος ἢ ἐγώ, σοφώτερος ἐμοῦ «más sabio que yo». ὡς con superlativo significa «lo más… posible»: ὡς τάχιστα «lo más rápido posible».

## La comparación irregular

| Positivo | Comparativo | Superlativo |
|---|---|---|
| ἀγαθός bueno | ἀμείνων, βελτίων | ἄριστος, βέλτιστος |
| κακός malo | κακίων, χείρων | κάκιστος, χείριστος |
| καλός bello | καλλίων | κάλλιστος |
| μέγας grande | μείζων | μέγιστος |
| πολύς mucho | πλείων | πλεῖστος |
| ταχύς rápido | θάττων | τάχιστος |

Los comparativos en -ων se declinan como εὐδαίμων: μείζων, μείζονος.

## Los números

| Número | Cardinal | Ordinal |
|---|---|---|
| 1 | εἷς, μία, ἕν | πρῶτος |
| 2 | δύο | δεύτερος |
| 3 | τρεῖς, τρία | τρίτος |
| 4 | τέτταρες, τέτταρα | τέταρτος |
| 5 | πέντε | πέμπτος |
| 10 | δέκα | δέκατος |
| 100 | ἑκατόν | ἑκατοστός |
| 1000 | χίλιοι | χιλιοστός |

A partir de cinco, los cardinales no se declinan. εἷς da οὐδείς, οὐδεμία, οὐδέν «nadie, nada»: οὐδεὶς ἦλθεν «no vino nadie».

::: exercise than
¿Cómo se expresa «que»?

- σοφώτερος … τοῦ πατρός → ((nada más: el genitivo dice «que»* / falta ἤ))
- μείζων ἢ ἐκεῖνος → ((ἤ + el mismo caso* / el genitivo))
- ὡς τάχιστα → ((muy rápido / lo más rápido posible* / más rápido que))
- ἀμείνων → ((bueno / mejor* / el mejor))
:::

::: exercise numbers
¿Qué número?

- τρεῖς → ((2 / 3* / 4))
- πέντε → ((5* / 6 / 10))
- ἑκατόν → ((10 / 100* / 1000))
- τρίτος → ((tres / tercero* / treinta))
:::

::: exercise translate
Traduzca.

- οὐδεὶς ἀνθρώπων σοφώτερος Σωκράτους. → {{Ningún hombre es más sabio que Sócrates. / Nadie es más sabio que Sócrates.}}
- ἄριστον μὲν ὕδωρ. → {{Lo mejor es el agua. / El agua es lo mejor.}}
- τρεῖς ἡμέρας ἐμένομεν. → {{Nos quedamos tres días. / Esperamos tres días.}}
- ἡ μεγίστη πόλις → {{la ciudad más grande / la mayor ciudad}}
:::

::: summary
- -τερος, -τατος: σοφώτερος, δικαιότερος; «que» ἤ o el genitivo; ὡς + superlativo.
- ἀγαθός ἀμείνων ἄριστος; κακός κακίων κάκιστος; μέγας μείζων μέγιστος; πολύς πλείων πλεῖστος.
- εἷς μία ἕν, δύο, τρεῖς, τέτταρες, πέντε, δέκα, ἑκατόν, χίλιοι; οὐδείς nadie.
:::
