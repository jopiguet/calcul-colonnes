# 10. El futuro y el aoristo primero

Dos tiempos formados con σ. El **futuro** es el presente con una σ añadida al tema: λύ-σ-ω «desataré». El **aoristo** es el gran tiempo pasado de la narración: ἔ-λυ-σα «desaté». El aoristo introduce la idea que recorre todo el verbo griego, el **aspecto**: el aoristo presenta una acción como un todo, el presente y el imperfecto como algo en curso.

## El futuro

| Persona | λύω | γράφω (γραφ-σ → ψ) | ἄγω (ἀγ-σ → ξ) |
|---|---|---|---|
| 1.ª sg. | λύσω | γράψω | ἄξω |
| 2.ª sg. | λύσεις | γράψεις | ἄξεις |
| 3.ª sg. | λύσει | γράψει | ἄξει |
| 1.ª pl. | λύσομεν | γράψομεν | ἄξομεν |
| 2.ª pl. | λύσετε | γράψετε | ἄξετε |
| 3.ª pl. | λύσουσι(ν) | γράψουσι(ν) | ἄξουσι(ν) |

Las desinencias son las del presente. La σ se une al tema como en el dativo plural: las labiales dan ψ (πέμπω → πέμψω), las guturales ξ (ἄγω → ἄξω), las dentales caen (πείθω → πείσω). Infinitivo: λύσειν.

## El aoristo primero

| Persona | Desinencia | λύω |
|---|---|---|
| 1.ª sg. | -σα | ἔλυσα desaté |
| 2.ª sg. | -σας | ἔλυσας |
| 3.ª sg. | -σε(ν) | ἔλυσε(ν) |
| 1.ª pl. | -σαμεν | ἐλύσαμεν |
| 2.ª pl. | -σατε | ἐλύσατε |
| 3.ª pl. | -σαν | ἔλυσαν |

El aumento, como en el imperfecto: ἔγραψα, ἦξα, ἔπεμψα. Solo el indicativo lo lleva; el infinitivo λῦσαι y el imperativo λῦσον no.

## El aspecto

| Forma | Aspecto | Sentido |
|---|---|---|
| ἔγραφε | imperfecto: proceso | escribía, solía escribir |
| ἔγραψε | aoristo: acto global | escribió |
| γράφειν | infinitivo presente: proceso | escribir (habitualmente, en curso) |
| γράψαι | infinitivo aoristo: acto global | escribir (una vez) |

Fuera del indicativo, el aoristo no tiene sentido de pasado: solo marca el aspecto. Un diccionario da los **tiempos principales** de un verbo, presente, futuro, aoristo y otros, porque cada tiempo puede formarse de modo distinto: γράφω, γράψω, ἔγραψα.

::: summary
- Futuro: tema + σ + desinencias de presente: λύσω; γράψω, ἄξω, πείσω.
- Aoristo primero: aumento + tema + σα: ἔλυσα, -σας, -σε(ν), -σαμεν, -σατε, -σαν; λῦσαι.
- Aspecto: aoristo = el acto como un todo; presente/imperfecto = proceso; tiempos principales γράφω, γράψω, ἔγραψα.
:::
