# 21. Las condicionales y el estilo indirecto

Dos piezas de sintaxis que sostienen párrafos enteros. Las condicionales griegas son precisas: el modo y la partícula ἄν dicen si el hablante considera la condición real, probable, remota o contraria a los hechos. El estilo indirecto tiene tres construcciones, elegidas por el verbo que lo introduce.

## Las condicionales

| Tipo | Oración «si» | Principal | Ejemplo |
|---|---|---|---|
| simple, presente o pasado | εἰ + indicativo | indicativo | εἰ τοῦτο λέγει, ἁμαρτάνει si dice esto, se equivoca |
| futuro probable | ἐάν + subjuntivo | futuro | ἐὰν ἔλθῃ, ὄψεται si viene, verá |
| futuro remoto | εἰ + optativo | optativo + ἄν | εἰ ἔλθοι, ἴδοι ἄν si viniera, vería |
| irreal de presente | εἰ + imperfecto | imperfecto + ἄν | εἰ ἦν σοφός, οὐκ ἂν ἔλεγε ταῦτα si fuera sabio, no diría esto |
| irreal de pasado | εἰ + aoristo | aoristo + ἄν | εἰ ἦλθεν, εἶδεν ἄν si hubiera venido, habría visto |
| general | ἐάν + subjuntivo | presente | ἐάν τις ἔλθῃ, ὁρᾷ siempre que alguien viene, ve |

La negación de la oración «si» es μή: εἰ μὴ ἦλθεν «si no hubiera venido».

## El estilo indirecto

| Introducido por | Construcción | Ejemplo |
|---|---|---|
| λέγω, εἶπον (decir) | ὅτι o ὡς + el verbo original | λέγει ὅτι ὁ βασιλεὺς ἥκει dice que el rey ha llegado |
| φημί, νομίζω, οἴομαι (decir, pensar) | infinitivo, sujeto en acusativo | νομίζω τὸν βασιλέα ἥκειν creo que el rey ha llegado |
| οἶδα, ὁράω, ἀκούω, ἀγγέλλω (saber, ver, anunciar) | participio | οἶδα τὸν βασιλέα ἥκοντα sé que el rey ha llegado |

El tiempo del enunciado original se mantiene: ἔφη τὸν βασιλέα ἥκειν «dijo que el rey *había* llegado» (había dicho «el rey ha llegado»). Cuando el sujeto es el del verbo principal, queda en nominativo y a menudo se omite: ἔφη σοφὸς εἶναι «dijo que era sabio». Tras un verbo principal pasado, el verbo tras ὅτι puede pasar a optativo: εἶπεν ὅτι ὁ βασιλεὺς ἥκοι.

::: exercise kind
¿Qué tipo de condicional?

- εἰ ἔλθοι, ἴδοι ἄν. → ((futuro probable / futuro remoto* / irreal))
- ἐὰν ἔλθῃ, ὄψεται. → ((futuro probable* / futuro remoto / irreal))
- εἰ ἦλθεν, εἶδεν ἄν. → ((pasado simple / irreal de pasado* / futuro remoto))
- εἰ τοῦτο λέγει, ἁμαρτάνει. → ((simple* / futuro probable / irreal))
:::

::: exercise particle
¿Qué palabra falta?

- si fuera sabio, no diría esto: εἰ ἦν σοφός, οὐκ … ἔλεγε ταῦτα → [[ἄν]]
- si viene (probable): … ἔλθῃ → [[ἐάν]]
- dice que el rey ha llegado: λέγει … ὁ βασιλεὺς ἥκει → [[ὅτι / ὡς]]
:::

::: exercise construction
¿Qué construcción sigue?

- νομίζω … → ((ὅτι + indicativo / infinitivo* / participio))
- οἶδα … → ((ὅτι + indicativo / infinitivo / participio*))
- λέγω … → ((ὅτι + indicativo* / solo participio))
- ἔφη … «dijo que era sabio» → ((σοφὸς εἶναι* / σοφὸν εἶναι / σοφὸς ὤν))
:::

::: exercise translate
Traduzca.

- εἰ ἦν σοφός, οὐκ ἂν ἔλεγε ταῦτα. → {{Si fuera sabio, no diría esto. / Si fuera sabio, no diría estas cosas.}}
- ἔφη τοὺς πολεμίους φεύγειν. → {{Dijo que los enemigos huían.}}
- οἶδα θνητὸς ὤν. → {{Sé que soy mortal.}}
- ἐὰν μάθῃς, σοφὸς ἔσῃ. → {{Si aprendes, serás sabio.}}
:::

::: summary
- εἰ + indicativo (simple); ἐάν + subjuntivo / futuro (probable); εἰ + optativo / optativo + ἄν (remoto).
- Irreal: εἰ + imperfecto o aoristo, el mismo tiempo + ἄν; negación μή en la oración «si».
- Estilo indirecto: ὅτι tras «decir», infinitivo tras φημί, νομίζω, participio tras «saber, ver»; el tiempo se mantiene.
:::
