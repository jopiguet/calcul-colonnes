# 21. Les conditions et le discours indirect

Deux pièces de syntaxe qui tiennent ensemble des paragraphes entiers. Les conditions grecques sont précises : le mode et la particule ἄν disent si le locuteur tient la condition pour réelle, probable, éloignée ou contraire aux faits. Le discours indirect a trois constructions, choisies par le verbe qui l'introduit.

## Les conditions

| Type | Proposition « si » | Principale | Exemple |
|---|---|---|---|
| simple, présent ou passé | εἰ + indicatif | indicatif | εἰ τοῦτο λέγει, ἁμαρτάνει s'il dit cela, il se trompe |
| futur probable | ἐάν + subjonctif | futur | ἐὰν ἔλθῃ, ὄψεται s'il vient, il verra |
| futur éloigné | εἰ + optatif | optatif + ἄν | εἰ ἔλθοι, ἴδοι ἄν s'il venait, il verrait |
| irréel du présent | εἰ + imparfait | imparfait + ἄν | εἰ ἦν σοφός, οὐκ ἂν ἔλεγε ταῦτα s'il était sage, il ne dirait pas cela |
| irréel du passé | εἰ + aoriste | aoriste + ἄν | εἰ ἦλθεν, εἶδεν ἄν s'il était venu, il aurait vu |
| général | ἐάν + subjonctif | présent | ἐάν τις ἔλθῃ, ὁρᾷ chaque fois que quelqu'un vient, il voit |

La négation de la proposition « si » est μή : εἰ μὴ ἦλθεν « s'il n'était pas venu ».

## Le discours indirect

| Introduit par | Construction | Exemple |
|---|---|---|
| λέγω, εἶπον (dire) | ὅτι ou ὡς + le verbe d'origine | λέγει ὅτι ὁ βασιλεὺς ἥκει il dit que le roi est arrivé |
| φημί, νομίζω, οἴομαι (dire, penser) | infinitif, sujet à l'accusatif | νομίζω τὸν βασιλέα ἥκειν je pense que le roi est arrivé |
| οἶδα, ὁράω, ἀκούω, ἀγγέλλω (savoir, voir, annoncer) | participe | οἶδα τὸν βασιλέα ἥκοντα je sais que le roi est arrivé |

Le temps de l'énoncé d'origine est conservé : ἔφη τὸν βασιλέα ἥκειν « il dit que le roi *était* arrivé » (il avait dit « le roi est arrivé »). Quand le sujet est celui du verbe principal, il reste au nominatif et souvent ne s'exprime pas : ἔφη σοφὸς εἶναι « il dit qu'il était sage ». Après un verbe principal passé, le verbe après ὅτι peut passer à l'optatif : εἶπεν ὅτι ὁ βασιλεὺς ἥκοι.

::: exercise kind
Quel type de condition ?

- εἰ ἔλθοι, ἴδοι ἄν. → ((futur probable / futur éloigné* / irréel))
- ἐὰν ἔλθῃ, ὄψεται. → ((futur probable* / futur éloigné / irréel))
- εἰ ἦλθεν, εἶδεν ἄν. → ((passé simple / irréel du passé* / futur éloigné))
- εἰ τοῦτο λέγει, ἁμαρτάνει. → ((simple* / futur probable / irréel))
:::

::: exercise particle
Quel mot manque ?

- s'il était sage, il ne dirait pas cela : εἰ ἦν σοφός, οὐκ … ἔλεγε ταῦτα → [[ἄν]]
- s'il vient (probable) : … ἔλθῃ → [[ἐάν]]
- il dit que le roi est arrivé : λέγει … ὁ βασιλεὺς ἥκει → [[ὅτι / ὡς]]
:::

::: exercise construction
Quelle construction suit ?

- νομίζω … → ((ὅτι + indicatif / infinitif* / participe))
- οἶδα … → ((ὅτι + indicatif / infinitif / participe*))
- λέγω … → ((ὅτι + indicatif* / participe seulement))
- ἔφη … « il dit qu'il était sage » → ((σοφὸς εἶναι* / σοφὸν εἶναι / σοφὸς ὤν))
:::

::: exercise translate
Traduisez.

- εἰ ἦν σοφός, οὐκ ἂν ἔλεγε ταῦτα. → {{S'il était sage, il ne dirait pas cela. / S'il était sage, il ne dirait pas ces choses.}}
- ἔφη τοὺς πολεμίους φεύγειν. → {{Il dit que les ennemis fuyaient. / Il dit que l'ennemi s'enfuyait.}}
- οἶδα θνητὸς ὤν. → {{Je sais que je suis mortel.}}
- ἐὰν μάθῃς, σοφὸς ἔσῃ. → {{Si tu apprends, tu seras sage.}}
:::

::: summary
- εἰ + indicatif (simple) ; ἐάν + subjonctif / futur (probable) ; εἰ + optatif / optatif + ἄν (éloigné).
- Irréel : εἰ + imparfait ou aoriste, le même temps + ἄν ; négation μή dans la proposition « si ».
- Discours indirect : ὅτι après « dire », infinitif après φημί, νομίζω, participe après « savoir, voir » ; le temps est conservé.
:::
