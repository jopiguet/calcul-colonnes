# 24. Lecture : Platon, Héraclite et Jean

Quatre textes courts pour finir, sur quatre siècles de grec : le dieu de Delphes, un philosophe d'Éphèse, le Socrate de Platon, et le début d'un évangile écrit dans le grec commun, la *koinè*, de l'Orient romain. Chacun emploie la grammaire de ce cours ; chacun a façonné la pensée européenne.

## Les textes

| Source | Grec | Traduction |
|---|---|---|
| Delphes | γνῶθι σεαυτόν. | Connais-toi toi-même. |
| Héraclite | ποταμῷ γὰρ οὐκ ἔστιν ἐμβῆναι δὶς τῷ αὐτῷ. | On ne peut entrer deux fois dans le même fleuve. |
| Platon, *Apologie* 38a | ὁ δὲ ἀνεξέταστος βίος οὐ βιωτὸς ἀνθρώπῳ. | Une vie sans examen ne vaut pas d'être vécue pour un homme. |
| Jean 1,1 | Ἐν ἀρχῇ ἦν ὁ λόγος, καὶ ὁ λόγος ἦν πρὸς τὸν θεόν, καὶ θεὸς ἦν ὁ λόγος. | Au commencement était le Verbe, et le Verbe était auprès de Dieu, et le Verbe était Dieu. |

## Notes

**γνῶθι** est l'impératif aoriste de γιγνώσκω (aoriste ἔγνων, un aoriste radical comme ἔστην). σεαυτόν « toi-même » est σε + αὐτόν.

**ἔστιν** en tête de proposition signifie « il est possible » (leçon 7) ; ἐμβῆναι est l'infinitif aoriste de ἐμβαίνω « entrer dans » ; τῷ αὐτῷ, dans l'article, est « le même » (leçon 13). La sentence nous vient par Plutarque ; Platon en résume l'idée par πάντα ῥεῖ, « tout s'écoule ».

**ἀνεξέταστος** : ἀν- « non » + ἐξεταστός « examiné », un adjectif verbal en -τος, comme βιωτός « vivable », de βιόω « vivre ». Le datif ἀνθρώπῳ signifie « pour un homme ». Socrate le dit à son procès, après le verdict, en refusant de cesser de questionner.

**Ἐν ἀρχῇ ἦν ὁ λόγος** : ἦν est l'imparfait de εἰμί. Dans θεὸς ἦν ὁ λόγος, l'article marque le sujet : ὁ λόγος est le sujet, θεός l'attribut, placé en tête pour insister.

::: summary
- γνῶθι σεαυτόν : impératif aoriste radical de γιγνώσκω.
- ὁ ἀνεξέταστος βίος οὐ βιωτὸς ἀνθρώπῳ : adjectifs verbaux en -τος, datif « pour ».
- Ἐν ἀρχῇ ἦν ὁ λόγος : l'article marque le sujet ; ἔστι + infinitif « il est possible ».
:::
