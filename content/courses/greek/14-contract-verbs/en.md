# 14. Contract verbs

Verbs whose stem ends in α, ε or ο merge that vowel with the vowel of the ending: τιμά-ω becomes τιμῶ "I honour", ποιέ-ει becomes ποιεῖ "he makes". The dictionary lists them uncontracted (τιμάω, ποιέω, δηλόω) so that you can see the stem vowel; texts print the contracted forms. A few rules give every form.

## The contractions

| Meeting | Result | Example |
|---|---|---|
| α + ε, η | α | τιμά-ετε → τιμᾶτε |
| α + ο, ω, ου | ω | τιμά-ομεν → τιμῶμεν |
| ε + ε | ει | ποιέ-ετε → ποιεῖτε |
| ε + ο | ου | ποιέ-ομεν → ποιοῦμεν |
| ο + ε, ο, ου | ου | δηλό-ομεν → δηλοῦμεν |
| any + ει | the ι survives: ᾳ, ει, οι | τιμά-ει → τιμᾷ; δηλό-ει → δηλοῖ |

## The present

| Person | τιμάω honour | ποιέω make, do | δηλόω show |
|---|---|---|---|
| 1st sg. | τιμῶ | ποιῶ | δηλῶ |
| 2nd sg. | τιμᾷς | ποιεῖς | δηλοῖς |
| 3rd sg. | τιμᾷ | ποιεῖ | δηλοῖ |
| 1st pl. | τιμῶμεν | ποιοῦμεν | δηλοῦμεν |
| 2nd pl. | τιμᾶτε | ποιεῖτε | δηλοῦτε |
| 3rd pl. | τιμῶσι(ν) | ποιοῦσι(ν) | δηλοῦσι(ν) |
| infinitive | τιμᾶν | ποιεῖν | δηλοῦν |

The imperfect contracts the same way: ἐτίμων, ἐποίουν, ἐδήλουν "I was honouring, making, showing".

## Other tenses

Outside the present system there is nothing to contract: the stem vowel lengthens before σ, α and ε to η, ο to ω. τιμάω, τιμήσω, ἐτίμησα; ποιέω, ποιήσω, ἐποίησα; δηλόω, δηλώσω, ἐδήλωσα.

Many common verbs belong here: ὁράω "see", νικάω "win", ζητέω "seek", φιλέω "love", καλέω "call", οἰκέω "live", ἀξιόω "think worthy".

::: summary
- α + ε → α, α + ο → ω; ε + ε → ει, ε + ο → ου; ο + any → ου, with ει → οι.
- τιμῶ, τιμᾷς, τιμᾷ; ποιῶ, ποιεῖς, ποιεῖ; δηλῶ, δηλοῖς, δηλοῖ; τιμᾶν, ποιεῖν, δηλοῦν.
- Other tenses lengthen the vowel: τιμήσω, ποιήσω, δηλώσω.
:::
