# 14. Les verbes contractes

Les verbes dont le radical se termine par α, ε ou ο fondent cette voyelle avec celle de la terminaison : τιμά-ω devient τιμῶ « j'honore », ποιέ-ει devient ποιεῖ « il fait ». Le dictionnaire les donne non contractés (τιμάω, ποιέω, δηλόω) pour qu'on voie la voyelle du radical ; les textes impriment les formes contractes. Quelques règles donnent toutes les formes.

## Les contractions

| Rencontre | Résultat | Exemple |
|---|---|---|
| α + ε, η | α | τιμά-ετε → τιμᾶτε |
| α + ο, ω, ου | ω | τιμά-ομεν → τιμῶμεν |
| ε + ε | ει | ποιέ-ετε → ποιεῖτε |
| ε + ο | ου | ποιέ-ομεν → ποιοῦμεν |
| ο + ε, ο, ου | ου | δηλό-ομεν → δηλοῦμεν |
| toute voyelle + ει | le ι subsiste : ᾳ, ει, οι | τιμά-ει → τιμᾷ ; δηλό-ει → δηλοῖ |

## Le présent

| Personne | τιμάω honorer | ποιέω faire | δηλόω montrer |
|---|---|---|---|
| 1re sg. | τιμῶ | ποιῶ | δηλῶ |
| 2e sg. | τιμᾷς | ποιεῖς | δηλοῖς |
| 3e sg. | τιμᾷ | ποιεῖ | δηλοῖ |
| 1re pl. | τιμῶμεν | ποιοῦμεν | δηλοῦμεν |
| 2e pl. | τιμᾶτε | ποιεῖτε | δηλοῦτε |
| 3e pl. | τιμῶσι(ν) | ποιοῦσι(ν) | δηλοῦσι(ν) |
| infinitif | τιμᾶν | ποιεῖν | δηλοῦν |

L'imparfait se contracte de la même façon : ἐτίμων, ἐποίουν, ἐδήλουν « j'honorais, je faisais, je montrais ».

## Les autres temps

Hors du système du présent, il n'y a rien à contracter : la voyelle du radical s'allonge devant σ, α et ε en η, ο en ω. τιμάω, τιμήσω, ἐτίμησα ; ποιέω, ποιήσω, ἐποίησα ; δηλόω, δηλώσω, ἐδήλωσα.

Beaucoup de verbes courants appartiennent à ce groupe : ὁράω « voir », νικάω « vaincre », ζητέω « chercher », φιλέω « aimer », καλέω « appeler », οἰκέω « habiter », ἀξιόω « juger digne ».

::: summary
- α + ε → α, α + ο → ω ; ε + ε → ει, ε + ο → ου ; ο + toute voyelle → ου, avec ει → οι.
- τιμῶ, τιμᾷς, τιμᾷ ; ποιῶ, ποιεῖς, ποιεῖ ; δηλῶ, δηλοῖς, δηλοῖ ; τιμᾶν, ποιεῖν, δηλοῦν.
- Les autres temps allongent la voyelle : τιμήσω, ποιήσω, δηλώσω.
:::
