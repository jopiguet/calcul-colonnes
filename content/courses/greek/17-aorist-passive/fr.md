# 17. L'aoriste et le futur passifs

Au présent, à l'imparfait et au parfait, le passif emprunte les formes du moyen. L'aoriste et le futur ont des formes passives à eux, marquées par **θη** : ἐλύθην « je fus délié », λυθήσομαι « je serai délié ». Ces formes sont fréquentes, et elles servent aussi à beaucoup de déponents : ἐβουλήθην « je voulus », ἐπορεύθην « je fis route ».

## L'aoriste passif

| Personne | Terminaison | λύω |
|---|---|---|
| 1re sg. | -θην | ἐλύθην je fus délié |
| 2e sg. | -θης | ἐλύθης |
| 3e sg. | -θη | ἐλύθη |
| 1re pl. | -θημεν | ἐλύθημεν |
| 2e pl. | -θητε | ἐλύθητε |
| 3e pl. | -θησαν | ἐλύθησαν |
| infinitif | -θῆναι | λυθῆναι |
| participe | -θείς, -θεῖσα, -θέν | λυθείς (gén. λυθέντος) |

Les terminaisons ont l'aspect de terminaisons actives, sans voyelle thématique. Le futur passif ajoute au même radical les terminaisons du futur moyen : λυθήσομαι, λυθήσῃ, λυθήσεται.

## Le radical rencontre θ

| Le radical finit par | Devant θ | Exemple |
|---|---|---|
| π, β, φ | φ | πέμπω → ἐπέμφθην |
| κ, γ, χ | χ | ἄγω → ἤχθην ; διώκω → ἐδιώχθην |
| τ, δ, θ | σ | πείθω → ἐπείσθην |
| une voyelle de contracte | allongée | τιμάω → ἐτιμήθην ; ποιέω → ἐποιήθην |

## L'aoriste passif second

Quelques verbes ont les mêmes terminaisons sans θ : γράφω → ἐγράφην « ce fut écrit » ; φαίνω → ἐφάνην « j'apparus » ; βλάπτω → ἐβλάβην « je fus lésé ».

- ἡ πόλις ὑπὸ τῶν πολεμίων ἐλήφθη. → {{La cité fut prise par les ennemis. / La ville a été prise par l'ennemi.}}

- ἐπείσθημεν. → {{Nous fûmes persuadés. / Nous avons obéi.}}
- ὁ νόμος ἐγράφη. → {{La loi fut écrite. / La loi a été écrite.}}
:::

::: summary
- Aoriste passif : augment + radical + θην, θης, θη, θημεν, θητε, θησαν ; λυθῆναι ; λυθείς.
- Futur passif : λυθήσομαι, -ῃ, -εται.
- Devant θ : labiales → φ, gutturales → χ, dentales → σ ; aoriste second ἐγράφην, ἐφάνην.
:::
