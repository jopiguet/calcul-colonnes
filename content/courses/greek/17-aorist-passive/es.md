# 17. El aoristo y el futuro pasivos

En presente, imperfecto y perfecto, la pasiva toma prestadas las formas de la media. El aoristo y el futuro tienen formas pasivas propias, marcadas por **θη**: ἐλύθην «fui liberado», λυθήσομαι «seré liberado». Estas formas son frecuentes, y sirven también a muchos deponentes: ἐβουλήθην «quise», ἐπορεύθην «viajé».

## El aoristo pasivo

| Persona | Desinencia | λύω |
|---|---|---|
| 1.ª sg. | -θην | ἐλύθην fui liberado |
| 2.ª sg. | -θης | ἐλύθης |
| 3.ª sg. | -θη | ἐλύθη |
| 1.ª pl. | -θημεν | ἐλύθημεν |
| 2.ª pl. | -θητε | ἐλύθητε |
| 3.ª pl. | -θησαν | ἐλύθησαν |
| infinitivo | -θῆναι | λυθῆναι |
| participio | -θείς, -θεῖσα, -θέν | λυθείς (gen. λυθέντος) |

Las desinencias parecen activas, sin vocal temática. El futuro pasivo añade al mismo tema las desinencias del futuro medio: λυθήσομαι, λυθήσῃ, λυθήσεται.

## El tema se encuentra con θ

| El tema termina en | Ante θ | Ejemplo |
|---|---|---|
| π, β, φ | φ | πέμπω → ἐπέμφθην |
| κ, γ, χ | χ | ἄγω → ἤχθην; διώκω → ἐδιώχθην |
| τ, δ, θ | σ | πείθω → ἐπείσθην |
| una vocal de contracto | alargada | τιμάω → ἐτιμήθην; ποιέω → ἐποιήθην |

## El aoristo pasivo segundo

Algunos verbos tienen las mismas desinencias sin θ: γράφω → ἐγράφην «fue escrito»; φαίνω → ἐφάνην «aparecí»; βλάπτω → ἐβλάβην «fui dañado».

::: summary
- Aoristo pasivo: aumento + tema + θην, θης, θη, θημεν, θητε, θησαν; λυθῆναι; λυθείς.
- Futuro pasivo: λυθήσομαι, -ῃ, -εται.
- Ante θ: labiales → φ, guturales → χ, dentales → σ; aoristo segundo ἐγράφην, ἐφάνην.
:::
