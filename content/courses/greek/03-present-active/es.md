# 3. El verbo: el presente activo

Un verbo griego lleva su sujeto en la desinencia: λέγω es «digo», λέγομεν «decimos». El pronombre solo se usa para insistir. Esta lección da el presente activo de los verbos en -ω, la clase más grande, con el modelo λύω «desato, libero», y luego el infinitivo, el imperativo y la negación.

## El presente de indicativo

| Persona | Desinencia | λύω desatar | γράφω escribir |
|---|---|---|---|
| 1.ª sg. | -ω | λύω desato | γράφω |
| 2.ª sg. | -εις | λύεις desatas | γράφεις |
| 3.ª sg. | -ει | λύει desata | γράφει |
| 1.ª pl. | -ομεν | λύομεν desatamos | γράφομεν |
| 2.ª pl. | -ετε | λύετε desatáis | γράφετε |
| 3.ª pl. | -ουσι(ν) | λύουσι(ν) desatan | γράφουσι(ν) |

El tema (λυ-, γραφ-) toma una vocal temática, ο ante μ y ν, ε en los demás casos, y luego la desinencia. La ν entre paréntesis, *ny efelcística*, se añade ante vocal o al final de la frase: λύουσιν ἀνθρώπους.

El presente tiene los dos sentidos: λύω es «desato» y «estoy desatando».

## Infinitivo e imperativo

| Forma | λύω | Sentido |
|---|---|---|
| infinitivo | λύειν | desatar |
| imperativo, sg. | λῦε | ¡desata! |
| imperativo, pl. | λύετε | ¡desatad! |

## La negación

El verbo se niega con **οὐ**, que pasa a **οὐκ** ante espíritu suave y a **οὐχ** ante espíritu áspero: οὐ λέγει, οὐκ ἔχει, οὐχ ἕπεται. Las órdenes y los infinitivos llevan **μή**: μὴ λέγε «no hables».

Una pregunta se marca con el signo ; y a menudo con ἆρα, que no se traduce: ἆρα γράφεις; «¿escribes?».

::: exercise person
¿Quién lo hace?

- λέγομεν → ((yo / nosotros* / ellos))
- ἔχεις → ((tú* / él / vosotros))
- πέμπουσι → ((nosotros / vosotros / ellos*))
- παιδεύει → ((yo / él o ella* / tú))
:::

::: exercise negation
¿Qué forma de la negación?

- … λέγει → ((οὐ* / οὐκ / οὐχ))
- … ἔχει → ((οὐ / οὐκ* / οὐχ))
- … ἕπεται → ((οὐ / οὐκ / οὐχ*))
- … γράφε! → ((οὐ / μή*))
:::

::: exercise translate
Traduzca.

- λέγομεν. → {{Decimos. / Hablamos.}}
- οὐκ ἔχεις. → {{No tienes.}}
- ἆρα γράφει; → {{¿Escribe? / ¿Está escribiendo?}}
- μὴ λῦε. → {{¡No desates! / ¡No liberes!}}
:::

::: summary
- Presente: -ω, -εις, -ει, -ομεν, -ετε, -ουσι(ν); infinitivo -ειν; imperativo -ε, -ετε.
- La desinencia da el sujeto; el pronombre sirve para insistir.
- οὐ / οὐκ / οὐχ para enunciados, μή para órdenes e infinitivos; ἆρα pregunta.
:::
