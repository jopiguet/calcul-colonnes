# 18. Le subjonctif

Jusqu'ici, chaque verbe énonçait un fait. Le **subjonctif** présente une action comme voulue, attendue ou possible : « allons », « afin qu'il apprenne », « si jamais il vient ». Ses formes sont faciles : la voyelle thématique s'allonge, ο en ω et ε en η. Il n'a pas d'augment, et ses temps ne diffèrent que par l'aspect.

## Les formes

| Personne | Présent actif | Aoriste actif | Présent moyen | εἰμί |
|---|---|---|---|---|
| 1re sg. | λύω | λύσω | λύωμαι | ὦ |
| 2e sg. | λύῃς | λύσῃς | λύῃ | ᾖς |
| 3e sg. | λύῃ | λύσῃ | λύηται | ᾖ |
| 1re pl. | λύωμεν | λύσωμεν | λυώμεθα | ὦμεν |
| 2e pl. | λύητε | λύσητε | λύησθε | ἦτε |
| 3e pl. | λύωσι(ν) | λύσωσι(ν) | λύωνται | ὦσι(ν) |

Comparez l'indicatif λύομεν et le subjonctif λύωμεν, λύει et λύῃ. Le subjonctif aoriste passif est λυθῶ, λυθῇς, λυθῇ.

## Les emplois

| Emploi | Construction | Exemple |
|---|---|---|
| exhortation | 1re personne du pluriel | ἴωμεν « allons » |
| délibération | dans une question | τί ποιῶμεν; « que devons-nous faire ? » |
| défense | μή + subjonctif aoriste | μὴ ποιήσῃς τοῦτο « ne fais pas cela » |
| but | ἵνα, ὅπως + subjonctif | ἔρχεται ἵνα μάθῃ « il vient pour apprendre » |
| crainte | φοβοῦμαι μή + subjonctif | φοβοῦμαι μὴ ἔλθῃ « je crains qu'il ne vienne » |
| condition future ou générale | ἐάν + subjonctif | ἐὰν ἔλθῃ, ὄψεται « s'il vient, il verra » |

ἐάν, c'est εἰ + ἄν. La particule ἄν, qui ne se traduit pas, marque une possibilité ou une généralité ; elle reviendra avec l'optatif.

::: exercise mood
Indicatif ou subjonctif ?

- λύωμεν → ((indicatif / subjonctif*))
- λύομεν → ((indicatif* / subjonctif))
- λύῃ (actif) → ((indicatif / subjonctif*))
- ᾖ → ((indicatif / subjonctif*))
- ἐστί → ((indicatif* / subjonctif))
:::

::: exercise word
Quel mot faut-il ?

- … afin de : ἔρχεται … μάθῃ → [[ἵνα / ὅπως]]
- si jamais : … ἔλθῃ, ὄψεται → [[ἐάν]]
- ne… pas : … ποιήσῃς τοῦτο → [[μή]]
:::

::: exercise use
Qu'exprime le subjonctif ?

- ἴωμεν. → ((allons !* / nous allâmes / nous allons))
- τί λέγω; (subjonctif) → ((que dis-je ? / que dois-je dire ?*))
- μὴ κλέψῃς. → ((tu n'as pas volé / ne vole pas*))
- ἐὰν ἔλθῃ → ((s'il venait / s'il vient*))
:::

::: exercise translate
Traduisez.

- μανθάνομεν ἵνα σοφοὶ γιγνώμεθα. → {{Nous apprenons afin de devenir sages. / Nous apprenons pour devenir sages.}}
- μὴ φύγητε. → {{Ne fuyez pas !}}
- τί ποιῶμεν; → {{Que devons-nous faire ? / Que faire ?}}
- φοβοῦμαι μὴ ὁ πόλεμος ἔλθῃ. → {{Je crains que la guerre ne vienne. / J'ai peur que la guerre arrive.}}
:::

::: summary
- Subjonctif : voyelle thématique allongée : λύω, λύῃς, λύῃ, λύωμεν, λύητε, λύωσι ; aoriste λύσω ; ὦ, ᾖς, ᾖ.
- Pas d'augment ; les temps diffèrent par l'aspect.
- Exhortation, délibération, μή + aoriste (défense), ἵνα (but), φοβοῦμαι μή (crainte), ἐάν (condition).
:::
