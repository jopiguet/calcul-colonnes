# 3. Les noms : genre, cas et nombre

Les noms akkadiens fonctionnent comme ceux du latin, mais avec moins de formes. Il y a deux genres, trois cas et trois nombres, et les terminaisons sont presque les mêmes pour tous les noms. Les cas sont les vieux cas sémitiques que l'arabe classique a encore : nominatif en *-u*, génitif en *-i*, accusatif en *-a*, chacun suivi en paléo-babylonien de la mimation *-m*.

## Le singulier

| Cas | Emploi | Masculin *šarrum* roi | Féminin *šarratum* reine |
|---|---|---|---|
| Nominatif | sujet | *šarr-um* | *šarrat-um* |
| Génitif | après un nom ou une préposition | *šarr-im* | *šarrat-im* |
| Accusatif | objet, et certains adverbes | *šarr-am* | *šarrat-am* |

Le féminin est marqué par *-t-* ou *-at-* avant la terminaison : *bēlum* seigneur, *bēltum* dame ; *šarrum* roi, *šarratum* reine ; *ilum* dieu, *iltum* déesse. Certains noms sont féminins sans lui : *ummum* mère, *qātum* main.

## Le pluriel et le duel

| Cas | Pluriel masculin | Pluriel féminin | Duel |
|---|---|---|---|
| Nominatif | *šarr-ū* | *šarr-ātum* | *šēp-ān* les deux pieds |
| Génitif / accusatif | *šarr-ī* | *šarr-ātim* | *šēp-īn* |

Le pluriel masculin n'a pas de mimation et n'a que deux formes : *-ū* pour le sujet, *-ī* pour tout le reste. Le duel s'emploie pour les paires du corps : *īnān* « les deux yeux », *uznān* « les deux oreilles », *šēpān* « les deux pieds ».

## Les prépositions

Les prépositions se construisent avec le génitif :

| Préposition | Sens | Exemple |
|---|---|---|
| *ina* | dans, à, hors de, avec | *ina bītim* dans la maison |
| *ana* | à, vers, pour | *ana šarrim* au roi |
| *itti* | avec (une personne) | *itti aḫim* avec le frère |
| *ištu* | depuis, de | *ištu ālim* depuis la ville |
| *eli* | sur, au-dessus de, plus que | *eli šarrim* au-dessus du roi |
| *ša* | de, celui de | *bītum ša šarrim* la maison du roi |

::: summary
- Singulier : nominatif *-um*, génitif *-im*, accusatif *-am* ; féminin en *-t-* / *-at-* (*šarratum*).
- Pluriel : masculin *-ū* / *-ī* ; féminin *-ātum* / *-ātim*. Duel *-ān* / *-īn* pour les paires du corps.
- Les prépositions prennent le génitif : *ina*, *ana*, *itti*, *ištu*, *eli*, *ša*.
:::
