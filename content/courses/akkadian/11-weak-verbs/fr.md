# 11. Les verbes faibles

*Parāsum* a trois radicales solides. Beaucoup de verbes courants non : une radicale est *n*, une voyelle, *w* ou une gutturale perdue (*ʾ*), et elle s'assimile, allonge une voyelle ou disparaît. Les formes paraissent irrégulières, mais chaque classe suit une règle. Les connaître permet de lire un vrai texte : *iddin* « il donna », *īmur* « il vit », *ibni* « il bâtit », *illik* « il alla ».

## Les classes

| Classe | Exemple | Prétérit | Duratif | Ce qui se passe |
|---|---|---|---|---|
| I-n | *nadānum* donner | *iddin* | *inaddin* | le *n* s'assimile à la consonne suivante : *indin* → *iddin* |
| I-ʾ (*a*) | *amārum* voir | *īmur* | *immar* | la première radicale perdue allonge la voyelle |
| I-ʾ (*e*) | *epēšum* faire | *īpuš* | *ippeš* | de même, avec coloration en *e* |
| I-w | *wašābum* s'asseoir | *ūšib* | *uššab* | le *w* disparaît, le préfixe devient *ū-*, *u-* |
| II-faible | *târum* revenir | *itūr* | *itâr* | une voyelle longue occupe le milieu |
| III-faible | *banûm* bâtir | *ibni* | *ibanni* | la dernière radicale est une voyelle |

*Alākum* « aller » forme une classe à lui seul : prétérit *illik*, duratif *illak*, parfait *ittalak*, impératif *alik*. *Leqûm* « prendre » est III-faible en *e* : *ilqe*, *ileqqe*.

## Retrouver la racine

Une forme courte cache souvent sa racine. Remontez depuis la voyelle et le redoublement :

| Forme | Racine | Verbe |
|---|---|---|
| *iddin* | n-d-n | *nadānum* |
| *ikkal* | ʾ-k-l | *akālum* manger (duratif) |
| *imūt* | m-w-t | *mâtum* mourir |
| *ilqe* | l-q-ʾ | *leqûm* prendre |

::: exercise translate

::: summary
- I-n : *iddin* (n assimilé) ; I-ʾ : *īmur*, *īpuš* (voyelle longue) ; I-w : *ūšib*.
- II-faible : *itūr*, *imūt* ; III-faible : *ibni*, *ilqe*.
- *alākum* : *illik*, *illak*, *ittalak*, *alik*.
:::
