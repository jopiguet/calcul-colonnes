# 6. El verbo: raíces y pretérito

El verbo acadio se construye como el hebreo y el árabe: una **raíz** de (casi siempre) tres consonantes lleva el sentido, y esquemas de vocales, prefijos y consonantes duplicadas llevan la gramática. De *p-r-s* «decidir» vienen *iprus* «decidió», *iparras* «decide», *purus* «¡decide!», *parsum* «decidido». Las gramáticas toman *p-r-s* como verbo modelo. Esta lección da las raíces y el primer tiempo, el **pretérito**, el pasado del relato.

## Las raíces

| Raíz | Sentido | Infinitivo |
|---|---|---|
| *p-r-s* | decidir, separar | *parāsum* |
| *š-k-n* | colocar, poner | *šakānum* |
| *ṣ-b-t* | agarrar, tomar | *ṣabātum* |
| *m-q-t* | caer | *maqātum* |
| *š-p-r* | enviar, escribir | *šapārum* |
| *k-š-d* | alcanzar, conquistar | *kašādum* |
| *p-q-d* | confiar, cuidar de | *paqādum* |

El esquema del infinitivo es *paRāSum*: la primera y la segunda radical con *a*, la tercera con *ā*.

## El pretérito iprus

| Persona | Prefijo + desinencia | *parāsum* | Sentido |
|---|---|---|---|
| 3.ª sg. | *i-* | *iprus* | él, ella decidió |
| 2.ª sg. m. | *ta-* | *taprus* | decidiste |
| 2.ª sg. f. | *ta- … -ī* | *taprusī* | decidiste (f.) |
| 1.ª sg. | *a-* | *aprus* | decidí |
| 3.ª pl. m. | *i- … -ū* | *iprusū* | decidieron |
| 3.ª pl. f. | *i- … -ā* | *iprusā* | decidieron (f.) |
| 2.ª pl. | *ta- … -ā* | *taprusā* | decidisteis |
| 1.ª pl. | *ni-* | *niprus* | decidimos |

## Las clases vocálicas

La vocal entre la segunda y la tercera radical depende del verbo; los diccionarios la dan.

| Clase | Pretérito | Ejemplo | Sentido |
|---|---|---|---|
| *u* | *iprus* | *imqut* | cayó |
| *a* | *iṣbat* | *iṣbat* | agarró |
| *i* | *ipqid* | *ipqid* | confió |
| *u* | *iškun* | *iškun* | colocó |

El pretérito cuenta lo que pasó: *šarrum ālam iṣbat* «el rey tomó la ciudad». El orden de las palabras es sujeto, objeto, **verbo al final**.

::: exercise conjugate
Conjugue *parāsum* en pretérito.

- «decidió» → [[iprus]]
- «decidí» → [[aprus]]
- «decidiste (m.)» → [[taprus]]
- «decidimos» → [[niprus]]
- «decidieron (m.)» → [[iprusū]]
:::

::: exercise preterite
Dé la 3.ª persona del singular del pretérito.

- ṣabātum «agarrar» (clase a) → [[iṣbat]]
- maqātum «caer» (clase u) → [[imqut]]
- paqādum «confiar» (clase i) → [[ipqid]]
- šakānum «colocar» (clase u) → [[iškun]]
:::

::: exercise person
¿Quién lo hizo?

- aškun → ((coloqué* / colocó / colocamos))
- tašpur → ((enviaste* / enviaron / envié))
- ikšudū → ((alcanzó / alcanzaron* / alcanzamos))
- niṣbat → ((agarramos* / agarró / agarraste))
:::

::: exercise translate
Traduzca.

- *šarrum ālam iṣbat* → {{El rey tomó la ciudad. / El rey se apoderó de la ciudad.}}
- *awīlum imqut* → {{El hombre cayó.}}
- *ṭuppam ašpur* → {{Envié una tablilla. / Escribí una carta.}}
- *mātam ikšudū* → {{Conquistaron el país. / Alcanzaron el país.}}
:::

::: summary
- Raíz de tres radicales (*p-r-s*); infinitivo *parāsum*.
- Pretérito *iprus*: *i-*, *ta-*, *ta-…-ī*, *a-*; *i-…-ū*, *i-…-ā*, *ta-…-ā*, *ni-*.
- Clases vocálicas: *iprus*, *iṣbat*, *ipqid*, *imqut*. Verbo al final: *šarrum ālam iṣbat*.
:::
