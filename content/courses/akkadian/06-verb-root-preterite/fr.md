# 6. Le verbe : racines et prétérit

Le verbe akkadien se construit comme le verbe hébreu et arabe : une **racine** de (le plus souvent) trois consonnes porte le sens, et des schèmes de voyelles, de préfixes et de consonnes redoublées portent la grammaire. De *p-r-s* « décider » viennent *iprus* « il décida », *iparras* « il décide », *purus* « décide ! », *parsum* « décidé ». Les grammaires prennent *p-r-s* comme verbe modèle. Cette leçon donne les racines et le premier temps, le **prétérit**, le passé du récit.

## Les racines

| Racine | Sens | Infinitif |
|---|---|---|
| *p-r-s* | décider, séparer | *parāsum* |
| *š-k-n* | placer, poser | *šakānum* |
| *ṣ-b-t* | saisir, prendre | *ṣabātum* |
| *m-q-t* | tomber | *maqātum* |
| *š-p-r* | envoyer, écrire | *šapārum* |
| *k-š-d* | atteindre, conquérir | *kašādum* |
| *p-q-d* | confier, prendre soin de | *paqādum* |

Le schème de l'infinitif est *paRāSum* : la première et la deuxième radicales avec *a*, la troisième avec *ā*.

## Le prétérit iprus

| Personne | Préfixe + terminaison | *parāsum* | Sens |
|---|---|---|---|
| 3e sg. | *i-* | *iprus* | il, elle décida |
| 2e sg. m. | *ta-* | *taprus* | tu décidas |
| 2e sg. f. | *ta- … -ī* | *taprusī* | tu (f.) décidas |
| 1re sg. | *a-* | *aprus* | je décidai |
| 3e pl. m. | *i- … -ū* | *iprusū* | ils décidèrent |
| 3e pl. f. | *i- … -ā* | *iprusā* | elles décidèrent |
| 2e pl. | *ta- … -ā* | *taprusā* | vous décidâtes |
| 1re pl. | *ni-* | *niprus* | nous décidâmes |

## Les classes vocaliques

La voyelle entre la deuxième et la troisième radicale dépend du verbe ; les dictionnaires la donnent.

| Classe | Prétérit | Exemple | Sens |
|---|---|---|---|
| *u* | *iprus* | *imqut* | il tomba |
| *a* | *iṣbat* | *iṣbat* | il saisit |
| *i* | *ipqid* | *ipqid* | il confia |
| *u* | *iškun* | *iškun* | il plaça |

Le prétérit dit ce qui est arrivé : *šarrum ālam iṣbat* « le roi prit la ville ». L'ordre des mots est sujet, objet, **verbe à la fin**.

::: exercise conjugate
Conjuguez *parāsum* au prétérit.

- « il décida » → [[iprus]]
- « je décidai » → [[aprus]]
- « tu (m.) décidas » → [[taprus]]
- « nous décidâmes » → [[niprus]]
- « ils décidèrent » → [[iprusū]]
:::

::: exercise preterite
Donnez la 3e personne du singulier du prétérit.

- ṣabātum « saisir » (classe a) → [[iṣbat]]
- maqātum « tomber » (classe u) → [[imqut]]
- paqādum « confier » (classe i) → [[ipqid]]
- šakānum « placer » (classe u) → [[iškun]]
:::

::: exercise person
Qui l'a fait ?

- aškun → ((je plaçai* / il plaça / nous plaçâmes))
- tašpur → ((tu envoyas* / ils envoyèrent / j'envoyai))
- ikšudū → ((il atteignit / ils atteignirent* / nous atteignîmes))
- niṣbat → ((nous saisîmes* / il saisit / tu saisis))
:::

::: exercise translate
Traduisez.

- *šarrum ālam iṣbat* → {{Le roi prit la ville. / Le roi s'empara de la ville.}}
- *awīlum imqut* → {{L'homme tomba. / L'homme est tombé.}}
- *ṭuppam ašpur* → {{J'envoyai une tablette. / J'ai écrit une lettre.}}
- *mātam ikšudū* → {{Ils conquirent le pays. / Ils atteignirent le pays.}}
:::

::: summary
- Racine de trois radicales (*p-r-s*) ; infinitif *parāsum*.
- Prétérit *iprus* : *i-*, *ta-*, *ta-…-ī*, *a-* ; *i-…-ū*, *i-…-ā*, *ta-…-ā*, *ni-*.
- Classes vocaliques : *iprus*, *iṣbat*, *ipqid*, *imqut*. Verbe à la fin : *šarrum ālam iṣbat*.
:::
