# 9. Le statif

« Je vais bien », « la ville est prise », « tu es roi » : l'akkadien exprime un **état** par une conjugaison spéciale, le **statif** (ou permansif). Il se construit sur l'adjectif ou l'adjectif verbal et prend des terminaisons courtes à lui, apparentées aux pronoms indépendants : *šalmāku* « je vais bien » (*anāku*). Presque toutes les lettres s'ouvrent par lui : *šalmāku* « je vais bien », *ālum šalim* « la ville va bien ».

## Les formes

| Personne | Terminaison | *damqum* bon | *šalmum* sain, en bonne santé |
|---|---|---|---|
| 3e sg. m. | aucune | *damiq* il est bon | *šalim* il va bien |
| 3e sg. f. | *-at* | *damqat* | *šalmat* |
| 2e sg. m. | *-āta* | *damqāta* | *šalmāta* |
| 2e sg. f. | *-āti* | *damqāti* | *šalmāti* |
| 1re sg. | *-āku* | *damqāku* | *šalmāku* |
| 3e pl. m. | *-ū* | *damqū* | *šalmū* |
| 3e pl. f. | *-ā* | *damqā* | *šalmā* |
| 1re pl. | *-ānu* | *damqānu* | *šalmānu* |

La 3e personne du masculin singulier a le schème *paris* : *damiq*, *šalim*, *rabi* « est grand ». Devant une terminaison, la seconde voyelle tombe : *dam(i)q-at* → *damqat*.

## Le statif des verbes

| Verbe | Statif | Sens |
|---|---|---|
| *ṣabātum* saisir | *ṣabit* | est saisi ; tient |
| *šakānum* placer | *šakin* | est placé, se trouve |
| *parāsum* décider | *paris* | est décidé, est séparé |
| *wašābum* s'asseoir | *wašib* | est assis, habite |

Avec un verbe transitif, le statif est d'ordinaire passif (« est saisi ») ; avec un intransitif, c'est l'état résultant (« est assis »).

## Le statif des noms

Tout nom peut prendre les terminaisons du statif : *šarrāku* « je suis roi », *mārāku* « je suis un fils », *awīlāta* « tu es un homme (conduis-toi comme tel !) ».

::: summary
- Statif : un état ; terminaisons aucune, *-at*, *-āta*, *-āti*, *-āku* ; *-ū*, *-ā*, *-ānu*.
- Schème *paris* : *damiq*, *šalim* ; voyelle tombée devant terminaison : *damqat*.
- Des verbes : passif ou état résultant (*ṣabit* est saisi) ; des noms : *šarrāku* je suis roi.
:::
