# 8. Ordres, souhaits et négation

Les lettres akkadiennes sont pleines d'ordres et de souhaits : « envoie-moi… », « que les dieux te gardent », « ne néglige pas… ». L'**impératif** donne un ordre à « tu » ; le **précatif** exprime un souhait ou un ordre pour « il », « je » et « nous » ; le **prohibitif** interdit. Et deux négations se partagent le travail : *ul* pour les affirmations, *lā* pour tout le reste.

## L'impératif

| Classe | Masculin sg. | Féminin sg. | Pluriel |
|---|---|---|---|
| *u* (*iprus*) | *purus* | *pursī* | *pursā* |
| *a* (*iṣbat*) | *ṣabat* | *ṣabtī* | *ṣabtā* |
| *i* (*ipqid*) | *piqid* | *piqdī* | *piqdā* |
| *u* (*iškun*) | *šukun* | *šuknī* | *šuknā* |

L'impératif est le prétérit sans son préfixe, avec la voyelle répétée devant les premières radicales : *iprus* → *purus*, *iṣbat* → *ṣabat*. Dans les lettres, il ouvre la demande : *šupram* « écris-moi ! » (*šupur* + *-am*, le ventif « vers moi »).

## Le précatif

Le précatif est le prétérit avec le préfixe *l-* :

| Personne | Forme | Sens |
|---|---|---|
| 3e sg. | *liprus* | puisse-t-il décider ; qu'il décide |
| 3e pl. | *liprusū* | puissent-ils décider |
| 1re sg. | *luprus* | que je décide ; je veux décider |
| 1re pl. | *i niprus* | décidons |

Les lettres saluent avec lui : *ilū liballiṭūka* « que les dieux te gardent en vie » ; Šamaš *lišallimka* « que Shamash te garde en bonne santé ».

## Négation et défense

| Négation | Où | Exemple | Sens |
|---|---|---|---|
| *ul* | propositions principales qui affirment | *ul iprus* | il n'a pas décidé |
| *lā* | subordonnées, noms, adjectifs | *ša lā iprusu* | qui n'a pas décidé |
| *lā* + duratif | défense, « ne … pas ! » | *lā taparras* | ne décide pas ! |
| *ē* + prétérit | vétitif, « que … ne … pas » | *ē taprus* | tu ne dois pas décider |

*lā* forme aussi des mots négatifs : *lā šēmûm* « désobéissant » (qui n'écoute pas).

::: exercise imperative
Donnez l'impératif masculin singulier.

- parāsum → [[purus]]
- ṣabātum → [[ṣabat]]
- paqādum → [[piqid]]
- šakānum → [[šukun]]
:::

::: exercise precative
Donnez le précatif.

- parāsum, « qu'il décide » → [[liprus]]
- parāsum, « que je décide » → [[luprus]]
- šapārum, « qu'il envoie » → [[lišpur]]
- ṣabātum, « qu'ils saisissent » → [[liṣbatū]]
:::

::: exercise negation
*ul* ou *lā* ?

- « il n'a pas pris la ville » : ((ul* / lā)) iṣbat
- « ne prends pas ! » : ((ul / lā*)) taṣabbat
- « l'homme qui n'a pas pris » : awīlum ša ((ul / lā*)) iṣbatu
- « je n'ai pas envoyé » : ((ul* / lā)) ašpur
:::

::: exercise translate
Traduisez.

- *ṭuppam šupram* → {{Envoie-moi une tablette ! / Écris-moi !}}
- *ilū liballiṭūka* → {{Que les dieux te gardent en vie ! / Que les dieux te gardent en bonne santé !}}
- *lā taparras* → {{Ne décide pas ! / Ne sépare pas !}}
- *ul ašpur* → {{Je n'ai pas envoyé. / Je n'ai pas écrit.}}
:::

::: summary
- Impératif : *purus, ṣabat, piqid, šukun* ; féminin *-ī*, pluriel *-ā* ; *šupram* écris-moi.
- Précatif : *liprus* qu'il, *luprus* que je, *i niprus* décidons.
- *ul* dans les affirmations principales ; *lā* ailleurs ; *lā* + duratif : ne … pas ! ; *ē* + prétérit : ne doit pas.
:::
