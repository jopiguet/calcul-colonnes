# 10. Préfixes dimensionnels et modaux

Deux autres groupes de préfixes complètent la chaîne verbale. Les **préfixes dimensionnels** répètent dans le verbe les cas des groupes nominaux : si la phrase contient « pour le dieu » (*-ra*), le verbe porte *-na-* « pour lui ». Les **préfixes modaux**, tout en tête, changent une affirmation en négation, souhait, exhortation ou défense. Avec eux, vous lisez le verbe clé de presque toutes les inscriptions de construction : *mu-na-du₃* « il (l')a bâti pour lui ».

## Les préfixes dimensionnels

| Cas dans la phrase | Préfixe dans le verbe | Exemple | Sens |
|---|---|---|---|
| datif *-ra* (3e sg.) | *-na-* | *mu-na-du₃* | il (l')a bâti pour lui |
| datif, « pour moi » | *-a-* (*mu-* + *-a-* = *ma-*) | *ma-an-šum₂* | il me (l')a donné |
| datif, « pour toi » | *-ra-* | *mu-ra-an-šum₂* | il te (l')a donné |
| comitatif *-da* | *-da-* | *mu-da-ĝen* | il est allé avec (lui) |
| terminatif *-še₃* | *-ši-* | *mu-ši-ĝen* | il est allé vers (cela) |
| ablatif *-ta* | *-ta-* | *ba-ta-e₃* | il est sorti de (cela) |
| locatif *-a* | *-ni-* | *ba-ni-in-du₃* | il (l')a bâti dedans |

Le groupe nominal et le préfixe s'accordent : ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃* « pour Ningirsu, il a bâti pour lui son temple ». Le français omet le « pour lui » ; le sumérien le dit deux fois.

## Les préfixes modaux

| Préfixe | Sens | Exemple | Traduction |
|---|---|---|---|
| *nu-* | négation | *nu-un-du₃* | il n'a pas bâti |
| *ḫe₂-* | souhait, « puisse » ; aussi « certes » | *ḫe₂-en-du₃* | puisse-t-il bâtir |
| *ga-* | « que je », « que nous » | *ga-an-du₃* | que je bâtisse, je veux bâtir |
| *na-* (avec l'imperfectif) | défense | *na-an-du₃-e* | qu'il ne bâtisse pas |

*nu-* devient *la-* ou *li-* devant *ba-* et *bi₂-* : *la-ba-an-du₃* « il n'a pas bâti ». *ḫe₂-* s'écrit *ḫa-* devant *a* : *ḫa-ma-an-šum₂* « puisse-t-il me le donner ».

::: exercise prefix
Qu'ajoute le préfixe ?

- -na- dans mu-na-du₃ → ((pour lui* / avec lui / ne … pas))
- nu- dans nu-un-du₃ → ((pour lui / ne … pas* / puisse))
- ḫe₂- dans ḫe₂-en-du₃ → ((puisse* / ne … pas / que je))
- ga- dans ga-an-du₃ → ((puisse-t-il / que je* / qu'il ne … pas))
- -da- dans mu-da-ĝen → ((pour lui / avec lui* / de cela))
:::

::: exercise agree

::: exercise translate
Traduisez.

- ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃* → {{Pour Ningirsu, il a bâti son temple. / Il a bâti son temple pour Ningirsu.}}
- *lugal-e e₂ nu-un-du₃* → {{Le roi n'a pas bâti la maison.}}
- *ḫe₂-en-du₃* → {{Puisse-t-il (le) bâtir ! / Qu'il le bâtisse !}}
- *ga-an-du₃* → {{Que je (le) bâtisse ! / Je veux le bâtir !}}
:::

::: summary
- Les préfixes dimensionnels répètent les cas : *-na-* pour lui (datif), *-da-* avec, *-ši-* vers, *-ta-* de, *-ni-* dans ; *ma-* pour moi, *-ra-* pour toi.
- Préfixes modaux : *nu-* ne … pas, *ḫe₂-* puisse, *ga-* que je, *na-* + imperfectif défense.
- ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃* : la formule des inscriptions de construction.
:::
