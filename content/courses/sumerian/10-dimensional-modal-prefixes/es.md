# 10. Prefijos dimensionales y modales

Otros dos grupos de prefijos completan la cadena verbal. Los **prefijos dimensionales** repiten dentro del verbo los casos de los sintagmas nominales: si la oración tiene «para el dios» (*-ra*), el verbo lleva *-na-* «para él». Los **prefijos modales**, al principio de todo, convierten una afirmación en negación, deseo, exhortación o prohibición. Con ellos se lee el verbo clave de casi todas las inscripciones de construcción: *mu-na-du₃* «(lo) construyó para él».

## Los prefijos dimensionales

| Caso en la oración | Prefijo en el verbo | Ejemplo | Sentido |
|---|---|---|---|
| dativo *-ra* (3.ª sg.) | *-na-* | *mu-na-du₃* | (lo) construyó para él |
| dativo, «para mí» | *-a-* (*mu-* + *-a-* = *ma-*) | *ma-an-šum₂* | me (lo) dio |
| dativo, «para ti» | *-ra-* | *mu-ra-an-šum₂* | te (lo) dio |
| comitativo *-da* | *-da-* | *mu-da-ĝen* | fue con (él) |
| terminativo *-še₃* | *-ši-* | *mu-ši-ĝen* | fue hacia (ello) |
| ablativo *-ta* | *-ta-* | *ba-ta-e₃* | salió de (ello) |
| locativo *-a* | *-ni-* | *ba-ni-in-du₃* | (lo) construyó dentro |

El sintagma nominal y el prefijo concuerdan: ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃* «para Ningirsu, construyó para él su templo». El español omite el «para él»; el sumerio lo dice dos veces.

## Los prefijos modales

| Prefijo | Sentido | Ejemplo | Traducción |
|---|---|---|---|
| *nu-* | negación | *nu-un-du₃* | no construyó |
| *ḫe₂-* | deseo, «ojalá»; también «ciertamente» | *ḫe₂-en-du₃* | que construya |
| *ga-* | «que yo», «que nosotros» | *ga-an-du₃* | que yo construya, quiero construir |
| *na-* (con el imperfectivo) | prohibición | *na-an-du₃-e* | que no construya |

*nu-* se vuelve *la-* o *li-* ante *ba-* y *bi₂-*: *la-ba-an-du₃* «no construyó». *ḫe₂-* se escribe *ḫa-* ante *a*: *ḫa-ma-an-šum₂* «que me lo dé».

::: exercise prefix
¿Qué añade el prefijo?

- -na- en mu-na-du₃ → ((para él* / con él / no))
- nu- en nu-un-du₃ → ((para él / no* / ojalá))
- ḫe₂- en ḫe₂-en-du₃ → ((ojalá* / no / que yo))
- ga- en ga-an-du₃ → ((que él / que yo* / que no))
- -da- en mu-da-ĝen → ((para él / con él* / desde ello))
:::

::: exercise build
Escriba la forma de *du₃* «construir».

- «lo construyó para él» → [[mu-na-du₃]]
- «no construyó» → [[nu-un-du₃]]
- «que construya» → [[ḫe₂-en-du₃]]
- «que yo construya» → [[ga-an-du₃]]
:::

::: exercise agree
¿Qué prefijo corresponde al caso de la oración?

- lugal-ra … → ((mu-na-du₃* / mu-da-du₃ / mu-ši-du₃)) «para el rey, construyó»
- dumu-ni-da … → ((mu-na-ĝen / mu-da-ĝen* / ba-ta-ĝen)) «fue con su hijo»
- uru-še₃ … → ((mu-na-ĝen / mu-da-ĝen / mu-ši-ĝen*)) «fue hacia la ciudad»
:::

::: exercise translate
Traduzca.

- ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃* → {{Para Ningirsu construyó su templo. / Construyó su templo para Ningirsu.}}
- *lugal-e e₂ nu-un-du₃* → {{El rey no construyó la casa.}}
- *ḫe₂-en-du₃* → {{¡Que lo construya! / ¡Ojalá lo construya!}}
- *ga-an-du₃* → {{¡Que yo lo construya! / ¡Quiero construirlo!}}
:::

::: summary
- Los prefijos dimensionales repiten los casos: *-na-* para él (dativo), *-da-* con, *-ši-* hacia, *-ta-* desde, *-ni-* en; *ma-* para mí, *-ra-* para ti.
- Prefijos modales: *nu-* no, *ḫe₂-* ojalá, *ga-* que yo, *na-* + imperfectivo prohibición.
- ᵈ*nin-ĝir₂-su-ra e₂-a-ni mu-na-du₃*: la fórmula de las inscripciones de construcción.
:::
