# 12. Lectura: las inscripciones reales de construcción

Miles de ladrillos, conos de arcilla y quicios de puerta sumerios llevan el mismo tipo de texto: un soberano recuerda que construyó un templo para un dios. El esquema nunca cambia: el dios en dativo, el soberano en ergativo, el edificio en absolutivo, y *mu-na-du₃* «lo construyó para él». Esta última lección lee dos ejemplos célebres, de Ur-Namma de Ur y de Gudea de Lagash, con la gramática de todo el curso. Las transliteraciones siguen los textos publicados; las traducciones son nuestras.

## Ur-Namma, rey de Ur (hacia 2100 a. C.)

ᵈ*nanna lugal-a-ni* \
*ur-*ᵈ*namma lugal urim₂*ᵏⁱ*-ma-ke₄* \
*e₂-a-ni mu-na-du₃* \
*bad₃-a-ni mu-na-du₃*

«Para Nanna, su señor, Ur-Namma, rey de Ur, construyó su templo, construyó su muralla.»

| Grupo | Gramática |
|---|---|
| ᵈ*nanna lugal-a-ni* | el dios, con *lugal* «señor» + *-a-ni* «su»; el dativo *-ra* se sobreentiende |
| *ur-*ᵈ*namma* | «servidor de Namma», un nombre en genitivo |
| *lugal urim₂*ᵏⁱ*-ma-ke₄* | «rey de Ur»: genitivo *urim₂-ak*, luego ergativo *-e*: *-ak-e* escrito *-ke₄* |
| *e₂-a-ni* | «su casa», objeto en absolutivo |
| *mu-na-du₃* | *mu-* + *-na-* «para él» + *-n-* «él» + *du₃* «construyó» |

## Gudea, soberano de Lagash (hacia 2125 a. C.)

ᵈ*nin-ĝir₂-su* \
*ur-saĝ kalag-ga* ᵈ*en-lil₂-la₂-ra* \
*gu₃-de₂-a ensi₂ lagaš*ᵏⁱ*-ke₄* \
*e₂-ninnu-ni mu-na-du₃*

«Para Ningirsu, el poderoso héroe de Enlil, Gudea, soberano de Lagash, construyó su Eninnu.»

| Grupo | Gramática |
|---|---|
| *ur-saĝ kalag-ga* | «poderoso héroe»: sustantivo + adjetivo *kalag* + *-a* |
| ᵈ*en-lil₂-la₂-ra* | genitivo de Enlil (*-ak*) + dativo *-ra* que cierra todo el grupo «para Ningirsu, héroe de Enlil» |
| *gu₃-de₂-a* | Gudea, «el llamado (por el dios)» |
| *ensi₂* | soberano, gobernador de una ciudad |
| *lagaš*ᵏⁱ*-ke₄* | «de Lagash» + ergativo: *-ak-e* |
| *e₂-ninnu-ni* | «su Eninnu», el templo «Casa de los Cincuenta», con el posesivo *-ni* |

::: exercise parts
¿Qué parte de la fórmula?

- ᵈnanna lugal-a-ni → ((el dios, para quien* / el constructor / el edificio))
- ur-ᵈnamma lugal urim₂ᵏⁱ-ma-ke₄ → ((el dios / el constructor* / el edificio))
- e₂-a-ni → ((el dios / el constructor / el edificio*))
- -ke₄ → ((genitivo + ergativo* / dativo / plural))
:::

::: summary
- Inscripciones de construcción: dios (+ *-ra*, a menudo sobreentendido), soberano + *-ke₄*, edificio + *-a-ni*, *mu-na-du₃*.
- *-ke₄* = genitivo *-ak* + ergativo *-e*: *lugal urim₂*ᵏⁱ*-ma-ke₄* «el rey de Ur (lo hizo)».
- Ur-Namma construyó para Nanna en Ur; Gudea construyó el Eninnu para Ningirsu en Lagash.
- Todos los elementos de la cadena nominal y de la cadena verbal aparecen en estas pocas líneas.
:::
