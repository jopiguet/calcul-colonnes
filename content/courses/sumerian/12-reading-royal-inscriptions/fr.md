# 12. Lecture : les inscriptions royales de construction

Des milliers de briques, de cônes d'argile et de crapaudines sumériens portent le même genre de texte : un souverain y rappelle qu'il a bâti un temple pour un dieu. Le schéma ne change jamais : le dieu au datif, le souverain à l'ergatif, le bâtiment à l'absolutif, et *mu-na-du₃* « il l'a bâti pour lui ». Cette dernière leçon lit deux exemples célèbres, d'Ur-Namma d'Ur et de Gudea de Lagash, avec la grammaire de tout le cours. Les translittérations suivent les textes publiés ; les traductions sont les nôtres.

## Ur-Namma, roi d'Ur (vers 2100 av. J.-C.)

ᵈ*nanna lugal-a-ni* \
*ur-*ᵈ*namma lugal urim₂*ᵏⁱ*-ma-ke₄* \
*e₂-a-ni mu-na-du₃* \
*bad₃-a-ni mu-na-du₃*

« Pour Nanna, son seigneur, Ur-Namma, roi d'Ur, a bâti son temple, a bâti son mur. »

| Groupe | Grammaire |
|---|---|
| ᵈ*nanna lugal-a-ni* | le dieu, avec *lugal* « seigneur » + *-a-ni* « son » ; le datif *-ra* est sous-entendu |
| *ur-*ᵈ*namma* | « serviteur de Namma », un nom au génitif |
| *lugal urim₂*ᵏⁱ*-ma-ke₄* | « roi d'Ur » : génitif *urim₂-ak*, puis ergatif *-e* : *-ak-e* écrit *-ke₄* |
| *e₂-a-ni* | « sa maison », objet à l'absolutif |
| *mu-na-du₃* | *mu-* + *-na-* « pour lui » + *-n-* « il » + *du₃* « a bâti » |

## Gudea, souverain de Lagash (vers 2125 av. J.-C.)

ᵈ*nin-ĝir₂-su* \
*ur-saĝ kalag-ga* ᵈ*en-lil₂-la₂-ra* \
*gu₃-de₂-a ensi₂ lagaš*ᵏⁱ*-ke₄* \
*e₂-ninnu-ni mu-na-du₃*

« Pour Ningirsu, le puissant héros d'Enlil, Gudea, souverain de Lagash, a bâti son Eninnu. »

| Groupe | Grammaire |
|---|---|
| *ur-saĝ kalag-ga* | « puissant héros » : nom + adjectif *kalag* + *-a* |
| ᵈ*en-lil₂-la₂-ra* | génitif d'Enlil (*-ak*) + datif *-ra* qui ferme tout le groupe « pour Ningirsu, héros d'Enlil » |
| *gu₃-de₂-a* | Gudea, « celui qui a été appelé (par le dieu) » |
| *ensi₂* | souverain, gouverneur d'une ville |
| *lagaš*ᵏⁱ*-ke₄* | « de Lagash » + ergatif : *-ak-e* |
| *e₂-ninnu-ni* | « son Eninnu », le temple « Maison des Cinquante », avec le possessif *-ni* |

::: exercise parts
Quelle partie de la formule ?

- ᵈnanna lugal-a-ni → ((le dieu, pour qui* / le bâtisseur / le bâtiment))
- ur-ᵈnamma lugal urim₂ᵏⁱ-ma-ke₄ → ((le dieu / le bâtisseur* / le bâtiment))
- e₂-a-ni → ((le dieu / le bâtisseur / le bâtiment*))
- -ke₄ → ((génitif + ergatif* / datif / pluriel))
:::

Traduisez.

- *e₂-a-ni mu-na-du₃* → {{Il a bâti son temple pour lui. / Il lui a bâti sa maison.}}
- *lugal urim₂*ᵏⁱ*-ma* → {{roi d'Ur / le roi d'Ur}}

- *bad₃-a-ni mu-na-du₃* → {{Il a bâti son mur pour lui. / Il lui a bâti son mur.}}
:::

::: summary
- Inscriptions de construction : dieu (+ *-ra*, souvent sous-entendu), souverain + *-ke₄*, bâtiment + *-a-ni*, *mu-na-du₃*.
- *-ke₄* = génitif *-ak* + ergatif *-e* : *lugal urim₂*ᵏⁱ*-ma-ke₄* « le roi d'Ur (a fait) ».
- Ur-Namma a bâti pour Nanna à Ur ; Gudea a bâti l'Eninnu pour Ningirsu à Lagash.
- Chaque élément de la chaîne nominale et de la chaîne verbale apparaît dans ces quelques lignes.
:::
