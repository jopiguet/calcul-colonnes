# 9. The transitive verb: perfective and imperfective

A transitive verb ("build", "write", "give") has an agent and an object, and Sumerian marks the agent inside the verb. How it does so depends on the **aspect**. In the **perfective** (Sumerian grammarians' *ḫamṭu*, "quick"), a finished action, the agent is a **prefix** just before the root: *mu-**n**-du₃* "he built". In the **imperfective** (*marû*, "slow"), an action going on or still to come, the agent is a **suffix**: *mu-du₃-**e*** "he builds, he will build". This lesson gives both, the forms you read in every royal inscription.

## The perfective (ḫamṭu)

| Agent | Prefix | Form | Meaning |
|---|---|---|---|
| 1st sg. | none | *mu-du₃* | I built |
| 2nd sg. | *-e-* | *mu-e-du₃* | you built |
| 3rd sg. human | *-n-* | *mu-un-du₃* | he, she built |
| 3rd non-human | *-b-* | *mu-ub-du₃*, *ib₂-du₃* | it built |
| 3rd pl. human | *-n-* … *-eš* | *mu-un-du₃-uš* | they built |

The *-n-* is written with the vowel of the prefix before it: *mu-un-*, *i₃-in-*, *ba-an-*. The object of the third person is unmarked: *lugal-e e₂ mu-un-du₃* "the king built the house".

## The imperfective (marû)

| Agent | Suffix | Form | Meaning |
|---|---|---|---|
| 1st sg. | *-en* | *mu-du₃-en* | I build, I will build |
| 2nd sg. | *-en* | *mu-du₃-en* | you build |
| 3rd sg. | *-e* | *mu-du₃-e* | he builds, he will build |
| 3rd pl. | *-ene* | *mu-du₃-ne* | they build |

Some verbs also change their root between the two aspects:

| Meaning | Perfective root | Imperfective root |
|---|---|---|
| to speak | *dug₄* | *e* |
| to go (one person) | *ĝen* | *du* |
| to give | *šum₂* | *šum₂-mu* |
| to build | *du₃* | *du₃-e* |

## Summary of agent marking

| Aspect | Agent | Example |
|---|---|---|
| perfective | prefix before the root | *mu-un-du₃* he built |
| imperfective | suffix after the root | *mu-du₃-e* he builds |

This split, prefix for the finished action and suffix for the unfinished one, is another face of Sumerian ergativity.

::: summary
- Perfective (*ḫamṭu*): agent prefix: none (I), *-e-* (you), *-n-* (he, human), *-b-* (it), *-n-…-eš* (they): *mu-un-du₃*.
- Imperfective (*marû*): agent suffix: *-en* (I, you), *-e* (he), *-ene* (they): *mu-du₃-e*.
- Some roots differ: *dug₄* / *e* speak, *ĝen* / *du* go.
:::
