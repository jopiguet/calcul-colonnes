# 9. Le verbe transitif : perfectif et imperfectif

Un verbe transitif (« bâtir », « écrire », « donner ») a un agent et un objet, et le sumérien marque l'agent dans le verbe. La manière dépend de l'**aspect**. Au **perfectif** (le *ḫamṭu*, « rapide », des grammairiens anciens), une action achevée, l'agent est un **préfixe** juste avant la racine : *mu-**n**-du₃* « il a bâti ». À l'**imperfectif** (*marû*, « lent »), une action en cours ou à venir, l'agent est un **suffixe** : *mu-du₃-**e*** « il bâtit, il bâtira ». Cette leçon donne les deux, les formes qu'on lit dans toutes les inscriptions royales.

## Le perfectif (ḫamṭu)

| Agent | Préfixe | Forme | Sens |
|---|---|---|---|
| 1re sg. | aucun | *mu-du₃* | j'ai bâti |
| 2e sg. | *-e-* | *mu-e-du₃* | tu as bâti |
| 3e sg. humain | *-n-* | *mu-un-du₃* | il, elle a bâti |
| 3e non humain | *-b-* | *mu-ub-du₃*, *ib₂-du₃* | cela a bâti |
| 3e pl. humain | *-n-* … *-eš* | *mu-un-du₃-uš* | ils ont bâti |

Le *-n-* s'écrit avec la voyelle du préfixe qui le précède : *mu-un-*, *i₃-in-*, *ba-an-*. L'objet de la troisième personne n'est pas marqué : *lugal-e e₂ mu-un-du₃* « le roi a bâti la maison ».

## L'imperfectif (marû)

| Agent | Suffixe | Forme | Sens |
|---|---|---|---|
| 1re sg. | *-en* | *mu-du₃-en* | je bâtis, je bâtirai |
| 2e sg. | *-en* | *mu-du₃-en* | tu bâtis |
| 3e sg. | *-e* | *mu-du₃-e* | il bâtit, il bâtira |
| 3e pl. | *-ene* | *mu-du₃-ne* | ils bâtissent |

Certains verbes changent aussi de racine d'un aspect à l'autre :

| Sens | Racine perfective | Racine imperfective |
|---|---|---|
| parler | *dug₄* | *e* |
| aller (une personne) | *ĝen* | *du* |
| donner | *šum₂* | *šum₂-mu* |
| bâtir | *du₃* | *du₃-e* |

## Résumé du marquage de l'agent

| Aspect | Agent | Exemple |
|---|---|---|
| perfectif | préfixe avant la racine | *mu-un-du₃* il a bâti |
| imperfectif | suffixe après la racine | *mu-du₃-e* il bâtit |

Ce partage, préfixe pour l'action achevée et suffixe pour l'inachevée, est une autre face de l'ergativité sumérienne.

::: exercise perfective
Donnez le perfectif de *du₃* « bâtir » avec *mu-*.

- « il a bâti » → [[mu-un-du₃]]
- « tu as bâti » → [[mu-e-du₃]]
- « j'ai bâti » → [[mu-du₃]]
- « ils ont bâti » → [[mu-un-du₃-uš]]
:::

::: exercise aspect
Perfectif ou imperfectif ?

- mu-un-du₃ → ((perfectif* / imperfectif))
- mu-du₃-e → ((perfectif / imperfectif*))
- mu-un-sar → ((perfectif* / imperfectif))
- mu-sar-re → ((perfectif / imperfectif*))
:::

::: exercise agent
Qui a agi ?

- mu-e-sar → ((tu as écrit* / il a écrit / j'ai écrit))
- mu-un-sar → ((tu as écrit / il a écrit* / ils ont écrit))
- mu-un-sar-re-eš → ((il a écrit / nous avons écrit / ils ont écrit*))
- mu-du₃-e → ((il bâtit* / j'ai bâti / tu as bâti))
:::

::: exercise translate
Traduisez.

- *lugal-e e₂ mu-un-du₃* → {{Le roi a bâti la maison. / Le roi a construit le temple.}}
- *dub-sar-e dub mu-un-sar* → {{Le scribe a écrit la tablette.}}
- *lugal-e e₂ mu-du₃-e* → {{Le roi bâtit la maison. / Le roi bâtira la maison.}}
- *e₂ mu-du₃* → {{J'ai bâti la maison.}}
:::

::: summary
- Perfectif (*ḫamṭu*) : préfixe d'agent : aucun (je), *-e-* (tu), *-n-* (il, humain), *-b-* (cela), *-n-…-eš* (ils) : *mu-un-du₃*.
- Imperfectif (*marû*) : suffixe d'agent : *-en* (je, tu), *-e* (il), *-ene* (ils) : *mu-du₃-e*.
- Certaines racines diffèrent : *dug₄* / *e* parler, *ĝen* / *du* aller.
:::
