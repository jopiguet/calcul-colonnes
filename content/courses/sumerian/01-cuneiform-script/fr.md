# 1. Le cunéiforme et sa translittération

L'écriture est née en Mésopotamie du Sud, dans la ville d'Uruk, vers 3300 av. J.-C., pour tenir les comptes des temples. Les premiers signes étaient des images tracées dans l'argile ; imprimés avec un roseau taillé, les traits devinrent des **coins** (latin *cuneus*), et l'écriture devint *cunéiforme*. La langue des premiers textes est le **sumérien**, une langue sans parenté connue. Cette leçon montre comment fonctionne l'écriture et comment les assyriologues l'écrivent en lettres latines : la translittération employée dans chaque exercice de ce cours.

## De l'image au coin

| Signe | Origine | Valeurs | Sens |
|---|---|---|---|
| 𒀭 | une étoile | *an*, *diĝir* | ciel ; dieu |
| 𒆠 | un morceau de terre | *ki* | terre, lieu |
| 𒂍 | une maison | *e₂* | maison, temple |
| 𒀀 | de l'eau qui coule | *a* | eau |
| 𒅗 | une tête, la bouche marquée | *ka*, *inim*, *dug₄* | bouche ; parole ; parler |
| 𒁺 | un pied | *du*, *gin*, *gub* | aller ; se tenir debout |
| 𒈗 | un homme couronné : *lu₂* + *gal* | *lugal* | roi, « grand homme » |

Vers 2500 av. J.-C., les signes furent tournés de 90° vers la gauche et écrits en lignes de gauche à droite. L'écriture servit pendant trois mille ans, pour le sumérien, l'akkadien, le hittite, l'élamite et d'autres langues ; la dernière tablette datable est d'environ 75 apr. J.-C.

## Un signe, plusieurs lectures

Un signe cunéiforme peut se lire de plusieurs façons (**polyphonie**) : 𒀭 est *an* « ciel » ou *diĝir* « dieu ». Et plusieurs signes peuvent avoir le même son (**homophonie**) : il existe de nombreux signes lus *du*. La translittération les distingue par un chiffre en indice :

| Translittération | Signe | Sens |
|---|---|---|
| *du* | 𒁺 | aller |
| *du₃* | 𒆕 | bâtir |
| *dug₄* | 𒅗 | parler |
| *e₂* | 𒂍 | maison |
| *lu₂* | 𒇽 | homme, personne |

Les livres anciens écrivent les premiers indices avec des accents : *dú* = *du₂*, *dù* = *du₃*. Un signe écrit en capitales, KA, DU, est son **nom**, employé quand sa lecture est incertaine.

## Les conventions

| Convention | Exemple | Sens |
|---|---|---|
| minuscules : une lecture sumérienne | *lugal* | roi |
| trait d'union : signes d'un même mot ou d'une même chaîne | *e₂-gal* | palais, « grande maison » |
| chiffre en indice : quel signe de ce son | *du₃* | bâtir |
| exposant : un déterminatif, qui ne se lit pas | ᵈ*en-lil₂* | le dieu Enlil |
| ĝ : le *ng* de l'anglais *sing* | *diĝir* | dieu |
| š, ḫ | *šu*, *ḫe₂* | comme en akkadien : *ch*, la *jota* espagnole |

Les déterminatifs sont des signes placés avant ou après un mot pour en indiquer la catégorie, comme en égyptien : ᵈ (*diĝir*) devant les dieux, ᵍⁱˢ devant les objets en bois, ˡᵘ² devant les métiers, ᵏⁱ après les lieux, ᵐᵘˢᵉⁿ après les oiseaux.

Dans les exercices, tapez š, ĝ, ḫ et les indices avec les boutons, ou sous la forme *sh*, *g*, *kh* et de simples chiffres : *du3* vaut *du₃*.

::: summary
- Cunéiforme : des images imprimées dans l'argile avec un roseau, devenues des coins ; Uruk, vers 3300 av. J.-C. ; trois mille ans d'usage, pour de nombreuses langues.
- Un signe, plusieurs lectures (𒀭 *an*, *diĝir*) ; un son, plusieurs signes (*du*, *du₃*, *dug₄*).
- Minuscules pour les lectures, traits d'union dans un mot, indices pour les homophones, exposants pour les déterminatifs (ᵈ, ᵍⁱˢ, ᵏⁱ), capitales pour les noms de signes.
:::
