# 3. Salutations, pronoms et « être »

L'hébreu n'a pas de verbe « être » au présent : אֲנִי סטוּדֶנְט *ani student*, c'est « je (suis) étudiant ». Ses pronoms distinguent « tu » au masculin et au féminin, et « ils » et « elles ». Avec eux et une dizaine de salutations, vous pouvez entamer une conversation dans une rue de Tel-Aviv.

## Les pronoms personnels

| Pronom | Sens | Pronom | Sens |
|---|---|---|---|
| אֲנִי *ani* | je | אֲנַחְנוּ *anachnu* | nous |
| אַתָּה *ata* | tu (m.) | אַתֶּם *atem* | vous (m.) |
| אַתְּ *at* | tu (f.) | אַתֶּן *aten* | vous (f.) |
| הוּא *hu* | il | הֵם *hem* | ils |
| הִיא *hi* | elle | הֵן *hen* | elles |

Un groupe mixte est masculin. À l'oral, *atem* et *hem* servent souvent aussi pour des femmes.

## La phrase sans « être »

| Hébreu | Sens |
|---|---|
| אֲנִי מִיִּשְׂרָאֵל. *ani mi-Yisra'el.* | Je suis d'Israël. |
| הִיא מוֹרָה. *hi mora.* | Elle est enseignante. |
| הוּא בַּבַּיִת. *hu ba-bayit.* | Il est à la maison. |
| זֶה טוֹב. *ze tov.* | C'est bien. |

Le passé et le futur de « être » existent (leçon 10) ; seul le présent est omis.

## Les salutations

| Hébreu | Sens | Réponse |
|---|---|---|
| שָׁלוֹם *shalom* | bonjour ; au revoir | שָׁלוֹם |
| בֹּקֶר טוֹב *boker tov* | bonjour (le matin) | בֹּקֶר אוֹר *boker or* « matin de lumière » |
| עֶרֶב טוֹב *erev tov* | bonsoir | |
| לַיְלָה טוֹב *laila tov* | bonne nuit | |
| מָה שְׁלוֹמְךָ? / מָה שְׁלוֹמֵךְ? *ma shlomkha? / ma shlomekh?* | comment vas-tu ? (à un homme / à une femme) | בְּסֵדֶר *beseder* ça va |
| מָה נִשְׁמָע? *ma nishma?* | quoi de neuf ? (litt. qu'entend-on ?) | |
| בְּבַקָּשָׁה *bevakasha* | s'il te plaît ; je t'en prie | |
| סְלִיחָה *slicha* | pardon, excuse-moi | |
| לְהִתְרָאוֹת *lehitra'ot* | à bientôt | |

- « pardon » → [[סליחה]]

::: exercise pronoun
Quel pronom ?

- tu, à une femme → ((אַתָּה / אַתְּ* / אַתֶּם))
- elles → ((הֵם / הֵן* / הִיא))
- il → ((הוּא* / הִיא / הֵם))
- vous, à plusieurs hommes → ((אַתֶּם* / אַתֶּן / אֲנַחְנוּ))
:::

::: exercise greeting
Que répondez-vous ?

- בֹּקֶר טוֹב → ((בֹּקֶר אוֹר* / לַיְלָה טוֹב / סְלִיחָה))
- תּוֹדָה → ((בְּבַקָּשָׁה* / שָׁלוֹם / בְּסֵדֶר))
- מָה שְׁלוֹמְךָ? → ((בְּסֵדֶר* / סְלִיחָה / לְהִתְרָאוֹת))
:::

::: exercise translate
Traduisez.

- אֲנִי מִיִּשְׂרָאֵל. → {{Je suis d'Israël. / Je viens d'Israël.}}
- הִיא מוֹרָה. → {{Elle est enseignante. / Elle est professeure.}}
- מָה נִשְׁמָע? → {{Quoi de neuf ? / Comment ça va ?}}
- לַיְלָה טוֹב → {{Bonne nuit.}}
:::

::: summary
- אני, אתה, את, הוא, היא, אנחנו, אתם, אתן, הם, הן ; « tu » et « ils » selon le genre.
- Pas de « être » au présent : אני סטודנט, הוא בבית.
- שלום, בוקר טוב / בוקר אור, מה שלומך?, בסדר, תודה, בבקשה, סליחה, להתראות.
:::
