# 3. Saludos, pronombres y «ser»

El hebreo no tiene verbo «ser» en presente: אֲנִי סטוּדֶנְט *ani student* es «yo (soy) estudiante». Sus pronombres distinguen «tú» masculino y femenino, y «ellos» y «ellas». Con ellos y una docena de saludos puede empezar una conversación en una calle de Tel Aviv.

## Los pronombres personales

| Pronombre | Sentido | Pronombre | Sentido |
|---|---|---|---|
| אֲנִי *ani* | yo | אֲנַחְנוּ *anachnu* | nosotros |
| אַתָּה *ata* | tú (m.) | אַתֶּם *atem* | vosotros |
| אַתְּ *at* | tú (f.) | אַתֶּן *aten* | vosotras |
| הוּא *hu* | él | הֵם *hem* | ellos |
| הִיא *hi* | ella | הֵן *hen* | ellas |

Un grupo mixto es masculino. Al hablar, *atem* y *hem* se usan a menudo también para mujeres.

## La oración sin «ser»

| Hebreo | Sentido |
|---|---|
| אֲנִי מִיִּשְׂרָאֵל. *ani mi-Yisra'el.* | Soy de Israel. |
| הִיא מוֹרָה. *hi mora.* | Es profesora. |
| הוּא בַּבַּיִת. *hu ba-bayit.* | Está en casa. |
| זֶה טוֹב. *ze tov.* | Está bien. |

El pasado y el futuro de «ser» sí existen (lección 10); solo se omite el presente.

## Los saludos

| Hebreo | Sentido | Respuesta |
|---|---|---|
| שָׁלוֹם *shalom* | hola; adiós | שָׁלוֹם |
| בֹּקֶר טוֹב *boker tov* | buenos días | בֹּקֶר אוֹר *boker or* «mañana de luz» |
| עֶרֶב טוֹב *erev tov* | buenas tardes, buenas noches | |
| לַיְלָה טוֹב *laila tov* | buenas noches (al acostarse) | |
| מָה שְׁלוֹמְךָ? / מָה שְׁלוֹמֵךְ? *ma shlomkha? / ma shlomekh?* | ¿cómo estás? (a un hombre / a una mujer) | בְּסֵדֶר *beseder* bien |
| מָה נִשְׁמָע? *ma nishma?* | ¿qué tal? (lit. ¿qué se oye?) | |
| בְּבַקָּשָׁה *bevakasha* | por favor; de nada | |
| סְלִיחָה *slicha* | perdón, disculpa | |
| לְהִתְרָאוֹת *lehitra'ot* | hasta luego | |

::: exercise translate
Traduzca.

- אֲנִי מִיִּשְׂרָאֵל. → {{Soy de Israel.}}
- הִיא מוֹרָה. → {{Es profesora. / Ella es maestra.}}
- מָה נִשְׁמָע? → {{¿Qué tal? / ¿Qué hay de nuevo?}}

:::

::: summary
- אני, אתה, את, הוא, היא, אנחנו, אתם, אתן, הם, הן; «tú» y «ellos» según el género.
- Sin «ser» en presente: אני סטודנט, הוא בבית.
- שלום, בוקר טוב / בוקר אור, מה שלומך?, בסדר, תודה, בבקשה, סליחה, להתראות.
:::
