# 11. Infinitivo, modales y negación

El infinitivo empieza por לְ־ «a, para»: לִכְתֹּב *likhtov* «escribir», לִלְמֹד *lilmod* «aprender», לְדַבֵּר *ledaber* «hablar». Es la forma que sigue a todo verbo modal y a todo verbo de querer o empezar.

## Los infinitivos por binyan

| Binyan | Esquema | Ejemplo |
|---|---|---|
| pa'al | לִ־ ־ֹ־ | לִכְתֹּב *likhtov* escribir |
| pi'el | לְ־ ־ַ־ ־ֵ־ | לְדַבֵּר *ledaber* hablar |
| hif'il | לְהַ־ ־ִי־ | לְהַתְחִיל *lehatchil* empezar |
| hitpa'el | לְהִתְ־ | לְהִתְלַבֵּשׁ *lehitlabesh* vestirse |

## Los modales

| Sentido | m. sg. | f. sg. | pl. |
|---|---|---|---|
| querer | רוֹצֶה *rotse* | רוֹצָה *rotsa* | רוֹצִים *rotsim* |
| poder | יָכוֹל *yakhol* | יְכוֹלָה *yekhola* | יְכוֹלִים *yekholim* |
| tener que | צָרִיךְ *tsarikh* | צְרִיכָה *tsrikha* | צְרִיכִים *tsrikhim* |

Concuerdan con el sujeto como cualquier participio presente: אֲנִי רוֹצָה לִלְמֹד «yo (f.) quiero aprender». Dos palabras impersonales no concuerdan: אֶפְשָׁר *efshar* «es posible, se puede» y אָסוּר *asur* «está prohibido». De ahí אָסוּר לְעַשֵּׁן «prohibido fumar».

## La negación

| Palabra | Uso | Ejemplo |
|---|---|---|
| לֹא *lo* | verbos, adjetivos, «no» | אֲנִי לֹא יָכוֹל «no puedo» |
| אֵין *ein* | «no hay» | אֵין זְמַן «no hay tiempo» |
| אַל *al* | prohibición, con el futuro | אַל תִּשְׁכַּח «no olvides» |

אֵין es la negación de יֵשׁ, y con לְ la de «tener»: אֵין לִי זְמַן «no tengo tiempo».

- הִיא ___ לִשְׁתּוֹת. → ((רוֹצֶה / רוֹצָה* / רוֹצִים))
- אֲנַחְנוּ ___ לָלֶכֶת. → ((צָרִיךְ / צְרִיכָה / צְרִיכִים*))

- ___ לְעַשֵּׁן כָּאן. → ((אָסוּר* / רוֹצֶה / יְכוֹלָה))
:::

::: exercise negative
¿Qué palabra negativa encaja?

- ___ לִי כֶּסֶף. → ((לֹא / אֵין* / אַל))
- ___ תִּשְׁכַּח! → ((לֹא / אֵין / אַל*))
- אֲנִי ___ מֵבִין. → ((לֹא* / אֵין / אַל))
- ___ כָּאן אַף אֶחָד. → ((לֹא / אֵין* / אַל))
:::

::: exercise translate
Traduzca.

- אֲנִי רוֹצֶה לִלְמֹד עִבְרִית. → {{Quiero aprender hebreo.}}
- אֶפְשָׁר לְדַבֵּר אִתְּךָ? → {{¿Puedo hablar contigo? / ¿Se puede hablar contigo?}}
- אֵין לִי זְמַן. → {{No tengo tiempo.}}
- אַתְּ צְרִיכָה לָלֶכֶת. → {{Tienes que irte. / Tienes que ir.}}
:::

::: summary
- Infinitivo: לכתוב, לדבר, להתחיל, להתלבש.
- Los modales concuerdan: רוצה, יכול, צריך + infinitivo; אפשר y אסור no.
- Negación: לא para los verbos, אין para «no hay», אל para las prohibiciones.
:::
