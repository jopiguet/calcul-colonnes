# 11. Infinitif, modaux et négation

L'infinitif commence par לְ־ « à, pour » : לִכְתֹּב *likhtov* « écrire », לִלְמֹד *lilmod* « apprendre », לְדַבֵּר *ledaber* « parler ». C'est la forme qui suit chaque verbe modal et chaque verbe de volonté ou de commencement.

## Les infinitifs par binyan

| Binyan | Schème | Exemple |
|---|---|---|
| pa'al | לִ־ ־ֹ־ | לִכְתֹּב *likhtov* écrire |
| pi'el | לְ־ ־ַ־ ־ֵ־ | לְדַבֵּר *ledaber* parler |
| hif'il | לְהַ־ ־ִי־ | לְהַתְחִיל *lehatchil* commencer |
| hitpa'el | לְהִתְ־ | לְהִתְלַבֵּשׁ *lehitlabesh* s'habiller |

## Les modaux

| Sens | m. sg. | f. sg. | pl. |
|---|---|---|---|
| vouloir | רוֹצֶה *rotse* | רוֹצָה *rotsa* | רוֹצִים *rotsim* |
| pouvoir | יָכוֹל *yakhol* | יְכוֹלָה *yekhola* | יְכוֹלִים *yekholim* |
| devoir | צָרִיךְ *tsarikh* | צְרִיכָה *tsrikha* | צְרִיכִים *tsrikhim* |

Ils s'accordent avec le sujet comme tout participe présent : אֲנִי רוֹצָה לִלְמֹד « je (f.) veux apprendre ». Deux mots impersonnels ne s'accordent pas : אֶפְשָׁר *efshar* « il est possible, on peut » et אָסוּר *asur* « il est interdit ». D'où אָסוּר לְעַשֵּׁן « défense de fumer ».

## La négation

| Mot | Emploi | Exemple |
|---|---|---|
| לֹא *lo* | verbes, adjectifs, « non » | אֲנִי לֹא יָכוֹל « je ne peux pas » |
| אֵין *ein* | « il n'y a pas » | אֵין זְמַן « il n'y a pas le temps » |
| אַל *al* | interdiction, avec le futur | אַל תִּשְׁכַּח « n'oublie pas » |

אֵין est la négation de יֵשׁ, et avec לְ celle de « avoir » : אֵין לִי זְמַן « je n'ai pas le temps ».

::: exercise infinitive
Écrivez l'infinitif, sans niqqud.

- כתב, pa'al → [[לכתוב]]
- למד, pa'al → [[ללמוד]]
- דבר, pi'el → [[לדבר]]
- אכל, pa'al → [[לאכול]]
:::

::: exercise agree
Choisissez la forme accordée.

- הִיא ___ לִשְׁתּוֹת. → ((רוֹצֶה / רוֹצָה* / רוֹצִים))
- אֲנַחְנוּ ___ לָלֶכֶת. → ((צָרִיךְ / צְרִיכָה / צְרִיכִים*))
- הוּא לֹא ___ לָבוֹא. → ((יָכוֹל* / יְכוֹלָה / יְכוֹלִים))
- ___ לְעַשֵּׁן כָּאן. → ((אָסוּר* / רוֹצֶה / יְכוֹלָה))
:::

::: exercise negative
Quel mot de négation convient ?

- ___ לִי כֶּסֶף. → ((לֹא / אֵין* / אַל))
- ___ תִּשְׁכַּח! → ((לֹא / אֵין / אַל*))
- אֲנִי ___ מֵבִין. → ((לֹא* / אֵין / אַל))
- ___ כָּאן אַף אֶחָד. → ((לֹא / אֵין* / אַל))
:::

::: exercise translate
Traduisez.

- אֲנִי רוֹצֶה לִלְמֹד עִבְרִית. → {{Je veux apprendre l'hébreu.}}
- אֶפְשָׁר לְדַבֵּר אִתְּךָ? → {{Je peux te parler ? / Puis-je te parler ?}}
- אֵין לִי זְמַן. → {{Je n'ai pas le temps.}}
- אַתְּ צְרִיכָה לָלֶכֶת. → {{Tu dois partir. / Tu dois y aller.}}
:::

::: summary
- Infinitif : לכתוב, לדבר, להתחיל, להתלבש.
- Les modaux s'accordent : רוצה, יכול, צריך + infinitif ; אפשר et אסור non.
- Négation : לא pour les verbes, אין pour « il n'y a pas », אל pour les interdictions.
:::
