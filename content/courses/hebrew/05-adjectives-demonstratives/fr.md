# 5. Les adjectifs et « ce »

L'adjectif hébreu suit son nom et s'accorde avec lui en genre, en nombre et en détermination : l'article se met sur les deux. C'est cette dernière règle qui distingue « la grande maison » de « la maison est grande ». Les démonstratifs « ce, ces » suivent le même modèle.

## Les formes de l'adjectif

| | Masculin | Féminin |
|---|---|---|
| singulier | גָּדוֹל *gadol* | גְּדוֹלָה *gdola* |
| pluriel | גְּדוֹלִים *gdolim* | גְּדוֹלוֹת *gdolot* |

Les terminaisons sont celles des noms : ה *-a*, ים *-im*, וֹת *-ot*. Adjectifs courants : קָטָן *katan* petit, חָדָשׁ *chadash* nouveau, יָשָׁן *yashan* vieux, יָפֶה *yafe* beau (f. יָפָה *yafa*), טוֹב *tov* bon, רַע *ra* mauvais.

## Groupe ou phrase

| Hébreu | Structure | Sens |
|---|---|---|
| בַּיִת גָּדוֹל *bayit gadol* | tous deux indéfinis | une grande maison |
| הַבַּיִת הַגָּדוֹל *ha-bayit ha-gadol* | article sur les deux | la grande maison |
| הַבַּיִת גָּדוֹל *ha-bayit gadol* | article sur le nom seul | la maison est grande |
| עִיר יָפָה *ir yafa* | féminin | une belle ville |

## « Ce » et « ces »

| | Masculin | Féminin |
|---|---|---|
| ce, ceci | זֶה *ze* | זֹאת *zot* |
| ces | אֵלֶּה *ele* | אֵלֶּה *ele* |

זֶה סֵפֶר *ze sefer* est une phrase, « c'est un livre ». הַסֵּפֶר הַזֶּה *ha-sefer ha-ze* est un groupe, « ce livre » : le démonstratif vient après le nom et prend l'article comme un adjectif.

::: exercise agree
Quelle forme s'accorde ?

- עִיר … « belle » → ((יָפֶה / יָפָה* / יָפִים))
- סְפָרִים … « nouveaux » → ((חֲדָשִׁים* / חֲדָשׁוֹת / חָדָשׁ))
- מוֹרוֹת … « bonnes » → ((טוֹבִים / טוֹבוֹת* / טוֹבָה))
- le duel יָדַיִם « mains » prend → ((des adjectifs au féminin pluriel* / le masculin singulier))
:::

::: exercise phrase
Groupe ou phrase ?

- הַבַּיִת הַגָּדוֹל → ((la grande maison* / la maison est grande))
- הַבַּיִת גָּדוֹל → ((la grande maison / la maison est grande*))
- זֶה סֵפֶר → ((ce livre / c'est un livre*))
- הַסֵּפֶר הַזֶּה → ((ce livre* / c'est un livre))
:::

::: exercise translate
Traduisez.

- הָעִיר הַזֹּאת יָפָה. → {{Cette ville est belle.}}
- יֵשׁ לִי מַחְבֶּרֶת חֲדָשָׁה. → {{J'ai un nouveau cahier. / J'ai un cahier neuf.}}
- אֵלֶּה סְפָרִים טוֹבִים. → {{Ce sont de bons livres.}}
- הַיֶּלֶד הַקָּטָן בַּבַּיִת. → {{Le petit garçon est à la maison. / Le petit enfant est dans la maison.}}
:::

::: summary
- Adjectif après le nom, accordé : גדול, גדולה, גדולים, גדולות.
- Article sur les deux : הבית הגדול « la grande maison » ; sur le nom seul : הבית גדול « la maison est grande ».
- זה, זאת, אלה : זה ספר « c'est un livre », הספר הזה « ce livre ».
:::
