# 6. Las preposiciones, «de», «tener»

Cuatro de las preposiciones más corrientes son letras solas unidas a la palabra siguiente: בְּ «en», לְ «a, para», מִ «de, desde», כְּ «como». Las preposiciones llevan sufijos pronominales: לִי *li* «a mí», שֶׁלִּי *sheli* «mío». Y «tener» se dice «hay a mí»: יֵשׁ לִי *yesh li*.

## Las preposiciones

| Preposición | Sentido | Ejemplo |
|---|---|---|
| בְּ *be-* | en | בְּתֵל אָבִיב en Tel Aviv |
| לְ *le-* | a, para | לִירוּשָׁלַיִם a Jerusalén |
| מִ / מִן *mi- / min* | de, desde | מִפָּרִיז de París |
| כְּ *ke-* | como | כְּמוֹ *kmo* como |
| עַל *al* | sobre, acerca de | עַל הַשֻּׁלְחָן sobre la mesa |
| עִם *im* | con | עִם חֲבֵרִים con amigos |
| לְיַד *leyad* | junto a | לְיַד הַבַּיִת junto a la casa |
| בִּשְׁבִיל *bishvil* | para | בִּשְׁבִילְךָ para ti |

## Los sufijos: לְ «a» y שֶׁל «de»

| Persona | לְ | שֶׁל (posesión) |
|---|---|---|
| yo | לִי *li* | שֶׁלִּי *sheli* mío |
| tú (m.) | לְךָ *lekha* | שֶׁלְּךָ *shelkha* |
| tú (f.) | לָךְ *lakh* | שֶׁלָּךְ *shelakh* |
| él | לוֹ *lo* | שֶׁלּוֹ *shelo* |
| ella | לָהּ *la* | שֶׁלָּהּ *shela* |
| nosotros | לָנוּ *lanu* | שֶׁלָּנוּ *shelanu* |
| vosotros | לָכֶם *lakhem* | שֶׁלָּכֶם *shelakhem* |
| ellos | לָהֶם *lahem* | שֶׁלָּהֶם *shelahem* |

«Mi libro» es הַסֵּפֶר שֶׁלִּי *ha-sefer sheli*, «el libro de mí»: el sustantivo conserva su artículo.

## «Tener» y la marca de objeto

יֵשׁ *yesh* «hay» y אֵין *ein* «no hay» son invariables: יֵשׁ לִי אָח *yesh li ach* «tengo un hermano», אֵין לָנוּ זְמַן *ein lanu zman* «no tenemos tiempo». Un objeto directo definido lleva delante אֶת *et*: אֲנִי רוֹאֶה אֶת הַיֶּלֶד «veo al niño»; sin artículo, no hay אֶת: אֲנִי רוֹאֶה יֶלֶד. Con sufijos: אוֹתִי *oti* me, אוֹתְךָ *otkha* te, אוֹתוֹ *oto* lo.

::: summary
- בְּ, לְ, מִ, כְּ unidas a la palabra; עַל, עִם, לְיַד, בִּשְׁבִיל separadas.
- לי, לך, לו, לה, לנו…; שלי, שלך, שלו… tras un sustantivo con artículo: הספר שלי.
- יש לי / אין לי «tengo / no tengo»; אֶת ante un objeto definido.
:::
