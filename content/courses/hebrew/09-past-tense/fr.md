# 9. Le passé

Le passé marque la personne par des suffixes, si bien que le pronom peut s'omettre aux première et deuxième personnes : כָּתַבְתִּי *katavti* « j'ai écrit ». La base est la troisième personne du masculin singulier, כָּתַב *katav* « il a écrit », qui est aussi la forme du dictionnaire.

## Le passé du pa'al

| Personne | Suffixe | כָּתַב écrire |
|---|---|---|
| je | ־תִּי *-ti* | כָּתַבְתִּי *katavti* |
| tu (m.) | ־תָּ *-ta* | כָּתַבְתָּ *katavta* |
| tu (f.) | ־תְּ *-t* | כָּתַבְתְּ *katavt* |
| il | — | כָּתַב *katav* |
| elle | ־ָה *-a* | כָּתְבָה *katva* |
| nous | ־נוּ *-nu* | כָּתַבְנוּ *katavnu* |
| vous (m.) | ־תֶּם *-tem* | כְּתַבְתֶּם *ktavtem* |
| vous (f.) | ־תֶּן *-ten* | כְּתַבְתֶּן *ktavten* |
| ils, elles | ־וּ *-u* | כָּתְבוּ *katvu* |

Les mêmes suffixes vont sur tous les verbes de tous les binyanim : דִּבַּרְתִּי *dibarti* « j'ai parlé » (pi'el), הִתְחַלְתִּי *hitchalti* « j'ai commencé » (hif'il). La négation est לֹא : לֹא כָּתַבְתִּי « je n'ai pas écrit ».

## « Être » au passé

| j'étais | tu étais (m. / f.) | il / elle était | nous étions | ils étaient |
|---|---|---|---|---|
| הָיִיתִי *hayiti* | הָיִיתָ / הָיִית *hayita / hayit* | הָיָה / הָיְתָה *haya / hayta* | הָיִינוּ *hayinu* | הָיוּ *hayu* |

הָיָה avec לְ est le passé de « avoir » : הָיָה לִי כֶּלֶב « j'avais un chien ».

## Mots de temps

אֶתְמוֹל *etmol* hier, שִׁלְשׁוֹם *shilshom* avant-hier, לִפְנֵי שָׁנָה *lifnei shana* il y a un an, כְּבָר *kvar* déjà, עוֹד לֹא *od lo* pas encore.

::: summary
- Passé : suffixes ־תי, ־ת, ־ת, —, ־ה, ־נו, ־תם, ־תן, ־ו sur tous les binyanim ; base כתב « il a écrit ».
- היה : הייתי, היית, היה, הייתה, היינו, היו ; היה לי « j'avais ».
- Négation לא ; אתמול, כבר, עוד לא.
:::
