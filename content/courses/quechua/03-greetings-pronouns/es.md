# 3. Saludos y pronombres

En los Andes, saludar es un breve intercambio sobre cómo está uno, y al despedirse se piensa en el próximo encuentro. Esta lección da las frases de una primera conversación y los siete pronombres personales, entre ellos dos palabras para «nosotros».

## Saludos

| Quechua | Significado |
|---|---|
| Napaykullayki. | Te saludo (respetuoso). |
| Allillanchu? | ¿Estás bien? |
| Allillanmi. | Estoy bien. |
| Imaynallan kachkanki? | ¿Cómo estás? |
| Imataq sutiyki? | ¿Cómo te llamas? |
| Sutiyqa Rosa. | Me llamo Rosa. |
| Maymantataq kanki? | ¿De dónde eres? |
| Qusqumanta kani. | Soy del Cusco. |
| Ari. Manan. | Sí. No. |
| Sulpayki. Añay. | Gracias. |
| Tupananchikkama. | Hasta la próxima. |

Cada frase es una palabra con sufijos: *alli-lla-n-chu* «bien-nomás-es-?», *suti-y-qa* «nombre-mi-en cuanto a». Las lecciones siguientes toman estos sufijos uno a uno.

## Los pronombres personales

| | Singular | Plural |
|---|---|---|
| 1.ª | ñuqa yo | ñuqanchik nosotros, contigo; ñuqayku nosotros, sin ti |
| 2.ª | qam tú | qamkuna ustedes |
| 3.ª | pay él, ella | paykuna ellos, ellas |

- *pay* es «él» y «ella»: el quechua no tiene género gramatical.
- *ñuqanchik* incluye a quien escucha: «nosotros, tú y yo». *ñuqayku* lo deja fuera: «nosotros, mi familia y yo, pero no tú».
- Al hablar, en el Cusco se dice a menudo *ñuqanchis*; la ortografía oficial es *ñuqanchik*.
- El plural se forma con *-kuna*: *qam*, *qamkuna*; *pay*, *paykuna*.

- yo → [[ñuqa]]

:::

::: exercise we
¿Qué «nosotros»?

- Le dice a un amigo: «nosotros, tú y yo, vamos al mercado» → ((ñuqanchik* / ñuqayku))
- Le dice a un desconocido: «nosotros, mi familia, vivimos en el Cusco» → ((ñuqanchik / ñuqayku*))
- La profesora dice a la clase: «hoy todos aprendemos quechua» → ((ñuqanchik* / ñuqayku))
- Dos viajeros dicen al posadero: «venimos de Puno» → ((ñuqanchik / ñuqayku*))
:::
