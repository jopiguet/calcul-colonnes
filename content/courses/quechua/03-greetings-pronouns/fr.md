# 3. Salutations et pronoms

Dans les Andes, saluer est un bref échange sur la santé, et l'on se quitte en pensant à la prochaine rencontre. Cette leçon donne les phrases d'une première conversation et les sept pronoms personnels, dont deux mots pour « nous ».

## Salutations

| Quechua | Sens |
|---|---|
| Napaykullayki. | Je te salue (respectueux). |
| Allillanchu? | Tu vas bien ? |
| Allillanmi. | Je vais bien. |
| Imaynallan kachkanki? | Comment vas-tu ? |
| Imataq sutiyki? | Comment t'appelles-tu ? |
| Sutiyqa Rosa. | Je m'appelle Rosa. |
| Maymantataq kanki? | D'où es-tu ? |
| Qusqumanta kani. | Je suis de Cusco. |
| Ari. Manan. | Oui. Non. |
| Sulpayki. Añay. | Merci. |
| Tupananchikkama. | À la prochaine. |

Chaque phrase est un mot avec des suffixes : *alli-lla-n-chu* « bien-juste-c'est-? », *suti-y-qa* « nom-mon-quant à ». Les leçons suivantes prennent ces suffixes un à un.

## Les pronoms personnels

| | Singulier | Pluriel |
|---|---|---|
| 1re | ñuqa je | ñuqanchik nous, toi compris ; ñuqayku nous, sans toi |
| 2e | qam tu | qamkuna vous |
| 3e | pay il, elle | paykuna ils, elles |

- *pay* veut dire « il » et « elle » : le quechua n'a pas de genre grammatical.
- *ñuqanchik* inclut la personne à qui l'on parle : « nous, toi et moi ». *ñuqayku* l'exclut : « nous, ma famille et moi, mais pas toi ».
- À l'oral, Cusco dit souvent *ñuqanchis* ; l'orthographe officielle est *ñuqanchik*.
- Le pluriel se fait avec *-kuna* : *qam*, *qamkuna* ; *pay*, *paykuna*.

::: exercise pronouns
Écrivez le pronom.

- je → [[ñuqa]]
- tu, une personne → [[qam]]
- elle → [[pay]]
- ils → [[paykuna]]
:::

::: exercise we
Quel « nous » ?

- Vous dites à un ami : « nous, toi et moi, allons au marché » → ((ñuqanchik* / ñuqayku))
- Vous dites à un inconnu : « nous, ma famille, habitons Cusco » → ((ñuqanchik / ñuqayku*))
- L'enseignante dit à la classe : « aujourd'hui nous apprenons tous le quechua » → ((ñuqanchik* / ñuqayku))
- Deux voyageurs disent à l'aubergiste : « nous venons de Puno » → ((ñuqanchik / ñuqayku*))
:::
