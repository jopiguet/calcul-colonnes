# 15. Nombres, famille et moments du jour

L'État inca comptait par dizaines et notait ses comptes sur des cordelettes nouées, les *khipu*. Les nombres quechuas sont encore entièrement décimaux. Les mots de la famille, eux, dépendent de qui parle : un homme et une femme n'emploient pas le même mot pour « ma sœur ». Cette leçon donne les deux, et les mots du jour.

## Les nombres

| 1–4 | 5–8 | 9, 10 | 100, 1000 |
|---|---|---|---|
| 1 huk | 5 pichqa | 9 isqun | 100 pachak |
| 2 iskay | 6 suqta | 10 chunka | 1000 waranqa |
| 3 kimsa | 7 qanchis | | |
| 4 tawa | 8 pusaq | | |

- Les dizaines : *iskay chunka* 20, *kimsa chunka* 30.
- Les unités après la dizaine prennent *-yuq* « qui a », ou *-niyuq* après une consonne : *chunka hukniyuq* 11, *chunka iskayniyuq* 12, *chunka kimsayuq* 13, *iskay chunka pichqayuq* 25.
- Après un nombre, pas de pluriel : *kimsa wasi* « trois maisons ».
- L'âge se dit avec *-yuq* : *Iskay chunka watayuqmi kani* « j'ai vingt ans (qui a vingt années) ».

## La famille

| | Dit par un homme | Dit par une femme |
|---|---|---|
| frère | wawqi | turi |
| sœur | pana | ñaña |
| fils | churi | wawa |
| fille | ususi | wawa |

*tayta* et *mama* sont le père et la mère ; *hatun tayta* et *hatun mama* le grand-père et la grand-mère ; *qhari* homme, *warmi* femme, épouse.

::: exercise sibling
Juan est un homme, Rosa une femme. Quel mot ?

- la sœur de Juan → ((pana* / ñaña))
- la sœur de Rosa → ((pana / ñaña*))
- le frère de Rosa → ((wawqi / turi*))
- le frère de Juan → ((wawqi* / turi))
:::

## Les moments du jour

| Quechua | Sens |
|---|---|
| tutamanta | le matin |
| chawpi p'unchaw | midi |
| ch'isi | le soir |
| tuta | la nuit |

::: exercise translate
Traduisez.

- Kimsa wawqiymi kan. → {{J'ai trois frères.}}
- Pachak wata. → {{Cent ans.}}
- Tutamanta llamk'ani. → {{Je travaille le matin.}}
- Iskay chunka watayuqmi kani. → {{J'ai vingt ans.}}
:::

::: summary
- huk, iskay, kimsa, tawa, pichqa, suqta, qanchis, pusaq, isqun, chunka ; pachak 100, waranqa 1000.
- 11 *chunka hukniyuq*, 20 *iskay chunka* ; pas de pluriel après un nombre.
- Un homme dit *wawqi, pana, churi, ususi* ; une femme *turi, ñaña, wawa*.
- *tutamanta, chawpi p'unchaw, ch'isi, tuta*.
:::
