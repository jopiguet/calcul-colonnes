# 4. Être, oui et non

*kay* « être » est le premier verbe à apprendre, et les phrases les plus simples n'en ont besoin qu'une fois sur deux : « elle est enseignante » n'a pas de verbe en quechua. Cette leçon donne *kay*, le suffixe *-mi* de l'affirmation simple, et *-chu*, qui fait les questions comme les négations.

## kay, être

| Personne | Forme | Sens |
|---|---|---|
| ñuqa | kani | je suis |
| qam | kanki | tu es |
| pay | kan | il, elle est |
| ñuqanchik | kanchik | nous sommes (toi compris) |
| ñuqayku | kayku | nous sommes (sans toi) |
| qamkuna | kankichik | vous êtes |
| paykuna | kanku | ils, elles sont |

Les terminaisons *-ni, -nki, -n, -nchik, -yku, -nkichik, -nku* sont celles de tous les verbes au présent (leçon 8). Le pronom peut tomber, puisque la terminaison dit la personne : *Qusqumanta kani* « je suis de Cusco ».

- ñuqa → [[kani]]
- qam → [[kanki]]
- ñuqayku → [[kayku]]
- paykuna → [[kanku]]
:::

## L'affirmation : -mi

Une affirmation simple met *-mi* sur son mot clé : *-mi* après une consonne, *-n* après une voyelle. Au présent, « il, elle est » ne se dit pas :

| Quechua | Sens |
|---|---|
| Pay yachachiqmi. | Elle est enseignante. |
| Ñuqa yachachiqmi kani. | Je suis enseignant. |
| Wasiqa hatunmi. | La maison est grande. |
| Allinmi. | C'est bien. |

L'adjectif précède son nom : *hatun wasi* « une grande maison », *huch'uy wasi* « une petite maison », *sumaq t'ika* « une belle fleur ». La leçon 9 en dit plus sur *-mi*.

## Questions et négation : -chu

*-chu* sur le mot clé pose une question fermée. Précédé de *mana* « ne … pas », le même *-chu* fait une négation :

| Affirmation | Question | Négation |
|---|---|---|
| Yachachiqmi kanki. | Yachachiqchu kanki? | Mana yachachiqchu kanki. |
| Hatunmi. | Hatunchu? | Mana hatunchu. |

La réponse : *Ari, yachachiqmi kani* « Oui, je suis enseignant » ; *Manan, mana yachachiqchu kani* « Non, je ne suis pas enseignant ».

::: summary
- kay : kani, kanki, kan, kanchik, kayku, kankichik, kanku ; « il, elle est » omis au présent.
- *-mi* (après une voyelle *-n*) marque l'affirmation simple : *Allinmi*.
- *-chu* interroge : *Hatunchu?* ; *mana … -chu* nie : *Mana hatunchu*.
- L'adjectif vient d'abord : *hatun wasi*.
:::
