# 8. El presente y el progresivo

Un verbo quechua es una raíz seguida de sufijos: el tiempo y luego la persona. La forma del diccionario acaba en *-y*: *rimay* «hablar», raíz *rima-*. Esta lección da el presente, sobre el que se construyen los demás tiempos, y *-chka-*, que dice que algo está pasando ahora.

## El presente

| Persona | rimay, hablar | |
|---|---|---|
| ñuqa | rimani | hablo |
| qam | rimanki | hablas |
| pay | riman | habla |
| ñuqanchik | rimanchik | hablamos (contigo) |
| ñuqayku | rimayku | hablamos (sin ti) |
| qamkuna | rimankichik | ustedes hablan |
| paykuna | rimanku | ellos hablan |

Todos los verbos siguen este modelo; casi no hay verbos irregulares. El presente dice lo que se hace ahora y lo que se hace por costumbre: *Runasimita rimani* «hablo quechua».

## Estar haciendo: -chka-

*-chka-* va entre la raíz y la persona: *rima-chka-ni* «estoy hablando». Con *kay* da «estar, ahora, en algún sitio»: *Wasipin kachkani* «estoy en casa»; *Imaynallan kachkanki?* «¿Cómo estás?». El quechua boliviano dice a menudo *-sha-*: *rimashani*.

| Verbo | Significado | Progresivo |
|---|---|---|
| upyay | beber | upyachkani, estoy bebiendo |
| puñuy | dormir | puñuchkan, está durmiendo |
| ruway | hacer | ruwachkanki, estás haciendo |
| takiy | cantar | takichkanku, están cantando |
| tusuy | bailar | tusuchkanchik, estamos bailando |
| rikuy | ver | rikuchkayku, estamos viendo |

::: summary
- Presente: raíz + *-ni, -nki, -n, -nchik, -yku, -nkichik, -nku*: *rimani, rimanki, riman*.
- *-chka-* «ahora mismo»: *rimachkani* «estoy hablando»; *kachkani* «estoy (aquí, ahora)».
- Verbos: *rimay, llamk'ay, upyay, puñuy, ruway, takiy, tusuy, rikuy*.
:::
