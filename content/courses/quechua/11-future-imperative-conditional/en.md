# 11. Future, commands and wishes

The future has its own endings, which mix with the present: "you will speak" is the same word as "you speak". Commands are short, and a request is softened with suffixes rather than with "please". This lesson gives the future, the imperative, the prohibition with *ama*, and the conditional of wishes.

## The future

| Person | riy, to go | |
|---|---|---|
| ñuqa | risaq | I will go |
| qam | rinki | you will go |
| pay | rinqa | he, she will go |
| ñuqanchik | risunchik | we will go (you included) |
| ñuqayku | risaqku | we will go (you excluded) |
| qamkuna | rinkichik | you all will go |
| paykuna | rinqaku | they will go |

The second persons are those of the present: *rinki* is "you go" and "you will go".

## Commands

| Form | Meaning |
|---|---|
| Mikhuy! | Eat! (you) |
| Mikhuychik! | Eat! (you all) |
| Mikhuchun. | Let him, her eat. |
| Mikhusun! | Let's eat! |
| Ama mikhuychu! | Don't eat! |

- The command to one person is the dictionary form: *mikhuy* "to eat" and "eat!".
- "Don't" is *ama* with the command and *-chu*: *Ama waqaychu* "Don't cry".
- "Let's go!" is usually *Haku!*; *Risun!* says the same.
- A request is made polite with *-yku-* and *-lla-*: *Yaykuykuy* "Please come in", *Tiyaykuy* "Please sit down".

## Wishes: the conditional

| Person | munay, to want | |
|---|---|---|
| ñuqa | munayman | I would like |
| qam | munawaq | you would like |
| pay | munanman | he, she would like |
| ñuqanchik | munanchikman | we would like (you included) |
| ñuqayku | munaykuman | we would like (you excluded) |
| qamkuna | munawaqchik | you all would like |
| paykuna | munankuman | they would like |

*Yakuta munayman* "I would like some water" is the polite way to ask.

::: summary
- Future: *-saq, -nki, -nqa, -sunchik, -saqku, -nkichik, -nqaku*.
- Command: *mikhuy!, mikhuychik!, mikhuchun, mikhusun!*; *Ama … -chu* "don't"; *Haku!* "let's go".
- Polite: *Yaykuykuy, tiyaykuy*.
- Conditional: *munayman* "I would like", *munawaq, munanman …*.
:::
