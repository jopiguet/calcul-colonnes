# 11. Futuro, órdenes y deseos

El futuro tiene sus propias terminaciones, mezcladas con las del presente: «hablarás» es la misma palabra que «hablas». Las órdenes son cortas, y un pedido se suaviza con sufijos más que con «por favor». Esta lección da el futuro, el imperativo, la prohibición con *ama* y el condicional de los deseos.

## El futuro

| Persona | riy, ir | |
|---|---|---|
| ñuqa | risaq | iré |
| qam | rinki | irás |
| pay | rinqa | irá |
| ñuqanchik | risunchik | iremos (contigo) |
| ñuqayku | risaqku | iremos (sin ti) |
| qamkuna | rinkichik | ustedes irán |
| paykuna | rinqaku | ellos irán |

Las segundas personas son las del presente: *rinki* es «vas» e «irás».

## Las órdenes

| Forma | Significado |
|---|---|
| Mikhuy! | ¡Come! |
| Mikhuychik! | ¡Coman! |
| Mikhuchun. | Que coma. |
| Mikhusun! | ¡Comamos! |
| Ama mikhuychu! | ¡No comas! |

- La orden a una persona es la forma del diccionario: *mikhuy* «comer» y «¡come!».
- «No» en una orden es *ama* con el imperativo y *-chu*: *Ama waqaychu* «No llores».
- «¡Vamos!» suele ser *Haku!*; *Risun!* dice lo mismo.
- Un pedido se hace cortés con *-yku-* y *-lla-*: *Yaykuykuy* «Pasa, por favor», *Tiyaykuy* «Siéntate, por favor».

## Los deseos: el condicional

| Persona | munay, querer | |
|---|---|---|
| ñuqa | munayman | quisiera |
| qam | munawaq | quisieras |
| pay | munanman | quisiera (él, ella) |
| ñuqanchik | munanchikman | quisiéramos (contigo) |
| ñuqayku | munaykuman | quisiéramos (sin ti) |
| qamkuna | munawaqchik | ustedes quisieran |
| paykuna | munankuman | ellos quisieran |

*Yakuta munayman* «quisiera agua» es la manera cortés de pedir.

- ¡No te vayas! → ((Ama riychu!* / Mana rinichu. / Risaq.))
:::

::: summary
- Futuro: *-saq, -nki, -nqa, -sunchik, -saqku, -nkichik, -nqaku*.
- Orden: *mikhuy!, mikhuychik!, mikhuchun, mikhusun!*; *Ama … -chu* «no»; *Haku!* «vamos».
- Cortesía: *Yaykuykuy, tiyaykuy*.
- Condicional: *munayman* «quisiera», *munawaq, munanman …*.
:::
