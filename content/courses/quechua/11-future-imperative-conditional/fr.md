# 11. Futur, ordres et souhaits

Le futur a ses propres terminaisons, mêlées à celles du présent : « tu parleras » est le même mot que « tu parles ». Les ordres sont courts, et une demande s'adoucit par des suffixes plutôt que par « s'il te plaît ». Cette leçon donne le futur, l'impératif, la défense avec *ama* et le conditionnel des souhaits.

## Le futur

| Personne | riy, aller | |
|---|---|---|
| ñuqa | risaq | j'irai |
| qam | rinki | tu iras |
| pay | rinqa | il, elle ira |
| ñuqanchik | risunchik | nous irons (toi compris) |
| ñuqayku | risaqku | nous irons (sans toi) |
| qamkuna | rinkichik | vous irez |
| paykuna | rinqaku | ils iront |

Les deuxièmes personnes sont celles du présent : *rinki* veut dire « tu vas » et « tu iras ».

## Les ordres

| Forme | Sens |
|---|---|
| Mikhuy! | Mange ! |
| Mikhuychik! | Mangez ! |
| Mikhuchun. | Qu'il, qu'elle mange. |
| Mikhusun! | Mangeons ! |
| Ama mikhuychu! | Ne mange pas ! |

- L'ordre à une personne est la forme du dictionnaire : *mikhuy* « manger » et « mange ! ».
- « Ne … pas » se dit *ama* avec l'impératif et *-chu* : *Ama waqaychu* « Ne pleure pas ».
- « Allons-y ! » se dit d'ordinaire *Haku!* ; *Risun!* dit la même chose.
- Une demande se fait polie avec *-yku-* et *-lla-* : *Yaykuykuy* « Entre, je t'en prie », *Tiyaykuy* « Assieds-toi, je t'en prie ».

## Les souhaits : le conditionnel

| Personne | munay, vouloir | |
|---|---|---|
| ñuqa | munayman | je voudrais |
| qam | munawaq | tu voudrais |
| pay | munanman | il, elle voudrait |
| ñuqanchik | munanchikman | nous voudrions (toi compris) |
| ñuqayku | munaykuman | nous voudrions (sans toi) |
| qamkuna | munawaqchik | vous voudriez |
| paykuna | munankuman | ils voudraient |

*Yakuta munayman* « je voudrais de l'eau » est la façon polie de demander.

- Assieds-toi, je t'en prie. → ((Tiyaykuy.* / Tiyay. / Tiyasaq.))

- Ne pars pas ! → ((Ama riychu!* / Mana rinichu. / Risaq.))
:::

::: summary
- Futur : *-saq, -nki, -nqa, -sunchik, -saqku, -nkichik, -nqaku*.
- Ordre : *mikhuy!, mikhuychik!, mikhuchun, mikhusun!* ; *Ama … -chu* « ne … pas » ; *Haku!* « allons-y ».
- Politesse : *Yaykuykuy, tiyaykuy*.
- Conditionnel : *munayman* « je voudrais », *munawaq, munanman …*.
:::
