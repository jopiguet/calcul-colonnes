# 10. Dos pasados: -rqa- y -sqa-

El quechua tiene dos tiempos pasados, y la elección entre ellos sigue la lógica de los evidenciales. *-rqa-* cuenta lo que uno presenció; *-sqa-* lo que no vio, lo que supo después o lo que descubre con sorpresa. Todo cuento empieza con *-sqa-*.

## El pasado presenciado: -rqa-

| Persona | puñuy, dormir | |
|---|---|---|
| ñuqa | puñurqani | dormí |
| qam | puñurqanki | dormiste |
| pay | puñurqan | durmió |
| ñuqanchik | puñurqanchik | dormimos (contigo) |
| ñuqayku | puñurqayku | dormimos (sin ti) |
| qamkuna | puñurqankichik | ustedes durmieron |
| paykuna | puñurqanku | ellos durmieron |

*-rqa-* va entre la raíz y las terminaciones del presente.

## El pasado no presenciado: -sqa-

| Persona | kay, ser | |
|---|---|---|
| ñuqa | kasqani | había sido (sin saberlo) |
| qam | kasqanki | habías sido |
| pay | kasqa | había sido, era |
| ñuqanchik | kasqanchik | habíamos sido (contigo) |
| ñuqayku | kasqayku | habíamos sido (sin ti) |
| qamkuna | kasqankichik | ustedes habían sido |
| paykuna | kasqaku | ellos habían sido |

- Las terceras personas son *-sqa* y *-sqaku*, sin *-n*.
- *-sqa-* es el pasado de los cuentos, de lo que a uno le contaron y de lo que descubre: el gato *se había comido* la carne, solo se ve el plato vacío.
- Con *ñuqa*, dice que uno no se dio cuenta: *Puñusqani* «me había quedado dormido (sin darme cuenta)».
- Un cuento empieza con *Huk kutis … kasqa* «Dicen que una vez había …».

::: exercise sqa
Escriba la forma con -sqa-.

- había, en un cuento → [[kasqa]]
- se habían ido, resulta → [[risqaku]]

:::

::: exercise choose
¿-rqa- o -sqa-?

- Usted vio llegar a su hermano ayer. → ((hamurqan* / hamusqa))
- Encuentra el plato vacío: el gato había comido. → ((mikhurqan / mikhusqa*))
- El cuento de la abuela: había un zorro. → ((karqan / kasqa*))
- Usted mismo trabajó ayer. → ((llamk'arqani* / llamk'asqani))
:::

## Palabras de tiempo

| Quechua | Significado |
|---|---|
| qayna p'unchaw | ayer |
| p'unchaw | día |
| wata | año |
| ñawpaq | antes, antiguamente |
| huk kuti | una vez |

::: exercise translate
Traduzca.

- Qayna p'unchaw Qusquman rirqani. → {{Ayer fui al Cusco. / Ayer fui a Cusco.}}
- Huk kutis huk atuq kasqa. → {{Había una vez un zorro. / Dicen que una vez había un zorro.}}
- Misi aychata mikhusqa. → {{El gato se había comido la carne. / El gato comió la carne.}}
- Ñawpaqqa urqupi tiyarqayku. → {{Antes vivíamos en el cerro. / Antes vivíamos en la montaña.}}
:::

::: summary
- *-rqa-*, el pasado presenciado: *puñurqani, puñurqanki, puñurqan …*.
- *-sqa-*, el pasado no presenciado, descubierto o contado: *kasqa, kasqaku*; el pasado de los cuentos.
- *Huk kutis huk atuq kasqa* «Había una vez un zorro».
:::
