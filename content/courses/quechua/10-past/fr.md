# 10. Deux passés : -rqa- et -sqa-

Le quechua a deux temps du passé, et le choix entre eux suit la logique des évidentiels. *-rqa-* raconte ce dont on a été témoin ; *-sqa-* ce qu'on n'a pas vu, qu'on a appris après coup ou qu'on découvre avec surprise. Tout conte commence par *-sqa-*.

## Le passé vu : -rqa-

| Personne | puñuy, dormir | |
|---|---|---|
| ñuqa | puñurqani | j'ai dormi |
| qam | puñurqanki | tu as dormi |
| pay | puñurqan | il, elle a dormi |
| ñuqanchik | puñurqanchik | nous avons dormi (toi compris) |
| ñuqayku | puñurqayku | nous avons dormi (sans toi) |
| qamkuna | puñurqankichik | vous avez dormi |
| paykuna | puñurqanku | ils ont dormi |

*-rqa-* se place entre le radical et les terminaisons du présent.

## Le passé non vu : -sqa-

| Personne | kay, être | |
|---|---|---|
| ñuqa | kasqani | j'étais (sans le savoir) |
| qam | kasqanki | tu étais |
| pay | kasqa | il, elle était |
| ñuqanchik | kasqanchik | nous étions (toi compris) |
| ñuqayku | kasqayku | nous étions (sans toi) |
| qamkuna | kasqankichik | vous étiez |
| paykuna | kasqaku | ils étaient |

- Les troisièmes personnes sont *-sqa* et *-sqaku*, sans *-n*.
- *-sqa-* est le passé des contes, de ce qu'on vous a dit et de ce qu'on découvre : le chat *avait mangé* la viande, on ne voit que l'assiette vide.
- Avec *ñuqa*, il dit qu'on ne s'en est pas rendu compte : *Puñusqani* « je me suis endormi (sans m'en apercevoir) ».
- Un conte s'ouvre sur *Huk kutis … kasqa* « Il était une fois, dit-on, … ».

::: exercise sqa
Écrivez la forme en -sqa-.

- il y avait, dans un conte → [[kasqa]]
- ils étaient partis, à ce qu'il paraît → [[risqaku]]
- il avait mangé → [[mikhusqa]]
- j'avais dormi, sans le savoir → [[puñusqani]]
:::

::: exercise choose
-rqa- ou -sqa- ?

- Vous avez vu votre frère arriver hier. → ((hamurqan* / hamusqa))
- Vous trouvez l'assiette vide : le chat avait mangé. → ((mikhurqan / mikhusqa*))
- Le conte de la grand-mère : il y avait un renard. → ((karqan / kasqa*))
- Vous-même avez travaillé hier. → ((llamk'arqani* / llamk'asqani))
:::

## Mots du temps

| Quechua | Sens |
|---|---|
| qayna p'unchaw | hier |
| p'unchaw | jour |
| wata | année |
| ñawpaq | avant, autrefois |
| huk kuti | une fois |

::: exercise translate
Traduisez.

- Qayna p'unchaw Qusquman rirqani. → {{Hier je suis allé à Cusco. / Hier je suis allée à Cusco.}}
- Huk kutis huk atuq kasqa. → {{Il était une fois un renard.}}
- Misi aychata mikhusqa. → {{Le chat avait mangé la viande. / Le chat a mangé la viande.}}
- Ñawpaqqa urqupi tiyarqayku. → {{Autrefois, nous habitions dans la montagne. / Avant, nous vivions en montagne.}}
:::

::: summary
- *-rqa-*, le passé dont on a été témoin : *puñurqani, puñurqanki, puñurqan …*.
- *-sqa-*, le passé non vu, découvert ou raconté : *kasqa, kasqaku* ; le passé des contes.
- *Huk kutis huk atuq kasqa* « Il était une fois un renard ».
:::
