# 5. Pluriel et possession

Là où le français met « mon » devant le nom, le quechua ajoute un suffixe après : *wasi* « maison », *wasiy* « ma maison ». Les suffixes se suivent ensuite dans un ordre fixe, qui est le cœur de la langue. Cette leçon donne le pluriel, les sept suffixes possessifs et la façon de dire « j'ai ».

## Le pluriel : -kuna

*-kuna* forme le pluriel : *wasikuna* « maisons », *runakuna* « gens », *allqukuna* « chiens ». Après un nombre, le pluriel est inutile : *huk wasi* « une maison » ; la leçon 15 donne les autres nombres.

## Les suffixes possessifs

| Possesseur | Après une voyelle : wasi | Après une consonne : atuq |
|---|---|---|
| mon | wasiy | atuqniy |
| ton | wasiyki | atuqniyki |
| son | wasin | atuqnin |
| notre (toi compris) | wasinchik | atuqninchik |
| notre (sans toi) | wasiyku | atuqniyku |
| votre | wasiykichik | atuqniykichik |
| leur | wasinku | atuqninku |

- Les terminaisons sont celles du verbe (leçon 4), avec *-y*, *-yki*, *-ykichik* à la place de *-ni*, *-nki*, *-nkichik*.
- Après une consonne, *-ni-* s'intercale : *atuq-ni-y* « mon renard ». Peu de noms quechuas finissent par une consonne.
- Le possessif précède le pluriel : *wasi-y-kuna* « mes maisons », *allqu-yki-kuna* « tes chiens ».

## Avoir

Le quechua n'a pas de verbe « avoir » : il dit que la chose possédée existe, avec *kan* « il y a » :

| Quechua | Sens |
|---|---|
| Huk wasiymi kan. | J'ai une maison (une ma-maison il y a). |
| Huk allquykichu kan? | As-tu un chien ? |
| Mana wasiy kanchu. | Je n'ai pas de maison. |
| Wawanmi kan. | Elle a un enfant. |

::: summary
- Pluriel *-kuna* ; aucun après un nombre : *huk wasi*.
- Possessif : *-y, -yki, -n, -nchik, -yku, -ykichik, -nku* ; après une consonne, *-ni-* d'abord : *atuqniy*.
- Ordre : nom, possessif, pluriel : *wasiykuna*.
- « J'ai » : *Huk wasiymi kan* ; « je n'ai pas » : *Mana wasiy kanchu*.
:::
