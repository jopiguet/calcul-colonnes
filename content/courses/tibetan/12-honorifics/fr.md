# 12. Les mots de respect

Le tibétain a un second vocabulaire pour parler des autres avec respect : de leur corps, de leur nom, de ce qu'ils mangent et d'où ils vont. On l'emploie pour les aînés, les invités, les enseignants et les lamas, et jamais pour soi. Les enfants de Lhassa l'apprennent tôt. Cette leçon donne les paires les plus courantes.

## Simple et respectueux

| Simple | Respectueux | Sens |
|---|---|---|
| མིང *ming* | མཚན *mtshan* | nom |
| མགོ *mgo* | དབུ *dbu* | tête |
| ལག་པ *lag pa* | ཕྱག *phyag* | main |
| ཁ *kha* | ཞལ *zhal* | bouche, visage |
| ལུས *lus* | སྐུ་གཟུགས *sku gzugs* | corps, santé |
| ཁ་ལག *kha lag* | ཞལ་ལག *zhal lag* | nourriture |
| ཟ *za* | བཞེས *bzhes* | manger, boire |
| འགྲོ *'gro* | ཕེབས *phebs* | aller, venir |
| སྡོད *sdod* | བཞུགས *bzhugs* | rester, s'asseoir |
| བྱེད *byed* | གནང *gnang* | faire |

- On parle de soi simplement et de l'autre avec respect : ངའི་མིང « mon nom », ཁྱེད་རང་གི་མཚན « votre nom ».
- ཕེབས *phebs* veut dire « aller » et « venir » : ག་ལེ་ཕེབས « va doucement », et *phep* « entrez ».
- Bien des mots de respect sont déjà dans les salutations : སྐུ་གཟུགས dans « comment allez-vous ? », བཞུགས dans ག་ལེ་བཞུགས.

## Les demandes polies

Une demande polie ajoute རོགས་གནང *rogs gnang*, « faites-moi la faveur », après le verbe.

| Écriture | Wylie | Sens |
|---|---|---|
| བཞུགས་རོགས་གནང་། | bzhugs rogs gnang | Asseyez-vous, je vous prie. |
| ཇ་བཞེས་རོགས་གནང་། | ja bzhes rogs gnang | Prenez du thé, je vous prie. |
| ཁྱེད་རང་ག་པར་ཕེབས་ཀྱི་ཡིན། | khyed rang ga par phebs kyi yin | Où irez-vous ? |

Les noms et les mots de la famille prennent ལགས *lags* : ཨ་མ་ལགས *a ma lags* « mère », པ་ལགས *pa lags* « père », *Tenzin la*.

::: exercise request
Laquelle est la demande ?

- Asseyez-vous, je vous prie. → ((བཞུགས་རོགས་གནང་།* / ག་ལེ་བཞུགས།))
- Prenez du thé, je vous prie. → ((ཇ་བཞེས་རོགས་གནང་།* / ཇ་འཐུང་གི་ཡོད།))
- Où irez-vous ? → ((ཁྱེད་རང་ག་པར་ཕེབས་ཀྱི་ཡིན།* / ང་ག་པར་འགྲོ་གི་ཡིན།))
- père, poliment → ((པ་ལགས* / ཕ))
:::

::: summary
- Un mot de respect pour les autres, un mot simple pour soi : མིང *ming* / མཚན *mtshan*, འགྲོ *'gro* / ཕེབས *phebs*, ཟ *za* / བཞེས *bzhes*, སྡོད *sdod* / བཞུགས *bzhugs*.
- རོགས་གནང *rogs gnang* après le verbe fait une demande : བཞུགས་རོགས་གནང « asseyez-vous, je vous prie ».
- ལགས *lags* après les noms et les mots de la famille : ཨ་མ་ལགས *a ma lags*, པ་ལགས *pa lags*.
:::
