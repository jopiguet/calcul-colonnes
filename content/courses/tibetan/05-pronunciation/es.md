# 5. De la ortografía al habla

La ortografía tibetana se fijó hace más de mil años, y el habla de Lhasa la ha simplificado desde entonces: hay letras que enmudecieron, apilamientos que se fundieron en sonidos nuevos, finales que colorearon la vocal. Unas pocas reglas cubren la mayoría de las palabras. Esta lección las da, para leer བཀྲ་ཤིས *bkra shis* *tashi* y བོད *bod* *pö*.

## Las letras mudas

Prefijos y sobrescritas no se pronuncian: solo se oye la raíz y lo que la sigue.

| Escritura | Wylie | Se dice | Significado |
|---|---|---|---|
| མཚོ | mtsho | tsho | lago |
| རྟ | rta | ta | caballo |
| དགུ | dgu | gu | nueve |
| སྐད | skad | ké | habla, lengua |

## Subscritas que cambian el sonido

| Apilamiento | Se dice | Ejemplo | Wylie | Se dice | Significado |
|---|---|---|---|---|---|
| k, g + ya | ky, gy | ཁྱི | khyi | khyi | perro |
| p, ph, b + ya | c, ch, j | བྱ | bya | ja | pájaro |
| k, t, p + ra | tr | བཀྲ་ཤིས | bkra shis | tashi | buena fortuna |
| g, d, b + ra | dr | འབྲས | 'bras | dré | arroz |
| z + la | d | ཟླ་བ | zla ba | dawa | luna |
| g, b + la | l | གླང | glang | lang | buey |

*tr* y *dr* se dicen con la punta de la lengua doblada hacia atrás, como en el inglés de la India.

::: exercise said
¿Cómo se dice?

- མཚོ → ((mtsho / tsho* / mo))
- བྱ → ((bya / ja* / ba))
- ཟླ་བ → ((zlawa / dawa* / lawa))
- གླང → ((glang / lang* / gang))
:::

## Las letras finales

| Final | Efecto | Ejemplo | Wylie | Se dice | Significado |
|---|---|---|---|---|---|
| ད ས ལ ན | a → é, o → ö, u → ü | བོད | bod | pö | Tíbet |
| | | ཡུལ | yul | yü | país |
| | | སྐད | skad | ké | lengua |
| ག བ | una *k*, una *p* breves y contenidas | ལུག | lug | luk | oveja |
| ང མ | una nasal | གངས | gangs | kang | nieve |

- *d* y *s* no se pronuncian; *l* y *n* alargan o nasalizan la vocal.
- Un segundo sufijo ས es mudo: གངས *kang*.
- Son guías del habla de Lhasa; el tono y la duración se aprenden de oído.

::: exercise final
¿Cómo se dice?

- ཡུལ → ((yul / yü* / yu))
- ལུག → ((luk* / lu / lü))
- སྐད → ((skad / ké* / ka))
:::

::: summary
- Prefijos y sobrescritas son mudos: མཚོ *tsho*, རྟ *ta*.
- Subscritas: *ky*, *ch*, *tr*, *dr*: བྱ *ja*, བཀྲ་ཤིས *tashi*, འབྲས *dré*; *zl* se dice *d*: ཟླ་བ *dawa*.
- Las finales *d s l n* cambian la vocal: བོད *pö*, ཡུལ *yü*, སྐད *ké*; *g b* finales son una *k*, una *p* contenidas.
:::
