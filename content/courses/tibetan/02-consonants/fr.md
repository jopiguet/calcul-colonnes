# 2. Les trente lettres

L'alphabet tibétain compte trente consonnes, récitées par rangées de quatre, comme les alphabets indiens. Chaque lettre se dit avec la voyelle *a*. Leurs colonnes comptent pour la prononciation : à Lhassa, les deux premières colonnes se disent sur un ton haut, les deux dernières sur un ton bas. Cette leçon donne les trente lettres.

## L'alphabet

| | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| k | ཀ ka | ཁ kha | ག ga | ང nga |
| c | ཅ ca | ཆ cha | ཇ ja | ཉ nya |
| t | ཏ ta | ཐ tha | ད da | ན na |
| p | པ pa | ཕ pha | བ ba | མ ma |
| ts | ཙ tsa | ཚ tsha | ཛ dza | ཝ wa |
| zh | ཞ zha | ཟ za | འ 'a | ཡ ya |
| r | ར ra | ལ la | ཤ sha | ས sa |
| h | ཧ ha | ཨ a | | |

- Dans les quatre premières rangées, la colonne 1 est simple (*ka*), la colonne 2 soufflée (*kha*, un *k* suivi d'un souffle), la colonne 3 écrite sonore (*ga*), la colonne 4 nasale (*nga*).
- À Lhassa, dans les cinq premières rangées, les colonnes 1 et 2 prennent un ton haut, les colonnes 3 et 4 un ton bas ; *ga*, *da*, *ba* se disent presque comme *ka*, *ta*, *pa* sur une note basse. Dans les dernières rangées, *zha za 'a ya ra la* sont bas, *sha sa ha a* hauts.
- ང *nga* est le son final de l'anglais « sing », ici en début de syllabe : ང *nga* veut dire « je ».
- འ, l'*a-chung*, est le plus souvent muet ; ཨ, l'*a-chen*, porte une voyelle en début de mot.

::: exercise letters
Quelle lettre est-ce ?

- ཀ → ((ka* / kha / ga))
- ཕ → ((pa / pha* / ba))
- ང → ((na / nga* / nya))
- ས → ((sa* / sha / za))
:::

::: exercise columns

- ག → ((colonne 1, ton haut / colonne 3, ton bas*))

- ཏ → ((colonne 1, ton haut* / colonne 3, ton bas))
:::

## Premiers mots

Certains mots tiennent en une ou deux lettres, chacune avec sa voyelle *a* :

| Écriture | Wylie | Prononcé | Sens |
|---|---|---|---|
| ང | nga | nga | je |
| ཇ | ja | ja | thé |
| ཤ | sha | sha | viande |
| ས | sa | sa | terre, sol |
| ཀ་བ | ka ba | kawa | pilier |

::: exercise write

- je → [[ང]]
- thé → [[ཇ]]
- viande → [[ཤ]]
- pilier → [[ཀ་བ]]
:::

::: exercise read
Lisez le mot en Wylie.

- ས → ((sa* / sha / za))
- ཇ → ((ca / ja* / cha))
- ང → ((na / nga* / ga))
- ཀ་བ → ((ka ba* / kha ba / ga ba))
:::

::: summary
- Trente lettres par rangées de quatre : ཀ ཁ ག ང, et ainsi de suite jusqu'à ཧ ཨ.
- Colonne 1 simple, 2 soufflée, 3 écrite sonore, 4 nasale ; à Lhassa, dans les premières rangées, 1 et 2 ton haut, 3 et 4 ton bas.
- Chaque lettre porte *a* : ང *nga* je, ཇ *ja* thé, ཤ *sha* viande, ས *sa* terre.
:::
