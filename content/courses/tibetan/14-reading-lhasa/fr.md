# 14. Lecture : Tenzin de Lhassa

La dernière leçon lit un court texte écrit pour ce cours, où Tenzin, qui habite Lhassa, parle de sa famille et de sa semaine. Il emploie les formes de « être », le présent, le passé et le futur. Elle lit ensuite les six syllabes qu'on voit sur les pierres, les murs et les moulins à prières dans tout le monde tibétain.

## Tenzin

བཀྲ་ཤིས་བདེ་ལེགས། ངའི་མིང་ལ་བསྟན་འཛིན་ཟེར། ང་ལྷ་སར་སྡོད་ཀྱི་ཡོད།

ངའི་ཨ་མ་ལགས་སྨན་པ་རེད། ངའི་པ་ལགས་དགེ་རྒན་རེད། ང་ཚོ་ཉིན་རེ་བོད་ཇ་འཐུང་གི་ཡོད།

ཁ་སང་ང་ཇོ་ཁང་ལ་ཕྱིན་པ་ཡིན། ཇོ་ཁང་གི་ནང་ལ་མི་མང་པོ་འདུག།

སང་ཉིན་ང་ཚོ་གནམ་མཚོར་འགྲོ་གི་ཡིན།

## Les mots du texte

| Écriture | Wylie | Sens |
|---|---|---|
| སྡོད་ཀྱི་ཡོད | sdod kyi yod | j'habite, je reste |
| ཉིན་རེ | nyin re | chaque jour |
| ཇོ་ཁང | jo khang | le Jokhang, le grand temple de Lhassa |
| མི་མང་པོ | mi mang po | beaucoup de gens |
| གནམ་མཚོ | gnam mtsho | le Namtso, « lac céleste » |
| གནམ་མཚོར | gnam mtshor | au Namtso |

- སྨན་པ་རེད, དགེ་རྒན་རེད : *red*, des faits sur les autres.
- འཐུང་གི་ཡོད : ce que nous faisons ; ཕྱིན་པ་ཡིན : ce que j'ai fait ; འགྲོ་གི་ཡིན : ce que nous ferons.
- མི་མང་པོ་འདུག : *'dug*, ce que Tenzin a vu dans le temple.
- Un temple se dit ལྷ་ཁང *lha khang*, « maison des dieux » ; un monastère དགོན་པ *dgon pa*.

## Six syllabes

ཨོཾ་མ་ཎི་པདྨེ་ཧཱུྃ། *oṃ maṇi padme hūṃ*, prononcé *om mani pémé houng* au Tibet, est le mantra d'Avalokiteśvara, le bodhisattva de la compassion, que les Tibétains appellent Chenrezig. C'est du sanskrit écrit en écriture tibétaine, qui montre des lettres réservées au sanskrit : ཎ *ṇa*, le signe de voyelle longue ཱ et les signes nasaux ཾ et ྃ. On le grave sur les pierres *mani*, on le peint sur les rochers, on l'imprime sur les rouleaux de papier des moulins à prières ; tourner le moulin vaut le réciter, selon la tradition.

Les drapeaux de prière s'appellent རླུང་རྟ *rlung rta*, « cheval du vent » : le vent emporte leurs prières imprimées.

::: exercise mantra
Qu'est-ce que c'est ?

- ཨོཾ་མ་ཎི་པདྨེ་ཧཱུྃ། → ((un mantra sanskrit en écriture tibétaine* / une salutation tibétaine / le nom de Lhassa))
- ཎ → ((une lettre pour des sons du sanskrit* / la lettre tibétaine na / un chiffre))
- རླུང་རྟ → ((les drapeaux de prière, « cheval du vent »* / un moulin à prières / une pierre mani))
- Chenrezig est → ((le bodhisattva de la compassion* / une montagne / un temple de Lhassa))
:::

::: summary
- Le texte emploie རེད, འདུག, གི་ཡོད, པ་ཡིན, གི་ཡིན : qui parle, comment il sait, quand.
- ཉིན་རེ *nyin re* chaque jour, ཇོ་ཁང *jo khang* le Jokhang, གནམ་མཚོ *gnam mtsho* le Namtso.
- ཨོཾ་མ་ཎི་པདྨེ་ཧཱུྃ། est du sanskrit en écriture tibétaine ; རླུང་རྟ *rlung rta*, les drapeaux de prière.
:::
