# 11. El pasado, y quién lo hizo

Muchos verbos tibetanos tienen una raíz de pasado aparte: ཟ *za* «comer», བཟས *bzas* «comió»; འགྲོ *'gro* «ir», ཕྱིན *phyin* «fue». En pasado, quien actúa sobre algo lleva una partícula propia, el ergativo: ང *nga* «yo» se vuelve ངས *ngas*. Esta lección da las terminaciones del pasado y el ergativo.

## Las raíces de pasado

| Presente | Pasado | Significado |
|---|---|---|
| ཟ | བཟས | comer |
| འཐུང | བཏུངས | beber |
| འགྲོ | ཕྱིན | ir |
| འབྲི | བྲིས | escribir |
| ཀློག | ཀློགས | leer |

Las raíces de pasado se aprenden con el verbo, como *ir*, *fue*.

## Las terminaciones del pasado

| Quién | Terminación | Ejemplo | Significado |
|---|---|---|---|
| yo, nosotros | པ་ཡིན | ང་ལྷ་སར་ཕྱིན་པ་ཡིན། | Fui a Lhasa. |
| él, ella | སོང | ཁོ་ལྷ་སར་ཕྱིན་སོང་། | Él fue a Lhasa. |

- པ་ཡིན *pa yin* dice lo que hice a propósito.
- སོང *song* dice lo que hizo otro, que quien habla vio o sabe.
- «No» en pasado es མ *ma* delante de la raíz de pasado: ང་མ་ཕྱིན། «no fui».

- Ella fue: མོ་ཕྱིན … → ((པ་ཡིན / སོང*))
- Escribí: ངས་བྲིས … → ((པ་ཡིན* / སོང))
- Él bebió: ཁོས་བཏུངས … → ((པ་ཡིན / སོང*))
:::

## El ergativo

Cuando un verbo actúa sobre algo (comer una comida, escribir una carta), quien actúa lleva la partícula ergativa, que se escribe como el genitivo con *s*:

| Última letra | Ergativo | Ejemplo |
|---|---|---|
| una vocal | ས, unida | ངས yo, ཁོས él, མོས ella |
| ག ང | གིས | ཁོང་གིས él (respetuoso) |
| ད བ ས | ཀྱིས | བཀྲ་ཤིས་ཀྱིས Tashi |
| ན མ ར ལ | གྱིས | བསྟན་འཛིན་གྱིས Tenzin |

| Ejemplo | Significado |
|---|---|
| ངས་ཁ་ལག་བཟས་པ་ཡིན། | Comí (una comida). |
| ཁོས་ཁ་ལག་བཟས་སོང་། | Él comió. |
| ངས་ཡི་གེ་བྲིས་པ་ཡིན། | Escribí una carta. |
| ང་ལྷ་སར་ཕྱིན་པ་ཡིན། | Fui a Lhasa: sin objeto, sin ergativo. |

::: summary
- Raíces de pasado: བཟས *bzas* comió, བཏུངས *btungs* bebió, ཕྱིན *phyin* fue, བྲིས *bris* escribió, ཀློགས *klogs* leyó.
- པ་ཡིན para lo que hice, སོང para lo que hizo otro; མ + raíz de pasado para «no».
- Quien actúa sobre un objeto lleva el ergativo: ངས *ngas*, ཁོས *khos*, གིས, ཀྱིས, གྱིས.
:::
