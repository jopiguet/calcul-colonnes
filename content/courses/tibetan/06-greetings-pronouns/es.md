# 6. Saludos y pronombres

Los saludos tibetanos desean buena fortuna y preguntan por la salud del otro con palabras de respeto. La despedida depende de quién se va: se dice «ve despacio» al que se va y «quédate despacio» al que se queda. Esta lección da los saludos, los pronombres y el *lags* de cortesía.

## Saludos

| Escritura | Wylie | Se dice | Significado |
|---|---|---|---|
| བཀྲ་ཤིས་བདེ་ལེགས། | bkra shis bde legs | tashi delek | hola |
| ཁྱེད་རང་སྐུ་གཟུགས་བདེ་པོ་ཡིན་པས། | khyed rang sku gzugs bde po yin pas | khyerang kusuk depo yinpé | ¿cómo está usted? |
| ལགས་ཡིན། ང་བདེ་པོ་ཡིན། | lags yin, nga bde po yin | la yin, nga depo yin | sí, estoy bien |
| ཐུགས་རྗེ་ཆེ། | thugs rje che | thukjé ché | gracias |
| ག་ལེ་ཕེབས། | ga le phebs | kalé phep | adiós (al que se va) |
| ག་ལེ་བཞུགས། | ga le bzhugs | kalé shuk | adiós (al que se queda) |

- *bkra shis* es «buena fortuna», *bde legs* «bienestar».
- *sku gzugs* es una palabra de respeto para «cuerpo»: se pregunta con cortesía por la salud del otro y se responde con sencillez de la propia.
- ལགས *la* vuelve cortés una palabra: ལགས་སོ *lags so* «sí, claro», ལགས *lags* solo «¿sí?».

## Los nombres

| Escritura | Wylie | Significado |
|---|---|---|
| ཁྱེད་རང་གི་མཚན་ལ་ག་རེ་ཞུ་གི་ཡོད། | khyed rang gi mtshan la ga re zhu gi yod | ¿Cómo se llama usted? |
| ངའི་མིང་ལ་བསྟན་འཛིན་ཟེར། | nga'i ming la bstan 'dzin zer | Me llamo Tenzin. |

Dos palabras para «nombre»: མཚན *tsen*, de respeto, para los demás; མིང *ming*, sencilla, para uno mismo.

## Los pronombres

| | Uno | Varios |
|---|---|---|
| yo, nosotros | ང *nga* | ང་ཚོ *nga tsho* |
| usted (cortés) | ཁྱེད་རང *khyed rang* | ཁྱེད་ཚོ *khyed tsho* |
| tú (familiar) | ཁྱོད *khyod* | |
| él | ཁོ *kho* | ཁོ་ཚོ *kho tsho* |
| ella | མོ *mo* | |
| él, ella (respetuoso) | ཁོང *khong* | ཁོང་ཚོ *khong tsho* |

*tsho* forma el plural de los pronombres. ཁྱེད་རང *khyed rang* es el «usted» corriente con un adulto; ཁོང *khong* el «él, ella» corriente para alguien respetado.

::: summary
- བཀྲ་ཤིས་བདེ་ལེགས *bkra shis bde legs* hola; ཐུགས་རྗེ་ཆེ *thugs rje che* gracias; ག་ལེ་ཕེབས *ga le phebs* al que se va, ག་ལེ་བཞུགས *ga le bzhugs* al que se queda.
- མཚན el nombre de otros, མིང el propio: ངའི་མིང་ལ … ཟེར.
- ང *nga* yo, ཁྱེད་རང *khyed rang* usted, ཁོ *kho* él, མོ *mo* ella, ཁོང *khong* él o ella (respetuoso); plural *tsho*.
- ལགས *lags* *la* vuelve cortés el habla.
:::
