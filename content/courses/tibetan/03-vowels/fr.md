# 3. Les quatre signes de voyelle

Une lettre seule se lit avec *a* ; quatre signes, écrits au-dessus ou au-dessous, changent cette voyelle en *i*, *u*, *e* ou *o*. En début de mot, la voyelle s'écrit sur la lettre support ཨ. Cette leçon lit et écrit des syllabes avec les cinq voyelles.

## Les signes

| Signe | Nom | Voyelle | Avec ཀ | Avec ཨ |
|---|---|---|---|---|
| ི | gigu | i | ཀི ki | ཨི i |
| ུ | zhabkyu | u | ཀུ ku | ཨུ u |
| ེ | drengbu | e | ཀེ ke | ཨེ e |
| ོ | naro | o | ཀོ ko | ཨོ o |

- *gigu*, *drengbu* et *naro* se placent au-dessus de la lettre ; *zhabkyu*, « le pied », en dessous.
- Sans signe, la voyelle est *a* : ཀ *ka*.
- Le support ཨ est muet quand il porte un signe : ཨོ se lit *o*.

::: exercise vowel
Quelle voyelle ?

- མི → ((ma / mi* / mu))
- བུ → ((bu* / bo / be))
- མེ → ((mi / me* / mo))
- ཞོ → ((zho* / zhu / zha))
:::

## Des mots d'une ou deux syllabes

| Écriture | Wylie | Prononcé | Sens |
|---|---|---|---|
| ཆུ | chu | chu | eau |
| རི | ri | ri | montagne |
| མེ | me | me | feu |
| མི | mi | mi | personne |
| བུ | bu | bu | fils, garçon |
| ཞོ | zho | sho | yaourt |

- རི → ((ri* / ra / ro))
- བུ → ((ba / bu* / bo))
- ཨོ → ((a / o* / u))
:::

::: exercise meaning
Que veut dire le mot ?

- མེ → ((eau / feu* / personne))
- ཞོ → ((yaourt* / viande / thé))
- མི → ((personne* / montagne / fils))
- བུ → ((fils, garçon* / feu / eau))
:::

::: summary
- Sans signe : *a*. ི *i*, ུ *u*, ེ *e*, ོ *o*.
- En début de mot, la voyelle se pose sur ཨ : ཨོ *o*.
- ཆུ *chu* eau, རི *ri* montagne, མེ *me* feu, མི *mi* personne, བུ *bu* fils, ཞོ *zho* yaourt.
:::
