# 2. La tabla de los silabarios

Quince formas de consonante, cada una girada para *i*, *u*, *a* y reducida para una final, escriben todo el inuktitut. Aprendidas en tabla, fila por fila, se leen en pocos días. Esta lección da la tabla completa y cómo cortar una palabra en sílabas.

## La tabla

| | i | u | a | final |
|---|---|---|---|---|
| — | ᐃ | ᐅ | ᐊ | |
| p | ᐱ | ᐳ | ᐸ | ᑉ |
| t | ᑎ | ᑐ | ᑕ | ᑦ |
| k | ᑭ | ᑯ | ᑲ | ᒃ |
| g | ᒋ | ᒍ | ᒐ | ᒡ |
| m | ᒥ | ᒧ | ᒪ | ᒻ |
| n | ᓂ | ᓄ | ᓇ | ᓐ |
| s | ᓯ | ᓱ | ᓴ | ᔅ |
| l | ᓕ | ᓗ | ᓚ | ᓪ |
| j | ᔨ | ᔪ | ᔭ | ᔾ |
| v | ᕕ | ᕗ | ᕙ | ᕝ |
| r | ᕆ | ᕈ | ᕋ | ᕐ |
| q | ᕿ | ᖁ | ᖃ | ᖅ |
| ng | ᖏ | ᖑ | ᖓ | ᖕ |
| ł | ᖠ | ᖢ | ᖤ | ᖦ |

- La fila *j* se pronuncia como la *y* de *yo*: ᔪ *ju* suena «yu». La ortografía latina de Nunavut escribe *j*.
- *g* entre vocales es suave, como en *lago*; *r* se dice al fondo de la garganta, como la *r* francesa.
- *ł*, escrita *&* o *lh* en algunos teclados, es una *l* soplada, como la *ll* galesa.
- Cada fila gira para *i*, *u*, *a*: aprendida una fila, cada nueva fila es solo una forma nueva.

::: exercise row-m
Lea la sílaba.

- ᒥ → ((mi* / mu / ma))
- ᓄ → ((ni / nu* / na))
- ᓴ → ((si / su / sa*))
- ᖃ → ((ka / qa* / ga))
:::

::: exercise finals
¿Qué final es?

- ᒃ → ((k* / t / p))
- ᖅ → ((k / q* / ng))
- ᑦ → ((t* / p / n))
- ᖕ → ((n / ng* / g))
:::

## Cortar una palabra en sílabas

Cada sílaba es una vocal, con la consonante que la precede; una consonante sin vocal detrás es una final. *qamutik* «trineo» se corta *qa-mu-ti-k*: ᖃ ᒧ ᑎ ᒃ, ᖃᒧᑎᒃ *qamutik*.

| Latín | Sílabas | Silabarios | Significado |
|---|---|---|---|
| qamutik | qa-mu-ti-k | ᖃᒧᑎᒃ | trineo |
| tuktu | tu-k-tu | ᑐᒃᑐ | caribú |
| qimmiq | qi-m-mi-q | ᕿᒻᒥᖅ | perro |
| siku | si-ku | ᓯᑯ | hielo marino |
| aput | a-pu-t | ᐊᐳᑦ | nieve en el suelo |
| nanuq | na-nu-q | ᓇᓄᖅ | oso polar |

::: exercise transcribe
Escriba en silabarios, o en ortografía latina.

- caribú → [[ᑐᒃᑐ]]
- perro → [[ᕿᒻᒥᖅ]]
- hielo marino → [[ᓯᑯ]]
- oso polar → [[ᓇᓄᖅ]]
:::

::: exercise roman
Lea la palabra.

- ᖃᒧᑎᒃ → ((kamutik / qamutik* / qamutiq))
- ᐊᐳᑦ → ((aput* / apu / apuk))
- ᓯᑯ → ((sika / siku* / suki))
- ᓇᓄᖅ → ((nanuk / nanuq* / nanu))
:::

::: summary
- Quince formas, cada una girada para *i*, *u*, *a*, y una pequeña final: toda la tabla.
- *j* suena «y»; *q* y *r* se dicen al fondo de la garganta; *ł* es una *l* soplada.
- Una palabra se corta en sílabas, cada una una vocal con su consonante: *qa-mu-ti-k*.
- ᖃᒧᑎᒃ *qamutik* trineo, ᑐᒃᑐ *tuktu* caribú, ᕿᒻᒥᖅ *qimmiq* perro, ᓯᑯ *siku* hielo marino, ᓇᓄᖅ *nanuq* oso polar.
:::
