# 2. The syllabics chart

Fifteen consonant shapes, each turned for *i*, *u*, *a* and made small for a final, write all of Inuktitut. Learnt as a chart, row by row, they are read in a few days. This lesson gives the whole chart and how a word is cut into syllables.

## The chart

| | i | u | a | final |
|---|---|---|---|---|
| — | ᐃ | ᐅ | ᐊ | |
| p | ᐱ | ᐳ | ᐸ | ᑉ |
| t | ᑎ | ᑐ | ᑕ | ᑦ |
| k | ᑭ | ᑯ | ᑲ | ᒃ |
| g | ᒋ | ᒍ | ᒐ | ᒡ |
| m | ᒥ | ᒧ | ᒪ | ᒻ |
| n | ᓂ | ᓄ | ᓇ | ᓐ |
| s | ᓯ | ᓱ | ᓴ | ᔅ |
| l | ᓕ | ᓗ | ᓚ | ᓪ |
| j | ᔨ | ᔪ | ᔭ | ᔾ |
| v | ᕕ | ᕗ | ᕙ | ᕝ |
| r | ᕆ | ᕈ | ᕋ | ᕐ |
| q | ᕿ | ᖁ | ᖃ | ᖅ |
| ng | ᖏ | ᖑ | ᖓ | ᖕ |
| ł | ᖠ | ᖢ | ᖤ | ᖦ |

- The *j* row is said as English *y*: ᔪ *ju* is "yu". The Roman spelling of Nunavut writes *j*.
- *g* between vowels is soft, as in Spanish *lago*; *r* is said at the back of the throat, as French *r*.
- *ł*, written *&* or *lh* on some keyboards, is a breathed *l*, as Welsh *ll*.
- Every row turns in the same order, *i*, *u*, *a*: once one row is learnt, each new row is one new shape.

::: exercise row-m
Read the syllable.

- ᒥ → ((mi* / mu / ma))
- ᓄ → ((ni / nu* / na))
- ᓴ → ((si / su / sa*))
- ᖃ → ((ka / qa* / ga))
:::

::: exercise finals
Which final is it?

- ᒃ → ((k* / t / p))
- ᖅ → ((k / q* / ng))
- ᑦ → ((t* / p / n))
- ᖕ → ((n / ng* / g))
:::

## Cutting a word into syllables

Each syllable is a vowel, with the consonant before it; a consonant with no vowel after it is a final. *qamutik* "sled" is *qa-mu-ti-k*: ᖃ ᒧ ᑎ ᒃ, ᖃᒧᑎᒃ *qamutik*.

| Roman | Syllables | Syllabics | Meaning |
|---|---|---|---|
| qamutik | qa-mu-ti-k | ᖃᒧᑎᒃ | sled |
| tuktu | tu-k-tu | ᑐᒃᑐ | caribou |
| qimmiq | qi-m-mi-q | ᕿᒻᒥᖅ | dog |
| siku | si-ku | ᓯᑯ | sea ice |
| aput | a-pu-t | ᐊᐳᑦ | snow on the ground |
| nanuq | na-nu-q | ᓇᓄᖅ | polar bear |

Write in syllabics, or in Roman spelling.

:::

::: exercise roman
Read the word.

- ᖃᒧᑎᒃ → ((kamutik / qamutik* / qamutiq))
- ᐊᐳᑦ → ((aput* / apu / apuk))
- ᓯᑯ → ((sika / siku* / suki))
- ᓇᓄᖅ → ((nanuk / nanuq* / nanu))
:::

::: summary
- Fifteen shapes, each turned for *i*, *u*, *a*, and a small final: the whole chart.
- *j* is said "y"; *q* and *r* are said far back; *ł* is a breathed *l*.
- A word is cut into syllables, each a vowel with its consonant: *qa-mu-ti-k*.
- ᖃᒧᑎᒃ *qamutik* sled, ᑐᒃᑐ *tuktu* caribou, ᕿᒻᒥᖅ *qimmiq* dog, ᓯᑯ *siku* sea ice, ᓇᓄᖅ *nanuq* polar bear.
:::
