# 7. La negación y las preguntas

«No» es una posbase, -ᙱᑦ- *-nngit-*, puesta dentro del verbo antes de su terminación. Una pregunta de sí o no tiene terminaciones propias, y las palabras interrogativas van delante. Esta lección da ambas cosas, con las respuestas *ii* y *aakka*.

## No: -nngit-

| Afirmación | Negación | Significado |
|---|---|---|
| ᓂᕆᔪᖓ | ᓂᕆᙱᑦᑐᖓ | no como |
| ᑕᑯᔪᖅ | ᑕᑯᙱᑦᑐᖅ | ella no ve |
| ᐱᓱᒃᑐᖓ | ᐱᓱᙱᑦᑐᖓ | no camino |
| ᐃᒥᖅᑐᑎᑦ | ᐃᒥᙱᑦᑐᑎᑦ | no bebes |

- *-nngit-* acaba en consonante: la terminación que sigue empieza por *t*, *niri-nngit-tunga*.
- Hace caer la última consonante de la base: *pisuk-* da *pisunngit-*.
- ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* «estoy bien» es «no estoy cómo»: *qanu-* «cómo», *-nngit-* «no».

::: exercise not
Póngalo en negativo, en silabarios o en ortografía latina.

- ᓂᕆᔪᑎᑦ → [[ᓂᕆᙱᑦᑐᑎᑦ]]
- ᑕᑯᔪᖓ → [[ᑕᑯᙱᑦᑐᖓ]]
- ᐊᓂᔪᖅ → [[ᐊᓂᙱᑦᑐᖅ]]
- ᓴᓇᔪᒍᑦ → [[ᓴᓇᙱᑦᑐᒍᑦ]]
:::

## Preguntas de sí o no

Una pregunta a «ti» acaba en *-vit*: ᓂᕆᕕᑦ *nirivit* «¿comes?», ᑕᑯᕕᑦ *takuvit* «¿ves?». Tras consonante es *-pit*, que se une al sonido anterior: *qanuq* «cómo», ᖃᓄᐃᑉᐱᑦ *qanuippit* «¿cómo estás?». Para preguntar por «él, ella», *-pa*: ᖃᓄᐃᑉᐸ *qanuippa* «¿cómo está ella?».

La respuesta es ᐄ *ii* «sí» o ᐋᒃᑲ *aakka* «no».

::: exercise question
¿Cuál hace la pregunta?

- ¿Comes? → ((ᓂᕆᕕᑦ* / ᓂᕆᔪᑎᑦ / ᓂᕆᙱᑦᑐᑎᑦ))
- ¿Ves? → ((ᑕᑯᔪᑎᑦ / ᑕᑯᕕᑦ* / ᑕᑯᔪᖓ))
- ¿Cómo está ella? → ((ᖃᓄᐃᑉᐱᑦ / ᖃᓄᐃᑉᐸ* / ᖃᓄᐃᙱᑦᑐᖅ))
- ¿Trabajas? → ((ᓴᓇᕕᑦ* / ᓴᓇᔪᖅ / ᓴᓇᙱᑦᑐᖓ))
:::

## Las palabras interrogativas

| Palabra | Significado | Ejemplo | |
|---|---|---|---|
| ᑭᓇ | quién | ᑭᓇ ᑖᓐᓇ | ¿Quién es ese? |
| ᓱᓇ | qué | ᓱᓇ ᐅᓇ | ¿Qué es esto? |
| ᓇᓂ | dónde | ᓇᓃᑉᐱᑦ | ¿Dónde estás? |
| ᖃᓄᖅ | cómo | ᖃᓄᐃᑉᐱᑦ | ¿Cómo estás? |
| ᖃᖓ | cuándo (pasado) | | |
| ᖃᑯᒍ | cuándo (futuro) | | |

El inuktitut pregunta «cuándo» de dos maneras, para lo pasado y para lo que vendrá.

- cuándo, en futuro → [[ᖃᑯᒍ]]
:::

Traduzca.

- ᓱᓇ ᐅᓇ → {{¿Qué es esto?}}
- ᓂᕆᙱᑦᑐᖓ → {{No como. / No estoy comiendo.}}
- ᓇᓃᑉᐱᑦ → {{¿Dónde estás?}}
- ᑭᓇ ᑖᓐᓇ → {{¿Quién es ese? / ¿Quién es?}}
:::

::: summary
- *-nngit-* «no», antes de la terminación: ᓂᕆᙱᑦᑐᖓ *nirinngittunga*; hace caer la última consonante de la base.
- Preguntas: *-vit* «¿tú?», ᓂᕆᕕᑦ *nirivit*; *-pa* «¿él, ella?», ᖃᓄᐃᑉᐸ *qanuippa*.
- ᑭᓇ *kina* quién, ᓱᓇ *suna* qué, ᓇᓂ *nani* dónde, ᖃᓄᖅ *qanuq* cómo, ᖃᖓ *qanga* cuándo (pasado), ᖃᑯᒍ *qakugu* cuándo (futuro).
- ᐄ *ii* sí, ᐋᒃᑲ *aakka* no.
:::
