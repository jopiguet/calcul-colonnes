# 7. Not, and questions

"Not" is a postbase, -ᙱᑦ- *-nngit-*, set inside the verb before its ending. A yes-or-no question has endings of its own, and the question words come first. This lesson gives both, with the answers *ii* and *aakka*.

## Not: -nngit-

| Statement | Negation | Meaning |
|---|---|---|
| ᓂᕆᔪᖓ | ᓂᕆᙱᑦᑐᖓ | I don't eat |
| ᑕᑯᔪᖅ | ᑕᑯᙱᑦᑐᖅ | she doesn't see |
| ᐱᓱᒃᑐᖓ | ᐱᓱᙱᑦᑐᖓ | I don't walk |
| ᐃᒥᖅᑐᑎᑦ | ᐃᒥᙱᑦᑐᑎᑦ | you don't drink |

- *-nngit-* ends in a consonant, so the ending after it starts with *t*: *niri-nngit-tunga*.
- It drops the last consonant of the base before it: *pisuk-* gives *pisunngit-*.
- ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* "I am fine" is "I am not how": *qanu-* "how", *-nngit-* "not".

- ᑕᑯᔪᖓ → [[ᑕᑯᙱᑦᑐᖓ]]
- ᐊᓂᔪᖅ → [[ᐊᓂᙱᑦᑐᖅ]]
- ᓴᓇᔪᒍᑦ → [[ᓴᓇᙱᑦᑐᒍᑦ]]

## Yes-or-no questions

A question to "you" ends in *-vit*: ᓂᕆᕕᑦ *nirivit* "do you eat?", ᑕᑯᕕᑦ *takuvit* "do you see?". After a consonant it is *-pit*, which joins the sound before it: *qanuq* "how", ᖃᓄᐃᑉᐱᑦ *qanuippit* "how are you?". To ask about "him, her", *-pa*: ᖃᓄᐃᑉᐸ *qanuippa* "how is she?".

The answer is ᐄ *ii* "yes" or ᐋᒃᑲ *aakka* "no".

::: exercise question
Which one asks?

- Do you eat? → ((ᓂᕆᕕᑦ* / ᓂᕆᔪᑎᑦ / ᓂᕆᙱᑦᑐᑎᑦ))
- Do you see? → ((ᑕᑯᔪᑎᑦ / ᑕᑯᕕᑦ* / ᑕᑯᔪᖓ))
- How is she? → ((ᖃᓄᐃᑉᐱᑦ / ᖃᓄᐃᑉᐸ* / ᖃᓄᐃᙱᑦᑐᖅ))
- Do you work? → ((ᓴᓇᕕᑦ* / ᓴᓇᔪᖅ / ᓴᓇᙱᑦᑐᖓ))
:::

## Question words

| Word | Meaning | Example | |
|---|---|---|---|
| ᑭᓇ | who | ᑭᓇ ᑖᓐᓇ | Who is that? |
| ᓱᓇ | what | ᓱᓇ ᐅᓇ | What is this? |
| ᓇᓂ | where | ᓇᓃᑉᐱᑦ | Where are you? |
| ᖃᓄᖅ | how | ᖃᓄᐃᑉᐱᑦ | How are you? |
| ᖃᖓ | when (past) | | |
| ᖃᑯᒍ | when (future) | | |

Inuktitut asks "when" two ways, for what is past and for what is to come.

:::

- ᓇᓃᑉᐱᑦ → {{Where are you?}}
- ᑭᓇ ᑖᓐᓇ → {{Who is that? / Who is that one?}}
:::

::: summary
- *-nngit-* "not", before the ending: ᓂᕆᙱᑦᑐᖓ *nirinngittunga*; it drops a base's last consonant.
- Questions: *-vit* "you?", ᓂᕆᕕᑦ *nirivit*; *-pa* "he, she?", ᖃᓄᐃᑉᐸ *qanuippa*.
- ᑭᓇ *kina* who, ᓱᓇ *suna* what, ᓇᓂ *nani* where, ᖃᓄᖅ *qanuq* how, ᖃᖓ *qanga* when (past), ᖃᑯᒍ *qakugu* when (future).
- ᐄ *ii* yes, ᐋᒃᑲ *aakka* no.
:::
