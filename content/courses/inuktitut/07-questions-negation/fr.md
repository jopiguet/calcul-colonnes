# 7. La négation et les questions

« Ne … pas » est une postbase, -ᙱᑦ- *-nngit-*, placée dans le verbe avant sa terminaison. Une question fermée a ses propres terminaisons, et les mots interrogatifs viennent en tête. Cette leçon donne les deux, avec les réponses *ii* et *aakka*.

## Ne … pas : -nngit-

| Affirmation | Négation | Sens |
|---|---|---|
| ᓂᕆᔪᖓ | ᓂᕆᙱᑦᑐᖓ | je ne mange pas |
| ᑕᑯᔪᖅ | ᑕᑯᙱᑦᑐᖅ | elle ne voit pas |
| ᐱᓱᒃᑐᖓ | ᐱᓱᙱᑦᑐᖓ | je ne marche pas |
| ᐃᒥᖅᑐᑎᑦ | ᐃᒥᙱᑦᑐᑎᑦ | tu ne bois pas |

- *-nngit-* finit par une consonne : la terminaison qui suit commence donc par *t*, *niri-nngit-tunga*.
- Elle fait tomber la dernière consonne de la base : *pisuk-* donne *pisunngit-*.
- ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* « je vais bien » se dit « je ne suis pas comment » : *qanu-* « comment », *-nngit-* « ne … pas ».

- ᐊᓂᔪᖅ → [[ᐊᓂᙱᑦᑐᖅ]]

## Les questions fermées

Une question posée à « toi » finit par *-vit* : ᓂᕆᕕᑦ *nirivit* « manges-tu ? », ᑕᑯᕕᑦ *takuvit* « vois-tu ? ». Après une consonne, c'est *-pit*, qui se joint au son précédent : *qanuq* « comment », ᖃᓄᐃᑉᐱᑦ *qanuippit* « comment vas-tu ? ». Pour demander de « lui, elle », *-pa* : ᖃᓄᐃᑉᐸ *qanuippa* « comment va-t-elle ? ».

La réponse est ᐄ *ii* « oui » ou ᐋᒃᑲ *aakka* « non ».

::: exercise question
Laquelle pose la question ?

- Manges-tu ? → ((ᓂᕆᕕᑦ* / ᓂᕆᔪᑎᑦ / ᓂᕆᙱᑦᑐᑎᑦ))
- Vois-tu ? → ((ᑕᑯᔪᑎᑦ / ᑕᑯᕕᑦ* / ᑕᑯᔪᖓ))
- Comment va-t-elle ? → ((ᖃᓄᐃᑉᐱᑦ / ᖃᓄᐃᑉᐸ* / ᖃᓄᐃᙱᑦᑐᖅ))
- Travailles-tu ? → ((ᓴᓇᕕᑦ* / ᓴᓇᔪᖅ / ᓴᓇᙱᑦᑐᖓ))
:::

## Les mots interrogatifs

| Mot | Sens | Exemple | |
|---|---|---|---|
| ᑭᓇ | qui | ᑭᓇ ᑖᓐᓇ | Qui est-ce ? |
| ᓱᓇ | quoi | ᓱᓇ ᐅᓇ | Qu'est-ce que c'est ? |
| ᓇᓂ | où | ᓇᓃᑉᐱᑦ | Où es-tu ? |
| ᖃᓄᖅ | comment | ᖃᓄᐃᑉᐱᑦ | Comment vas-tu ? |
| ᖃᖓ | quand (passé) | | |
| ᖃᑯᒍ | quand (futur) | | |

L'inuktitut demande « quand » de deux façons, pour ce qui est passé et pour ce qui est à venir.

- quand, au futur → [[ᖃᑯᒍ]]
:::

- ᓂᕆᙱᑦᑐᖓ → {{Je ne mange pas.}}
- ᓇᓃᑉᐱᑦ → {{Où es-tu ?}}
- ᑭᓇ ᑖᓐᓇ → {{Qui est-ce ? / Qui est celui-là ?}}
:::

::: summary
- *-nngit-* « ne … pas », avant la terminaison : ᓂᕆᙱᑦᑐᖓ *nirinngittunga* ; il fait tomber la dernière consonne de la base.
- Questions : *-vit* « toi ? », ᓂᕆᕕᑦ *nirivit* ; *-pa* « lui, elle ? », ᖃᓄᐃᑉᐸ *qanuippa*.
- ᑭᓇ *kina* qui, ᓱᓇ *suna* quoi, ᓇᓂ *nani* où, ᖃᓄᖅ *qanuq* comment, ᖃᖓ *qanga* quand (passé), ᖃᑯᒍ *qakugu* quand (futur).
- ᐄ *ii* oui, ᐋᒃᑲ *aakka* non.
:::
