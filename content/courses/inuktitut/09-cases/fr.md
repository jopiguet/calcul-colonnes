# 9. Dans, vers, depuis, par, comme

Là où le français emploie des prépositions, l'inuktitut ajoute au nom une terminaison de cas : ᐃᒡᓗᒥ *iglumi* « dans la maison », ᐃᒡᓗᒧᑦ *iglumut* « vers la maison ». Les terminaisons rencontrent le dernier son du nom et le changent ; c'est pourquoi la capitale, *Iqaluit*, devient *Iqalunni* « à Iqaluit ». Cette leçon donne cinq cas.

## Cinq cas

| Terminaison | Sens | Exemple | |
|---|---|---|---|
| -mi | dans, à, sur | ᐃᒡᓗᒥ | dans la maison |
| -mut | vers, à | ᐃᒡᓗᒧᑦ | vers la maison |
| -mit | de, depuis | ᐃᒡᓗᒥᑦ | depuis la maison |
| -kkut | par, en passant par | ᐃᒐᓛᒃᑯᑦ | par la fenêtre |
| -tut | comme, à la manière de | ᐃᓄᒃᑐᑦ | comme les Inuit, en inuktut |

- ᖃᓪᓗᓈᑐᑦ *qallunaatut* « comme les *qallunaat* », les gens venus du Sud, veut dire « en anglais ».
- *Iqaluit* est le pluriel d'*iqaluk* « poisson » : « les poissons », pour l'omble chevalier qu'on y pêche.

::: exercise which-case
Quel cas convient ?

- Je marche vers la maison : ᐃᒡᓗ… → ((-mi / -mut* / -mit))
- Je travaille dans la maison : ᐃᒡᓗ… → ((-mi* / -mut / -kkut))
- Je viens de la maison : ᐃᒡᓗ… → ((-mut / -mit* / -tut))
- Je parle comme les Inuit : ᐃᓄᒃ… → ((-mi / -kkut / -tut*))
:::

## Quand les sons se rencontrent

| Dernier son | Avec -mi | Exemple | Sens |
|---|---|---|---|
| une voyelle | -mi | ᓄᓇᒥ | sur la terre |
| t | -nni | ᐃᖃᓗᓐᓂ | à Iqaluit |
| q | -rmi | ᐃᒪᕐᒥ | dans l'eau |
| k | -ngmi | ᖃᒧᑎᖕᒥ | sur le traîneau |

Les mêmes changements se font avec *-mut* et *-mit* : ᐃᖃᓗᓐᓄᑦ *iqalunnut* « vers Iqaluit », ᐃᖃᓗᓐᓂᑦ *iqalunnit* « depuis Iqaluit ».

::: exercise meet
Quelle forme est juste ?

- vers Iqaluit → ((ᐃᖃᓗᐃᑦᒧᑦ / ᐃᖃᓗᓐᓄᑦ* / ᐃᖃᓗᒻᒧᑦ))
- dans l'eau (imaq) → ((ᐃᒪᖅᒥ / ᐃᒪᕐᒥ* / ᐃᒪᒥ))
- sur le traîneau (qamutik) → ((ᖃᒧᑎᒃᒥ / ᖃᒧᑎᖕᒥ* / ᖃᒧᑎᒥ))
- sur la terre → ((ᓄᓇᒥ* / ᓄᓇᓐᓂ / ᓄᓇᕐᒥ))
:::

## Dans une phrase

| Inuktitut | Sens |
|---|---|
| ᐃᒡᓗᒥ ᓴᓇᔪᖓ | Je travaille dans la maison. |
| ᐃᒡᓗᒧᑦ ᐱᓱᒃᑐᖓ | Je marche vers la maison. |
| ᐃᖃᓗᓐᓂᑦ ᑎᑭᑦᑐᖓ | J'arrive d'Iqaluit. |
| ᐃᓄᒃᑐᑦ ᐅᖃᖅᑐᖓ | Je parle inuktut. |

::: exercise translate
Traduisez.

- ᐃᖃᓗᓐᓂ ᓴᓇᔪᖓ → {{Je travaille à Iqaluit.}}
- ᐃᒡᓗᒧᑦ ᐱᓱᒃᑐᖅ → {{Il marche vers la maison. / Elle marche vers la maison. / Elle rentre à pied.}}
- ᖃᓪᓗᓈᑐᑦ ᐅᖃᖅᑐᑎᑦ → {{Tu parles anglais.}}
- ᓄᓇᒥ ᐱᓱᒃᑐᒍᑦ → {{Nous marchons sur la terre. / Nous marchons dans la nature.}}
:::

::: summary
- *-mi* dans, *-mut* vers, *-mit* depuis, *-kkut* par, *-tut* comme.
- Le dernier son du nom change : *Iqaluit*, ᐃᖃᓗᓐᓂ *iqalunni* ; *imaq*, ᐃᒪᕐᒥ *imarmi* ; *qamutik*, ᖃᒧᑎᖕᒥ *qamutingmi*.
- ᐃᓄᒃᑐᑦ *inuktut* en inuktut, ᖃᓪᓗᓈᑐᑦ *qallunaatut* en anglais.
:::
