# 3. Sons longs, sons doubles

L'inuktitut distingue les mots par la durée : une voyelle ou une consonne tenue deux fois plus longtemps est un autre son. Les syllabiques marquent une voyelle longue d'un point et une consonne longue d'une finale devant la syllabe. Cette leçon lit et écrit les deux, avec les deux combinaisons qui s'écrivent d'une façon particulière.

## Les voyelles longues

Une voyelle longue dure à peu près deux fois plus. Les syllabiques mettent un point sur la syllabe ; l'orthographe latine écrit la voyelle deux fois.

| Brève | Longue | Mot | Sens |
|---|---|---|---|
| ᓇ *na* | ᓈ *naa* | ᐊᓈᓇ *anaana* | mère |
| ᑕ *ta* | ᑖ *taa* | ᐊᑖᑕ *ataata* | père |
| ᓴ *sa* | ᓵ *saa* | ᑐᓵᔪᖓ *tusaajunga* | j'entends |
| ᐃ *i* | ᐄ *ii* | ᐄ *ii* | oui |

## Les consonnes doubles

Une consonne double est tenue : *ll* dans ᐅᓪᓛᒃᑯᑦ *ullaakkut* « bonjour (le matin) ». Les syllabiques écrivent sa première moitié comme une finale : ᓪ puis ᓛ.

| Latin | Syllabiques | Sens |
|---|---|---|
| qimmiq | ᕿᒻᒥᖅ | chien |
| ullaakkut | ᐅᓪᓛᒃᑯᑦ | bonjour (le matin) |
| ilinniaqtunga | ᐃᓕᓐᓂᐊᖅᑐᖓ | j'étudie |
| unnusakkut | ᐅᓐᓄᓴᒃᑯᑦ | bon après-midi |

Deux doubles s'écrivent autrement :

- *qq* s'écrit avec la finale *q* et la ligne *k* : *taqqiq* « lune, mois » est ᑕᖅᑭᖅ, ᖅ ᑭ.
- *nng* a sa propre ligne, un petit ᓐ accolé à la forme *ng* : ᙱ *nngi*, comme dans ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* « je vais bien ».

## Des voyelles côte à côte

Deux voyelles peuvent se suivre, chacune dans sa syllabe : *ai* « salut » s'écrit ᐊᐃ, *a-i* ; *Iqaluit*, la capitale du Nunavut, ᐃᖃᓗᐃᑦ, *i-qa-lu-i-t*. Le Nunavik écrit *ai* d'un seul signe, ᐁ ; le Nunavut en écrit deux.

- ᐃᓄᐃᑦ → ((deux / trois* / quatre))
- ᐃᒡᓗ → ((deux* / trois))
:::

::: summary
- Un point fait une voyelle longue : ᑕ *ta*, ᑖ *taa* ; le latin écrit *aa*.
- Une consonne double est une finale puis une syllabe : ᕿᒻᒥᖅ *qimmiq*.
- *qq* s'écrit ᖅ avec la ligne *k* : ᑕᖅᑭᖅ ; *nng* a sa ligne : ᙱ.
- Deux voyelles côte à côte font deux syllabes : ᐊᐃ, ᐃᖃᓗᐃᑦ.
:::
