# 13. Nombres, famille, saisons

Les nombres inuktitut vont par cinq, comme les doigts d'une main ; au quotidien, beaucoup de locuteurs comptent en anglais au-delà de cinq. Les mots de la famille distinguent aînés et cadets, et l'année tourne au fil de saisons nommées d'après la glace et la lumière. Cette leçon donne les trois.

## Les nombres

| | Inuktitut | Latin |
|---|---|---|
| 1 | ᐊᑕᐅᓯᖅ | atausiq |
| 2 | ᒪᕐᕉᒃ | marruuk |
| 3 | ᐱᖓᓱᑦ | pingasut |
| 4 | ᓯᓴᒪᑦ | sisamat |
| 5 | ᑕᓪᓕᒪᑦ | tallimat |

- Le nombre suit le nom, et le nom prend son nombre : ᕿᒻᒦᒃ ᒪᕐᕉᒃ *qimmiik marruuk* « deux chiens », ᐃᒡᓗᑦ ᐱᖓᓱᑦ *iglut pingasut* « trois maisons ».
- *marruuk* « deux » finit lui-même par le duel *-k* ; *pingasut*, *sisamat*, *tallimat* par le pluriel *-t*.
- Au-delà de cinq, les anciens nombres varient d'une communauté à l'autre.

## La famille

| Inuktitut | Sens |
|---|---|
| ᐊᓈᓇᑦᓯᐊᖅ | grand-mère |
| ᐊᑖᑕᑦᓯᐊᖅ | grand-père |
| ᐃᕐᓂᖅ | fils |
| ᐸᓂᒃ | fille |
| ᐊᖓᔪᒃ | frère aîné d'un homme, sœur aînée d'une femme |
| ᓄᑲᖅ | frère cadet d'un homme, sœur cadette d'une femme |
| ᓄᓕᐊᖅ | épouse |
| ᐅᐃ | mari |

Les grands-parents se forment avec *-tsiaq-* « bien, joliment » : *anaana-tsiaq*, *ataata-tsiaq*. *angajuk* et *nukaq* désignent un frère ou une sœur du même sexe que soi, aîné ou cadet.

::: exercise family
Quel mot ?

- Saali (une femme) parle de sa sœur aînée → ((ᐊᖓᔪᒃ* / ᓄᑲᖅ / ᐸᓂᒃ))
- Jaani parle de son frère cadet → ((ᐊᖓᔪᒃ / ᓄᑲᖅ* / ᐃᕐᓂᖅ))
- grand-mère → ((ᐊᓈᓇᑦᓯᐊᖅ* / ᐊᓈᓇ / ᓄᓕᐊᖅ))
- fille → ((ᐃᕐᓂᖅ / ᐸᓂᒃ* / ᐅᐃ))
:::

## Les saisons

| Inuktitut | Saison |
|---|---|
| ᐅᑭᐅᖅ | hiver |
| ᐅᐱᕐᖔᖅ | printemps |
| ᐊᐅᔭᖅ | été |
| ᐅᑭᐊᒃᓴᖅ | automne |

*ukiuq* veut aussi dire « année » : on compte les années en hivers.

::: exercise translate
Traduisez.

- ᐊᓈᓇᑦᓯᐊᒐ → {{Ma grand-mère.}}
- ᐅᑭᐅᖅ → {{L'hiver. / Une année. / Hiver, année.}}
- ᕿᒻᒦᑦ ᑕᓪᓕᒪᑦ → {{Cinq chiens.}}
- ᐃᕐᓂᒐ → {{Mon fils.}}
:::

::: summary
- ᐊᑕᐅᓯᖅ *atausiq* 1, ᒪᕐᕉᒃ *marruuk* 2, ᐱᖓᓱᑦ *pingasut* 3, ᓯᓴᒪᑦ *sisamat* 4, ᑕᓪᓕᒪᑦ *tallimat* 5 ; le nombre suit le nom.
- ᐊᓈᓇᑦᓯᐊᖅ *anaanatsiaq*, ᐊᑖᑕᑦᓯᐊᖅ *ataatatsiaq* grands-parents ; ᐃᕐᓂᖅ *irniq* fils, ᐸᓂᒃ *panik* fille ; ᐊᖓᔪᒃ *angajuk*, ᓄᑲᖅ *nukaq* aîné, cadet.
- ᐅᑭᐅᖅ *ukiuq* hiver, année ; ᐅᐱᕐᖔᖅ *upirngaaq* printemps ; ᐊᐅᔭᖅ *aujaq* été ; ᐅᑭᐊᒃᓴᖅ *ukiaksaq* automne.
:::
