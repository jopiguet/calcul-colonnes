# 6. Les verbes : qui le fait

Un verbe inuktitut est une base suivie d'une terminaison qui nomme la personne : ᓂᕆᔪᖓ *nirijunga* « je mange », ᓂᕆᔪᖅ *nirijuq* « elle mange ». Les terminaisons comptent un, deux et plusieurs, comme les pronoms. Cette leçon donne les terminaisons du présent de tous les jours.

## Les terminaisons

| Personne | Après une voyelle : niri- manger | Après une consonne : pisuk- marcher |
|---|---|---|
| je | ᓂᕆᔪᖓ | ᐱᓱᒃᑐᖓ |
| tu | ᓂᕆᔪᑎᑦ | ᐱᓱᒃᑐᑎᑦ |
| il, elle | ᓂᕆᔪᖅ | ᐱᓱᒃᑐᖅ |
| nous deux | ᓂᕆᔪᒍᒃ | ᐱᓱᒃᑐᒍᒃ |
| eux deux | ᓂᕆᔫᒃ | ᐱᓱᒃᑑᒃ |
| nous | ᓂᕆᔪᒍᑦ | ᐱᓱᒃᑐᒍᑦ |
| vous | ᓂᕆᔪᓯ | ᐱᓱᒃᑐᓯ |
| ils | ᓂᕆᔪᑦ | ᐱᓱᒃᑐᑦ |

- Après une voyelle la terminaison commence par *j* ; après une consonne, par *t*.
- Le temps n'est pas marqué : ᓂᕆᔪᖓ *nirijunga* veut dire « je mange » ou « je suis en train de manger ».
- Certaines bases changent leur dernier son devant *t* : *sinik-* « dormir », ᓯᓂᑦᑐᖓ *sinittunga* « je dors ».
- L'écrit emploie aussi une seconde série de terminaisons, ᓂᕆᕗᖓ *nirivunga*, ᓂᕆᕗᑎᑦ *nirivutit*, ᓂᕆᕗᖅ *nirivuq*, de même sens.

## Des verbes de tous les jours

| Base | Sens | je … |
|---|---|---|
| niri- | manger | ᓂᕆᔪᖓ |
| imiq- | boire | ᐃᒥᖅᑐᖓ |
| taku- | voir | ᑕᑯᔪᖓ |
| uqaq- | parler | ᐅᖃᖅᑐᖓ |
| ilinniaq- | étudier, apprendre | ᐃᓕᓐᓂᐊᖅᑐᖓ |
| ani- | sortir | ᐊᓂᔪᖓ |
| isiq- | entrer | ᐃᓯᖅᑐᖓ |
| sana- | travailler, fabriquer | ᓴᓇᔪᖓ |

::: exercise who
Qui le fait ?

- ᐃᒥᖅᑐᑎᑦ → ((je / tu* / ils))
- ᑕᑯᔫᒃ → ((eux deux* / nous deux / vous))
- ᐅᖃᖅᑐᓯ → ((nous / vous* / ils))
- ᐊᓂᔪᒍᒃ → ((nous deux* / eux deux / nous))
:::

::: summary
- Terminaisons : *-junga, -jutit, -juq* ; deux : *-juguk, -juuk* ; plusieurs : *-jugut, -jusi, -jut*.
- Après une consonne, elles commencent par *t* : ᐱᓱᒃᑐᖓ *pisuktunga*.
- Pas de temps : ᓂᕆᔪᖓ *nirijunga* « je mange, je suis en train de manger ».
- Verbes : *niri-* manger, *imiq-* boire, *taku-* voir, *uqaq-* parler, *ilinniaq-* étudier, *ani-* sortir, *isiq-* entrer, *sana-* travailler.
:::
