# 6. Los verbos: quién lo hace

Un verbo inuktitut es una base con una terminación que nombra a la persona: ᓂᕆᔪᖓ *nirijunga* «como», ᓂᕆᔪᖅ *nirijuq* «ella come». Las terminaciones cuentan uno, dos y muchos, como los pronombres. Esta lección da las terminaciones del presente de cada día.

## Las terminaciones

| Persona | Tras vocal: niri- comer | Tras consonante: pisuk- caminar |
|---|---|---|
| yo | ᓂᕆᔪᖓ | ᐱᓱᒃᑐᖓ |
| tú | ᓂᕆᔪᑎᑦ | ᐱᓱᒃᑐᑎᑦ |
| él, ella | ᓂᕆᔪᖅ | ᐱᓱᒃᑐᖅ |
| nosotros dos | ᓂᕆᔪᒍᒃ | ᐱᓱᒃᑐᒍᒃ |
| ellos dos | ᓂᕆᔫᒃ | ᐱᓱᒃᑑᒃ |
| nosotros | ᓂᕆᔪᒍᑦ | ᐱᓱᒃᑐᒍᑦ |
| ustedes | ᓂᕆᔪᓯ | ᐱᓱᒃᑐᓯ |
| ellos | ᓂᕆᔪᑦ | ᐱᓱᒃᑐᑦ |

- Tras vocal la terminación empieza por *j*; tras consonante, por *t*.
- El tiempo no se marca: ᓂᕆᔪᖓ *nirijunga* es «como» o «estoy comiendo».
- Algunas bases cambian su último sonido ante *t*: *sinik-* «dormir», ᓯᓂᑦᑐᖓ *sinittunga* «duermo».
- La escritura usa también una segunda serie de terminaciones, ᓂᕆᕗᖓ *nirivunga*, ᓂᕆᕗᑎᑦ *nirivutit*, ᓂᕆᕗᖅ *nirivuq*, con el mismo sentido.

## Verbos de cada día

| Base | Significado | yo … |
|---|---|---|
| niri- | comer | ᓂᕆᔪᖓ |
| imiq- | beber | ᐃᒥᖅᑐᖓ |
| taku- | ver | ᑕᑯᔪᖓ |
| uqaq- | hablar | ᐅᖃᖅᑐᖓ |
| ilinniaq- | estudiar, aprender | ᐃᓕᓐᓂᐊᖅᑐᖓ |
| ani- | salir | ᐊᓂᔪᖓ |
| isiq- | entrar | ᐃᓯᖅᑐᖓ |
| sana- | trabajar, hacer | ᓴᓇᔪᖓ |

::: exercise who
¿Quién lo hace?

- ᐃᒥᖅᑐᑎᑦ → ((yo / tú* / ellos))
- ᑕᑯᔫᒃ → ((ellos dos* / nosotros dos / ustedes))
- ᐅᖃᖅᑐᓯ → ((nosotros / ustedes* / ellos))
- ᐊᓂᔪᒍᒃ → ((nosotros dos* / ellos dos / nosotros))
:::

::: summary
- Terminaciones: *-junga, -jutit, -juq*; dos: *-juguk, -juuk*; muchos: *-jugut, -jusi, -jut*.
- Tras consonante empiezan por *t*: ᐱᓱᒃᑐᖓ *pisuktunga*.
- Sin tiempo: ᓂᕆᔪᖓ *nirijunga* «como, estoy comiendo».
- Verbos: *niri-* comer, *imiq-* beber, *taku-* ver, *uqaq-* hablar, *ilinniaq-* estudiar, *ani-* salir, *isiq-* entrar, *sana-* trabajar.
:::
