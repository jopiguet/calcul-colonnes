# 4. Salutations et pronoms

Une première conversation en inuktitut est brève et pleine de mots faits de suffixes : « je vais bien » se dit littéralement « je ne suis pas comment ». Cette leçon donne les salutations et les pronoms, qui comptent un, deux, et plus de deux.

## Salutations

| Inuktitut | Latin | Sens |
|---|---|---|
| ᐊᐃ | ai | salut |
| ᐅᓪᓛᒃᑯᑦ | ullaakkut | bonjour (le matin) |
| ᖃᓄᐃᑉᐱᑦ | qanuippit? | comment vas-tu ? |
| ᖃᓄᐃᙱᑦᑐᖓ | qanuinngittunga | je vais bien |
| ᓇᑯᕐᒦᒃ | nakurmiik | merci |
| ᐃᓛᓕ | ilaali | de rien |
| ᐄ ᐋᒃᑲ | ii, aakka | oui, non |
| ᑭᓇᐅᕕᑦ | kinauvit? | qui es-tu ? |
| ᔮᓂᒥᒃ ᐊᑎᖃᖅᑐᖓ | Jaanimik atiqaqtunga | je m'appelle Jaani |
| ᑕᕝᕙᐅᕗᑎᑦ | tavvauvutit | au revoir (à une personne) |
| ᑕᕝᕙᐅᕗᓯ | tavvauvusi | au revoir (à plusieurs) |

- ᖃᓄᐃᑉᐱᑦ *qanuippit* est *qanuq* « comment » avec *-pit* « es-tu ? » ; ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* est *qanu-* « comment », *-nngit-* « ne … pas », *-tunga* « je suis ».
- « Je m'appelle » se dit « j'ai pour nom » : *atiq* « nom », *-qaq-* « avoir », *-tunga* « je » ; le nom prend *-mik*.
- Jaani est la forme inuktitut de Jean.

## Les pronoms : un, deux, plusieurs

L'inuktitut compte les personnes de trois façons : un, deux, et plus de deux ; le « deux » s'appelle le duel.

| | Un | Deux | Plusieurs |
|---|---|---|---|
| je, nous | ᐅᕙᖓ *uvanga* | ᐅᕙᒍᒃ *uvaguk* | ᐅᕙᒍᑦ *uvagut* |
| tu, vous | ᐃᕝᕕᑦ *ivvit* | ᐃᓕᑦᑎᒃ *ilittik* | ᐃᓕᔅᓯ *ilissi* |

Pour « il, elle, ils », l'inuktitut montre du doigt : ᐅᓇ *una* « celui-ci », ᑖᓐᓇ *taanna* « celui-là ». Pas de genre : un seul mot pour « il » et « elle ».

::: summary
- ᐊᐃ *ai* salut, ᖃᓄᐃᑉᐱᑦ *qanuippit* comment vas-tu ?, ᖃᓄᐃᙱᑦᑐᖓ *qanuinngittunga* je vais bien, ᓇᑯᕐᒦᒃ *nakurmiik* merci.
- ᐄ *ii* oui, ᐋᒃᑲ *aakka* non ; ᑕᕝᕙᐅᕗᑎᑦ *tavvauvutit* au revoir à une personne, ᑕᕝᕙᐅᕗᓯ *tavvauvusi* à plusieurs.
- Un, deux, plusieurs : ᐅᕙᖓ *uvanga*, ᐅᕙᒍᒃ *uvaguk*, ᐅᕙᒍᑦ *uvagut* ; ᐃᕝᕕᑦ *ivvit*, ᐃᓕᑦᑎᒃ *ilittik*, ᐃᓕᔅᓯ *ilissi*.
- ᐅᓇ *una* celui-ci, ᑖᓐᓇ *taanna* celui-là : pas de genre.
:::
