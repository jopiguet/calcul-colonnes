# 5. Una palabra, una frase

Una palabra inuktitut se construye con una base, cualquier número de posbases y una terminación, en ese orden. Lo que el castellano dice en una frase, el inuktitut lo dice a menudo en una palabra: ᐃᒡᓗᓕᐅᖅᑐᖓ *igluliuqtunga*, «estoy construyendo una casa». Esta lección desarma palabras y las arma.

## Base, posbase, terminación

| Palabra | Base | Posbase | Terminación | Significado |
|---|---|---|---|---|
| ᐃᒡᓗᓕᐅᖅᑐᖓ | iglu casa | -liuq- hacer | -tunga yo | estoy construyendo una casa |
| ᑐᒃᑐᓯᐅᖅᑐᖓ | tuktu caribú | -siuq- buscar | -tunga yo | estoy cazando caribúes |
| ᕿᒻᒥᖃᖅᑐᖓ | qimmiq perro | -qaq- tener | -tunga yo | tengo un perro |
| ᐊᑎᖃᖅᑐᖓ | atiq nombre | -qaq- tener | -tunga yo | tengo un nombre |

- La base va primero y da aquello de lo que se habla: una cosa o una acción.
- Las posbases añaden sentido, una tras otra; hay varios cientos.
- La terminación va al final y dice quién: *-tunga* «yo», *-tuq* «él, ella».
- Los sonidos se encuentran y cambian en las uniones: *qimmiq* + *-qaq-* pierde una *q*, *qimmiqaq-*; *qimmiq* + *-siuq-* la cambia en *r*, *qimmirsiuq-*.

::: exercise parts
¿Qué añade la posbase?

- ᐃᒡᓗᓕᐅᖅᑐᖓ: -liuq- → ((hacer* / tener / buscar))
- ᑐᒃᑐᓯᐅᖅᑐᖓ: -siuq- → ((hacer / tener / buscar*))
- ᕿᒻᒥᖃᖅᑐᖓ: -qaq- → ((hacer / tener* / buscar))
- -tunga → ((yo* / tú / él, ella))
:::

::: exercise build
Construya la palabra, en silabarios o en ortografía latina.

- tengo un trineo (qamutik) → [[ᖃᒧᑎᖃᖅᑐᖓ]]

- busco un perro → [[ᕿᒻᒥᕐᓯᐅᖅᑐᖓ]]
- tengo una casa → [[ᐃᒡᓗᖃᖅᑐᖓ]]
:::

## Posbases en los nombres

Algunas posbases hacen nombres nuevos: *-jjuaq* «grande», *-apik* «pequeño, querido», *-miut* «la gente de».

| Palabra | Piezas | Significado |
|---|---|---|
| ᐃᒡᓗᔾᔪᐊᖅ | iglu-jjuaq | un edificio grande |
| ᕿᒻᒥᐊᐱᒃ | qimmi-apik | un perrito, un cachorro |
| ᓄᓇᕗᒻᒥᐅᑦ | nunavut-miut | la gente de Nunavut |

## Una palabra larga famosa

ᑐᓵᑦᓯᐊᕈᓐᓇᙱᑦᑐᐊᓘᔪᖓ *tusaatsiarunnanngittualuujunga* «de verdad no logro oír bien»:

| Pieza | Significado |
|---|---|
| tusaa- | oír |
| -tsiaq- | bien |
| -junnaq- | poder |
| -nngit- | no |
| -tualuu- | muchísimo |
| -junga | yo |

Las piezas se unen con cambios de sonido: *-tsiaq-* y *-junnaq-* se encuentran como *-tsiarunnaq-*.

::: exercise long-word
¿Qué pieza lo dice?

- no → ((-tsiaq- / -nngit-* / -junga))
- bien → ((-tsiaq-* / -tualuu- / tusaa-))
- oír → ((-junnaq- / tusaa-* / -nngit-))
- yo → ((-junga* / -tsiaq- / -tualuu-))
:::

::: exercise translate
Traduzca.

- ᐃᒡᓗᓕᐅᖅᑐᖓ → {{Estoy construyendo una casa. / Construyo una casa.}}
- ᕿᒻᒥᖃᖅᑐᖓ → {{Tengo un perro.}}
- ᑐᒃᑐᓯᐅᖅᑐᖓ → {{Estoy cazando caribúes. / Busco caribúes.}}
- ᐃᒡᓗᔾᔪᐊᖅ → {{Un edificio grande. / Una casa grande.}}
:::

::: summary
- Una palabra es una base, posbases y una terminación: *iglu-liuq-tunga*.
- Posbases: *-liuq-* hacer, *-siuq-* buscar, *-qaq-* tener, *-jjuaq* grande, *-apik* pequeño, *-miut* gente de.
- Los sonidos cambian en las uniones: *qimmiq-qaq-* da *qimmiqaq-*, *qimmiq-siuq-* da *qimmirsiuq-*.
- ᑐᓵᑦᓯᐊᕈᓐᓇᙱᑦᑐᐊᓘᔪᖓ *tusaatsiarunnanngittualuujunga* «de verdad no logro oír bien».
:::
