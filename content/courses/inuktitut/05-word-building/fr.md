# 5. Un mot, une phrase

Un mot inuktitut se construit d'une base, d'un nombre quelconque de postbases et d'une terminaison, dans cet ordre. Ce que le français dit en une phrase, l'inuktitut le dit souvent en un mot : ᐃᒡᓗᓕᐅᖅᑐᖓ *igluliuqtunga*, « je construis une maison ». Cette leçon démonte des mots et en assemble.

## Base, postbase, terminaison

| Mot | Base | Postbase | Terminaison | Sens |
|---|---|---|---|---|
| ᐃᒡᓗᓕᐅᖅᑐᖓ | iglu maison | -liuq- fabriquer | -tunga je | je construis une maison |
| ᑐᒃᑐᓯᐅᖅᑐᖓ | tuktu caribou | -siuq- chercher | -tunga je | je chasse le caribou |
| ᕿᒻᒥᖃᖅᑐᖓ | qimmiq chien | -qaq- avoir | -tunga je | j'ai un chien |
| ᐊᑎᖃᖅᑐᖓ | atiq nom | -qaq- avoir | -tunga je | j'ai un nom |

- La base vient d'abord et donne de quoi l'on parle : une chose ou une action.
- Les postbases ajoutent du sens, l'une après l'autre ; il y en a plusieurs centaines.
- La terminaison vient en dernier et dit qui : *-tunga* « je », *-tuq* « il, elle ».
- Les sons se rencontrent et changent aux jointures : *qimmiq* + *-qaq-* perd un *q*, *qimmiqaq-* ; *qimmiq* + *-siuq-* le change en *r*, *qimmirsiuq-*.

::: exercise parts
Qu'ajoute la postbase ?

- ᐃᒡᓗᓕᐅᖅᑐᖓ: -liuq- → ((fabriquer* / avoir / chercher))
- ᑐᒃᑐᓯᐅᖅᑐᖓ: -siuq- → ((fabriquer / avoir / chercher*))
- ᕿᒻᒥᖃᖅᑐᖓ: -qaq- → ((fabriquer / avoir* / chercher))
- -tunga → ((je* / tu / il, elle))
:::

## Des postbases sur les noms

Certaines postbases font de nouveaux noms : *-jjuaq* « grand », *-apik* « petit, cher », *-miut* « les gens de ».

| Mot | Morceaux | Sens |
|---|---|---|
| ᐃᒡᓗᔾᔪᐊᖅ | iglu-jjuaq | un grand bâtiment |
| ᕿᒻᒥᐊᐱᒃ | qimmi-apik | un petit chien, un chiot |
| ᓄᓇᕗᒻᒥᐅᑦ | nunavut-miut | les gens du Nunavut |

## Un long mot célèbre

ᑐᓵᑦᓯᐊᕈᓐᓇᙱᑦᑐᐊᓘᔪᖓ *tusaatsiarunnanngittualuujunga* « je n'arrive vraiment pas à bien entendre » :

| Morceau | Sens |
|---|---|
| tusaa- | entendre |
| -tsiaq- | bien |
| -junnaq- | pouvoir |
| -nngit- | ne … pas |
| -tualuu- | vraiment beaucoup |
| -junga | je |

Les morceaux se joignent avec des changements de son : *-tsiaq-* et *-junnaq-* se rencontrent en *-tsiarunnaq-*.

::: exercise long-word
Quel morceau le dit ?

- ne … pas → ((-tsiaq- / -nngit-* / -junga))
- bien → ((-tsiaq-* / -tualuu- / tusaa-))
- entendre → ((-junnaq- / tusaa-* / -nngit-))
- je → ((-junga* / -tsiaq- / -tualuu-))
:::

::: summary
- Un mot est une base, des postbases, une terminaison : *iglu-liuq-tunga*.
- Postbases : *-liuq-* fabriquer, *-siuq-* chercher, *-qaq-* avoir, *-jjuaq* grand, *-apik* petit, *-miut* gens de.
- Les sons changent aux jointures : *qimmiq-qaq-* donne *qimmiqaq-*, *qimmiq-siuq-* donne *qimmirsiuq-*.
- ᑐᓵᑦᓯᐊᕈᓐᓇᙱᑦᑐᐊᓘᔪᖓ *tusaatsiarunnanngittualuujunga* « je n'arrive vraiment pas à bien entendre ».
:::
