# 15. La négation

L'égyptien n'a pas un mot unique pour « ne … pas ». Il a deux mots négatifs, *n* et *nn*, un verbe négatif *tm*, et la paire *nj … js* pour les phrases sans verbe. Le choix dépend de ce qu'on nie, et deux des combinaisons signifient le contraire de ce qu'on attendrait : *n sḏm.f* est un **passé** (« il n'entendit pas »), *n sḏm.n.f* un **présent** (« il n'entend pas, il ne peut pas entendre »). Apprenez bien le tableau de cette leçon : la négation décide du sens de phrases entières.

## Nier un verbe

| Négation | Sens | Exemple | Traduction |
|---|---|---|---|
| *n sḏm.f* | passé | *n sḏm.f* | il n'entendit pas |
| *n sḏm.n.f* | général, capacité | *n sḏm.n.f* | il n'entend pas, il ne peut pas entendre |
| *nn sḏm.f* | futur | *nn sḏm.f* | il n'entendra pas |
| *tm* + complément négatif | « ne pas … » dans une proposition | *r tm sḏm* | pour ne pas entendre |

Le croisement de *n sḏm.f* et *n sḏm.n.f* a une histoire : l'ancienne forme du passé, après *n*, a survécu comme passé, et le sens général est passé à l'autre. Moyen mnémotechnique : **n sans .n = pas d'action passée** ; **n + .n = jamais, pas du tout**.

## Nier l'existence et la phrase adverbiale

| Construction | Exemple | Sens |
|---|---|---|
| *nn* + nom | *nn mw* | il n'y a pas d'eau |
| *nn* + sujet + prédicat | *nn sw m pr* | il n'est pas dans la maison |
| *nn* + nom + *n* + personne | *nn sꜣ n.f* | il n'a pas de fils |

## Nier les phrases nominales et adjectivales

*nj* vient en tête et *js* après le premier mot ou groupe :

| Construction | Exemple | Sens |
|---|---|---|
| nominale | *nj jnk js sš* | je ne suis pas scribe |
| nominale avec *pw* | *nj sꜣ.j js pw* | ce n'est pas mon fils |
| adjectivale | *nj nfr js* | ce n'est pas bon |

## Mots négatifs utiles

| Mot | Sens |
|---|---|
| *nn* … *nb* | aucun …, nul : *nn rmṯ nb* personne |
| *n zp* | jamais : *n zp jr.j st* je ne l'ai jamais fait |
| *nj-sw* | il appartient à |
| *jwtj* | qui n'a pas, sans (nisbé négative) : *jwtj sꜣ.f* qui n'a pas de fils |

::: exercise meaning
Que signifie-t-il ?

- n sḏm.f → ((il n'entendit pas* / il ne peut pas entendre / il n'entendra pas))
- n sḏm.n.f → ((il n'entendit pas / il ne peut pas entendre* / il n'entendra pas))
- nn sḏm.f → ((il n'entendit pas / il ne peut pas entendre / il n'entendra pas*))
- nn mw → ((il n'y a pas d'eau* / il n'est pas l'eau / ne bois pas d'eau))
:::

::: exercise choose
Choisissez la négation.

- « il ne viendra pas » → ((n / nn* / nj … js)) jj.f
- « il n'est pas venu » → ((n* / nn / nj … js)) jj.f
- « il n’y a pas d’eau » → ((n / nn* / tm)) mw
- « ce n'est pas mon fils » → ((n / nn / nj … js*)) sꜣ.j pw
:::

Traduisez.

- *n jr.j st* → {{Je ne l'ai pas fait. / Je ne le fis pas.}}

:::

::: summary
- *n sḏm.f* passé « ne … pas » ; *n sḏm.n.f* général « ne … pas, ne peut pas » ; *nn sḏm.f* futur « ne … pas ».
- *nn* + nom : « il n'y a pas » ; *nn sw m pr* : « il n'est pas dans la maison » ; *nn … nb* : personne, rien.
- *nj … js* nie les phrases nominales et adjectivales ; *tm* nie dans les propositions (*r tm sḏm*).
- *n zp* jamais ; *jwtj* qui n'a pas.
:::
