# 15. La negación

El egipcio no tiene una sola palabra para «no». Tiene dos palabras negativas, *n* y *nn*, un verbo negativo *tm*, y el par *nj … js* para las oraciones sin verbo. La elección depende de lo que se niega, y dos de las combinaciones significan lo contrario de lo que se esperaría: *n sḏm.f* es un **pasado** («no oyó»), *n sḏm.n.f* un **presente** («no oye, no puede oír»). Aprenda bien la tabla de esta lección: la negación decide el sentido de oraciones enteras.

## Negar un verbo

| Negación | Sentido | Ejemplo | Traducción |
|---|---|---|---|
| *n sḏm.f* | pasado | *n sḏm.f* | no oyó |
| *n sḏm.n.f* | general, capacidad | *n sḏm.n.f* | no oye, no puede oír |
| *nn sḏm.f* | futuro | *nn sḏm.f* | no oirá |
| *tm* + complemento negativo | «no …» dentro de una oración | *r tm sḏm* | para no oír |

El cruce de *n sḏm.f* y *n sḏm.n.f* tiene una historia: la antigua forma del pasado, tras *n*, sobrevivió como pasado, y el sentido general pasó a la otra. Regla mnemotécnica: **n sin .n = ninguna acción pasada**; **n + .n = nunca, en absoluto**.

## Negar la existencia y la oración adverbial

| Construcción | Ejemplo | Sentido |
|---|---|---|
| *nn* + sustantivo | *nn mw* | no hay agua |
| *nn* + sujeto + predicado | *nn sw m pr* | no está en la casa |
| *nn* + sustantivo + *n* + persona | *nn sꜣ n.f* | no tiene hijo |

## Negar oraciones nominales y adjetivales

*nj* va en cabeza y *js* tras la primera palabra o grupo:

| Construcción | Ejemplo | Sentido |
|---|---|---|
| nominal | *nj jnk js sš* | no soy escriba |
| nominal con *pw* | *nj sꜣ.j js pw* | no es mi hijo |
| adjetival | *nj nfr js* | no es bueno |

## Palabras negativas útiles

| Palabra | Sentido |
|---|---|
| *nn* … *nb* | ningún …, nadie: *nn rmṯ nb* nadie |
| *n zp* | nunca: *n zp jr.j st* nunca lo hice |
| *nj-sw* | él pertenece a |
| *jwtj* | que no tiene, sin (nisba negativa): *jwtj sꜣ.f* que no tiene hijo |

::: exercise meaning
¿Qué significa?

- n sḏm.f → ((no oyó* / no puede oír / no oirá))
- n sḏm.n.f → ((no oyó / no puede oír* / no oirá))
- nn sḏm.f → ((no oyó / no puede oír / no oirá*))
- nn mw → ((no hay agua* / él no es agua / no bebas agua))
:::

::: summary
- *n sḏm.f* pasado «no …»; *n sḏm.n.f* general «no …, no puede»; *nn sḏm.f* futuro «no …».
- *nn* + sustantivo: «no hay»; *nn sw m pr*: «no está en la casa»; *nn … nb*: nadie, nada.
- *nj … js* niega las oraciones nominales y adjetivales; *tm* niega dentro de las oraciones (*r tm sḏm*).
- *n zp* nunca; *jwtj* que no tiene.
:::
