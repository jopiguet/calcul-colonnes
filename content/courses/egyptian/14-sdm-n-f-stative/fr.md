# 14. Le sḏm.n.f et le pseudo-participe

Pour dire que quelque chose **est arrivé**, l'égyptien insère *.n* entre le verbe et son sujet : *sḏm.n.f* « il entendit, il a entendu ». Pour dire que quelque chose **est dans un état** résultant d'une action, il emploie une forme distincte avec ses propres terminaisons, le **pseudo-participe** (ou statif) : *jj.kj* « je suis venu, me voici », *ꜥnḫ.w* « vivant ». Avec ces deux formes, on peut lire le récit et la plupart des inscriptions biographiques.

## Le sḏm.n.f

| Sujet | Forme | Sens |
|---|---|---|
| 1re sg. | *sḏm.n.j* | j'entendis |
| 3e sg. m. | *sḏm.n.f* | il entendit |
| 3e sg. f. | *sḏm.n.s* | elle entendit |
| 3e pl. | *sḏm.n.sn* | ils entendirent |
| un nom | *sḏm.n nswt* | le roi entendit |

Le *.n* s'écrit 𓈖 avant le suffixe. Les verbes faibles ne redoublent jamais ici :

| Verbe | sḏm.n.f | Sens |
|---|---|---|
| *jrj* faire | *jr.n.f* | il fit |
| *mꜣꜣ* voir | *mꜣ.n.f* | il vit |
| *rdj* donner | *rdj.n.f* | il donna |
| *jnj* apporter | *jn.n.f* | il apporta |
| *jj* venir | *jj.n.f* | il vint |

| Construction | Exemple | Sens |
|---|---|---|
| seul, dans le récit | *ḏd.n.f n.j* | il me dit |
| avec *jw* : le résultat compte maintenant | *jw sḏm.n.j mdw.k* | j'ai entendu tes paroles |
| avec un objet | *rdj.n.f n.j jnw* | il me donna un tribut |

## Le pseudo-participe

Le pseudo-participe a ses propres terminaisons et suit son sujet :

| Personne | Terminaison | Exemple | Sens |
|---|---|---|---|
| 1re sg. | *.kj* | *jj.kj* | je suis venu |
| 2e sg. | *.tj* | *jj.tj* | tu es venu |
| 3e sg. m. | *.w* (souvent non écrit) | *jj.w* | il est venu |
| 3e sg. f. | *.tj* | *jj.tj* | elle est venue |
| 1re pl. | *.wjn* | *jj.wjn* | nous sommes venus |
| 3e pl. | *.w* | *jj.w* | ils sont venus |

Son sens dépend du verbe :

| Verbe | Le pseudo-participe signifie | Exemple |
|---|---|---|
| de mouvement | accompli, « est venu » | *jw.f jj.w* il est venu |
| transitif | état passif, « est (a été) fait » | *jw pr qd.w* la maison est bâtie |
| de qualité | « est … » | *jw.f nfr.w* il est bon |
| *ꜥnḫ* vivre | « vivant » | *jw.f ꜥnḫ.w* il est vivant |

Un souhait célèbre clôt beaucoup de noms royaux : *ꜥnḫ ḏt* « vivant à jamais ».

- *ḏd.n.f n.j* → {{Il me dit. / Il m'a dit.}}

:::

::: summary
- *sḏm.n.f* : passé, action accomplie ; *.n* avant le sujet ; verbes faibles sans redoublement (*jr.n.f*, *mꜣ.n.f*). *jw sḏm.n.f* « il a entendu ».
- Pseudo-participe : *.kj, .tj, .w, .tj ; .wjn, .tjwnj, .w* ; un état : accompli avec les verbes de mouvement, passif avec les transitifs, « est » avec les qualités.
- *ꜥnḫ.w* vivant ; *ꜥnḫ ḏt* vivant à jamais.
:::
