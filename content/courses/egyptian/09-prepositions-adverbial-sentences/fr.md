# 9. Les prépositions et la phrase adverbiale

L'égyptien n'a pas de verbe « être » au présent : « le roi est dans le palais » se dit simplement *nswt m pr nswt*, « roi dans palais ». Un sujet suivi d'un groupe prépositionnel ou d'un adverbe forme une phrase complète, la **phrase adverbiale**. Cette leçon donne les prépositions courantes et les trois manières de construire cette phrase : avec un sujet nominal, avec *jw* et avec *mk* « vois ».

## Les prépositions

| Préposition | Sens | Exemple |
|---|---|---|
| *m* 𓅓 | dans, à, avec (un instrument), hors de, en tant que | *m pr* dans la maison ; *m sš* en tant que scribe |
| *n* 𓈖 | à, pour (une personne) | *n nb.f* pour son seigneur |
| *r* 𓂋 | vers (un lieu), contre, plus que | *r nwt* vers la ville |
| *ḥr* 𓁷 | sur, à cause de | *ḥr mw* sur l'eau |
| *ḫr* | auprès de, sous l'autorité de | *ḫr nswt* auprès du roi |
| *ẖr* | sous, portant | *ẖr jnw* chargé de tribut |
| *ḥnꜥ* | avec, en compagnie de | *ḥnꜥ snt.f* avec sa sœur |
| *mj* | comme | *mj rꜥ* comme Rê |
| *jn* | par (l'agent) | *jn nswt* par le roi |
| *ḏr* | depuis | *ḏr rk nṯr* depuis le temps du dieu |
| *m-ꜥ* | de la part de, dans la main de | *m-ꜥ ḥqꜣ* de la part du souverain |
| *m-ḫt* | après | *m-ḫt hrw* après des jours |

Devant un suffixe, *m* devient *jm* et *r* devient *jr* : *jm.f* dedans, *jr.f* vers lui.

## La phrase adverbiale

| Sujet | Construction | Exemple | Sens |
|---|---|---|---|
| un nom | nom + prédicat | *nswt m pr.f* | le roi est dans sa maison |
| un nom ou un suffixe | *jw* + sujet + prédicat | *jw.f m pr.f* | il est dans sa maison |
| un pronom dépendant | *mk* + sujet + prédicat | *mk sw m pr.f* | vois, il est dans sa maison |

Un sujet pronominal a besoin d'un appui : la particule *jw* prend un **suffixe** (*jw.f*, *jw.s*, *jw.j*), la particule *mk* « vois » un pronom **dépendant** (*mk wj*, *mk sw*). *jw* présente l'énoncé comme un fait de la situation ; *mk* le désigne, comme « me voici ».

Le prédicat peut aussi être un adverbe : *jw.f ꜥꜣ* « il est ici », *jw.f jm* « il est là ».

::: exercise preposition
Choisissez la préposition.

- dans la maison → ((m* / n / r)) pr
- vers la ville → ((m / n / r*)) nwt
- pour son seigneur → ((m / n* / r)) nb.f
- avec sa sœur → ((ḥnꜥ* / ḥr / mj)) snt.f
- comme Rê → ((ḥnꜥ / jn / mj*)) rꜥ
:::

::: exercise subject
Complétez avec le sujet demandé.

- il : [[jw.f]] m pr → il est dans la maison
- elle : [[jw.s]] ḥnꜥ sn.s → elle est avec son frère
- vois, je : mk [[wj]] m nwt → vois, je suis dans la ville
- vois, il : mk [[sw]] ḥr mw → vois, il est sur l'eau
:::

::: exercise jm
Devant un suffixe : donnez la forme.

- m + .f « dedans » → [[jm.f]]
- r + .f « vers lui » → [[jr.f]]
- n + .s « à elle » → [[n.s]]
- ḥnꜥ + .k « avec toi » → [[ḥnꜥ.k]]
:::

::: exercise translate
Traduisez.

- *nswt m pr nswt* → {{Le roi est dans le palais. / Le roi est dans la maison du roi.}}
- *jw.j ḥnꜥ.k* → {{Je suis avec toi.}}
- *mk sw r nwt* → {{Vois, il va vers la ville. / Voici qu'il se dirige vers la ville.}}
- *jw ḥmt.f m pr* → {{Sa femme est dans la maison.}}
:::

::: summary
- *m* dans, *n* à (une personne), *r* vers (un lieu), *ḥr* sur, *ḫr* auprès de, *ẖr* sous, *ḥnꜥ* avec, *mj* comme, *jn* par, *ḏr* depuis, *m-ꜥ* de la part de, *m-ḫt* après. *jm.f*, *jr.f* devant un suffixe.
- Pas de « être » au présent : sujet + groupe prépositionnel ou adverbe.
- Sujet nominal seul ; *jw* + suffixe (*jw.f m pr*) ; *mk* + dépendant (*mk sw m pr*).
:::
