# 2. Les signes unilitères

Environ vingt-cinq signes notent chacun une seule consonne. On les appelle souvent l'« alphabet » hiéroglyphique, bien que les Égyptiens n'aient jamais écrit avec eux seuls : ils les mêlaient aux signes de deux et trois consonnes et aux déterminatifs. Tout mot peut s'épeler avec eux, et les noms étrangers (Ptolémée, Cléopâtre) l'étaient. Apprenez ce tableau par cœur ; tout le reste repose sur lui. Le numéro de Gardiner après chaque signe est le nom que lui donnent les égyptologues dans les listes de signes.

Deux confusions faciles : la chouette 𓅓 *m* et le vautour 𓄿 *ꜣ* ; le cobra 𓆓 *ḏ* et la vipère 𓆑 *f*. La chouette est le seul oiseau qui vous regarde.

## Épeler un mot

Un mot se lit signe par signe, dans le sens de lecture, le haut avant le bas :

| Signes | Lettres | Mot |
|---|---|---|
| 𓂋𓈖 | r + n | *rn* « nom » |
| 𓇋𓏏𓆑 | j + t + f | *jt* « père » (la vipère vient de l'ancienne graphie *jtf*) |
| 𓆓𓂧 | ḏ + d | *ḏd* « dire » |
| 𓊪𓏏𓇯 | p + t + ciel | *pt* « ciel » |
| 𓂝𓈎 | ꜥ + ḳ | *ꜥḳ* « entrer » |

Le dernier signe de *pt*, 𓇯, est l'image du ciel lui-même : un déterminatif, qui ne se lit pas. Les déterminatifs viennent à la leçon 4.
