# 4. Logogrammes et déterminatifs

Les sons seuls rendraient l'égyptien difficile à lire : sans voyelles, *pr* peut être « maison » ou « sortir », *mn* « demeurer » ou « souffrir ». Deux procédés règlent le problème. Un **logogramme** écrit un mot entier par une seule image, marquée d'un trait. Un **déterminatif**, placé à la fin d'un mot, ne se lit pas du tout : il indique la catégorie de sens et, en prime, montre où le mot finit. Cette leçon enseigne les deux, et la trentaine de déterminatifs qui couvrent la plupart des textes.

## Les logogrammes

Un signe employé pour le mot qu'il représente prend un petit trait 𓏤, qui ne se lit pas :

| Graphie | Mot | Sens |
|---|---|---|
| 𓉐𓏤 | *pr* | maison |
| 𓂋𓏤 | *r* | bouche |
| 𓁷𓏤 | *ḥr* | visage |
| 𓁶𓏤 | *tp* | tête |
| 𓇳𓏤 | *rꜥ* | soleil, le dieu Rê |
| 𓄣𓏤 | *jb* | cœur |

Le même signe sans trait est un phonogramme : 𓉐 dans *prj* « sortir » n'est que *pr*.

## Les déterminatifs

| Signe | Catégorie | Exemple |
|---|---|---|
| 𓀀 | homme, personne masculine | *sꜣ* fils |
| 𓁐 | femme | *ḥmt* femme, épouse |
| 𓀀𓁐𓏥 | les gens | *rmṯ* les hommes, le peuple |
| 𓀁 | bouche, manger, parler, penser | *wnm* manger ; *mdw* parler |
| 𓀭 | dieu, roi | *Wsjr* Osiris |
| 𓂻 | jambes en marche : mouvement | *šm* aller ; *prj* sortir |
| 𓂡 | bras tenant un bâton : force, effort | *nḫt* fort |
| 𓁹 | œil : voir | *mꜣꜣ* voir |
| 𓇳 | soleil : temps, lumière | *hrw* jour |
| 𓇰 | ciel avec un sceptre : nuit | *grḥ* nuit |
| 𓊖 | carrefour dans une enceinte : ville | *nwt* ville |
| 𓈉 | trois collines : pays étranger, désert | *ḫꜣst* pays étranger |
| 𓉐 | plan de maison : bâtiment | *pr* maison |
| 𓏛 | papyrus roulé : idée abstraite, écriture | *rḫ* savoir |
| 𓅪 | moineau : petit, mauvais | *bjn* mauvais |
| 𓏥 | trois traits : pluriel | *nṯrw* dieux |

Un mot peut prendre deux déterminatifs, ou aucun. Un **nom de personne** finit par 𓀀 ou 𓁐 ; un nom de dieu par 𓀭 ou par le faucon sur son pavois 𓅆.

## Lire un mot entier

| Graphie | Phonogrammes | Déterminatif | Mot |
|---|---|---|---|
| 𓃹𓈖𓅓𓀁 | wn + n + m | 𓀁 manger | *wnm* manger |
| 𓈙𓅓𓂻 | š + m | 𓂻 mouvement | *šm* aller |
| 𓉐𓂋𓂻 | pr + r | 𓂻 mouvement | *prj* sortir |
| 𓉔𓂋𓅱𓇳 | h + r + w | 𓇳 temps | *hrw* jour |
| 𓎼𓂋𓎛𓇰 | g + r + ḥ | 𓇰 nuit | *grḥ* nuit |
| 𓈞𓏏𓁐 | ḥm + t | 𓁐 femme | *ḥmt* femme |

Le lièvre 𓃹 est le bilitère *wn* ; le *j* de *prj* ne s'écrit pas, comme souvent pour les consonnes faibles.

::: summary
- Logogramme : le mot représenté, avec un trait 𓏤 : 𓉐𓏤 *pr*, 𓇳𓏤 *rꜥ*.
- Déterminatif : signe de catégorie muet à la fin d'un mot ; il montre aussi où le mot finit.
- 𓀀 homme, 𓁐 femme, 𓀁 bouche, 𓀭 dieu, 𓂻 mouvement, 𓂡 force, 𓇳 temps, 𓇰 nuit, 𓊖 ville, 𓈉 pays étranger, 𓏛 abstrait, 𓅪 mauvais, 𓏥 pluriel.
:::
