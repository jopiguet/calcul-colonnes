# 21. Lecture : Sinouhé et le Naufragé

Le Moyen Empire a laissé la littérature classique de l'Égypte, recopiée par les scribes pendant des siècles comme modèle de style. Deux œuvres ouvrent presque tous les cours d'égyptologie : l'**Histoire de Sinouhé**, un fonctionnaire qui fuit l'Égypte à la mort du roi Amenemhat Ier et y revient dans sa vieillesse, et le **Conte du Naufragé**, un récit dans le récit raconté pour réconforter un fonctionnaire inquiet. Cette leçon lit leurs premières lignes avec la grammaire du cours. Les translittérations suivent les manuscrits ; les traductions sont les nôtres.

## Sinouhé : le début

*jrj-pꜥt ḥꜣtj-ꜥ sꜣb ꜥḏ-mr … Sꜣ-nht ḏd.f:*

*jnk šmsw šms nb.f, bꜣk n jpt nswt.*

« Le noble héréditaire et comte, juge et administrateur de district … Sinouhé, il dit : j'étais un suivant qui suivait son maître, un serviteur du harem royal. »

| Groupe | Grammaire |
|---|---|
| *jrj-pꜥt*, *ḥꜣtj-ꜥ* | titres : « celui qui appartient à l'élite », « le premier dans l'action », comte |
| *sꜣb ꜥḏ-mr* | titres : « juge », « administrateur de district » |
| *ḏd.f* | *sḏm.f* : « il dit » |
| *jnk šmsw* | phrase nominale avec le pronom indépendant : « je suis (j'étais) un suivant » |
| *šms nb.f* | participe avec objet : « qui suivait son maître » |
| *bꜣk n jpt nswt* | génitif indirect *n* après un nom masculin |

## Sinouhé : la mort du roi

*ḥꜣt-sp 30 ꜣbd 3 ꜣḫt sw 7, ꜥr nṯr r ꜣḫt.f, nswt-bjtj Sḥtp-jb-Rꜥ.*

« An 30 du règne, 3e mois de l'Inondation, jour 7 : le dieu monta vers son horizon, le roi de Haute et de Basse-Égypte Sehetepibrê. »

| Groupe | Grammaire |
|---|---|
| *ḥꜣt-sp 30 ꜣbd 3 ꜣḫt sw 7* | une date (leçon 11) |
| *ꜥr nṯr* | *sḏm.f* avec un sujet nominal : « le dieu monta » |
| *r ꜣḫt.f* | préposition *r* + nom + suffixe : « vers son horizon » |
| *Sḥtp-jb-Rꜥ* | nom de couronnement d'Amenemhat Ier : « c'est Rê qui satisfait le cœur », *Rꜥ* écrit en premier |

Le roi ne meurt pas : « le dieu monta vers son horizon », comme le soleil qui se couche.

## Le Naufragé

*ḏd jn šmsw jqr: wḏꜣ jb.k ḥꜣtj-ꜥ. mk pḥ.n.n ẖnw.*

« Alors le suivant excellent dit : Que ton cœur soit sain, comte ! Vois, nous avons atteint la Résidence. »

| Groupe | Grammaire |
|---|---|
| *ḏd jn šmsw jqr* | « dit par le suivant excellent » : verbe + *jn* + sujet nominal, une forme de récit |
| *wḏꜣ jb.k* | *sḏm.f* subjonctif de souhait : « que ton cœur soit sain » |
| *mk* | particule « vois » |
| *pḥ.n.n ẖnw* | *sḏm.n.f* avec le suffixe *.n* « nous » : « nous avons atteint la Résidence » |

::: exercise forms
Nommez la forme.

- ḏd.f dans « Sinouhé, il dit » → ((sḏm.f* / sḏm.n.f / pseudo-participe))
- pḥ.n.n « nous avons atteint » → ((sḏm.f / sḏm.n.f* / infinitif))
- šms dans « qui suivait son maître » → ((infinitif / participe* / impératif))
- wḏꜣ jb.k « que ton cœur soit sain » → ((subjonctif* / passé / futur))
:::

::: exercise translate
Traduisez.

- *jnk šmsw šms nb.f* → {{J'étais un suivant qui suivait son maître. / Je suis un suivant qui a suivi son maître.}}
- *ꜥr nṯr r ꜣḫt.f* → {{Le dieu monta vers son horizon. / Le dieu est monté vers son horizon.}}
- *wḏꜣ jb.k* → {{Que ton cœur soit sain ! / Courage !}}
- *mk pḥ.n.n ẖnw* → {{Vois, nous avons atteint la Résidence. / Vois, nous sommes arrivés chez nous.}}
:::

::: summary
- Sinouhé : *jnk šmsw šms nb.f* « j'étais un suivant qui suivait son maître » : pronom indépendant, participe avec objet.
- *ꜥr nṯr r ꜣḫt.f* : la mort du roi comme le soleil qui atteint son horizon ; une date en années de règne.
- Le Naufragé : *ḏd jn* + sujet ; *wḏꜣ jb.k* (souhait au subjonctif) ; *mk pḥ.n.n ẖnw* (*sḏm.n.f*).
- Toutes les formes du cours apparaissent dans les premières lignes des classiques.
:::
