# 12. Classes verbales et infinitif

Un verbe égyptien est une racine de deux à cinq consonnes. Ses formes se font en ajoutant des terminaisons, et parfois en redoublant ou en perdant une consonne : la première chose à savoir d'un verbe est donc sa **classe**, la forme de sa racine. Cette leçon présente les classes, puis la forme verbale la plus simple, l'**infinitif**, et son emploi le plus courant : *jw.f ḥr sḏm* « il est en train d'entendre », le progressif égyptien.

## Les classes verbales

Les grammaires nomment les classes d'après leur nombre de consonnes et leur point faible :

| Classe | Racine | Exemple | Sens |
|---|---|---|---|
| forte bilitère | 2 consonnes | *ḏd*, *mn* | dire ; demeurer |
| forte trilitère | 3 consonnes | *sḏm*, *ꜥnḫ* | entendre ; vivre |
| 3ae-inf. (« troisième faible ») | dernière consonne *j* ou *w*, souvent non écrite | *mrj*, *prj*, *jrj*, *ḥsj* | aimer ; sortir ; faire ; louer |
| 2ae-gem. (« deuxième redoublée ») | deux dernières consonnes identiques | *mꜣꜣ*, *wnn* | voir ; être, exister |
| irrégulière | | *rdj*, *jj*, *jnj* | donner ; venir ; apporter |

Le *j* faible des verbes 3ae-inf. disparaît dans beaucoup de formes : *mrj* « aimer » s'écrit *mr*. Les verbes géminés ne montrent leur consonne redoublée que dans certaines formes : *mꜣꜣ.f* « il voit » mais *mꜣ.n.f* « il vit ».

## L'infinitif

L'infinitif nomme l'action : « entendre, le fait d'entendre ». C'est un nom masculin, sauf dans les classes faibles, qui ajoutent *-t* :

| Classe | Racine | Infinitif |
|---|---|---|
| forte | *sḏm* | *sḏm* |
| forte | *ḏd* | *ḏd* |
| 3ae-inf. | *mrj* | *mrt* |
| 3ae-inf. | *prj* | *prt* |
| 3ae-inf. | *jrj* | *jrt* |
| 2ae-gem. | *mꜣꜣ* | *mꜣꜣ* |
| irrégulière | *rdj* | *rdjt* |
| irrégulière | *jj* | *jwt* ou *jjt* |
| irrégulière | *jnj* | *jnt* |

Comme nom, l'infinitif prend un suffixe ou un génitif. Le suffixe peut en être le sujet ou l'objet : *mrt.f* « son amour (qu'il porte) » ou « l'aimer » ; *sḏm mdw* « entendre des paroles ».

## Le progressif : jw.f ḥr sḏm

La préposition *ḥr* « sur » + infinitif signifie « en train de faire » : l'action est en cours.

| Construction | Exemple | Sens |
|---|---|---|
| sujet + *ḥr* + infinitif | *jw.f ḥr sḏm* | il entend, il est en train d'entendre |
| avec un objet | *jw.f ḥr sḏm mdw* | il écoute les paroles |
| verbe de mouvement : *m* + infinitif | *jw.f m jwt* | il est en train de venir |
| après *mk* | *mk wj ḥr ḏd* | vois, je suis en train de parler |

C'est la phrase adverbiale de la leçon 9 avec un infinitif dans le groupe prépositionnel. Les grammaires l'appellent la **construction pseudo-verbale**.

::: summary
- Classes : forte (*sḏm*, *ḏd*), 3ae-inf. (*mrj*, *prj*, *jrj* : *j* faible), 2ae-gem. (*mꜣꜣ*, *wnn*), irrégulière (*rdj*, *jj*, *jnj*).
- Infinitif : la racine ; les 3ae-inf. ajoutent *-t* (*mrt*, *prt*, *jrt*) ; *rdjt*, *jwt*, *jnt*.
- Progressif : *jw.f ḥr* + infinitif « il est en train de » ; avec les verbes de mouvement *m* + infinitif.
:::
