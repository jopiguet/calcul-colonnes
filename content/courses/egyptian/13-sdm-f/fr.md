# 13. Le sḏm.f

Les formes verbales égyptiennes portent le nom d'un verbe modèle, *sḏm* « entendre » : la forme *sḏm.f* est « la forme comme *sḏm.f* », quel que soit le verbe. C'est le radical du verbe suivi directement de son sujet, pronom suffixe ou nom. Elle n'a pas de temps propre : selon sa forme et son contexte, elle exprime un présent général (« il entend »), un souhait (« puisse-t-il entendre ») ou un but (« pour qu'il entende »). Cette leçon en présente les formes et deux des emplois : l'**inaccompli** et le **subjonctif**.

## Les formes

| Sujet | Forme | Sens |
|---|---|---|
| 1re sg. | *sḏm.j* | j'entends |
| 2e sg. m. | *sḏm.k* | tu entends |
| 3e sg. m. | *sḏm.f* | il entend |
| 3e sg. f. | *sḏm.s* | elle entend |
| 1re pl. | *sḏm.n* | nous entendons |
| 3e pl. | *sḏm.sn* | ils entendent |
| un nom | *sḏm sꜣ* | le fils entend |

Un sujet nominal prend la place du suffixe : *ḏd.f* « il dit », *ḏd nswt* « le roi dit ». L'objet suit le sujet : *sḏm.f mdw* « il entend les paroles » ; un pronom objet est dépendant : *sḏm.f sw* « il l'entend ».

## Inaccompli et subjonctif

Avec les verbes forts, les deux se ressemblent. Les verbes faibles et géminés les distinguent : l'**inaccompli** redouble la dernière consonne, le **subjonctif** non.

| Verbe | Inaccompli (répété, général) | Subjonctif (souhait, but) |
|---|---|---|
| *jrj* faire | *jrr.f* il fait | *jr.f* puisse-t-il faire, qu'il fasse |
| *mrj* aimer | *mrr.f* il aime | *mr.f* puisse-t-il aimer |
| *mꜣꜣ* voir | *mꜣꜣ.f* il voit | *mꜣ.f* puisse-t-il voir |
| *rdj* donner | *dd.f* il donne | *dj.f* puisse-t-il donner |
| *sḏm* entendre | *sḏm.f* il entend | *sḏm.f* puisse-t-il entendre |

| Emploi | Exemple | Sens |
|---|---|---|
| inaccompli : ce qui se fait d'habitude | *jrr.f mrrt nṯr* | il fait ce que le dieu aime |
| subjonctif : souhait | *dj.f ꜥnḫ* | puisse-t-il donner la vie |
| subjonctif : but | *jj.n.j mꜣ.j nfrw.k* | je suis venu pour voir ta beauté |
| subjonctif après *rdj* « faire que » | *rdj.n.f jr.j st* | il me l'a fait faire, il m'a laissé le faire |

*jw* + *sḏm.f* énonce une vérité générale : *jw sḏm.f* « il entend (toujours) ».

::: summary
- *sḏm.f* : radical + sujet (suffixe ou nom) ; objet après le sujet ; pronom objet dépendant (*sḏm.f sw*).
- Inaccompli : général, répété ; les verbes faibles redoublent (*jrr.f*, *mrr.f*, *dd.f*).
- Subjonctif : souhait, but, après *rdj* « faire que » ; pas de redoublement (*jr.f*, *mr.f*, *dj.f*).
:::
