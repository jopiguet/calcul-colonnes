# 3. Los signos bilíteros y trilíteros

La mayoría de las palabras jeroglíficas no se deletrean letra a letra. Muchos signos anotan dos consonantes (**bilíteros**) o tres (**trilíteros**), y el escriba añadía unilíteros a su lado para confirmar la lectura: los **complementos fonéticos**. Esta lección da los signos multilíteros más frecuentes y la regla de los complementos, que permite leer las palabras más corrientes de la lengua.

| 𓉐 | pr | planta de casa | *pr* casa |

| 𓅭 | sꜣ | ánade rabudo | *sꜣ* hijo |
| 𓏠 | mn | tablero de juego | *mn* permanecer; *Jmn* Amón |
| 𓁹 | jr | ojo | *jrj* hacer |
| 𓂓 | kꜣ | brazos alzados | *kꜣ* el ka |
| 𓌢 | sn | punta de flecha | *sn* hermano |
| 𓁷 | ḥr | rostro | *ḥr* rostro; sobre |
| 𓁶 | tp | cabeza | *tp* cabeza; sobre |
| 𓇾 | tꜣ | franja de tierra | *tꜣ* tierra, país |
| 𓌳 | mꜣ | hoz | *mꜣꜣ* ver |

## Los complementos fonéticos

Un signo multilítero suele ir seguido (o rodeado) de unilíteros que repiten **su última consonante, o sus dos últimas**. No se leen una segunda vez.

| Grafía | Signo + complementos | Lectura |
|---|---|---|
| 𓋹𓈖𓐍 | ꜥnḫ + n + ḫ | *ꜥnḫ*, no *ꜥnḫnḫ* |
| 𓄤𓆑𓂋 | nfr + f + r | *nfr* |
| 𓊵𓏏𓊪 | ḥtp + t + p | *ḥtp* |
| 𓏠𓈖 | mn + n | *mn* |
| 𓆣𓂋 | ḫpr + r | *ḫpr* |
| 𓁹𓂋 | jr + r | *jr* (en *jrj*) |
| 𓇋𓏠𓈖 | j + mn + n | *jmn*, Amón |

La regla da la lectura de un signo nuevo: si 𓅨𓂋 es *wr*, la golondrina vale *wr* y la boca solo confirma la *r*.

::: summary
- Bilíteros: 𓉐 pr, 𓎟 nb, 𓅭 sꜣ, 𓏠 mn, 𓁹 jr, 𓂓 kꜣ, 𓌢 sn, 𓁷 ḥr, 𓁶 tp, 𓇾 tꜣ, 𓌳 mꜣ, 𓅨 wr, 𓄣 jb.
- Trilíteros: 𓋹 ꜥnḫ, 𓄤 nfr, 𓊵 ḥtp, 𓊹 nṯr, 𓆣 ḫpr, 𓊤 ḫrw, 𓋾 ḥqꜣ, 𓐙 mꜣꜥ.
- Los complementos fonéticos repiten la última o las dos últimas consonantes de un signo y se leen una sola vez.
