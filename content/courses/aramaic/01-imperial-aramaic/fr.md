# 1. L'araméen d'empire

L'araméen était la langue des Araméens de Syrie, écrite dès le IXe siècle avant notre ère. Les empires assyrien puis perse en firent la langue de leur administration, de l'Égypte à l'Indus : cette norme écrite, en usage d'environ 600 à 330 avant notre ère, s'appelle l'araméen d'empire, ou araméen officiel. Cette leçon présente son écriture et ses onze premières lettres.

## Une écriture de vingt-deux consonnes

- L'écriture compte 22 lettres, dans l'ordre de l'alphabet phénicien, celui que l'hébreu garde encore. Elle se lit de droite à gauche, et les mots sont séparés par des espaces.
- Seules les consonnes s'écrivent. ʾ (aleph), h, w et y notent aussi certaines voyelles longues : 𐡁𐡉𐡕 *byt* se lit *bayt*, « maison » ; 𐡉𐡅𐡌 *ywm* se lit *yōm*, « jour ».
- La translittération donne les consonnes seules : 𐡌𐡋𐡊 *mlk*, « roi », se disait probablement *malk*. Vous tapez la translittération : les touches sous la réponse donnent ʾ ʿ ḥ ṭ ṣ š, ʾ peut aussi se taper ', et les voyelles ajoutées sont ignorées.
- Les lettres carrées de l'hébreu, l'écriture nabatéenne devenue l'arabe, le syriaque et le sogdien, d'où viennent l'ouïghour et le mongol, descendent toutes de celle-ci.

## Les onze premières lettres

| Lettre | Son | Nom |
|---|---|---|
| 𐡀 | ʾ | aleph |
| 𐡁 | b | beth |
| 𐡂 | g | gimel |
| 𐡃 | d | daleth |
| 𐡄 | h | he |
| 𐡅 | w | waw |
| 𐡆 | z | zayin |
| 𐡇 | ḥ | heth |
| 𐡈 | ṭ | teth |
| 𐡉 | y | yodh |
| 𐡊 | k | kaph |

- ʾ est un coup de glotte, l'arrêt de « oh-oh ». En fin de mot, il ne marque souvent qu'une voyelle *ā*.
- ḥ est un h serré dans la gorge, comme l'arabe ح ; ṭ un t « emphatique », prononcé plus en arrière. Vous pouvez les taper sans le point ; les exercices à choix les distinguent.
- Dans cette écriture, 𐡃 et 𐡓 (leçon suivante) sont presque le même signe : une petite tête sur un trait. Le mot dit lequel c'est.

## Premiers mots

| Lettres | Translittération | Sens |
|---|---|---|
| 𐡀𐡁 | ʾb | père |
| 𐡀𐡇 | ʾḥ | frère |
| 𐡀𐡇𐡕 | ʾḥt | sœur |
| 𐡁𐡉𐡕 | byt | maison |
| 𐡉𐡃 | yd | main |
| 𐡀𐡋𐡄 | ʾlh | dieu |

- 𐡀𐡋𐡄 *ʾlh* se disait *ʾelāh* : le même mot que l'hébreu *ʾĕlōah* et l'arabe *ʾilāh*.
- 𐡀𐡇𐡕 *ʾḥt* est 𐡀𐡇 *ʾḥ* avec le *-t* du féminin.
