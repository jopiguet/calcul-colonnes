# 6. «Ser» y «tener»

El verbo va al final de la frase: sujeto, objeto, verbo. El malayalam tiene dos verbos «ser/estar», y ninguno para «tener».

## ആണ് y ഉണ്ട്

| | Sí | No | Pregunta |
|---|---|---|---|
| es (qué o quién es algo) | ആണ് *āṇŭ* | അല്ല *alla* | ആണോ? *āṇō?* |
| hay, existe, está en un lugar | ഉണ്ട് *uṇṭŭ* | ഇല്ല *illa* | ഉണ്ടോ? *uṇṭō?* |

ആണ് une dos sustantivos: ഇത് എന്റെ വീട് ആണ് *itŭ enṯe vīṭŭ āṇŭ* «esta es mi casa»; ഞാൻ ഡോക്ടർ അല്ല «no soy médico». ഉണ്ട് dice que algo existe o está ahí: ചായ ഉണ്ട് *cāya uṇṭŭ* «hay té»; ചായ ഇല്ല «no hay té». La terminación *-ō* convierte cualquiera de los dos en pregunta; അല്ലേ? *allē?* pregunta «¿verdad?». Ninguno cambia según la persona: ഞാൻ ആണ്, അവർ ആണ്.

ആണ് suele soldarse a la palabra anterior: ഡോക്ടറാണ് *ḍōkṭarāṇŭ*, എന്താണ് *entāṇŭ* «qué es».

## «Tener»: el dativo

Tener algo es que la cosa exista *para* alguien: el poseedor va en dativo y el verbo es ഉണ്ട്.

| Pronombre | Dativo | Ejemplo |
|---|---|---|
| ഞാൻ | എനിക്ക് *enikkŭ* | എനിക്ക് ഒരു പൂച്ച ഉണ്ട് tengo un gato |
| നീ | നിനക്ക് *ninakkŭ* | |
| നിങ്ങൾ | നിങ്ങൾക്ക് *niṅṅaḷkkŭ* | |
| അവൻ | അവന് *avanŭ* | |
| അവൾ | അവൾക്ക് *avaḷkkŭ* | |
| നമ്മൾ | നമുക്ക് *namukkŭ* | |
| ഞങ്ങൾ | ഞങ്ങൾക്ക് *ñaṅṅaḷkkŭ* | |
| അവർ | അവർക്ക് *avarkkŭ* | അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട് tienen dos hijos |

ഒരു *oru* «un, uno» va delante del sustantivo cuando importa que haya uno.

::: exercise ask
Conviértalo en pregunta.

- ഇത് പാൽ ആണ്. → ((ഇത് പാൽ ആണോ?* / ഇത് പാൽ അല്ല. / ഇത് പാൽ ഉണ്ട്.))
- ചായ ഉണ്ട്. → ((ചായ ഉണ്ടോ?* / ചായ ഇല്ല. / ചായ ആണ്.))
- «Es tu libro, ¿verdad?» → ((നിന്റെ പുസ്തകം ആണ്, അല്ലേ?* / നിന്റെ പുസ്തകം ഇല്ല. / നിന്റെ പുസ്തകം ഉണ്ടോ?))
- «¿Tiene usted tiempo?» → ((നിങ്ങൾക്ക് സമയം ഉണ്ടോ?* / നിങ്ങൾ സമയം ആണോ? / നിങ്ങൾക്ക് സമയം ഇല്ല.))
:::

::: exercise translate
Traduzca.

- എനിക്ക് സമയം ഇല്ല. → {{No tengo tiempo.}}
- ഇത് എന്റെ പുസ്തകം ആണ്. → {{Este es mi libro.}}
- അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട്. → {{Tienen dos hijos. / Ellos tienen dos niños.}}
- അവൻ ഡോക്ടർ അല്ല. → {{No es médico. / Él no es médico.}}
:::

::: summary
- Verbo al final; no cambia según la persona.
- ആണ് / അല്ല: qué es algo. ഉണ്ട് / ഇല്ല: que existe o está. Pregunta *-ō*: ആണോ?, ഉണ്ടോ?; അല്ലേ? «¿verdad?».
- Tener = dativo + ഉണ്ട്: എനിക്ക് ഒരു പൂച്ച ഉണ്ട്.
:::
