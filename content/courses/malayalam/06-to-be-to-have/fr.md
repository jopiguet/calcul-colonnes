# 6. « Être » et « avoir »

Le verbe vient en fin de phrase : sujet, objet, verbe. Le malayalam a deux verbes « être », et aucun pour « avoir ».

## ആണ് et ഉണ്ട്

| | Oui | Non | Question |
|---|---|---|---|
| est (ce qu'est quelque chose) | ആണ് *āṇŭ* | അല്ല *alla* | ആണോ? *āṇō?* |
| il y a, existe, se trouve | ഉണ്ട് *uṇṭŭ* | ഇല്ല *illa* | ഉണ്ടോ? *uṇṭō?* |

ആണ് relie deux noms : ഇത് എന്റെ വീട് ആണ് *itŭ enṯe vīṭŭ āṇŭ* « c'est ma maison » ; ഞാൻ ഡോക്ടർ അല്ല « je ne suis pas médecin ». ഉണ്ട് dit qu'une chose existe ou se trouve là : ചായ ഉണ്ട് *cāya uṇṭŭ* « il y a du thé » ; ചായ ഇല്ല « il n'y a pas de thé ». La terminaison *-ō* fait de l'un ou l'autre une question ; അല്ലേ? *allē?* demande « n'est-ce pas ? ». Aucun des deux ne change selon la personne : ഞാൻ ആണ്, അവർ ആണ്.

ആണ് se soude souvent au mot qui précède : ഡോക്ടറാണ് *ḍōkṭarāṇŭ*, എന്താണ് *entāṇŭ* « qu'est-ce que c'est ».

## « Avoir » : le datif

Avoir quelque chose, c'est que la chose existe *pour* quelqu'un : le possesseur se met au datif et le verbe est ഉണ്ട്.

| Pronom | Datif | Exemple |
|---|---|---|
| ഞാൻ | എനിക്ക് *enikkŭ* | എനിക്ക് ഒരു പൂച്ച ഉണ്ട് j'ai un chat |
| നീ | നിനക്ക് *ninakkŭ* | |
| നിങ്ങൾ | നിങ്ങൾക്ക് *niṅṅaḷkkŭ* | |
| അവൻ | അവന് *avanŭ* | |
| അവൾ | അവൾക്ക് *avaḷkkŭ* | |
| നമ്മൾ | നമുക്ക് *namukkŭ* | |
| ഞങ്ങൾ | ഞങ്ങൾക്ക് *ñaṅṅaḷkkŭ* | |
| അവർ | അവർക്ക് *avarkkŭ* | അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട് ils ont deux enfants |

ഒരു *oru* « un » se place devant le nom quand il importe qu'il y en ait un.

::: exercise which
ആണ്, ഉണ്ട് ou leur négation ?

- ഇത് എന്റെ വീട് ___. → ((ആണ്* / ഉണ്ട്))
- എനിക്ക് ഒരു പൂച്ച ___. → ((ആണ് / ഉണ്ട്*))
- അവൻ ഡോക്ടർ ___. (pas) → ((അല്ല* / ഇല്ല))
- വെള്ളം ___. (il n'y en a pas) → ((അല്ല / ഇല്ല*))
:::

::: exercise ask
Faites-en une question.

- ഇത് പാൽ ആണ്. → ((ഇത് പാൽ ആണോ?* / ഇത് പാൽ അല്ല. / ഇത് പാൽ ഉണ്ട്.))
- ചായ ഉണ്ട്. → ((ചായ ഉണ്ടോ?* / ചായ ഇല്ല. / ചായ ആണ്.))
- « C'est ton livre, n'est-ce pas ? » → ((നിന്റെ പുസ്തകം ആണ്, അല്ലേ?* / നിന്റെ പുസ്തകം ഇല്ല. / നിന്റെ പുസ്തകം ഉണ്ടോ?))
- « Avez-vous le temps ? » → ((നിങ്ങൾക്ക് സമയം ഉണ്ടോ?* / നിങ്ങൾ സമയം ആണോ? / നിങ്ങൾക്ക് സമയം ഇല്ല.))
:::

::: exercise translate
Traduisez.

- എനിക്ക് സമയം ഇല്ല. → {{Je n'ai pas le temps.}}
- ഇത് എന്റെ പുസ്തകം ആണ്. → {{C'est mon livre.}}
- അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട്. → {{Ils ont deux enfants.}}
- അവൻ ഡോക്ടർ അല്ല. → {{Il n'est pas médecin.}}
:::

::: summary
- Verbe en dernier ; il ne change pas selon la personne.
- ആണ് / അല്ല : ce qu'est une chose. ഉണ്ട് / ഇല്ല : qu'elle existe ou se trouve là. Question *-ō* : ആണോ?, ഉണ്ടോ? ; അല്ലേ? « n'est-ce pas ? ».
- Avoir = datif + ഉണ്ട് : എനിക്ക് ഒരു പൂച്ച ഉണ്ട്.
:::
