# 6. "To be" and "to have"

The verb comes at the end of the sentence: subject, object, verb. Malayalam has two verbs "to be", and none for "to have".

## ആണ് and ഉണ്ട്

| | Yes | No | Question |
|---|---|---|---|
| is (who or what something is) | ആണ് *āṇŭ* | അല്ല *alla* | ആണോ? *āṇō?* |
| there is, exists, is somewhere | ഉണ്ട് *uṇṭŭ* | ഇല്ല *illa* | ഉണ്ടോ? *uṇṭō?* |

ആണ് links two nouns: ഇത് എന്റെ വീട് ആണ് *itŭ enṯe vīṭŭ āṇŭ* "this is my house"; ഞാൻ ഡോക്ടർ അല്ല "I am not a doctor". ഉണ്ട് says that something exists or is there: ചായ ഉണ്ട് *cāya uṇṭŭ* "there is tea"; ചായ ഇല്ല "there is no tea". The question ending *-ō* turns either into a question; അല്ലേ? *allē?* asks "isn't it?". Neither verb changes for the person: ഞാൻ ആണ്, അവർ ആണ്.

ആണ് often fuses with the word before it: ഡോക്ടറാണ് *ḍōkṭarāṇŭ*, എന്താണ് *entāṇŭ* "what is it".

## "To have": the dative

To have something is for it to exist *to* someone: the owner takes the dative and the verb is ഉണ്ട്.

| Pronoun | Dative | Example |
|---|---|---|
| ഞാൻ | എനിക്ക് *enikkŭ* | എനിക്ക് ഒരു പൂച്ച ഉണ്ട് I have a cat |
| നീ | നിനക്ക് *ninakkŭ* | |
| നിങ്ങൾ | നിങ്ങൾക്ക് *niṅṅaḷkkŭ* | |
| അവൻ | അവന് *avanŭ* | |
| അവൾ | അവൾക്ക് *avaḷkkŭ* | |
| നമ്മൾ | നമുക്ക് *namukkŭ* | |
| ഞങ്ങൾ | ഞങ്ങൾക്ക് *ñaṅṅaḷkkŭ* | |
| അവർ | അവർക്ക് *avarkkŭ* | അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട് they have two children |

ഒരു *oru* "a, one" stands before a noun when it matters that there is one.

::: exercise ask
Make it a question.

- ഇത് പാൽ ആണ്. → ((ഇത് പാൽ ആണോ?* / ഇത് പാൽ അല്ല. / ഇത് പാൽ ഉണ്ട്.))
- ചായ ഉണ്ട്. → ((ചായ ഉണ്ടോ?* / ചായ ഇല്ല. / ചായ ആണ്.))
- "It's your book, isn't it?" → ((നിന്റെ പുസ്തകം ആണ്, അല്ലേ?* / നിന്റെ പുസ്തകം ഇല്ല. / നിന്റെ പുസ്തകം ഉണ്ടോ?))
- "Do you have time?" → ((നിങ്ങൾക്ക് സമയം ഉണ്ടോ?* / നിങ്ങൾ സമയം ആണോ? / നിങ്ങൾക്ക് സമയം ഇല്ല.))
:::

::: exercise translate
Translate.

- എനിക്ക് സമയം ഇല്ല. → {{I have no time. / I don't have time.}}
- ഇത് എന്റെ പുസ്തകം ആണ്. → {{This is my book.}}
- അവർക്ക് രണ്ട് കുട്ടികൾ ഉണ്ട്. → {{They have two children.}}
- അവൻ ഡോക്ടർ അല്ല. → {{He is not a doctor. / He isn't a doctor.}}
:::

::: summary
- Verb last; it does not change for the person.
- ആണ് / അല്ല: what something is. ഉണ്ട് / ഇല്ല: that it exists or is there. Question *-ō*: ആണോ?, ഉണ്ടോ?; അല്ലേ? "isn't it?".
- To have = dative + ഉണ്ട്: എനിക്ക് ഒരു പൂച്ച ഉണ്ട്.
:::
