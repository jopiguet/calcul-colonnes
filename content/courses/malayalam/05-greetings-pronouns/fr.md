# 5. Salutations et pronoms

Les Malayalis saluent d'un നമസ്കാരം *namaskāraṁ*, paumes jointes, à toute heure ; entre amis, une simple question sur la santé suffit. On remercie moins qu'en Europe : നന്ദി *nandi* exprime une vraie gratitude, pas un réflexe.

## Salutations

| Malayalam | Lecture | Sens |
|---|---|---|
| നമസ്കാരം | *namaskāraṁ* | bonjour (soutenu) |
| സുഖമാണോ? | *sukhamāṇō?* | tu vas bien ? |
| സുഖമാണ് | *sukhamāṇŭ* | je vais bien |
| എന്റെ പേര് മീര ആണ് | *enṯe pērŭ Mīra āṇŭ* | je m'appelle Meera |
| നിങ്ങളുടെ പേര് എന്താണ്? | *niṅṅaḷuṭe pērŭ entāṇŭ?* | comment vous appelez-vous ? |
| നന്ദി | *nandi* | merci |
| ശരി | *śari* | d'accord, juste |
| പോയിട്ട് വരാം | *pōyiṭṭŭ varāṁ* | au revoir (« je pars et je reviens ») |

Le malayalam n'a pas d'« au revoir » qui dise « je m'en vais » : on dit qu'on reviendra.

## Les pronoms personnels

| | Familier | Poli ou pluriel |
|---|---|---|
| je | ഞാൻ *ñān* | |
| tu, vous | നീ *nī* | നിങ്ങൾ *niṅṅaḷ* ; soutenu താങ്കൾ *tāṅkaḷ* |
| il | അവൻ *avan* | അദ്ദേഹം *addēhaṁ* |
| elle | അവൾ *avaḷ* | അവർ *avar* |
| ça, cela | അത് *atŭ* | |
| nous, avec vous | നമ്മൾ *nammaḷ* | |
| nous, sans vous | ഞങ്ങൾ *ñaṅṅaḷ* | |
| ils, elles | അവർ *avar* | |

നീ se dit aux enfants, aux amis proches et aux cadets de la famille ; à tous les autres, നിങ്ങൾ. Les pronoms en *a-* désignent le lointain (അവൻ « il, celui-là ») ; les formes en *i-* le proche : ഇവൻ *ivan*, ഇവൾ *ivaḷ*, ഇവർ *ivar* « celui-ci ». Le malayalam a deux « nous » : നമ്മൾ inclut l'interlocuteur, ഞങ്ങൾ l'exclut.

- നിങ്ങളുടെ പേര് എന്താണ്? → {{Comment vous appelez-vous ? / Quel est votre nom ?}}

::: summary
- നമസ്കാരം, സുഖമാണോ?, നന്ദി, ശരി, പോയിട്ട് വരാം.
- ഞാൻ, നീ / നിങ്ങൾ / താങ്കൾ, അവൻ, അവൾ, അത്, അവർ ; respect : അദ്ദേഹം, അവർ.
- Deux « nous » : നമ്മൾ avec l'interlocuteur, ഞങ്ങൾ sans ; *i-* proche, *a-* lointain (ഇവൻ, അവൻ).
:::
