# 5. Saludos y pronombres

Los malayalis saludan con un നമസ്കാരം *namaskāraṁ*, con las palmas juntas, a cualquier hora; entre amigos basta una pregunta por la salud. Se dan menos las gracias que en Europa: നന്ദി *nandi* es gratitud de verdad, no un reflejo.

## Saludos

| Malayalam | Lectura | Sentido |
|---|---|---|
| നമസ്കാരം | *namaskāraṁ* | hola (formal) |
| സുഖമാണോ? | *sukhamāṇō?* | ¿estás bien? |
| സുഖമാണ് | *sukhamāṇŭ* | estoy bien |
| എന്റെ പേര് മീര ആണ് | *enṯe pērŭ Mīra āṇŭ* | me llamo Meera |
| നിങ്ങളുടെ പേര് എന്താണ്? | *niṅṅaḷuṭe pērŭ entāṇŭ?* | ¿cómo se llama usted? |
| നന്ദി | *nandi* | gracias |
| ശരി | *śari* | vale, correcto |
| പോയിട്ട് വരാം | *pōyiṭṭŭ varāṁ* | adiós («me voy y vuelvo») |

El malayalam no tiene un «adiós» que diga «me voy»: se dice que se volverá.

## Los pronombres personales

| | Familiar | Cortés o plural |
|---|---|---|
| yo | ഞാൻ *ñān* | |
| tú, usted | നീ *nī* | നിങ്ങൾ *niṅṅaḷ*; formal താങ്കൾ *tāṅkaḷ* |
| él | അവൻ *avan* | അദ്ദേഹം *addēhaṁ* |
| ella | അവൾ *avaḷ* | അവർ *avar* |
| eso | അത് *atŭ* | |
| nosotros, contigo | നമ്മൾ *nammaḷ* | |
| nosotros, sin ti | ഞങ്ങൾ *ñaṅṅaḷ* | |
| ellos, ellas | അവർ *avar* | |

നീ se usa con niños, amigos íntimos y familiares más jóvenes; con todos los demás, നിങ്ങൾ. Los pronombres en *a-* señalan lo lejano (അവൻ «él, aquel»); las formas en *i-*, lo cercano: ഇവൻ *ivan*, ഇവൾ *ivaḷ*, ഇവർ *ivar* «este». El malayalam tiene dos «nosotros»: നമ്മൾ incluye al oyente, ഞങ്ങൾ lo excluye.

::: exercise which
¿Qué pronombre?

- «nosotros» dicho a amigos, de todos juntos → ((നമ്മൾ* / ഞങ്ങൾ))
- «nosotros» dicho a un tendero, de su familia → ((നമ്മൾ / ഞങ്ങൾ*))
- «usted» a un profesor → ((നീ / നിങ്ങൾ*))
- «tú» a su hermano pequeño → ((നീ* / താങ്കൾ))
:::

::: exercise translate
Traduzca.

- എന്റെ പേര് മീര ആണ്. → {{Me llamo Meera. / Mi nombre es Meera.}}
- നിങ്ങളുടെ പേര് എന്താണ്? → {{¿Cómo se llama usted? / ¿Cuál es su nombre? / ¿Cómo te llamas?}}
- ശരി, പോയിട്ട് വരാം. → {{Vale, adiós. / Bien, hasta luego.}}
- നമസ്കാരം, സുഖമാണോ? → {{Hola, ¿está bien? / Hola, ¿qué tal?}}
:::

::: summary
- നമസ്കാരം, സുഖമാണോ?, നന്ദി, ശരി, പോയിട്ട് വരാം.
- ഞാൻ, നീ / നിങ്ങൾ / താങ്കൾ, അവൻ, അവൾ, അത്, അവർ; respeto: അദ്ദേഹം, അവർ.
- Dos «nosotros»: നമ്മൾ con el oyente, ഞങ്ങൾ sin él; *i-* cerca, *a-* lejos (ഇവൻ, അവൻ).
:::
