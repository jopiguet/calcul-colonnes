# 5. Greetings and pronouns

Malayalis greet with നമസ്കാരം *namaskāraṁ*, palms together, at any hour; among friends a simple question about health does the job. Thanks are said less than in Europe: നന്ദി *nandi* is real gratitude, not a reflex.

## Greetings

| Malayalam | Reading | Meaning |
|---|---|---|
| നമസ്കാരം | *namaskāraṁ* | hello (formal) |
| സുഖമാണോ? | *sukhamāṇō?* | are you well? |
| സുഖമാണ് | *sukhamāṇŭ* | I'm well |
| എന്റെ പേര് മീര ആണ് | *enṯe pērŭ Mīra āṇŭ* | my name is Meera |
| നിങ്ങളുടെ പേര് എന്താണ്? | *niṅṅaḷuṭe pērŭ entāṇŭ?* | what is your name? |
| നന്ദി | *nandi* | thank you |
| ശരി | *śari* | OK, right |
| പോയിട്ട് വരാം | *pōyiṭṭŭ varāṁ* | goodbye ("I'll go and come back") |

Malayalam has no word for "goodbye" that means "go": one says one will come back.

## Personal pronouns

| | Familiar | Polite or plural |
|---|---|---|
| I | ഞാൻ *ñān* | |
| you | നീ *nī* | നിങ്ങൾ *niṅṅaḷ*; formal താങ്കൾ *tāṅkaḷ* |
| he | അവൻ *avan* | അദ്ദേഹം *addēhaṁ* |
| she | അവൾ *avaḷ* | അവർ *avar* |
| it, that | അത് *atŭ* | |
| we, with you | നമ്മൾ *nammaḷ* | |
| we, not you | ഞങ്ങൾ *ñaṅṅaḷ* | |
| they | അവർ *avar* | |

നീ is for children, close friends and family younger than you; to anyone else use നിങ്ങൾ. The *a-* pronouns point away (അവൻ "he, that one"); *i-* forms point near: ഇവൻ *ivan*, ഇവൾ *ivaḷ*, ഇവർ *ivar* "this one". Malayalam has two words for "we": നമ്മൾ includes the person spoken to, ഞങ്ങൾ leaves them out.

::: exercise pronoun
Write the pronoun.

- I → [[ñān]]
- we, you included → [[nammaḷ]]
- she, familiar → [[avaḷ]]
- they → [[avar]]
:::

::: exercise which
Which pronoun?

- "we" said to friends, of all of you together → ((നമ്മൾ* / ഞങ്ങൾ))
- "we" said to a shopkeeper, of your family → ((നമ്മൾ / ഞങ്ങൾ*))
- "you" to a teacher → ((നീ / നിങ്ങൾ*))
- "you" to your little brother → ((നീ* / താങ്കൾ))
:::

::: exercise reply
Choose the reply.

- സുഖമാണോ? → ((സുഖമാണ്* / നന്ദി / പോയിട്ട് വരാം))
- നിങ്ങളുടെ പേര് എന്താണ്? → ((എന്റെ പേര് രവി ആണ്* / ശരി / നമസ്കാരം))
- You are leaving. → ((പോയിട്ട് വരാം* / സുഖമാണോ? / നമസ്കാരം))
- Someone helped you. → ((നന്ദി* / ഞങ്ങൾ / അത്))
:::

::: exercise translate
Translate.

- എന്റെ പേര് മീര ആണ്. → {{My name is Meera. / I am Meera.}}
- നിങ്ങളുടെ പേര് എന്താണ്? → {{What is your name? / What's your name?}}
- ശരി, പോയിട്ട് വരാം. → {{OK, goodbye. / OK, see you. / Right, bye.}}
- നമസ്കാരം, സുഖമാണോ? → {{Hello, are you well? / Hello, how are you?}}
:::

::: summary
- നമസ്കാരം, സുഖമാണോ?, നന്ദി, ശരി, പോയിട്ട് വരാം.
- ഞാൻ, നീ / നിങ്ങൾ / താങ്കൾ, അവൻ, അവൾ, അത്, അവർ; respect: അദ്ദേഹം, അവർ.
- Two "we": നമ്മൾ with the listener, ഞങ്ങൾ without; *i-* near, *a-* far (ഇവൻ, അവൻ).
:::
