# 9. Los casos II y las posposiciones

Los demás casos dicen dónde, con quién, con qué y de dónde. Lo que el español hace con una preposición delante del sustantivo, el malayalam lo hace con una terminación o una **posposición** detrás.

## Locativo, sociativo, instrumental, ablativo

| Caso | Terminación | Ejemplo | Sentido |
|---|---|---|---|
| locativo, «en» | -ഇൽ *-il* | കേരളത്തിൽ *kēraḷattil* | en Kerala |
| sociativo, «a, con» una persona | -ഓട് *-ōṭŭ* | അവനോട് *avanōṭŭ* | a él (al hablar) |
| instrumental, «con, por» | കൊണ്ട് *koṇṭŭ*; -ആൽ *-āl* | പേന കൊണ്ട് *pēna koṇṭŭ* | con un bolígrafo |
| «de, desde» | -ഇൽ നിന്ന് *-il ninnŭ* | വീട്ടിൽ നിന്ന് *vīṭṭil ninnŭ* | desde casa |

- Las uniones son las de la lección 8: മരം → മരത്തിൽ, കുട്ടി → കുട്ടിയിൽ. Los sustantivos en ട് y റ് la doblan: വീട് → വീട്ടിൽ *vīṭṭil* «en casa», നാട് → നാട്ടിൽ «en la tierra natal».
- El sociativo acompaña a los verbos de hablar y preguntar: ഞാൻ അവനോട് ചോദിച്ചു «le pregunté».
- «De» es el locativo seguido de നിന്ന് «estando de pie»: ഞാൻ കേരളത്തിൽ നിന്നാണ് «soy de Kerala».

## Las posposiciones

La mayoría de las posposiciones siguen a un sustantivo en genitivo.

| Posposición | Sentido | Ejemplo |
|---|---|---|
| കൂടെ *kūṭe* | con, junto a | അമ്മയുടെ കൂടെ con mamá |
| മുകളിൽ *mukaḷil* | sobre, encima | മേശയുടെ മുകളിൽ sobre la mesa |
| താഴെ *tāḻe* | debajo | മേശയുടെ താഴെ debajo de la mesa |
| അടുത്ത് *aṭuttŭ* | cerca de | വീടിന്റെ അടുത്ത് cerca de la casa |
| വേണ്ടി *vēṇṭi* | por, para (+ dativo) | എനിക്ക് വേണ്ടി para mí |
| പോലെ *pōle* | como (+ acusativo) | കുട്ടിയെ പോലെ como un niño |

::: exercise case
¿Qué dice la terminación?

- ഞാൻ അവനോട് സംസാരിച്ചു. → ((a él, al hablar* / desde él / en él))
- പേന കൊണ്ട് എഴുതി. → ((escribió con un bolígrafo* / escribió a un bolígrafo / escribió desde un bolígrafo))
- വീട്ടിൽ നിന്ന് → ((en casa / desde casa* / para la casa))
- കടലിൽ → ((en el mar* / al mar, hablando / como el mar))
:::

::: exercise where
Elija la posposición.

- El libro está debajo de la mesa: പുസ്തകം മേശയുടെ ___ ആണ്. → ((മുകളിൽ / താഴെ* / കൂടെ))
- con mi amigo: എന്റെ സുഹൃത്തിന്റെ ___ → ((കൂടെ* / വേണ്ടി / താഴെ))
- como un niño: കുട്ടിയെ ___ → ((പോലെ* / കൂടെ / മുകളിൽ))
:::

Traduzca.

- പൂച്ച വീട്ടിൽ ഉണ്ട്. → {{El gato está en casa.}}
- അവൾ അമ്മയുടെ കൂടെ ആണ്. → {{Está con su madre. / Ella está con mamá.}}
- ഇത് എനിക്ക് വേണ്ടി ആണോ? → {{¿Esto es para mí? / ¿Es para mí?}}
:::

::: summary
- Locativo -ഇൽ (കേരളത്തിൽ, വീട്ടിൽ), sociativo -ഓട് (അവനോട്), instrumental കൊണ്ട് / -ആൽ, «desde» -ഇൽ നിന്ന്.
- ട് y റ് se doblan ante una terminación: വീട്ടിൽ, നാട്ടിൽ.
- Posposiciones tras el genitivo: കൂടെ, മുകളിൽ, താഴെ, അടുത്ത്; വേണ്ടി tras el dativo, പോലെ tras el acusativo.
:::
