# 11. Le passé

Le passé est le seul temps où les verbes malayalam diffèrent les uns des autres : chaque verbe a son radical de passé, à apprendre avec lui, comme on apprend *aller, allé*. Trois modèles couvrent la plupart des verbes.

## Trois modèles

| Modèle | Forme du dictionnaire | Passé | Sens |
|---|---|---|---|
| -ക്കുക → -ച്ചു | പഠിക്കുക | പഠിച്ചു *paṭhiccu* | a étudié |
| | കുടിക്കുക | കുടിച്ചു *kuṭiccu* | a bu |
| | കഴിക്കുക | കഴിച്ചു *kaḻiccu* | a mangé |
| -ഉക → -ഇ | പോകുക | പോയി *pōyi* | est allé |
| | എഴുതുക | എഴുതി *eḻuti* | a écrit |
| | വാങ്ങുക | വാങ്ങി *vāṅṅi* | a acheté |
| radical propre | വരുക | വന്നു *vannu* | est venu |
| | കാണുക | കണ്ടു *kaṇṭu* | a vu |
| | പറയുക | പറഞ്ഞു *paṟaññu* | a dit |
| | ചെയ്യുക | ചെയ്തു *ceytu* | a fait |
| | കേൾക്കുക | കേട്ടു *kēṭṭu* | a entendu |
| | ഇരിക്കുക | ഇരുന്നു *irunnu* | s'est assis |

La plupart des verbes en -ക്കുക prennent -ച്ചു, la plupart des autres -ഇ ; les irréguliers sont les verbes les plus courants de la langue, qu'on rencontre chaque jour. Comme au présent, la personne ne change jamais la forme : ഞാൻ വന്നു, അവർ വന്നു.

## Négation et direction

Le passé négatif ajoute ഇല്ല : വന്നില്ല *vannilla* « n'est pas venu », കണ്ടില്ല « n'a pas vu ». Le lieu où l'on va prend -ലേക്ക് *-lēkkŭ* « vers, dans » après le radical du locatif : കൊച്ചിയിലേക്ക് « à Kochi », വീട്ടിലേക്ക് « à la maison » ; l'oral emploie souvent le simple locatif : കൊച്ചിയിൽ പോയി.

::: exercise translate

::: summary
- Chaque verbe a son passé : -ക്കുക → -ച്ചു (പഠിച്ചു), -ഉക → -ഇ (പോയി), ou le sien (വന്നു, കണ്ടു, പറഞ്ഞു, ചെയ്തു).
- Négation : + ഇല്ല (വന്നില്ല).
- Direction -ലേക്ക് : കൊച്ചിയിലേക്ക്, വീട്ടിലേക്ക്.
:::
