# 11. The past

The past is the one tense where Malayalam verbs differ from one another: each verb has its past stem, which has to be learnt with it, as English learns *go, went*. Three patterns cover most verbs.

## Three patterns

| Pattern | Dictionary form | Past | Meaning |
|---|---|---|---|
| -ക്കുക → -ച്ചു | പഠിക്കുക | പഠിച്ചു *paṭhiccu* | studied |
| | കുടിക്കുക | കുടിച്ചു *kuṭiccu* | drank |
| | കഴിക്കുക | കഴിച്ചു *kaḻiccu* | ate |
| -ഉക → -ഇ | പോകുക | പോയി *pōyi* | went |
| | എഴുതുക | എഴുതി *eḻuti* | wrote |
| | വാങ്ങുക | വാങ്ങി *vāṅṅi* | bought |
| own stem | വരുക | വന്നു *vannu* | came |
| | കാണുക | കണ്ടു *kaṇṭu* | saw |
| | പറയുക | പറഞ്ഞു *paṟaññu* | said |
| | ചെയ്യുക | ചെയ്തു *ceytu* | did |
| | കേൾക്കുക | കേട്ടു *kēṭṭu* | heard |
| | ഇരിക്കുക | ഇരുന്നു *irunnu* | sat |

Most verbs in -ക്കുക take -ച്ചു, and most others -ഇ; the irregular ones are the commonest verbs of the language, met every day. As in the present, the person never changes the form: ഞാൻ വന്നു, അവർ വന്നു.

## Negative and direction

The negative past adds ഇല്ല: വന്നില്ല *vannilla* "did not come", കണ്ടില്ല "did not see". Where one goes takes -ലേക്ക് *-lēkkŭ* "to, into" after the locative stem: കൊച്ചിയിലേക്ക് "to Kochi", വീട്ടിലേക്ക് "home"; speech often uses the plain locative: കൊച്ചിയിൽ പോയി.

::: exercise translate
Translate.

- ഇന്നലെ ഞാൻ കൊച്ചിയിലേക്ക് പോയി. → {{Yesterday I went to Kochi. / I went to Kochi yesterday.}}

- അവൾ എന്നോട് ഒന്നും പറഞ്ഞില്ല. → {{She didn't say anything to me. / She told me nothing.}}
:::

::: summary
- Each verb has its past: -ക്കുക → -ച്ചു (പഠിച്ചു), -ഉക → -ഇ (പോയി), or its own (വന്നു, കണ്ടു, പറഞ്ഞു, ചെയ്തു).
- Negative: + ഇല്ല (വന്നില്ല).
- Direction -ലേക്ക്: കൊച്ചിയിലേക്ക്, വീട്ടിലേക്ക്.
:::
