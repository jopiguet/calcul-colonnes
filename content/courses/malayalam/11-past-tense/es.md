# 11. El pasado

El pasado es el único tiempo en que los verbos malayalam difieren entre sí: cada verbo tiene su raíz de pasado, que se aprende con él, como se aprende *ir, fui*. Tres modelos cubren la mayoría de los verbos.

## Tres modelos

| Modelo | Forma del diccionario | Pasado | Sentido |
|---|---|---|---|
| -ക്കുക → -ച്ചു | പഠിക്കുക | പഠിച്ചു *paṭhiccu* | estudió |
| | കുടിക്കുക | കുടിച്ചു *kuṭiccu* | bebió |
| | കഴിക്കുക | കഴിച്ചു *kaḻiccu* | comió |
| -ഉക → -ഇ | പോകുക | പോയി *pōyi* | fue |
| | എഴുതുക | എഴുതി *eḻuti* | escribió |
| | വാങ്ങുക | വാങ്ങി *vāṅṅi* | compró |
| raíz propia | വരുക | വന്നു *vannu* | vino |
| | കാണുക | കണ്ടു *kaṇṭu* | vio |
| | പറയുക | പറഞ്ഞു *paṟaññu* | dijo |
| | ചെയ്യുക | ചെയ്തു *ceytu* | hizo |
| | കേൾക്കുക | കേട്ടു *kēṭṭu* | oyó |
| | ഇരിക്കുക | ഇരുന്നു *irunnu* | se sentó |

La mayoría de los verbos en -ക്കുക toman -ച്ചു, y la mayoría de los demás -ഇ; los irregulares son los verbos más corrientes de la lengua, que se oyen a diario. Como en presente, la persona nunca cambia la forma: ഞാൻ വന്നു, അവർ വന്നു.

## Negación y dirección

El pasado negativo añade ഇല്ല: വന്നില്ല *vannilla* «no vino», കണ്ടില്ല «no vio». El lugar adonde se va toma -ലേക്ക് *-lēkkŭ* «a, hacia» tras la raíz del locativo: കൊച്ചിയിലേക്ക് «a Kochi», വീട്ടിലേക്ക് «a casa»; el habla usa a menudo el locativo simple: കൊച്ചിയിൽ പോയി.

¿Cuál es el pasado?

- വരുക → ((വന്നു* / വരിച്ചു / വരി))

:::

::: exercise translate
Traduzca.

- ഇന്നലെ ഞാൻ കൊച്ചിയിലേക്ക് പോയി. → {{Ayer fui a Kochi.}}
- അവൻ വന്നില്ല. → {{No vino. / Él no vino.}}
- ഞങ്ങൾ ചോറ് കഴിച്ചു. → {{Comimos arroz.}}
- അവൾ എന്നോട് ഒന്നും പറഞ്ഞില്ല. → {{No me dijo nada. / Ella no me dijo nada.}}
:::

::: summary
- Cada verbo tiene su pasado: -ക്കുക → -ച്ചു (പഠിച്ചു), -ഉക → -ഇ (പോയി), o el suyo propio (വന്നു, കണ്ടു, പറഞ്ഞു, ചെയ്തു).
- Negación: + ഇല്ല (വന്നില്ല).
- Dirección -ലേക്ക്: കൊച്ചിയിലേക്ക്, വീട്ടിലേക്ക്.
:::
