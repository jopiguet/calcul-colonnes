# 7. Noms, pluriel, adjectifs et « ce »

Les noms malayalam n'ont pas d'article ni de genre grammatical pour les choses : un arbre n'est ni masculin ni féminin. Les personnes sont masculines ou féminines selon le sens, et la terminaison le montre souvent : അധ്യാപകൻ *adhyāpakan* « professeur » (homme), അധ്യാപിക *adhyāpika* (femme).

## Le pluriel

| Singulier | Pluriel | Règle |
|---|---|---|
| പൂച്ച *pūcca* chat | പൂച്ചകൾ *pūccakaḷ* | + കൾ *-kaḷ* |
| കുട്ടി *kuṭṭi* enfant | കുട്ടികൾ *kuṭṭikaḷ* | + കൾ |
| വീട് *vīṭŭ* maison | വീടുകൾ *vīṭukaḷ* | ŭ devient *u*, + കൾ |
| മരം *maraṁ* arbre | മരങ്ങൾ *maraṅṅaḷ* | ം devient ങ്ങൾ *-ṅṅaḷ* |
| അമ്മ *amma* mère | അമ്മമാർ *ammamār* | parenté et titres : + മാർ *-mār* |
| അധ്യാപകൻ *adhyāpakan* professeur | അധ്യാപകർ *adhyāpakar* | ൻ devient ർ |

On omet souvent le pluriel quand un nombre ou le contexte suffit : രണ്ട് പൂച്ച « deux chat(s) » est courant à l'oral.

## Adjectifs et démonstratifs

Les adjectifs se placent devant le nom et ne changent jamais : നല്ല കുട്ടി *nalla kuṭṭi* « un bon enfant », നല്ല കുട്ടികൾ « de bons enfants ». Après le nom, comme attribut, ils prennent une forme nominale en *-tŭ* : ഈ വീട് വലുതാണ് *ī vīṭŭ valutāṇŭ* « cette maison est grande ».

| Devant un nom | Attribut | Sens |
|---|---|---|
| നല്ല *nalla* | നല്ലത് *nallatŭ* | bon |
| വലിയ *valiya* | വലുത് *valutŭ* | grand |
| ചെറിയ *ceṟiya* | ചെറുത് *ceṟutŭ* | petit |
| പുതിയ *putiya* | പുതിയത് *putiyatŭ* | nouveau |
| പഴയ *paḻaya* | പഴയത് *paḻayatŭ* | vieux |

« Ce » et « cela » suivent le schéma proche/lointain des pronoms : ഈ *ī* et ആ *ā* devant un nom (ഈ വീട് « cette maison »), ഇത് *itŭ* et അത് *atŭ* seuls (ഇത് എന്റെ വീട് ആണ് « c'est ma maison »), ഇവിടെ *iviṭe* « ici », അവിടെ *aviṭe* « là-bas ».

::: summary
- Pas d'article ; les choses n'ont pas de genre, les personnes si (അധ്യാപകൻ, അധ്യാപിക).
- Pluriel : -കൾ (പൂച്ചകൾ, വീടുകൾ), -ം → -ങ്ങൾ (മരങ്ങൾ), -മാർ pour la parenté (അമ്മമാർ), -ൻ → -ർ (അധ്യാപകർ).
- Adjectifs devant le nom, invariables (നല്ല, വലിയ) ; attributs en *-tŭ* (വലുതാണ്).
- ഈ / ആ + nom, ഇത് / അത് seuls, ഇവിടെ / അവിടെ.
:::
