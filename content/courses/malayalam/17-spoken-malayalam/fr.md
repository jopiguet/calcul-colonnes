# 17. Le malayalam tel qu'on le parle

Le malayalam est fortement diglossique : la langue écrite des livres, des journaux et de ce cours n'est pas celle qu'on parle au salon de thé. Les formes parlées sont plus courtes, changent d'un district à l'autre et se mêlent d'anglais. On vous comprendra avec les formes écrites ; vous ne comprendrez les gens qu'une fois les formes parlées connues.

## Écrit et parlé

| Écrit | Parlé | Sens |
|---|---|---|
| എന്താണ് *entāṇŭ* | എന്താ *entā* | qu'est-ce que c'est |
| ശരിയാണ് *śariyāṇŭ* | ശരിയാ *śariyā* | c'est vrai |
| പോകുകയാണ് *pōkukayāṇŭ* | പോവാ *pōvā*, പോകുവാ | (je) m'en vais |
| എന്ത് ചെയ്യുന്നു? | എന്താ ചെയ്യുന്നേ? *entā ceyyunnē?* | qu'est-ce que tu fais ? |
| വരുന്നു *varunnu* | വരണു *varaṇu* (sud) | vient |
| ഇല്ലേ? *illē?* | ഇല്ലേ? | n'est-ce pas ? |

L'oral laisse tomber le ആണ് de l'identité, adoucit -ക- entre voyelles en -വ- (പോകുക, പോവുക) et adore le ഇല്ലേ? final. Les noms anglais prennent sans façon les terminaisons malayalam : ബസ്സിൽ « dans le bus », ഫോണിൽ « au téléphone », ഓഫീസിലേക്ക് « au bureau ».

## Appeler les gens

Les mots de parenté font office de « monsieur » et « madame », et prennent une terminaison de vocatif quand on appelle quelqu'un : -ആ pour les mots en -അൻ, -ഏ ou une voyelle longue pour les autres.

| Mot | Sens | Pour appeler |
|---|---|---|
| ചേട്ടൻ *cēṭṭan* | frère aîné ; un homme un peu plus âgé | ചേട്ടാ *cēṭṭā* |
| ചേച്ചി *cēcci* | sœur aînée ; une femme un peu plus âgée | ചേച്ചീ *cēccī* |
| അനിയൻ *aniyan* | frère cadet | അനിയാ |
| അനിയത്തി *aniyatti* | sœur cadette | അനിയത്തീ |
| മോൻ *mōn*, മോൾ *mōḷ* | fils, fille ; tout enfant | മോനേ *mōnē*, മോളേ |
| അമ്മ *amma*, അച്ഛൻ *acchan* | mère, père | അമ്മേ *ammē*, അച്ഛാ *acchā* |

C'est ainsi qu'on commande un thé à l'homme du comptoir : ചേട്ടാ, ഒരു ചായ.

## Les districts et le manglish

Le sud (Thiruvananthapuram), le centre (Thrissur, Kochi) et le nord (Malabar, riche en mots arabes et ourdous) ont chacun leur accent et leurs tournures ; le cinéma s'en sert pour situer un personnage d'un mot. En ligne, les Malayalis écrivent en manglish, le malayalam en lettres latines : *Njan varaam* « je viendrai », *Sughamano?* « ça va ? ».

::: exercise spoken
Quelle est la forme parlée ?

- എന്താണ് → ((എന്താ* / എന്ത്ത / എന്താൻ))
- പോകുകയാണ് → ((പോവാ* / പോകി / പോയ))
- ശരിയാണ് → ((ശരിയാ* / ശരിൻ / ശരിമ്))
- എന്ത് ചെയ്യുന്നു? → ((എന്താ ചെയ്യുന്നേ?* / എന്ത് ചെയ്തു / എന്താ പോയി))
:::

::: exercise who
Comment les appelez-vous ?

- le contrôleur du bus, un homme plus âgé que vous → ((ചേട്ടാ* / അനിയാ / മോനേ))
- la femme de la boutique, un peu plus âgée que vous → ((ചേച്ചീ* / മോളേ / അനിയത്തീ))
- un petit garçon → ((മോനേ* / ചേട്ടാ / അച്ഛാ))
- votre père → ((അച്ഛാ* / ചേട്ടാ / അനിയാ))
:::

::: exercise translate
Traduisez.

- ചേട്ടാ, ഒരു ചായ. → {{Un thé, s'il vous plaît. / Frère, un thé.}}
- എന്താ ചെയ്യുന്നേ? → {{Qu'est-ce que tu fais ? / Tu fais quoi ?}}
- ഞാൻ വീട്ടിൽ പോവാ. → {{Je rentre à la maison. / Je vais à la maison.}}
- ബസ്സ് എപ്പോൾ വരും? → {{Quand le bus va-t-il arriver ? / Quand vient le bus ?}}
:::

::: summary
- L'oral abrège : എന്താ, ശരിയാ, പോവാ, എന്താ ചെയ്യുന്നേ? ; ഇല്ലേ? final.
- Les mots de parenté servent à appeler : ചേട്ടാ, ചേച്ചീ, മോനേ, അമ്മേ, അച്ഛാ.
- Les noms anglais prennent les terminaisons malayalam (ബസ്സിൽ) ; les districts diffèrent ; manglish en ligne.
:::
