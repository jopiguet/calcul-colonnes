# 2. Les consonnes

Les consonnes sont rangées comme en sanskrit : selon l'endroit où la bouche les forme, de la gorge vers les lèvres, chaque rangée dans le même ordre : simple, aspirée, sonore, sonore aspirée, nasale. Chaque consonne se lit avec la voyelle *a* : ക se lit *ka*.

## Les cinq rangées

| | simple | aspirée | sonore | sonore aspirée | nasale |
|---|---|---|---|---|---|
| gorge | ക *ka* | ഖ *kha* | ഗ *ga* | ഘ *gha* | ങ *ṅa* |
| palais | ച *ca* | ഛ *cha* | ജ *ja* | ഝ *jha* | ഞ *ña* |
| rétroflexe | ട *ṭa* | ഠ *ṭha* | ഡ *ḍa* | ഢ *ḍha* | ണ *ṇa* |
| dents | ത *ta* | ഥ *tha* | ദ *da* | ധ *dha* | ന *na* |
| lèvres | പ *pa* | ഫ *pha* | ബ *ba* | ഭ *bha* | മ *ma* |

ച *ca* se dit « tcha », ജ *ja* « dja ». La rangée **rétroflexe** se forme la pointe de la langue recourbée contre le palais ; la rangée **dentale**, la langue contre les dents (le *t* français est dental). Les aspirées (ഖ, ഥ…) et les sonores (ഗ, ദ…) abondent dans les mots sanskrits, moins dans les mots dravidiens.

## Les autres

| Lettre | Son | Lettre | Son |
|---|---|---|---|
| യ | *ya* | ശ | *śa*, « ch » doux |
| ര | *ra*, battu | ഷ | *ṣa*, « ch » rétroflexe |
| ല | *la* | സ | *sa* |
| വ | *va*, entre *v* et *w* | ഹ | *ha*, aspiré |
| ള | *ḷa*, *l* rétroflexe | ഴ | *ḻa*, écrit *zh* |
| റ | *ṟa*, *r* roulé | | |

ഴ *ḻa* est la fierté du malayalam (et du tamoul) : la langue se recourbe comme pour ട sans toucher le palais, et le son tient d'un *r* et d'un *l* américain. On l'entend dans മഴ *maḻa* « pluie » et dans കോഴിക്കോട് *Kōḻikkōṭŭ* (Kozhikode). Le nom même de la langue, മലയാളം, a ള, le *l* rétroflexe, et non ഴ ; il vient de മല *mala* « montagne ».

::: summary
- Cinq rangées de cinq, de la gorge aux lèvres : simple, aspirée, sonore, sonore aspirée, nasale.
- Rétroflexes ട ഠ ഡ ഢ ണ (langue recourbée) contre dentales ത ഥ ദ ധ ന (langue sur les dents).
- യ ര ല വ, ശ ഷ സ ഹ, et les trois lettres dravidiennes ള *ḷa*, ഴ *ḻa*, റ *ṟa*.
- Une consonne seule se lit avec *a* : മല *mala*.
:::
