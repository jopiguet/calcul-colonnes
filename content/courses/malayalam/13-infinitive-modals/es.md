# 13. Querer, deber, poder

Muchas necesidades y capacidades cotidianas se dicen, como «tener», con la persona en dativo: «a mí hay necesidad de agua». Esta lección las reúne, con el infinitivo que a menudo rigen.

## El infinitivo: -ആൻ

El infinitivo cambia -ഉക por -ആൻ *-ān*: പോകാൻ *pōkān* «ir», വരാൻ, കാണാൻ, പഠിക്കാൻ. Dice «para»: ഞാൻ മലയാളം പഠിക്കാൻ കേരളത്തിൽ വന്നു «vine a Kerala para aprender malayalam».

## Con el dativo

| Sentido | Forma | Ejemplo |
|---|---|---|
| querer (una cosa) | വേണം *vēṇaṁ*; no: വേണ്ട *vēṇṭa* | എനിക്ക് വെള്ളം വേണം quiero agua |
| tener que, querer (hacer) | raíz + -അണം *-aṇaṁ* | എനിക്ക് പോകണം tengo que irme |
| poder | infinitivo + കഴിയും *kaḻiyuṁ* o പറ്റും *paṟṟuṁ* | എനിക്ക് നീന്താൻ കഴിയും sé nadar |
| no poder | infinitivo + കഴിയില്ല o പറ്റില്ല | എനിക്ക് വരാൻ പറ്റില്ല no puedo venir |
| saber | അറിയാം *aṟiyāṁ*; no: അറിയില്ല | എനിക്ക് മലയാളം അറിയാം sé malayalam |
| gustar | ഇഷ്ടമാണ് *iṣṭamāṇŭ*; no: ഇഷ്ടമല്ല | എനിക്ക് ചായ ഇഷ്ടമാണ് me gusta el té |

Quien quiere, puede o sabe nunca es el sujeto: ഞാൻ വെള്ളം വേണം está mal; എനിക്ക് വെള്ളം വേണം está bien. La forma en -അണം dice a la vez «deber» y «querer»: എനിക്ക് പോകണം es «tengo que irme» o «quiero irme», según la situación.

Para pedir permiso se añade -ഓ a la forma en -ആം: ഇവിടെ ഇരിക്കാമോ? *iviṭe irikkāmō?* «¿puedo sentarme aquí?». എനിക്ക് അറിയില്ല «no sé» es una de las frases más útiles de la lengua.

::: exercise say
¿Qué frase?

- Quiero agua. → ((എനിക്ക് വെള്ളം വേണം.* / ഞാൻ വെള്ളം വേണം. / എനിക്ക് വെള്ളം ആണ്.))
- No puedo venir. → ((എനിക്ക് വരാൻ കഴിയില്ല.* / ഞാൻ വരാൻ കഴിയും. / എനിക്ക് വരും.))
- No sé. → ((എനിക്ക് അറിയില്ല.* / ഞാൻ അറിയില്ല. / എനിക്ക് ഇല്ല.))
- ¿Puedo sentarme aquí? → ((ഇവിടെ ഇരിക്കാമോ?* / ഇവിടെ ഇരിക്കരുത്. / ഇവിടെ ഇരുന്നു.))
:::

Traduzca.

- നിങ്ങൾക്ക് എന്ത് വേണം? → {{¿Qué quiere usted? / ¿Qué desea?}}

:::

::: summary
- Infinitivo -ആൻ (പോകാൻ): «para».
- Dativo + വേണം / വേണ്ട (querer), raíz + -അണം (tener que, querer hacer), infinitivo + കഴിയും / പറ്റും (poder), അറിയാം (saber), ഇഷ്ടമാണ് (gustar).
- Permiso: -ആമോ? (ഇരിക്കാമോ?).
:::
