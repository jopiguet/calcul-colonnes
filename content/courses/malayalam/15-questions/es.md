# 15. Las preguntas y «y»

Una pregunta de sí o no lleva -ഓ *-ō* en la palabra preguntada, normalmente el verbo: നീ വരുമോ? «¿vendrás?», ചായ ഉണ്ടോ? «¿hay té?». La respuesta repite el verbo: വരും «(sí) vendré», ഇല്ല «no». «Sí» a secas es അതെ *ate*; «no» es ഇല്ല para existir o hacer, അല്ല para ser algo.

## Las palabras interrogativas

| Palabra | Sentido | Ejemplo |
|---|---|---|
| ആര് *ārŭ* | quién | അത് ആരാണ്? ¿quién es ese? |
| എന്ത് *entŭ* | qué | ഇത് എന്താണ്? ¿qué es esto? |
| എവിടെ *eviṭe* | dónde | നിങ്ങൾ എവിടെ താമസിക്കുന്നു? ¿dónde vive usted? |
| എപ്പോൾ *eppōḷ* | cuándo | അവൻ എപ്പോൾ വന്നു? ¿cuándo vino? |
| എങ്ങനെ *eṅṅane* | cómo | ഇത് എങ്ങനെ ചെയ്യും? ¿cómo se hace esto? |
| എത്ര *etra* | cuánto, cuántos | ഇത് എത്രയാണ്? ¿cuánto cuesta esto? |
| എന്തിന് *entinŭ* | por qué, para qué | എന്തിന് കരയുന്നു? ¿por qué lloras? |
| ഏത് *ētŭ* | cuál | ഏത് ബസ്? ¿qué autobús? |
| ആരുടെ *āruṭe* | de quién | ഇത് ആരുടെ പുസ്തകമാണ്? ¿de quién es este libro? |

La palabra interrogativa va donde iría la respuesta: delante del verbo. El habla abrevia എന്താണ് en എന്താ *entā*: എന്താ പേര്? «¿cómo te llamas?».

## «Y», «también», «o»

-ഉം *-uṁ* en cada palabra las une: ഞാനും നീയും «tú y yo»; en una sola, significa «también»: ഞാനും വരാം «yo también vengo». -ഓ en cada una da «o»: ചായയോ കാപ്പിയോ? «¿té o café?»; entre oraciones, അല്ലെങ്കിൽ *allenkil* «o si no».

::: summary
- Sí o no: -ഓ (വരുമോ?, ഉണ്ടോ?); sí അതെ, no ഇല്ല / അല്ല.
- ആര്, എന്ത്, എവിടെ, എപ്പോൾ, എങ്ങനെ, എത്ര, എന്തിന്, ഏത്, ആരുടെ, delante del verbo.
- -ഉം … -ഉം «y», -ഉം «también», -ഓ … -ഓ «o»; അല്ലെങ്കിൽ «o si no».
:::
