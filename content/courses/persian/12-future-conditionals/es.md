# 12. El futuro y las condicionales

El persa tiene futuro, pero pertenece sobre todo a la escritura, las noticias y el registro formal: en la conversación basta el presente, فردا می‌روم «me voy mañana». Las condicionales usan los tiempos que ya conoce, con اگر *agar* «si»; una combinación, con el imperfecto, da el condicional del español.

## El futuro

| Persona | خواستن (presente, sin می) + tema de pasado | Sentido |
|---|---|---|
| من | خواهم رفت *khâham raft* | iré |
| تو | خواهی رفت *khâhi raft* | irás |
| او | خواهد رفت *khâhad raft* | irá |
| ما | خواهیم رفت *khâhim raft* | iremos |
| شما | خواهید رفت *khâhid raft* | iréis |
| آنها | خواهند رفت *khâhand raft* | irán |

La negación es نخواهم رفت *nakhâham raft*. En los verbos compuestos, el sustantivo va delante: کار خواهم کرد «trabajaré».

## Las condicionales

| Tipo | Oración «si» | Principal | Ejemplo |
|---|---|---|---|
| posible | اگر + subjuntivo | presente o imperativo | اگر بیایی، خوشحال می‌شوم si vienes, me alegraré |
| una vez cumplida | اگر + pretérito simple | imperativo o presente | اگر رسیدی، زنگ بزن cuando llegues, llama |
| irreal | اگر + imperfecto | imperfecto | اگر پول داشتم، ماشین می‌خریدم si tuviera dinero, compraría un coche |
| irreal de pasado | اگر + pluscuamperfecto | imperfecto o pluscuamperfecto | اگر دیده بودم، می‌گفتم si lo hubiera visto, lo habría dicho |

El imperfecto es el condicional persa: می‌خریدم es «compraba» y «compraría». کاش *kâsh* «ojalá» lleva los mismos tiempos: کاش اینجا بودی «ojalá estuvieras aquí».

::: exercise kind
¿Qué tipo de condicional?

- اگر پول داشتم، می‌خریدم. → ((posible / irreal*))
- اگر فردا بیایی، می‌بینیم. → ((posible* / irreal))
- اگر می‌دانستم، می‌گفتم. → ((posible / irreal*))
:::

::: exercise form
¿Qué forma?

- «si» → ((اگر* / که / تا))
- «compraría» → ((می‌خرم / می‌خریدم* / بخرم))
- «si vienes», posible → ((اگر بیایی* / اگر می‌آمدی))
- «ojalá» → ((کاش* / شاید / باید))
:::

::: summary
- Futuro: خواهم، خواهی، خواهد… + tema de pasado: خواهم رفت; al hablar, el presente.
- اگر + subjuntivo (posible), + pretérito simple (una vez cumplida), + imperfecto (irreal).
- El imperfecto hace de condicional: می‌خریدم; کاش «ojalá».
:::
