# 12. Le futur et les conditions

Le persan a un futur, mais il appartient surtout à l'écrit, aux informations et au langage soutenu : dans la conversation, le présent suffit, فردا می‌روم « je pars demain ». Les conditions emploient les temps que vous connaissez, avec اگر *agar* « si » ; une combinaison, avec l'imparfait, donne le conditionnel du français.

## Le futur

| Personne | خواستن (présent, sans می) + radical du passé | Sens |
|---|---|---|
| من | خواهم رفت *khâham raft* | j'irai |
| تو | خواهی رفت *khâhi raft* | tu iras |
| او | خواهد رفت *khâhad raft* | il ira |
| ما | خواهیم رفت *khâhim raft* | nous irons |
| شما | خواهید رفت *khâhid raft* | vous irez |
| آنها | خواهند رفت *khâhand raft* | ils iront |

La négation est نخواهم رفت *nakhâham raft*. Dans les verbes composés, le nom vient d'abord : کار خواهم کرد « je travaillerai ».

## Les conditions

| Type | Proposition « si » | Principale | Exemple |
|---|---|---|---|
| possible | اگر + subjonctif | présent ou impératif | اگر بیایی، خوشحال می‌شوم si tu viens, je serai content |
| une fois réalisée | اگر + passé simple | impératif ou présent | اگر رسیدی، زنگ بزن quand tu seras arrivé, appelle |
| irréel | اگر + imparfait | imparfait | اگر پول داشتم، ماشین می‌خریدم si j'avais de l'argent, j'achèterais une voiture |
| irréel du passé | اگر + plus-que-parfait | imparfait ou plus-que-parfait | اگر دیده بودم، می‌گفتم si je l'avais vu, je l'aurais dit |

L'imparfait est le conditionnel persan : می‌خریدم, c'est « j'achetais » et « j'achèterais ». کاش *kâsh* « si seulement » prend les mêmes temps : کاش اینجا بودی « si seulement tu étais là ».

::: exercise form
Quelle forme ?

- « si » → ((اگر* / که / تا))
- « j'achèterais » → ((می‌خرم / می‌خریدم* / بخرم))
- « si tu viens », possible → ((اگر بیایی* / اگر می‌آمدی))
- « si seulement » → ((کاش* / شاید / باید))
:::

::: exercise translate
Traduisez.

- فردا به شیراز خواهیم رفت. → {{Demain, nous irons à Chiraz.}}
- اگر وقت داشتم، می‌آمدم. → {{Si j'avais le temps, je viendrais.}}
- اگر رسیدی، به من زنگ بزن. → {{Quand tu arrives, appelle-moi. / Si tu arrives, téléphone-moi.}}
- کاش اینجا بودی. → {{Si seulement tu étais là. / J'aimerais que tu sois là.}}
:::

::: summary
- Futur : خواهم، خواهی، خواهد… + radical du passé : خواهم رفت ; l'oral emploie le présent.
- اگر + subjonctif (possible), + passé simple (une fois réalisé), + imparfait (irréel).
- L'imparfait sert de conditionnel : می‌خریدم ; کاش « si seulement ».
:::
