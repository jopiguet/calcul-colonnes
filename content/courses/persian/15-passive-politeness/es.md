# 15. La pasiva y el habla cortés

Dos cosas que hacen sonar el persa como persa. La **pasiva** se forma como en español, con el participio pasado y شدن *shodan* «volverse»: نوشته شد *neveshte shod* «fue escrito». El **habla cortés**, تعارف *ta'ârof*, es todo un registro: se eleva al otro con verbos de respeto, uno se rebaja con verbos de humildad, y se ofrece y se rechaza por ritual antes de aceptar.

## La pasiva

| Tiempo | Forma | Sentido |
|---|---|---|
| presente | ساخته می‌شود *sâkhte mishavad* | se construye, está siendo construido |
| pretérito simple | ساخته شد *sâkhte shod* | fue construido |
| pretérito perfecto | ساخته شده است *sâkhte shode ast* | ha sido construido |
| futuro | ساخته خواهد شد *sâkhte khâhad shod* | será construido |

Solo los verbos transitivos tienen pasiva. Al hablar se evita nombrar al agente; la escritura formal usa توسط *tavassot-e* «por»: این کتاب توسط سعدی نوشته شد «este libro fue escrito por Saadí». «Dicen», می‌گویند, se prefiere a menudo a una pasiva.

## Los verbos de cortesía

| Simple | Para el otro (elevar) | Para uno mismo (humildad) |
|---|---|---|
| گفتن decir | فرمودن *farmudan*: چه فرمودید؟ ¿qué ha dicho? | عرض کردن *arz kardan*: عرض کردم dije |
| آمدن venir | تشریف آوردن *tashrif âvordan*: تشریف بیاورید venga, por favor | خدمت رسیدن *khedmat residan*: خدمت می‌رسم iré a verle |
| بودن estar | تشریف داشتن *tashrif dâshtan*: تشریف دارند está aquí | |

## La cortesía diaria

| Persa | Uso |
|---|---|
| ببخشید *bebakhshid* | perdone, disculpe |
| خواهش می‌کنم *khâhesh mikonam* | por favor; de nada |
| خسته نباشید *khaste nabâshid* | «que no esté cansado»: gracias a quien trabaja |
| قابل ندارد *ghâbel nadârad* | «no es digno de usted»: lo dice un vendedor o anfitrión, rechazo ritual del pago |
| دستتان درد نکند *dastetân dard nakonad* | «que no le duela la mano»: gracias por una comida o un servicio |

Cuando un tendero dice قابل ندارد, se insiste y se paga; cuando un anfitrión ofrece comida, se rechaza una o dos veces antes de aceptar.

::: summary
- Pasiva: participio pasado + شدن: ساخته می‌شود، ساخته شد، ساخته شده است; agente توسط (culto).
- Verbos que elevan فرمودن، تشریف آوردن; de humildad عرض کردن، خدمت رسیدن.
- ببخشید، خواهش می‌کنم، خسته نباشید، دستتان درد نکند; قابل ندارد es una oferta ritual: insista y pague.
:::
