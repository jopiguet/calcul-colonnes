# 16. Le persan parlé

Les Iraniens ne parlent pas comme ils écrivent. La langue écrite de ce cours est celle des journaux et des livres, et des informations ; dans la rue, à la maison, dans les films et les chansons, on entend la langue familière de Téhéran, que tout le pays comprend. Les différences sont régulières : une douzaine de règles, et la langue parlée s'ouvre.

## Changements de sons

| Écrit | Parlé | Règle |
|---|---|---|
| نان *nân* pain | نون *nun* | *ân*, *âm* → *un*, *um* |
| خانه *khâne* maison | خونه *khune* | |
| آن *ân* cela | اون *un* | |
| تهران *Tehrân* | *Tehrun* | |
| خوب است *khub ast* | خوبه *khube* | است → *-e* |
| کتاب‌ها *ketâbhâ* livres | کتابا *ketâbâ* | -hâ → -â |

## Les verbes

| Écrit | Parlé | Sens |
|---|---|---|
| می‌روم *miravam* | میرم *miram* | je vais |
| می‌رود *miravad* | میره *mire* | il va |
| می‌گویم *miguyam* | میگم *migam* | je dis |
| می‌خواهم *mikhâham* | میخوام *mikhâm* | je veux |
| می‌آیم *miâyam* | میام *miyâm* | je viens |
| می‌دهم *midaham* | میدم *midam* | je donne |
| می‌شود *mishavad* | میشه *mishe* | ça devient ; c'est possible |
| می‌کنند *mikonand* | میکنن *mikonan* | ils font |

La 3e personne du singulier -ad devient -e, la 3e du pluriel -and devient -an. Des radicaux courts remplacent les longs : رو → ر، گو → گ، خواه → خوا، ده → د.

## Les petits mots

| Écrit | Parlé | Sens |
|---|---|---|
| را *râ* | رو *ro*, après consonne *-o* | marque d'objet : کتابو *ketâbo* |
| او *u* | اون *un* | il, elle |
| آنها *ânhâ* | اونا *unâ* | ils |
| چه *che* | چی *chi* | quoi |
| بله *bale* | آره *âre* | oui |

Les messages informels emploient ces graphies : میرم خونه « je rentre à la maison ».

::: exercise translate

- میشه کمکم کنی؟ → {{Tu peux m'aider ? / Pourrais-tu m'aider ?}}
:::

::: summary
- Persan parlé de Téhéran : *ân/âm* → *un/um* (نون، خونه), است → -e (خوبه), -hâ → -â.
- Verbes : میرم، میگم، میخوام، میام، میشه ; 3e sg. -e, 3e pl. -an.
- را → رو / -o ; او → اون ; چه → چی ; بله → آره.
:::
