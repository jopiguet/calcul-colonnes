# 16. El persa hablado

Los iraníes no hablan como escriben. La lengua escrita de este curso es la de los periódicos y los libros, y la de las noticias; en la calle, en casa, en las películas y las canciones se oye la lengua coloquial de Teherán, que todo el país entiende. Las diferencias son regulares: una docena de reglas, y la lengua hablada se abre.

## Cambios de sonido

| Escrito | Hablado | Regla |
|---|---|---|
| نان *nân* pan | نون *nun* | *ân*, *âm* → *un*, *um* |
| خانه *khâne* casa | خونه *khune* | |
| آن *ân* eso | اون *un* | |
| تهران *Tehrân* | *Tehrun* | |
| خوب است *khub ast* | خوبه *khube* | است → *-e* |
| کتاب‌ها *ketâbhâ* libros | کتابا *ketâbâ* | -hâ → -â |

## Los verbos

| Escrito | Hablado | Sentido |
|---|---|---|
| می‌روم *miravam* | میرم *miram* | voy |
| می‌رود *miravad* | میره *mire* | va |
| می‌گویم *miguyam* | میگم *migam* | digo |
| می‌خواهم *mikhâham* | میخوام *mikhâm* | quiero |
| می‌آیم *miâyam* | میام *miyâm* | vengo |
| می‌دهم *midaham* | میدم *midam* | doy |
| می‌شود *mishavad* | میشه *mishe* | se vuelve; se puede |
| می‌کنند *mikonand* | میکنن *mikonan* | hacen |

La 3.ª persona del singular -ad pasa a -e, la 3.ª del plural -and pasa a -an. Temas cortos sustituyen a los largos: رو → ر، گو → گ، خواه → خوا، ده → د.

## Las palabras pequeñas

| Escrito | Hablado | Sentido |
|---|---|---|
| را *râ* | رو *ro*, tras consonante *-o* | marca de objeto: کتابو *ketâbo* |
| او *u* | اون *un* | él, ella |
| آنها *ânhâ* | اونا *unâ* | ellos |
| چه *che* | چی *chi* | qué |
| بله *bale* | آره *âre* | sí |

Los mensajes informales usan estas grafías: میرم خونه «me voy a casa».

::: summary
- Persa hablado de Teherán: *ân/âm* → *un/um* (نون، خونه), است → -e (خوبه), -hâ → -â.
- Verbos: میرم، میگم، میخوام، میام، میشه; 3.ª sg. -e, 3.ª pl. -an.
- را → رو / -o; او → اون; چه → چی; بله → آره.
:::
