# 16. Spoken Persian

Persians speak differently from the way they write. The written language of this course is what you read in newspapers and books, and hear in the news; in the street, at home, in films and songs, you hear the colloquial language of Tehran, which the whole country understands. The differences are regular: learn a dozen rules and the spoken language opens up.

## Sound changes

| Written | Spoken | Rule |
|---|---|---|
| نان *nân* bread | نون *nun* | *ân*, *âm* → *un*, *um* |
| خانه *khâne* house | خونه *khune* | |
| آن *ân* that | اون *un* | |
| تهران *Tehrân* | *Tehrun* | |
| خوب است *khub ast* | خوبه *khube* | است → *-e* |
| کتاب‌ها *ketâbhâ* books | کتابا *ketâbâ* | -hâ → -â |

## Verbs

| Written | Spoken | Meaning |
|---|---|---|
| می‌روم *miravam* | میرم *miram* | I go |
| می‌رود *miravad* | میره *mire* | he goes |
| می‌گویم *miguyam* | میگم *migam* | I say |
| می‌خواهم *mikhâham* | میخوام *mikhâm* | I want |
| می‌آیم *miâyam* | میام *miyâm* | I come |
| می‌دهم *midaham* | میدم *midam* | I give |
| می‌شود *mishavad* | میشه *mishe* | it becomes; it's possible |
| می‌کنند *mikonand* | میکنن *mikonan* | they do |

The 3rd singular -ad becomes -e, the 3rd plural -and becomes -an. Short stems replace long ones: رو → ر، گو → گ، خواه → خوا، ده → د.

## Little words

| Written | Spoken | Meaning |
|---|---|---|
| را *râ* | رو *ro*, after a consonant *-o* | object marker: کتابو *ketâbo* |
| او *u* | اون *un* | he, she |
| آنها *ânhâ* | اونا *unâ* | they |
| چه *che* | چی *chi* | what |
| بله *bale* | آره *âre* | yes |

Informal written chat uses these spellings: میرم خونه "I'm going home".

::: summary
- Spoken Tehran Persian: *ân/âm* → *un/um* (نون، خونه), است → -e (خوبه), -hâ → -â.
- Verbs: میرم، میگم، میخوام، میام، میشه; 3rd sg. -e, 3rd pl. -an.
- را → رو / -o; او → اون; چه → چی; بله → آره.
:::
