# 9. Los verbos compuestos

El persa solo tiene unos cientos de verbos simples, y no necesita más. La mayoría de las acciones se dicen con un sustantivo o un adjetivo seguido de un verbo ligero, casi siempre کردن *kardan* «hacer» o شدن *shodan* «volverse»: کار کردن *kâr kardan* «trabajar», literalmente «hacer trabajo». Aprenda el par entero; solo se conjuga el verbo ligero.

## Verbos compuestos frecuentes

| Compuesto | Literalmente | Sentido |
|---|---|---|
| کار کردن *kâr kardan* | hacer trabajo | trabajar |
| صحبت کردن *sohbat kardan* | hacer conversación | hablar |
| زندگی کردن *zendegi kardan* | hacer vida | vivir |
| کمک کردن *komak kardan* | hacer ayuda | ayudar |
| شروع کردن *shoru' kardan* | hacer comienzo | empezar (algo) |
| تمام شدن *tamâm shodan* | volverse acabado | terminarse |
| بیدار شدن *bidâr shodan* | volverse despierto | despertarse |
| یاد گرفتن *yâd gereftan* | tomar memoria | aprender |
| یاد دادن *yâd dâdan* | dar memoria | enseñar |
| گوش دادن *gush dâdan* | dar oído | escuchar |
| دوست داشتن *dust dâshtan* | tener por amigo | gustar, querer |
| زنگ زدن *zang zadan* | tocar la campana | llamar por teléfono |

## Cómo se comportan

El verbo ligero toma todos los prefijos y desinencias: کار می‌کنم *kâr mikonam* «trabajo», کار نمی‌کنم «no trabajo», کار کردم «trabajé». El sustantivo queda delante, sin cambios.

کردن y شدن forman a menudo un par: تمام کردن «terminar (algo)», تمام شدن «terminarse»; درست کردن «hacer, arreglar», درست شدن «arreglarse».

:::

::: exercise light
¿Qué verbo ligero?

- escuchar: گوش … → ((کردن / دادن* / شدن))
- despertarse: بیدار … → ((کردن / شدن* / زدن))
- llamar por teléfono: زنگ … → ((زدن* / دادن / داشتن))
- vivir: زندگی … → ((کردن* / شدن / گرفتن))
:::

::: exercise pair
¿Transitivo o intransitivo?

- کلاس تمام شد. → ((la clase terminó* / terminó la clase, él))
- کار را تمام کردم. → ((el trabajo terminó / terminé el trabajo*))
- ماشین درست شد. → ((el coche quedó arreglado* / arregló el coche))
:::

::: exercise translate
Traduzca.

- موسیقی را دوست دارد. → {{Le gusta la música. / Ama la música.}}
- به مادرم زنگ زدم. → {{Llamé a mi madre.}}
:::

::: summary
- Sustantivo o adjetivo + verbo ligero: کار کردن، تمام شدن، یاد گرفتن، گوش دادن، دوست داشتن.
- Solo el verbo ligero se conjuga y se niega: کار نمی‌کنم.
- کردن transitivo, شدن intransitivo: تمام کردن / تمام شدن.
:::
