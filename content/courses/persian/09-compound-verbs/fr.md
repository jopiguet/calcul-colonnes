# 9. Les verbes composés

Le persan n'a que quelques centaines de verbes simples, et il n'en a pas besoin de plus. La plupart des actions se disent avec un nom ou un adjectif suivi d'un verbe léger, le plus souvent کردن *kardan* « faire » ou شدن *shodan* « devenir » : کار کردن *kâr kardan* « travailler », littéralement « faire travail ». Apprenez la paire ensemble ; seul le verbe léger se conjugue.

## Verbes composés courants

| Composé | Littéralement | Sens |
|---|---|---|
| کار کردن *kâr kardan* | faire travail | travailler |
| صحبت کردن *sohbat kardan* | faire conversation | parler |
| زندگی کردن *zendegi kardan* | faire vie | vivre, habiter |
| کمک کردن *komak kardan* | faire aide | aider |
| شروع کردن *shoru' kardan* | faire commencement | commencer (quelque chose) |
| تمام شدن *tamâm shodan* | devenir fini | se terminer |
| بیدار شدن *bidâr shodan* | devenir éveillé | se réveiller |
| یاد گرفتن *yâd gereftan* | prendre mémoire | apprendre |
| یاد دادن *yâd dâdan* | donner mémoire | enseigner |
| گوش دادن *gush dâdan* | donner oreille | écouter |
| دوست داشتن *dust dâshtan* | avoir pour ami | aimer |
| زنگ زدن *zang zadan* | frapper la cloche | téléphoner, sonner |

## Leur comportement

Le verbe léger prend tous les préfixes et terminaisons : کار می‌کنم *kâr mikonam* « je travaille », کار نمی‌کنم « je ne travaille pas », کار کردم « j'ai travaillé ». Le nom reste devant, inchangé.

کردن et شدن forment souvent une paire : تمام کردن « finir (quelque chose) », تمام شدن « prendre fin » ; درست کردن « faire, réparer », درست شدن « être réparé ».

::: exercise pair
Transitif ou intransitif ?

- کلاس تمام شد. → ((le cours s'est terminé* / il a terminé le cours))
- کار را تمام کردم. → ((le travail s'est terminé / j'ai terminé le travail*))
- ماشین درست شد. → ((la voiture a été réparée* / il a réparé la voiture))
:::

::: exercise translate
Traduisez.

- در تهران زندگی می‌کنم. → {{J'habite à Téhéran. / Je vis à Téhéran.}}
- فارسی یاد می‌گیرم. → {{J'apprends le persan.}}
- موسیقی را دوست دارد. → {{Il aime la musique. / Elle aime la musique.}}
- به مادرم زنگ زدم. → {{J'ai téléphoné à ma mère. / J'ai appelé ma mère.}}
:::

::: summary
- Nom ou adjectif + verbe léger : کار کردن، تمام شدن، یاد گرفتن، گوش دادن، دوست داشتن.
- Seul le verbe léger se conjugue et se nie : کار نمی‌کنم.
- کردن transitif, شدن intransitif : تمام کردن / تمام شدن.
:::
