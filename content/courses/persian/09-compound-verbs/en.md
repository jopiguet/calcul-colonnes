# 9. Compound verbs

Persian has only a few hundred simple verbs, and it does not need more. Most actions are said with a noun or an adjective followed by a light verb, most often کردن *kardan* "to do" or شدن *shodan* "to become": کار کردن *kâr kardan* "to work", literally "to do work". Learn the pair together; only the light verb is conjugated.

## Common compound verbs

| Compound | Literally | Meaning |
|---|---|---|
| کار کردن *kâr kardan* | do work | to work |
| صحبت کردن *sohbat kardan* | do talk | to speak, talk |
| زندگی کردن *zendegi kardan* | do life | to live |
| کمک کردن *komak kardan* | do help | to help |
| شروع کردن *shoru' kardan* | do beginning | to begin (something) |
| تمام شدن *tamâm shodan* | become finished | to end |
| بیدار شدن *bidâr shodan* | become awake | to wake up |
| یاد گرفتن *yâd gereftan* | take memory | to learn |
| یاد دادن *yâd dâdan* | give memory | to teach |
| گوش دادن *gush dâdan* | give ear | to listen |
| دوست داشتن *dust dâshtan* | have as friend | to like, love |
| زنگ زدن *zang zadan* | strike a bell | to phone, ring |

## How they behave

The light verb takes every prefix and ending: کار می‌کنم *kâr mikonam* "I work", کار نمی‌کنم "I don't work", کار کردم "I worked". The noun stays in front, unchanged.

کردن and شدن often make a pair: تمام کردن "to finish (something)", تمام شدن "to come to an end"; درست کردن "to make, fix", درست شدن "to be fixed".

::: exercise write
Write in Persian.

- "I work" → [[کار می‌کنم]]
- "we speak" → [[صحبت می‌کنیم]]
- "I don't like (it)" → [[دوست ندارم]]
- "he learned" → [[یاد گرفت]]
:::

::: exercise light
Which light verb?

- to listen: گوش … → ((کردن / دادن* / شدن))
- to wake up: بیدار … → ((کردن / شدن* / زدن))
- to phone: زنگ … → ((زدن* / دادن / داشتن))
- to live: زندگی … → ((کردن* / شدن / گرفتن))
:::

::: exercise pair
Transitive or intransitive?

- کلاس تمام شد. → ((the class ended* / he finished the class))
- کار را تمام کردم. → ((the work ended / I finished the work*))
- ماشین درست شد. → ((the car was fixed* / he fixed the car))
:::

::: exercise translate
Translate.

- در تهران زندگی می‌کنم. → {{I live in Tehran.}}
- فارسی یاد می‌گیرم. → {{I am learning Persian. / I learn Persian.}}
- موسیقی را دوست دارد. → {{He likes music. / She loves music.}}
- به مادرم زنگ زدم. → {{I phoned my mother. / I called my mother.}}
:::

::: summary
- Noun or adjective + light verb: کار کردن، تمام شدن، یاد گرفتن، گوش دادن، دوست داشتن.
- Only the light verb is conjugated and negated: کار نمی‌کنم.
- کردن transitive, شدن intransitive: تمام کردن / تمام شدن.
:::
