# 11. El subjuntivo, el imperativo y los verbos modales

«Quiero **ir**», «tienes que **venir**», «quizá lo **sepa**»: el persa usa aquí una forma especial, el **subjuntivo**, hecho con el prefijo بـ *be-* en lugar de می‌: بروم *beravam* «que vaya». El imperativo es la misma forma sin desinencia: برو *boro* «¡ve!». Con estas dos formas, el persa expresa deseos, obligaciones, posibilidades y órdenes.

## El presente de subjuntivo

| Persona | رفتن ir (رو) | کردن hacer (کن) | خوردن comer (خور) |
|---|---|---|---|
| من | بروم *beravam* | بکنم *bokonam* | بخورم *bokhoram* |
| تو | بروی *beravi* | بکنی *bokoni* | بخوری *bokhori* |
| او | برود *beravad* | بکند *bokonad* | بخورد *bokhorad* |
| ما | برویم *beravim* | بکنیم *bokonim* | بخوریم *bokhorim* |
| شما | بروید *beravid* | بکنید *bokonid* | بخورید *bokhorid* |
| آنها | بروند *beravand* | بکنند *bokonand* | بخورند *bokhorand* |

بـ se pronuncia *bo-* ante un tema con *o*. La negación lo sustituye por نـ: نروم *naravam*. Los verbos compuestos suelen omitirlo: کار کنم *kâr konam*. بودن tiene باشم *bâsham*, داشتن tiene داشته باشم.

## Dónde se usa

| Palabra | Sentido | Ejemplo |
|---|---|---|
| می‌خواهم | quiero | می‌خواهم بروم quiero ir |
| باید *bâyad* | hay que | باید بروم tengo que ir |
| می‌توانم *mitavânam* | puedo | می‌توانم بیایم puedo venir |
| شاید *shâyad* | quizá | شاید بداند quizá lo sepa |
| که *ke* | para que | آمدم که ببینم vine a ver |
| بیا | vamos a (con 1.ª pl.) | بیا برویم vámonos |

باید y شاید no cambian según la persona; el subjuntivo que las sigue, sí.

## El imperativo

| Verbo | Singular | Plural, cortesía | Negativo |
|---|---|---|---|
| رفتن | برو *boro* | بروید *beravid* | نرو *naro* |
| آمدن | بیا *biyâ* | بیایید *biyâyid* | نیا *nayâ* |
| نوشتن | بنویس *benevis* | بنویسید *benevisid* | ننویس *nanevis* |
| نشستن | بنشین *beneshin* | بنشینید *beneshinid* | ننشین *naneshin* |

بفرمایید *befarmâyid* «por favor, adelante, sírvase» es el imperativo cortés que se oye en todas partes.

::: exercise write
Escriba en persa.

- «(que) vaya» → [[بروم]]
- «¡ven!» → [[بیا]]
- «¡escribe!» → [[بنویس]]
- «puedo» → [[می‌توانم]]
- «hay que» → [[باید]]
:::

::: exercise form
¿Qué forma sigue?

- می‌خواهم فارسی … «aprender» → ((یاد می‌گیرم / یاد بگیرم*))
- باید … «que vaya» → ((بروم* / می‌روم / رفتم))
- شاید … «lo sepa» → ((می‌داند / بداند*))
- … «¡no vayas!» → ((نرو* / نمی‌روی / نرفت))
:::

::: exercise meaning
¿Qué significa?

- بفرمایید. → ((por favor, adelante* / gracias / adiós))
- بیا برویم. → ((ven y ve / vámonos* / vino y se fue))
- نمی‌توانم بیایم. → ((no puedo venir* / no quiero venir / no vine))
:::

::: exercise translate
Traduzca.

- می‌خواهم ایران را ببینم. → {{Quiero ver Irán. / Quiero conocer Irán.}}
- باید کار کنیم. → {{Tenemos que trabajar. / Debemos trabajar.}}
- لطفاً بنشینید. → {{Siéntese, por favor. / Siéntense, por favor.}}
- شاید فردا بیاید. → {{Quizá venga mañana. / Tal vez venga mañana.}}
:::

::: summary
- Subjuntivo: بـ + tema de presente + desinencias: بروم، بکنم؛ negativo نروم؛ باشم.
- Tras خواستن، باید، توانستن، شاید، که.
- Imperativo: برو، بیا، بنویس; plural -id; negativo نرو؛ بفرمایید.
:::
