# 2. Les voyelles et l'orthographe

Le persan a six voyelles : trois longues, *â*, *i*, *u*, qui s'écrivent, et trois brèves, *a*, *e*, *o*, qui en général ne s'écrivent pas. دختر, c'est *dokhtar* « fille » : le *o* et le *a* ne sont pas sur la page, et vous les lisez parce que vous connaissez le mot. C'est la vraie difficulté de l'écriture, et elle diminue vite : la liste de vocabulaire de chaque leçon donne la prononciation.

## Les voyelles

| Voyelle | Écrite | En début de mot | Exemple |
|---|---|---|---|
| â (long, comme dans *pâte*) | ا | آ | آب *âb* eau ; بابا *bâbâ* papa |
| i (long) | ی | ای | ایران *Irân* ; سیب *sib* pomme |
| u (long, *ou*) | و | او | دوست *dust* ami ; او *u* il, elle |
| a (bref) | non écrite | ا | اسب *asb* cheval ; شب *shab* nuit |
| e (bref) | non écrite ; ه en fin de mot | ا | اسم *esm* nom ; خانه *khâne* maison |
| o (bref) | non écrite ; parfois و | ا | امید *omid* espoir ; تو *to* tu |

Dans les manuels et la poésie, les voyelles brèves peuvent être notées : un petit trait au-dessus pour *a* (َ), au-dessous pour *e* (ِ), un petit و au-dessus pour *o* (ُ). Les textes courants les omettent.

## Remarques d'orthographe

| Signe | Nom | Emploi | Exemple |
|---|---|---|---|
| ‌ | demi-espace | sépare les parties d'un mot sans espace | کتاب‌ها *ketâb-hâ* livres ; می‌روم *miravam* je vais |
| ّ | tashdid | redouble une consonne | اوّل *avval* premier |
| ء | hamze | un arrêt de la voix | مسئله *mas'ale* problème |
| خوا | و muet | *khâ* : le و ne se lit pas | خواهر *khâhar* sœur |

Le ه final de خانه ne se prononce pas *h* : il porte la voyelle *-e*. Dans ماه *mâh* « lune », c'est un vrai *h*.

::: exercise vowel
Comment s'écrit la voyelle ?

- le o de دختر dokhtar → ((non écrit* / و / ا))
- le â au début de آب → ((ا / آ* / non écrit))
- le i de سیب sib → ((ی* / ا / non écrit))
- le e final de خانه → ((ه* / ی / non écrit))
:::

::: exercise sign
À quoi sert le signe ?

- le petit blanc dans می‌روم → ((demi-espace entre parties d'un mot* / une lettre manquante / une voyelle brève))
- ّ dans اوّل → ((une consonne redoublée* / un a bref / un ou long))
- و dans خواهر → ((ne se lit pas* / se lit ou / se lit v))
:::

::: summary
- Voyelles longues écrites : â ا (آ en début de mot), i ی, u و ; brèves a, e, o non écrites.
- Une voyelle initiale est portée par ا : اسب asb, اسم esm, امید omid ; le -e final s'écrit ه.
- Demi-espace ‌ (ketâb‌hâ, mi‌ravam), tashdid ّ, و muet dans خوا.
:::
