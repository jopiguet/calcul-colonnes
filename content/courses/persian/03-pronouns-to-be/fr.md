# 3. Salutations, pronoms et « être »

Avec les pronoms et le verbe « être », vous pouvez vous présenter, demander des nouvelles et dire d'où vous venez. Le persan met le verbe en fin de phrase, n'a pas de genre grammatical (او, c'est « il » et « elle ») et emploie le pluriel شما *shomâ* comme « vous » de politesse.

## Pronoms personnels et « être »

| Pronom | Sens | « être », forme pleine | Forme brève (après un mot) |
|---|---|---|---|
| من *man* | je | هستم *hastam* | ـم / ـام *-am* |
| تو *to* | tu | هستی *hasti* | ـی / ـای *-i* |
| او *u* | il, elle | است *ast*, هست *hast* | است *ast* (parlé *-e*) |
| ما *mâ* | nous | هستیم *hastim* | ـیم *-im* |
| شما *shomâ* | vous | هستید *hastid* | ـید *-id* |
| آنها *ânhâ* | ils, elles | هستند *hastand* | ـند *-and* |

Les formes brèves sont les plus courantes : من ایرانی‌ام *man irâni-am* « je suis iranien », ما خسته‌ایم *mâ khaste-im* « nous sommes fatigués ». La négation est نیست- à toutes les personnes : نیستم *nistam* « je ne suis pas », نیست *nist* « il n'est pas ».

## Salutations

| Persan | Translittération | Sens |
|---|---|---|
| سلام | *salâm* | bonjour |
| حال شما چطور است؟ | *hâl-e shomâ chetor ast?* | comment allez-vous ? |
| خوبم، ممنون | *khubam, mamnun* | je vais bien, merci |
| اسم من سارا است | *esm-e man Sârâ ast* | je m'appelle Sara |
| اهل کجا هستید؟ | *ahl-e kojâ hastid?* | d'où êtes-vous ? |
| خداحافظ | *khodâhâfez* | au revoir |

Le point d'interrogation est retourné : ؟. L'ordre des mots ne change pas dans une question : c'est la voix ou un mot interrogatif qui marque la question.

::: exercise pronoun
Quel pronom ?

- nous → ((من / ما* / شما))
- il ou elle → ((او* / تو / آنها))
- vous, politesse → ((تو / شما* / ما))
- ils → ((ما / آنها* / او))
:::

::: exercise to-be
Donnez la forme pleine de « être ».

- ما … → [[هستیم]]
- شما … → [[هستید]]
- آنها … → [[هستند]]
- من … négatif → [[نیستم]]
:::

::: exercise greeting
Que signifie-t-il ?

- خداحافظ → ((bonjour / au revoir* / merci))
- ممنون → ((merci* / s'il vous plaît / pardon))
- حال شما چطور است؟ → ((comment allez-vous ?* / comment vous appelez-vous ? / d'où êtes-vous ?))
- اهل کجا هستید؟ → ((où allez-vous ? / d'où êtes-vous ?* / qui êtes-vous ?))
:::

::: exercise translate
Traduisez.

- من ایرانی هستم. → {{Je suis iranien. / Je suis iranienne.}}
- او خسته است. → {{Il est fatigué. / Elle est fatiguée.}}
- ما دانشجو هستیم. → {{Nous sommes étudiants. / Nous sommes étudiantes.}}
- اسم من سارا است. → {{Je m'appelle Sara. / Mon nom est Sara.}}
:::

::: summary
- من، تو، او، ما، شما، آنها ; pas de genre : او est il et elle ; شما est aussi le « vous » de politesse.
- هستم، هستی، است، هستیم، هستید، هستند ; brèves -am, -i, ast, -im, -id, -and ; négatif نیستم.
- سلام، خداحافظ، ممنون ; le verbe vient en dernier ; ؟ est le point d'interrogation.
:::
