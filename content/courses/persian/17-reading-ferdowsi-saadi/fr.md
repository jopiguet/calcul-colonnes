# 17. Lecture : Ferdowsi et Saadi

Le persan a si peu changé en mille ans qu'un écolier iranien lit les poètes classiques avec quelques notes seulement. Ferdowsi acheva le *Shâhnâme*, le *Livre des rois*, vers 1010 ; Saadi écrivit le *Golestân*, le *Jardin des roses*, en 1258 à Chiraz. Tous deux sont cités chaque jour. Avec la grammaire de ce cours et une poignée de formes anciennes, vous pouvez les lire aussi.

## Ferdowsi

| Persan | Traduction |
|---|---|
| توانا بود هر که دانا بود | Est puissant quiconque est savant ; |
| ز دانش دل پیر برنا بود | par le savoir, un vieux cœur est jeune. |

*tavânâ bovad har ke dânâ bovad / ze dânesh del-e pir bornâ bovad.* بود est ici le présent classique « est », employé pour les vérités générales ; ز est la forme poétique de از.

## Saadi

| Persan | Traduction |
|---|---|
| بنی‌آدم اعضای یک پیکرند | Les fils d'Adam sont les membres d'un même corps, |
| که در آفرینش ز یک گوهرند | car dans la création ils sont d'une même essence. |
| چو عضوی به درد آورد روزگار | Quand le sort fait souffrir un membre, |
| دگر عضوها را نماند قرار | les autres membres ne trouvent plus de repos. |
| تو کز محنت دیگران بی‌غمی | Toi que la peine des autres laisse sans chagrin, |
| نشاید که نامت نهند آدمی | il ne convient pas qu'on te nomme homme. |

Ces vers du *Golestân* sont parmi les plus connus de la langue ; une leçon plus ancienne du premier vers porte اعضای یکدیگرند « membres les uns des autres ».

## Formes classiques

| Classique | Moderne | Sens |
|---|---|---|
| ز | از | de, par |
| چو | چون | quand ; comme |
| دگر | دیگر | autre |
| کز | که از | qui … de |
| بود (présent) | است | est (vérité générale) |
| نماند، نشاید | نمی‌ماند، شایسته نیست | ne reste pas ; ne convient pas |

::: exercise modern
Donnez la forme moderne.

- ز → [[از]]
- دگر → [[دیگر]]
- چو → [[چون]]
- کز → [[که از]]
:::

::: exercise complete
Complétez le vers.

- توانا بود هر که … بود → [[دانا]]
- بنی‌آدم اعضای یک … → [[پیکرند]]
- ز … دل پیر برنا بود → [[دانش]]
:::

::: exercise sense
Que signifie-t-il ?

- برنا → ((jeune* / vieux / savant))
- گوهر → ((essence, joyau* / corps / chagrin))
- آفرینش → ((création* / savoir / repos))
- بی‌غم → ((sans chagrin* / plein de chagrin / sans corps))
:::

::: exercise translate
Traduisez.

- توانا بود هر که دانا بود → {{Est puissant quiconque est savant. / Celui qui sait est puissant.}}
- بنی‌آدم اعضای یک پیکرند → {{Les fils d'Adam sont les membres d'un même corps. / Les humains sont les membres d'un seul corps.}}
- نشاید که نامت نهند آدمی → {{Il ne convient pas qu'on te nomme homme. / Tu ne mérites pas d'être appelé homme.}}
:::

::: summary
- Ferdowsi, *Shâhnâme* : توانا بود هر که دانا بود.
- Saadi, *Golestân* : بنی‌آدم اعضای یک پیکرند.
- Formes classiques : ز = از، چو = چون، دگر = دیگر، کز = که از ; بود présent gnomique.
:::
