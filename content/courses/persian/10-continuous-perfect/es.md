# 10. Los tiempos continuos y compuestos

El pretérito simple dice que algo ocurrió. El persa tiene otros pasados para decir cómo: en duración o por costumbre, con un resultado que aún vale, o antes de otro hecho pasado. Todos se forman con piezas que ya conoce: el prefijo می‌ y el tema de pasado, más el **participio pasado**, tema de pasado + ـه *-e*: رفته *rafte* «ido».

## Los tiempos

| Tiempo | Formado con | رفتن ir | Sentido |
|---|---|---|---|
| imperfecto | می + tema de pasado + desinencia | می‌رفتم *miraftam* | iba |
| pretérito perfecto | participio + «ser» breve | رفته‌ام *rafte-am* | he ido |
| pluscuamperfecto | participio + بودن en pasado | رفته بودم *rafte budam* | había ido |
| presente progresivo | داشتن + presente | دارم می‌روم *dâram miravam* | estoy yendo |
| pasado progresivo | داشتن en pasado + imperfecto | داشتم می‌رفتم *dâshtam miraftam* | estaba yendo |

## El pretérito perfecto

| Persona | Forma |
|---|---|
| من | رفته‌ام *rafte-am* |
| تو | رفته‌ای *rafte-i* |
| او | رفته است *rafte ast* |
| ما | رفته‌ایم *rafte-im* |
| شما | رفته‌اید *rafte-id* |
| آنها | رفته‌اند *rafte-and* |

El pretérito perfecto se usa para hechos pasados cuyo efecto aún cuenta, y para lo que se ha oído decir: گویا رفته است «al parecer se ha ido». Negaciones: نرفته‌ام «no he ido», نمی‌رفتم «no iba», نرفته بودم «no había ido». El progresivo con داشتن no tiene negativo: se usa entonces el presente o el imperfecto simples.

Escriba en persa.

- «iba» → [[می‌رفتم]]
- «escribía» (él) → [[می‌نوشت]]
- «había ido» → [[رفته بودم]]
- «estoy yendo» → [[دارم می‌روم]]
:::

::: exercise tense
¿Qué tiempo?

- دیده‌ام → ((pretérito simple / pretérito perfecto* / pluscuamperfecto))
- می‌خواندیم → ((imperfecto* / presente / pretérito perfecto))
- رفته بودند → ((pretérito perfecto / pluscuamperfecto* / imperfecto))
- دارد می‌خورد → ((presente progresivo* / pasado progresivo / pretérito simple))
:::

::: exercise meaning
¿Qué significa?

- تا حالا ایران را دیده‌ای؟ → ((¿viste Irán ayer? / ¿has visto alguna vez Irán?* / ¿veías Irán?))
- هر روز به مدرسه می‌رفتم. → ((un día fui a la escuela / iba a la escuela todos los días* / he ido a la escuela))
- وقتی رسیدم، رفته بود. → ((cuando llegué, se había ido* / cuando llego, se va / cuando llegué, se iba))
:::

::: exercise translate
Traduzca.

- داشتم غذا می‌خوردم. → {{Estaba comiendo.}}
- این کتاب را خوانده‌ام. → {{He leído este libro.}}
- بچه بودم، در شیراز زندگی می‌کردیم. → {{Cuando era niño, vivíamos en Shiraz. / De niño, vivíamos en Shiraz.}}
- هنوز نیامده است. → {{Todavía no ha venido. / Aún no ha llegado.}}
:::

::: summary
- Participio pasado: tema de pasado + ه: رفته، دیده، خوانده.
- می + pasado: imperfecto; participio + ام، ای، است…: pretérito perfecto; participio + بودم: pluscuamperfecto.
- داشتن + presente o imperfecto: progresivo, «ahora mismo»; sin negativo.
:::
