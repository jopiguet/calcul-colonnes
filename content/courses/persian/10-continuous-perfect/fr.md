# 10. Les temps continus et composés

Le passé simple dit qu'une chose a eu lieu. Le persan a d'autres passés pour dire comment : en durée ou par habitude, avec un résultat qui vaut encore, ou avant un autre événement passé. Tous se forment avec les pièces que vous connaissez : le préfixe می‌ et le radical du passé, plus le **participe passé**, radical du passé + ـه *-e* : رفته *rafte* « allé ».

## Les temps

| Temps | Formé de | رفتن aller | Sens |
|---|---|---|---|
| imparfait | می + radical du passé + terminaison | می‌رفتم *miraftam* | j'allais |
| passé composé | participe + « être » bref | رفته‌ام *rafte-am* | je suis allé |
| plus-que-parfait | participe + بودن au passé | رفته بودم *rafte budam* | j'étais allé |
| présent progressif | داشتن + présent | دارم می‌روم *dâram miravam* | je suis en train d'aller |
| passé progressif | داشتن au passé + imparfait | داشتم می‌رفتم *dâshtam miraftam* | j'étais en train d'aller |

## Le passé composé

| Personne | Forme |
|---|---|
| من | رفته‌ام *rafte-am* |
| تو | رفته‌ای *rafte-i* |
| او | رفته است *rafte ast* |
| ما | رفته‌ایم *rafte-im* |
| شما | رفته‌اید *rafte-id* |
| آنها | رفته‌اند *rafte-and* |

Le passé composé s'emploie pour des faits passés dont l'effet compte encore, et pour ce qu'on a entendu dire : گویا رفته است « il serait parti, paraît-il ». Négations : نرفته‌ام « je ne suis pas allé », نمی‌رفتم « je n'allais pas », نرفته بودم « je n'étais pas allé ». Le progressif avec داشتن n'a pas de négatif : on emploie alors le présent ou l'imparfait simples.

::: exercise tense
Quel temps ?

- دیده‌ام → ((passé simple / passé composé* / plus-que-parfait))
- می‌خواندیم → ((imparfait* / présent / passé composé))
- رفته بودند → ((passé composé / plus-que-parfait* / imparfait))
- دارد می‌خورد → ((présent progressif* / passé progressif / passé simple))
:::

::: exercise meaning
Que signifie-t-il ?

- تا حالا ایران را دیده‌ای؟ → ((as-tu vu l'Iran hier ? / as-tu déjà vu l'Iran ?* / voyais-tu l'Iran ?))
- هر روز به مدرسه می‌رفتم. → ((je suis allé à l'école un jour / j'allais à l'école tous les jours* / je suis allé à l'école))
- وقتی رسیدم، رفته بود. → ((quand je suis arrivé, il était parti* / quand j'arrive, il part / quand je suis arrivé, il partait))
:::

::: exercise translate
Traduisez.

- داشتم غذا می‌خوردم. → {{J'étais en train de manger.}}
- این کتاب را خوانده‌ام. → {{J'ai lu ce livre.}}
- بچه بودم، در شیراز زندگی می‌کردیم. → {{Quand j'étais enfant, nous vivions à Chiraz. / Enfant, nous habitions à Chiraz.}}
- هنوز نیامده است. → {{Il n'est pas encore venu. / Elle n'est pas encore arrivée.}}
:::

::: summary
- Participe passé : radical du passé + ه : رفته، دیده، خوانده.
- می + passé : imparfait ; participe + ام، ای، است… : passé composé ; participe + بودم : plus-que-parfait.
- داشتن + présent ou imparfait : progressif, « en ce moment » ; pas de négatif.
:::
