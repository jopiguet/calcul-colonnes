# 24. Órdenes, deseos y el subjuntivo independiente

El subjuntivo no es solo para las subordinadas. Solo en una oración principal expresa lo que quien habla quiere, teme o imagina: «vamos», «que los dioses te ayuden», «¿qué debo hacer?», «alguien podría decir». Esta lección reúne todas las maneras en que el latín ordena, prohíbe, exhorta o desea.

## El imperativo

| Conjugación | Singular | Plural | Pasiva / deponente sg. | Pasiva / deponente pl. |
|---|---|---|---|---|
| 1.ª amō | amā | amāte | hortāre | hortāminī |
| 2.ª moneō | monē | monēte | verēre | verēminī |
| 3.ª regō | rege | regite | sequere | sequiminī |
| 3.ª en -iō capiō | cape | capite | patere | patiminī |
| 4.ª audiō | audī | audīte | orīre | orīminī |
| sum | es | este | — | — |
| eō, ferō | ī, fer | īte, ferte | — | — |

Cuatro verbos pierden la *-e* final en el singular: ***dīc, dūc, fac, fer*** (di, conduce, haz, lleva). El imperativo deponente parece un infinitivo activo: *sequere!* «¡sigue!», *loquere!* «¡habla!». Un imperativo futuro en *-tō, -tōte* aparece en leyes y recetas: *estō* «sea», *mementō* «acuérdate».

## La prohibición

El latín no usa *nōn* + imperativo. Tiene dos formas habituales:

| Construcción | Ejemplo | Sentido |
|---|---|---|
| *nōlī, nōlīte* + infinitivo (cortés) | *Nōlī timēre.* | No tengas miedo. |
| *nē* + perfecto de subjuntivo (firme) | *Nē timueris.* | No temas. |

## El subjuntivo independiente

| Uso | Negación | Ejemplo | Sentido |
|---|---|---|---|
| **Exhortativo** (1.ª pl.) | *nē* | *Eāmus!* | ¡Vamos! |
| **Yusivo** (3.ª persona) | *nē* | *Veniat.* | Que venga. |
| **Deliberativo** (pregunta) | *nōn* | *Quid faciam?* | ¿Qué debo hacer? |
| **Desiderativo** posible | *nē* | *Utinam veniat!* | ¡Ojalá venga! |
| **Desiderativo** irreal de presente | *nē* | *Utinam adesset!* | ¡Ojalá estuviera aquí! |
| **Desiderativo** irreal de pasado | *nē* | *Utinam vēnisset!* | ¡Ojalá hubiera venido! |
| **Potencial** | *nōn* | *Dīcat aliquis…* | Alguien podría decir… |

El tiempo de un deseo indica si aún puede cumplirse: presente de subjuntivo = posible; imperfecto = imposible ahora; pluscuamperfecto = imposible en el pasado. *Utinam* «ojalá» introduce a menudo el deseo; *Vīvat rēx!* «¡Viva el rey!» no lo necesita.

::: exercise which-use
Nombre el uso del subjuntivo.

- *Gaudeāmus igitur!* → ((exhortativo* / deliberativo / potencial))
- *Quō eam?* → ((exhortativo / deliberativo* / desiderativo))
- *Utinam nē vēnissent!* → ((yusivo / deliberativo / desiderativo*))
- *Dī tē servent!* → ((deliberativo / desiderativo* / potencial))
- *Cōnsulēs videant nē quid rēs pūblica dētrīmentī capiat.* → ((yusivo* / deliberativo / potencial))
:::

::: exercise wish
Elija el tiempo que conviene al deseo.

- Ojalá estuviera aquí ahora (no está) → Utinam ((adsit / adesset* / adfuisset))!
- Ojalá venga (todavía es posible) → Utinam ((veniat* / venīret / vēnisset))!
- Ojalá lo hubiera visto (no lo vi) → Utinam ((videam / vidērem / vīdissem*))!
:::

::: exercise translate
Traduzca.

- *Nōlīte fugere, mīlitēs!* → {{¡No huyáis, soldados! / ¡No huyan, soldados!}}
- *Pugnēmus prō patriā!* → {{¡Luchemos por la patria!}}

:::

::: summary
- Imperativo: *amā, amāte; rege, regite; audī, audīte*; *dīc, dūc, fac, fer*; deponente *sequere, sequiminī*.
- Prohibición: *nōlī / nōlīte* + infinitivo, o *nē* + perfecto de subjuntivo.
- Exhortativo *eāmus*; yusivo *veniat*; deliberativo *quid faciam?*; potencial *dīcat aliquis*.
- Deseos, a menudo con *utinam*: presente posible, imperfecto irreal de presente, pluscuamperfecto irreal de pasado; negación *nē*.
:::
