# 24. Ordres, souhaits et subjonctif indépendant

Le subjonctif ne sert pas qu'aux subordonnées. Seul dans une principale, il exprime ce que celui qui parle veut, craint ou imagine : « allons », « que les dieux t'aident », « que dois-je faire ? », « on pourrait dire ». Cette leçon réunit toutes les manières dont le latin ordonne, défend, exhorte ou souhaite.

## L'impératif

| Conjugaison | Singulier | Pluriel | Passif / déponent sg. | Passif / déponent pl. |
|---|---|---|---|---|
| 1re amō | amā | amāte | hortāre | hortāminī |
| 2e moneō | monē | monēte | verēre | verēminī |
| 3e regō | rege | regite | sequere | sequiminī |
| 3e en -iō capiō | cape | capite | patere | patiminī |
| 4e audiō | audī | audīte | orīre | orīminī |
| sum | es | este | — | — |
| eō, ferō | ī, fer | īte, ferte | — | — |

Quatre verbes perdent le *-e* final au singulier : ***dīc, dūc, fac, fer*** (dis, conduis, fais, porte). L'impératif déponent ressemble à un infinitif actif : *sequere !* « suis ! », *loquere !* « parle ! ». Un impératif futur en *-tō, -tōte* apparaît dans les lois et les recettes : *estō* « qu'il soit », *mementō* « souviens-toi ».

## La défense

Le latin n'emploie pas *nōn* + impératif. Il a deux formes usuelles :

| Construction | Exemple | Sens |
|---|---|---|
| *nōlī, nōlīte* + infinitif (poli) | *Nōlī timēre.* | N'aie pas peur. |
| *nē* + subjonctif parfait (ferme) | *Nē timueris.* | Ne crains pas. |

## Le subjonctif indépendant

| Emploi | Négation | Exemple | Sens |
|---|---|---|---|
| **Exhortation** (1re pl.) | *nē* | *Eāmus!* | Allons ! |
| **Ordre** (3e personne) | *nē* | *Veniat.* | Qu'il vienne. |
| **Délibération** (question) | *nōn* | *Quid faciam?* | Que dois-je faire ? |
| **Souhait** réalisable | *nē* | *Utinam veniat!* | Puisse-t-il venir ! |
| **Souhait** irréel du présent | *nē* | *Utinam adesset!* | Si seulement il était là ! |
| **Souhait** irréel du passé | *nē* | *Utinam vēnisset!* | Si seulement il était venu ! |
| **Potentiel** | *nōn* | *Dīcat aliquis…* | Quelqu'un pourrait dire… |

Le temps d'un souhait indique s'il peut encore se réaliser : subjonctif présent = possible ; imparfait = impossible maintenant ; plus-que-parfait = impossible dans le passé. *Utinam* « si seulement » introduit souvent le souhait ; *Vīvat rēx !* « Vive le roi ! » s'en passe.

::: exercise which-use
Nommez l'emploi du subjonctif.

- *Gaudeāmus igitur!* → ((exhortation* / délibération / potentiel))
- *Quō eam?* → ((exhortation / délibération* / souhait))
- *Utinam nē vēnissent!* → ((ordre / délibération / souhait*))
- *Dī tē servent!* → ((délibération / souhait* / potentiel))
- *Cōnsulēs videant nē quid rēs pūblica dētrīmentī capiat.* → ((ordre* / délibération / potentiel))
:::

::: exercise wish
Choisissez le temps qui convient au souhait.

- Si seulement il était là maintenant (il n'y est pas) → Utinam ((adsit / adesset* / adfuisset))!
- Puisse-t-il venir (c'est encore possible) → Utinam ((veniat* / venīret / vēnisset))!
- Si seulement je l'avais vu (je ne l'ai pas vu) → Utinam ((videam / vidērem / vīdissem*))!
:::

::: exercise translate
Traduisez.

- *Nōlīte fugere, mīlitēs!* → {{Ne fuyez pas, soldats !}}
- *Pugnēmus prō patriā!* → {{Combattons pour la patrie !}}
- *Utinam pater meus vīveret!* → {{Si seulement mon père était vivant ! / Si seulement mon père vivait !}}
- *Quid dīcam?* → {{Que dois-je dire ? / Que dire ?}}
:::

::: summary
- Impératif : *amā, amāte ; rege, regite ; audī, audīte* ; *dīc, dūc, fac, fer* ; déponent *sequere, sequiminī*.
- Défense : *nōlī / nōlīte* + infinitif, ou *nē* + subjonctif parfait.
- Exhortation *eāmus* ; ordre *veniat* ; délibération *quid faciam ?* ; potentiel *dīcat aliquis*.
- Souhaits, souvent avec *utinam* : présent réalisable, imparfait irréel du présent, plus-que-parfait irréel du passé ; négation *nē*.
:::
