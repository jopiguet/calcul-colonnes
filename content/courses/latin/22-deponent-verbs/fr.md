# 22. Les verbes déponents et semi-déponents

Certains verbes latins ont **des formes passives mais un sens actif** : *hortor* « j'exhorte », *sequor* « je suis », *loquor* « je parle ». Les grammairiens romains les appelaient *verba dēpōnentia*, verbes qui ont « déposé » leurs formes actives. Vous connaissez déjà toutes leurs formes : ils se conjuguent exactement comme le passif. La seule nouveauté est de les traduire à l'actif.

## Reconnaître un déponent

Le dictionnaire donne trois temps primitifs, tous passifs : présent, infinitif, parfait.

| Conjugaison | Temps primitifs | Sens |
|---|---|---|
| 1re | hortor, hortārī, hortātus sum | exhorter, encourager |
| 2e | vereor, verērī, veritus sum | craindre, respecter |
| 3e | sequor, sequī, secūtus sum | suivre |
| 3e en -iō | patior, patī, passus sum | souffrir, permettre |
| 4e | orior, orīrī, ortus sum | se lever, naître |

| Temps | Forme | Sens |
|---|---|---|
| Présent | *sequitur* | il suit |
| Imparfait | *sequēbātur* | il suivait |
| Futur | *sequētur* | il suivra |
| Parfait | *secūtus est* | il suivit, il a suivi |
| Subjonctif présent | *sequātur* | (qu')il suive |
| Infinitif | *sequī* | suivre |

Trois formes actives subsistent, parce que le passif n'a rien à proposer à leur place :

| Forme | Exemple | Sens |
|---|---|---|
| Participe présent | *sequēns, sequentis* | suivant |
| Participe futur | *secūtūrus* | devant suivre |
| Infinitif futur | *secūtūrus esse* | devoir suivre |

Le participe parfait d'un déponent a un sens **actif** : *hortātus* « ayant exhorté », *secūtus* « ayant suivi ». Il comble un manque : un verbe ordinaire n'a pas de participe parfait actif (*amātus* signifie « ayant été aimé »), mais *Caesar, mīlitēs hortātus, …* signifie « César, ayant exhorté les soldats, … ».

::: exercise identify
Déponent ou passif ordinaire ? Traduisez la forme.

- *hortātur* → ((il exhorte* / il est exhorté))
- *amātur* → ((il aime / il est aimé*))
- *locūtus est* → ((il a parlé* / il a été parlé))
- *secūtī sunt* → ((ils ont suivi* / ils ont été suivis))
- *captī sunt* → ((ils ont pris / ils ont été pris*))
:::

## Cinq déponents avec l'ablatif

*Ūtor, fruor, fungor, potior, vēscor* se construisent avec l'**ablatif**, non l'accusatif. Pour s'en souvenir : ils décrivent le fait de « tirer profit au moyen de » quelque chose.

| Verbe | Sens | Exemple |
|---|---|---|
| *ūtor, ūtī, ūsus sum* | se servir de | *Gladiō ūtitur.* Il se sert d'une épée. |
| *fruor, fruī, frūctus sum* | jouir de | *Vītā fruimur.* Nous jouissons de la vie. |
| *fungor, fungī, fūnctus sum* | s'acquitter de | *Officiō fungitur.* Il s'acquitte de son devoir. |
| *potior, potīrī, potītus sum* | s'emparer de | *Urbe potītus est.* Il s'empara de la ville. |
| *vēscor, vēscī* | se nourrir de | *Lacte vēscuntur.* Ils se nourrissent de lait. |

## Les semi-déponents

Quelques verbes sont normaux au système du présent mais déponents au parfait :

| Verbe | Présent | Parfait |
|---|---|---|
| *audeō, audēre, ausus sum* | *audet*, il ose | *ausus est*, il osa |
| *gaudeō, gaudēre, gāvīsus sum* | *gaudet*, il se réjouit | *gāvīsus est*, il se réjouit (parfait) |
| *soleō, solēre, solitus sum* | *solet*, il a l'habitude | *solitus est*, il avait l'habitude |
| *fīdō, fīdere, fīsus sum* | *fīdit*, il se fie | *fīsus est*, il se fia |

::: exercise case
Choisissez le cas correct après le verbe.

- Caesar ((nāvēs / nāvibus*)) ūtēbātur. → se servir de
- Hostēs ((urbem / urbe*)) potītī sunt. → s'emparer de
- Puerī ((patrem* / patre)) sequuntur. → suivre
- Pāce ((fruimur* / fruimus)). → jouir de
:::

::: exercise translate
Traduisez.

- *Caesar mīlitēs hortātus est ut fortiter pugnārent.* → {{César exhorta les soldats à combattre courageusement.}}
- *Multa locūtus, discessit.* → {{Après avoir beaucoup parlé, il partit. / Ayant dit beaucoup de choses, il s'en alla.}}
- *Rōmānī armīs optimīs ūtēbantur.* → {{Les Romains se servaient d'excellentes armes. / Les Romains utilisaient les meilleures armes.}}
- *Nōn ausus est domum redīre.* → {{Il n'osa pas rentrer chez lui. / Il n'a pas osé retourner à la maison.}}
:::

::: summary
- Déponents : formes passives, sens actif. Temps primitifs *sequor, sequī, secūtus sum*.
- Formes actives conservées : participe présent, participe futur, infinitif futur.
- Le participe parfait d'un déponent est actif : *hortātus*, ayant exhorté.
- *Ūtor, fruor, fungor, potior, vēscor* + ablatif.
- Semi-déponents : *audeō ausus sum, gaudeō gāvīsus sum, soleō solitus sum, fīdō fīsus sum*.
:::
