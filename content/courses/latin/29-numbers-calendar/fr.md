# 29. Les nombres et le calendrier romain

Les nombres latins forment deux séries : les **cardinaux** (un, deux, trois) et les **ordinaux** (premier, deuxième, troisième). Seuls les trois premiers cardinaux, les centaines et *mīlia* se déclinent ; les autres sont invariables. Les chiffres romains et les dates romaines suivent leur propre logique, en comptant à rebours à partir de trois jours fixes de chaque mois.

## Cardinaux et ordinaux

| Valeur | Chiffre | Cardinal | Ordinal |
|---|---|---|---|
| 1 | I | ūnus, -a, -um | prīmus |
| 2 | II | duo, duae, duo | secundus |
| 3 | III | trēs, tria | tertius |
| 4 | IV | quattuor | quārtus |
| 5 | V | quīnque | quīntus |
| 6 | VI | sex | sextus |
| 7 | VII | septem | septimus |
| 8 | VIII | octō | octāvus |
| 9 | IX | novem | nōnus |
| 10 | X | decem | decimus |
| 20 | XX | vīgintī | vīcēsimus |
| 50 | L | quīnquāgintā | quīnquāgēsimus |
| 100 | C | centum | centēsimus |
| 500 | D | quīngentī, -ae, -a | quīngentēsimus |
| 1000 | M | mīlle | mīllēsimus |

*Duo* et *trēs* se déclinent :

| Cas | duo (m.) | duae (f.) | trēs (m./f.) | tria (n.) |
|---|---|---|---|---|
| Nominatif | duo | duae | trēs | tria |
| Génitif | duōrum | duārum | trium | trium |
| Datif | duōbus | duābus | tribus | tribus |
| Accusatif | duōs | duās | trēs | tria |
| Ablatif | duōbus | duābus | tribus | tribus |

*Mīlle* est un adjectif invariable au singulier (*mīlle mīlitēs*) ; le pluriel *mīlia, mīlium* est un nom neutre suivi d'un génitif partitif : *tria mīlia mīlitum*, trois mille soldats. *Mīlle passūs* (mille pas) est le mille romain, environ 1,48 km.

Dans les chiffres, un signe plus petit placé avant un plus grand se soustrait : IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900.

## Le calendrier romain

Chaque mois a trois jours nommés :

| Jour | Nom | Date |
|---|---|---|
| Premier du mois | *Kalendae* | le 1er |
| « Neuvième » jour avant les Ides | *Nōnae* | le 5, ou le 7 en mars, mai, juillet, octobre |
| Milieu du mois | *Īdūs* | le 13, ou le 15 en mars, mai, juillet, octobre |

Les autres jours se comptent **à rebours** jusqu'au jour nommé suivant, de façon **inclusive** (les deux extrémités comptent) : *ante diem tertium Kalendās Iānuāriās*, abrégé *a.d. III Kal. Ian.*, est le troisième jour avant les Calendes de janvier, Calendes comprises : le 30 décembre. La veille se dit *prīdiē* : *prīdiē Īdūs Mārtiās*, le 14 mars.

Les années portaient le nom des deux consuls (*M. Tulliō Cicerōne C. Antōniō cōnsulibus*, 63 av. J.-C.) ou se comptaient *ab urbe conditā* (A.U.C.), depuis la fondation de Rome en 753 av. J.-C.

Les noms de mois sont des adjectifs accordés avec *Kalendae, Nōnae, Īdūs* : *Iānuārius, Februārius, Mārtius, Aprīlis, Māius, Iūnius, Iūlius* (anciennement *Quīntīlis*), *Augustus* (anciennement *Sextīlis*), *September, Octōber, November, December*. Les quatre derniers trahissent une année plus ancienne qui commençait en mars : *September* est le « septième » mois.

::: summary
- *Ūnus, duo, trēs* se déclinent ; de *quattuor* à *centum*, invariables ; les centaines se déclinent comme *bonī* ; *mīlle* invariable, *mīlia* + génitif.
- Ordinaux en *-us, -a, -um* : *prīmus, secundus, tertius, … decimus*.
- Chiffres : un signe plus petit avant un plus grand se soustrait (IV, IX, XL, XC, CD, CM).
- *Kalendae* le 1er, *Nōnae* le 5/7, *Īdūs* le 13/15 ; compter à rebours de façon inclusive ; *prīdiē* la veille.
:::
