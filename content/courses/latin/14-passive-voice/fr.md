# 14. Le passif : présent, imparfait, futur

« La jeune fille est aimée », « la ville était attaquée », « les lettres seront envoyées » : le français construit le passif avec « être ». Le latin le construit, à ces trois temps, avec une seconde série de terminaisons personnelles. Changez la terminaison, et *amat* (il aime) devient *amātur* (il est aimé).

## Les terminaisons passives

| Personne | Actif | Passif |
|---|---|---|
| 1re sg. | -ō / -m | **-or / -r** |
| 2e sg. | -s | **-ris** (-re) |
| 3e sg. | -t | **-tur** |
| 1re pl. | -mus | **-mur** |
| 2e pl. | -tis | **-minī** |
| 3e pl. | -nt | **-ntur** |

## Le présent passif

| Personne | amāre | monēre | regere | audīre |
|---|---|---|---|---|
| 1re sg. | am**or** | mone**or** | reg**or** | audi**or** |
| 2e sg. | amā**ris** | monē**ris** | reg**eris** | audī**ris** |
| 3e sg. | amā**tur** | monē**tur** | reg**itur** | audī**tur** |
| 1re pl. | amā**mur** | monē**mur** | reg**imur** | audī**mur** |
| 2e pl. | amā**minī** | monē**minī** | reg**iminī** | audī**minī** |
| 3e pl. | ama**ntur** | mone**ntur** | reg**untur** | audi**untur** |

La troisième conjugaison a *-eris* à la deuxième personne du singulier (et non *-iris*). *Capiō* donne *capior, caperis, capitur, capimur, capiminī, capiuntur*.

## L'imparfait et le futur passifs

L'imparfait échange simplement les terminaisons : *amābar, amābāris, amābātur, amābāmur, amābāminī, amābantur* ; *regēbar*, *audiēbar*.

Le futur fait de même : première et deuxième conjugaisons *amābor, amāberis, amābitur, amābimur, amābiminī, amābuntur* ; troisième et quatrième *regar, regēris, regētur, regēmur, regēminī, regentur* ; *audiar, audiēris…*

Remarquez deux quasi-jumeaux à la troisième conjugaison : *regeris* (tu es dirigé, présent) et *regēris* (tu seras dirigé, futur) : seule la longueur du *e* diffère.

## L'infinitif passif

| Conjugaison | Actif | Passif |
|---|---|---|
| 1re | amāre | amā**rī** |
| 2e | monēre | monē**rī** |
| 3e | regere | reg**ī** |
| 3e en *-iō* | capere | cap**ī** |
| 4e | audīre | audī**rī** |

*Amārī vult* : il veut être aimé. La troisième conjugaison retire tout le *-ere* et ajoute *-ī*.

## L'agent et le moyen

Dans une phrase passive, l'auteur de l'action, si c'est une personne, se met à l'ablatif avec **ā, ab** ; une chose employée comme instrument se met à l'ablatif seul :

| Latin | Sens |
|---|---|
| *Urbs ā mīlitibus capitur.* | La ville est prise par les soldats. (agent) |
| *Urbs gladiīs capitur.* | La ville est prise avec des épées. (moyen) |
| *Puer ā mātre vocābātur.* | Le garçon était appelé par sa mère. |
| *Epistulae crās mittentur.* | Les lettres seront envoyées demain. |

::: exercise agent-means
Agent ou moyen ? Choisissez la construction.

- par le roi → ((ā rēge* / rēge))
- avec des flèches (*sagittīs*) → ((ā sagittīs / sagittīs*))
- par les ennemis → ((ab hostibus* / hostibus))
- avec un grand courage → ((ā magnā virtūte / magnā virtūte*))
:::

::: exercise translate
Traduisez.

- *Puella ab omnibus amātur.* → {{La jeune fille est aimée de tous. / La jeune fille est aimée par tout le monde.}}
- *Oppidum ā Rōmānīs oppugnābātur.* → {{La ville était attaquée par les Romains. / La place forte était assiégée par les Romains.}}
- *Librī tuī ā multīs legentur.* → {{Tes livres seront lus par beaucoup de gens. / Tes livres seront lus par beaucoup.}}
- *Vincī nōlumus.* → {{Nous ne voulons pas être vaincus.}}
:::

::: summary
- Terminaisons passives : *-or/-r, -ris, -tur, -mur, -minī, -ntur*.
- Présent *amor, amāris, amātur…* ; imparfait *amābar…* ; futur *amābor, amāberis…* / *regar, regēris…*
- Infinitif passif : *amārī, monērī, regī, capī, audīrī*.
- Agent (personne) : *ā, ab* + ablatif ; moyen (chose) : ablatif seul.
:::
