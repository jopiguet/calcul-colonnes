# 15. El participio perfecto pasivo y los tiempos de perfecto pasivo

«Fue amado», «había sido tomado», «habrá sido enviado»: los tiempos pasivos de lo acabado no se forman con terminaciones sino, como en español, con un auxiliar. El latín combina el **participio perfecto pasivo** (del cuarto elemento del enunciado) con *sum*. Este participio es también un adjetivo de pleno derecho, una de las palabras más útiles del latín.

## El participio perfecto pasivo

Tome el cuarto elemento del enunciado, el supino en *-um*, y declínelo como *bonus, -a, -um*:

| Verbo | Supino | Participio | Sentido |
|---|---|---|---|
| amō, amāre, amāvī, amātum | amātum | amātus, -a, -um | amado |
| moneō, monēre, monuī, monitum | monitum | monitus, -a, -um | advertido |
| regō, regere, rēxī, rēctum | rēctum | rēctus, -a, -um | regido |
| capiō, capere, cēpī, captum | captum | captus, -a, -um | tomado, capturado |
| audiō, audīre, audīvī, audītum | audītum | audītus, -a, -um | oído |

Concuerda como cualquier adjetivo: *urbs capta* (la ciudad tomada), *litterae missae* (la carta enviada), *mīlitēs vulnerātī* (los soldados heridos).

## Los tiempos de perfecto pasivo

Participio + *sum* (perfecto), *eram* (pluscuamperfecto), *erō* (futuro perfecto). El participio concuerda con el sujeto en género y número.

| Persona | Perfecto | Pluscuamperfecto | Futuro perfecto |
|---|---|---|---|
| 1.ª sg. | amātus sum | amātus eram | amātus erō |
| 2.ª sg. | amātus es | amātus erās | amātus eris |
| 3.ª sg. | amātus est | amātus erat | amātus erit |
| 1.ª pl. | amātī sumus | amātī erāmus | amātī erimus |
| 2.ª pl. | amātī estis | amātī erātis | amātī eritis |
| 3.ª pl. | amātī sunt | amātī erant | amātī erunt |

Cuidado con el desfase: *amātus est* no es «es amado» (eso es *amātur*) sino «fue amado, ha sido amado». El *sum* sitúa el momento respecto al participio, que ya es pasado. Una mujer dice *amāta sum*; de una ciudad, *capta est*; de una carta, *missae sunt*.

El infinitivo perfecto pasivo es el participio + *esse*: *amātus esse*, «haber sido amado».

::: exercise perfect-passive
Ponga en perfecto pasivo, manteniendo el sujeto.

- *Urbs capitur.* → Urbs [[capta est]].
- *Puerī vocantur.* → Puerī [[vocātī sunt]].
- *Epistula mittitur.* → Epistula [[missa est]].
- *Dōna dantur.* → Dōna [[data sunt]].
- *Ego (fēmina) moneor.* → Ego [[monita sum]].
:::

## Leer las formas

| Latín | Sentido |
|---|---|
| *Carthāgō dēlēta est.* | Cartago fue destruida. |
| *Hostēs victī erant.* | Los enemigos habían sido vencidos. |
| *Cum epistula scrīpta erit, eam mittam.* | Cuando la carta haya sido escrita, la enviaré. |
| *Mīlitēs vulnerātī in castra portātī sunt.* | Los soldados heridos fueron llevados al campamento. |

::: exercise which
¿Presente pasivo o perfecto pasivo?

- *vocātur* → ((es llamado* / fue llamado))
- *vocātus est* → ((es llamado / fue llamado*))
- *captae sunt* → ((son tomadas / fueron tomadas*))
- *capiuntur* → ((son tomados* / fueron tomados))
:::

::: exercise translate
Traduzca.

- *Urbs ā Rōmānīs capta est.* → {{La ciudad fue tomada por los romanos.}}
- *Litterae iam scrīptae erant.* → {{La carta ya había sido escrita.}}
- *Puellae ā mātre vocātae sunt.* → {{Las muchachas fueron llamadas por su madre.}}
- *Gladius inventus est.* → {{La espada fue encontrada. / La espada ha sido hallada.}}
:::

::: summary
- Participio perfecto pasivo: del supino, declinado en *-us, -a, -um* (*amātus, captus, missus*).
- Perfecto pasivo: participio + *sum*; pluscuamperfecto: + *eram*; futuro perfecto: + *erō*. El participio concuerda con el sujeto.
- *Amātus est* = fue (ha sido) amado; *amātur* = es amado.
- Infinitivo perfecto pasivo: *amātus esse*.
:::
