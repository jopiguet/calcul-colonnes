# 15. Le participe parfait passif et les temps du parfait passif

« Fut aimé », « avait été pris », « aura été envoyé » : les temps passifs de l'accompli ne se forment pas avec des terminaisons mais, comme en français, avec un auxiliaire. Le latin combine le **participe parfait passif** (tiré du quatrième temps primitif) avec *sum*. Ce participe est aussi un adjectif à part entière, l'un des mots les plus utiles du latin.

## Le participe parfait passif

Prenez le quatrième temps primitif, le supin en *-um*, et déclinez-le comme *bonus, -a, -um* :

| Verbe | Supin | Participe | Sens |
|---|---|---|---|
| amō, amāre, amāvī, amātum | amātum | amātus, -a, -um | aimé |
| moneō, monēre, monuī, monitum | monitum | monitus, -a, -um | averti |
| regō, regere, rēxī, rēctum | rēctum | rēctus, -a, -um | dirigé |
| capiō, capere, cēpī, captum | captum | captus, -a, -um | pris, capturé |
| audiō, audīre, audīvī, audītum | audītum | audītus, -a, -um | entendu |

Il s'accorde comme tout adjectif : *urbs capta* (la ville prise), *litterae missae* (la lettre envoyée), *mīlitēs vulnerātī* (les soldats blessés).

## Les temps du parfait passif

Participe + *sum* (parfait), *eram* (plus-que-parfait), *erō* (futur antérieur). Le participe s'accorde avec le sujet en genre et en nombre.

| Personne | Parfait | Plus-que-parfait | Futur antérieur |
|---|---|---|---|
| 1re sg. | amātus sum | amātus eram | amātus erō |
| 2e sg. | amātus es | amātus erās | amātus eris |
| 3e sg. | amātus est | amātus erat | amātus erit |
| 1re pl. | amātī sumus | amātī erāmus | amātī erimus |
| 2e pl. | amātī estis | amātī erātis | amātī eritis |
| 3e pl. | amātī sunt | amātī erant | amātī erunt |

Attention au décalage : *amātus est* ne signifie pas « il est aimé » (c'est *amātur*) mais « il fut aimé, il a été aimé ». Le *sum* donne le moment par rapport au participe, déjà passé. Une femme dit *amāta sum* ; d'une ville, *capta est* ; d'une lettre, *missae sunt*.

L'infinitif parfait passif est le participe + *esse* : *amātus esse*, « avoir été aimé ».

## Lire les formes

| Latin | Sens |
|---|---|
| *Carthāgō dēlēta est.* | Carthage a été détruite. |
| *Hostēs victī erant.* | Les ennemis avaient été vaincus. |
| *Cum epistula scrīpta erit, eam mittam.* | Quand la lettre aura été écrite, je l'enverrai. |
| *Mīlitēs vulnerātī in castra portātī sunt.* | Les soldats blessés furent portés dans le camp. |

::: exercise which
Présent passif ou parfait passif ?

- *vocātur* → ((il est appelé* / il a été appelé))
- *vocātus est* → ((il est appelé / il a été appelé*))
- *captae sunt* → ((elles sont prises / elles ont été prises*))
- *capiuntur* → ((ils sont pris* / ils ont été pris))
:::

::: exercise translate
Traduisez.

- *Urbs ā Rōmānīs capta est.* → {{La ville a été prise par les Romains. / La ville fut prise par les Romains.}}
- *Litterae iam scrīptae erant.* → {{La lettre avait déjà été écrite.}}
- *Puellae ā mātre vocātae sunt.* → {{Les jeunes filles ont été appelées par leur mère. / Les filles furent appelées par la mère.}}
- *Gladius inventus est.* → {{L'épée a été trouvée. / L'épée fut trouvée.}}
:::

::: summary
- Participe parfait passif : tiré du supin, décliné en *-us, -a, -um* (*amātus, captus, missus*).
- Parfait passif : participe + *sum* ; plus-que-parfait : + *eram* ; futur antérieur : + *erō*. Le participe s'accorde avec le sujet.
- *Amātus est* = il a été (fut) aimé ; *amātur* = il est aimé.
- Infinitif parfait passif : *amātus esse*.
:::
