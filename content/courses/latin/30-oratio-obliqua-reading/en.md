# 30. Indirect speech and first readings

Roman historians rarely quote a speech word for word. They report it in **indirect speech** (*ōrātiō oblīqua*), a whole passage governed by an implied "he said". It combines everything from lessons 18 and 21: main statements become accusative and infinitive, subordinate verbs become subjunctive, and the sequence of tenses holds throughout. This lesson sets out the rules, then reads two famous texts: the opening of Caesar's *Gallic War* and a poem by Catullus.

## The rules of indirect speech

| In direct speech | In indirect speech | Example |
|---|---|---|
| Main statement | accusative + infinitive | *Rōmānī vincent* → *Rōmānōs victūrōs esse* |
| Main command | subjunctive (negative *nē*) | *Discēdite!* → *discēderent* |
| Real question | subjunctive | *Cūr venīs?* → *cūr venīret* |
| Rhetorical question | accusative + infinitive | *Num oblīvīscī possum?* → *num sē oblīvīscī posse* |
| Any subordinate clause | subjunctive, by sequence | *quod habētis* → *quod habērent* |
| *ego, nōs* (the speaker) | *sē, suus* | *meus exercitus* → *suum exercitum* |
| *tū, vōs* (the listeners) | *ille, is* | *vestra urbs* → *illōrum urbem* |
| *hic, nunc* | *ille, tum* | *hōc diē* → *illō diē* |

Caesar, *Gallic War* 1.13 (adapted): the Helvetian envoy Divico speaks to Caesar.

*Dīvicō ita cum Caesare ēgit: sī pācem populus Rōmānus cum Helvētiīs faceret, in eam partem itūrōs Helvētiōs ubi Caesar cōnstituisset; sīn bellō persequī persevērāret, reminīscerētur veteris incommodī populī Rōmānī.*

Divico addressed Caesar as follows: if the Roman people made peace with the Helvetii, the Helvetii would go to the region where Caesar decided; but if he persisted in pursuing them in war, he should remember the old disaster of the Roman people.

## Reading 1: Caesar, Gallic War 1.1

*Gallia est omnis dīvīsa in partēs trēs, quārum ūnam incolunt Belgae, aliam Aquītānī, tertiam quī ipsōrum linguā Celtae, nostrā Gallī appellantur. Hī omnēs linguā, īnstitūtīs, lēgibus inter sē differunt. Gallōs ab Aquītānīs Garumna flūmen, ā Belgīs Matrona et Sēquana dīvidit. Hōrum omnium fortissimī sunt Belgae.*

| Phrase | Note |
|---|---|
| *est dīvīsa* | perfect passive: "is divided"; *omnis* agrees with *Gallia*, "Gaul as a whole" |
| *quārum ūnam* | partitive genitive: "of which one (part)" |
| *quī … appellantur* | "those who are called"; the antecedent *eī* is understood |
| *ipsōrum linguā … nostrā* | ablative of means: "in their own language … in ours" |
| *linguā, īnstitūtīs, lēgibus* | ablative of respect: "in language, customs, laws" |
| *Garumna flūmen* | apposition: "the river Garonne" (Marne, Seine) |
| *fortissimī* | superlative + partitive genitive *hōrum omnium* |

::: exercise caesar
Answer from the text.

- *Quot partēs Galliae sunt?* → ((duae / trēs* / quattuor))
- *Quī tertiam partem incolunt?* → ((Belgae / Aquītānī / Celtae*))
- *Quod flūmen Gallōs ab Aquītānīs dīvidit?* → ((Garumna* / Matrona / Sēquana))
- *Quī fortissimī sunt?* → ((Gallī / Belgae* / Aquītānī))
:::

## Reading 2: Catullus 5

*Vīvāmus, mea Lesbia, atque amēmus,* \
*rūmōrēsque senum sevēriōrum* \
*omnēs ūnius aestimēmus assis!* \
*Sōlēs occidere et redīre possunt:* \
*nōbīs cum semel occidit brevis lūx,* \
*nox est perpetua ūna dormienda.*

Let us live, my Lesbia, and let us love, and let us value all the gossip of rather stern old men at a single penny! Suns can set and return; for us, once our brief light has set, there is one everlasting night to be slept.

| Form | Grammar |
|---|---|
| *vīvāmus, amēmus, aestimēmus* | hortatory subjunctives (lesson 24) |
| *sevēriōrum* | comparative, "rather stern" |
| *ūnius … assis* | genitive of value: "at one *as*", the smallest coin |
| *occidere et redīre* | infinitives after *possunt* |
| *cum semel occidit* | *cum* + indicative: pure time |
| *dormienda* | gerundive + *est*, with dative of agent *nōbīs*: "must be slept by us" |

::: exercise catullus
Find the form in the poem.

- a hortatory subjunctive meaning "let us love" → [[amēmus]]
- a comparative adjective → [[sevēriōrum]]
- a gerundive → [[dormienda]]
- the dative of agent → [[nōbīs]]
:::

::: exercise translate
Translate.

- *Caesar dīxit sē ad urbem ventūrum esse.* → {{Caesar said that he would come to the city.}}
- *Lēgātī respondērunt Helvētiōs pācem velle.* → {{The envoys replied that the Helvetii wanted peace.}}
- *Rogāvit cūr mīlitēs nōn pugnārent.* → {{He asked why the soldiers were not fighting.}}
- *Hī omnēs linguā inter sē differunt.* → {{All these differ from one another in language.}}
:::

::: summary
- Indirect speech: statements → accusative + infinitive; commands and real questions → subjunctive; subordinate clauses → subjunctive.
- Persons shift: *ego* → *sē*, *tū* → *ille*; *hic, nunc* → *ille, tum*.
- Caesar *BG* 1.1: perfect passive, partitive genitive, ablative of respect, superlative + genitive.
- Catullus 5: hortatory subjunctives, genitive of value, gerundive with dative of agent.
:::
