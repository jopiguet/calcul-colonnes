# 30. Le discours indirect et premières lectures

Les historiens romains citent rarement un discours mot pour mot. Ils le rapportent au **style indirect** (*ōrātiō oblīqua*), un passage entier dépendant d'un « il dit » sous-entendu. Il combine tout ce qu'ont apporté les leçons 18 et 21 : les affirmations principales passent à la proposition infinitive, les verbes subordonnés au subjonctif, et la concordance des temps s'applique d'un bout à l'autre. Cette leçon pose les règles, puis lit deux textes célèbres : le début de la *Guerre des Gaules* de César et un poème de Catulle.

## Les règles du discours indirect

| Au style direct | Au style indirect | Exemple |
|---|---|---|
| Affirmation principale | accusatif + infinitif | *Rōmānī vincent* → *Rōmānōs victūrōs esse* |
| Ordre principal | subjonctif (négation *nē*) | *Discēdite!* → *discēderent* |
| Question réelle | subjonctif | *Cūr venīs?* → *cūr venīret* |
| Question oratoire | accusatif + infinitif | *Num oblīvīscī possum?* → *num sē oblīvīscī posse* |
| Toute subordonnée | subjonctif, selon la concordance | *quod habētis* → *quod habērent* |
| *ego, nōs* (celui qui parle) | *sē, suus* | *meus exercitus* → *suum exercitum* |
| *tū, vōs* (ceux qui écoutent) | *ille, is* | *vestra urbs* → *illōrum urbem* |
| *hic, nunc* | *ille, tum* | *hōc diē* → *illō diē* |

César, *Guerre des Gaules* 1, 13 (adapté) : l'ambassadeur helvète Divico s'adresse à César.

*Dīvicō ita cum Caesare ēgit: sī pācem populus Rōmānus cum Helvētiīs faceret, in eam partem itūrōs Helvētiōs ubi Caesar cōnstituisset; sīn bellō persequī persevērāret, reminīscerētur veteris incommodī populī Rōmānī.*

Divico parla ainsi à César : si le peuple romain faisait la paix avec les Helvètes, les Helvètes iraient dans la région que César aurait fixée ; mais s'il persistait à les poursuivre par la guerre, qu'il se souvînt de l'ancien désastre du peuple romain.

## Lecture 1 : César, Guerre des Gaules 1, 1

*Gallia est omnis dīvīsa in partēs trēs, quārum ūnam incolunt Belgae, aliam Aquītānī, tertiam quī ipsōrum linguā Celtae, nostrā Gallī appellantur. Hī omnēs linguā, īnstitūtīs, lēgibus inter sē differunt. Gallōs ab Aquītānīs Garumna flūmen, ā Belgīs Matrona et Sēquana dīvidit. Hōrum omnium fortissimī sunt Belgae.*

| Groupe | Remarque |
|---|---|
| *est dīvīsa* | parfait passif : « est divisée » ; *omnis* s'accorde avec *Gallia*, « la Gaule dans son ensemble » |
| *quārum ūnam* | génitif partitif : « dont l'une (des parties) » |
| *quī … appellantur* | « ceux qui sont appelés » ; l'antécédent *eī* est sous-entendu |
| *ipsōrum linguā … nostrā* | ablatif de moyen : « dans leur propre langue … dans la nôtre » |
| *linguā, īnstitūtīs, lēgibus* | ablatif de point de vue : « par la langue, les institutions, les lois » |
| *Garumna flūmen* | apposition : « le fleuve Garonne » (Marne, Seine) |
| *fortissimī* | superlatif + génitif partitif *hōrum omnium* |

::: exercise caesar
Répondez d'après le texte.

- *Quot partēs Galliae sunt?* → ((duae / trēs* / quattuor))
- *Quī tertiam partem incolunt?* → ((Belgae / Aquītānī / Celtae*))
- *Quod flūmen Gallōs ab Aquītānīs dīvidit?* → ((Garumna* / Matrona / Sēquana))
- *Quī fortissimī sunt?* → ((Gallī / Belgae* / Aquītānī))
:::

## Lecture 2 : Catulle 5

*Vīvāmus, mea Lesbia, atque amēmus,* \
*rūmōrēsque senum sevēriōrum* \
*omnēs ūnius aestimēmus assis!* \
*Sōlēs occidere et redīre possunt:* \
*nōbīs cum semel occidit brevis lūx,* \
*nox est perpetua ūna dormienda.*

Vivons, ma Lesbie, et aimons, et tous les bavardages des vieillards trop sévères, estimons-les à un sou ! Les soleils peuvent se coucher et revenir ; nous, une fois que s'est couchée notre brève lumière, nous devons dormir une seule nuit éternelle.

| Forme | Grammaire |
|---|---|
| *vīvāmus, amēmus, aestimēmus* | subjonctifs d'exhortation (leçon 24) |
| *sevēriōrum* | comparatif, « trop sévères » |
| *ūnius … assis* | génitif de prix : « à un *as* », la plus petite pièce |
| *occidere et redīre* | infinitifs après *possunt* |
| *cum semel occidit* | *cum* + indicatif : temps pur |
| *dormienda* | adjectif verbal + *est*, avec datif d'agent *nōbīs* : « doit être dormie par nous » |

::: exercise catullus
Trouvez la forme dans le poème.

- un subjonctif d'exhortation signifiant « aimons » → [[amēmus]]
- un adjectif au comparatif → [[sevēriōrum]]
- un adjectif verbal → [[dormienda]]
- le datif d'agent → [[nōbīs]]
:::

::: exercise translate
Traduisez.

- *Caesar dīxit sē ad urbem ventūrum esse.* → {{César dit qu'il viendrait à la ville.}}
- *Lēgātī respondērunt Helvētiōs pācem velle.* → {{Les ambassadeurs répondirent que les Helvètes voulaient la paix.}}
- *Rogāvit cūr mīlitēs nōn pugnārent.* → {{Il demanda pourquoi les soldats ne combattaient pas.}}
- *Hī omnēs linguā inter sē differunt.* → {{Tous ceux-ci diffèrent entre eux par la langue.}}
:::

::: summary
- Style indirect : affirmations → accusatif + infinitif ; ordres et vraies questions → subjonctif ; subordonnées → subjonctif.
- Les personnes changent : *ego* → *sē*, *tū* → *ille* ; *hic, nunc* → *ille, tum*.
- César, *BG* 1, 1 : parfait passif, génitif partitif, ablatif de point de vue, superlatif + génitif.
- Catulle 5 : subjonctifs d'exhortation, génitif de prix, adjectif verbal avec datif d'agent.
:::
