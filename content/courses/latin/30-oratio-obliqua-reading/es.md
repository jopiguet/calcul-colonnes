# 30. El estilo indirecto y primeras lecturas

Los historiadores romanos rara vez citan un discurso palabra por palabra. Lo refieren en **estilo indirecto** (*ōrātiō oblīqua*), un pasaje entero que depende de un «dijo» sobreentendido. Combina todo lo de las lecciones 18 y 21: las afirmaciones principales pasan a acusativo con infinitivo, los verbos subordinados a subjuntivo, y la concordancia de tiempos rige de principio a fin. Esta lección expone las reglas y luego lee dos textos célebres: el comienzo de la *Guerra de las Galias* de César y un poema de Catulo.

## Las reglas del estilo indirecto

| En estilo directo | En estilo indirecto | Ejemplo |
|---|---|---|
| Afirmación principal | acusativo + infinitivo | *Rōmānī vincent* → *Rōmānōs victūrōs esse* |
| Orden principal | subjuntivo (negación *nē*) | *Discēdite!* → *discēderent* |
| Pregunta real | subjuntivo | *Cūr venīs?* → *cūr venīret* |
| Pregunta retórica | acusativo + infinitivo | *Num oblīvīscī possum?* → *num sē oblīvīscī posse* |
| Toda subordinada | subjuntivo, según la concordancia | *quod habētis* → *quod habērent* |
| *ego, nōs* (quien habla) | *sē, suus* | *meus exercitus* → *suum exercitum* |
| *tū, vōs* (quienes escuchan) | *ille, is* | *vestra urbs* → *illōrum urbem* |
| *hic, nunc* | *ille, tum* | *hōc diē* → *illō diē* |

César, *Guerra de las Galias* 1, 13 (adaptado): el embajador helvecio Divicón se dirige a César.

*Dīvicō ita cum Caesare ēgit: sī pācem populus Rōmānus cum Helvētiīs faceret, in eam partem itūrōs Helvētiōs ubi Caesar cōnstituisset; sīn bellō persequī persevērāret, reminīscerētur veteris incommodī populī Rōmānī.*

Divicón habló así con César: si el pueblo romano hacía la paz con los helvecios, los helvecios irían a la región que César hubiera fijado; pero si persistía en perseguirlos con la guerra, que recordara el antiguo desastre del pueblo romano.

::: exercise oblique
Ponga la oración en estilo indirecto tras *Dīxit* (tiempo secundario).

- *Hostēs veniunt.* → Dīxit [[hostēs venīre]].
- *Discēdite!* (a sus hombres) → Dīxit ut [[discēderent]].
- *Ego Rōmam ībō.* → Dīxit [[sē Rōmam itūrum esse]].
- *Cūr fugitis?* → Rogāvit cūr [[fugerent]].
:::

## Lectura 1: César, Guerra de las Galias 1, 1

*Gallia est omnis dīvīsa in partēs trēs, quārum ūnam incolunt Belgae, aliam Aquītānī, tertiam quī ipsōrum linguā Celtae, nostrā Gallī appellantur. Hī omnēs linguā, īnstitūtīs, lēgibus inter sē differunt. Gallōs ab Aquītānīs Garumna flūmen, ā Belgīs Matrona et Sēquana dīvidit. Hōrum omnium fortissimī sunt Belgae.*

| Grupo | Nota |
|---|---|
| *est dīvīsa* | perfecto pasivo: «está dividida»; *omnis* concuerda con *Gallia*, «la Galia en su conjunto» |
| *quārum ūnam* | genitivo partitivo: «de las cuales una» |
| *quī … appellantur* | «los que son llamados»; el antecedente *eī* se sobreentiende |
| *ipsōrum linguā … nostrā* | ablativo instrumental: «en su propia lengua … en la nuestra» |
| *linguā, īnstitūtīs, lēgibus* | ablativo de limitación: «en lengua, costumbres, leyes» |
| *Garumna flūmen* | aposición: «el río Garona» (Marne, Sena) |
| *fortissimī* | superlativo + genitivo partitivo *hōrum omnium* |

::: exercise caesar
Responda según el texto.

- *Quot partēs Galliae sunt?* → ((duae / trēs* / quattuor))
- *Quī tertiam partem incolunt?* → ((Belgae / Aquītānī / Celtae*))
- *Quod flūmen Gallōs ab Aquītānīs dīvidit?* → ((Garumna* / Matrona / Sēquana))
- *Quī fortissimī sunt?* → ((Gallī / Belgae* / Aquītānī))
:::

## Lectura 2: Catulo 5

*Vīvāmus, mea Lesbia, atque amēmus,* \
*rūmōrēsque senum sevēriōrum* \
*omnēs ūnius aestimēmus assis!* \
*Sōlēs occidere et redīre possunt:* \
*nōbīs cum semel occidit brevis lūx,* \
*nox est perpetua ūna dormienda.*

Vivamos, Lesbia mía, y amemos, y todas las habladurías de los viejos demasiado severos ¡estimémoslas en un as! Los soles pueden ponerse y volver; nosotros, una vez que se ha puesto nuestra breve luz, hemos de dormir una sola noche eterna.

| Forma | Gramática |
|---|---|
| *vīvāmus, amēmus, aestimēmus* | subjuntivos exhortativos (lección 24) |
| *sevēriōrum* | comparativo, «demasiado severos» |
| *ūnius … assis* | genitivo de precio: «en un *as*», la moneda más pequeña |
| *occidere et redīre* | infinitivos tras *possunt* |
| *cum semel occidit* | *cum* + indicativo: tiempo puro |
| *dormienda* | gerundivo + *est*, con dativo agente *nōbīs*: «debe ser dormida por nosotros» |

::: exercise catullus
Encuentre la forma en el poema.

- un subjuntivo exhortativo que significa «amemos» → [[amēmus]]
- un adjetivo en comparativo → [[sevēriōrum]]
- un gerundivo → [[dormienda]]
- el dativo agente → [[nōbīs]]
:::

::: summary
- Estilo indirecto: afirmaciones → acusativo + infinitivo; órdenes y preguntas reales → subjuntivo; subordinadas → subjuntivo.
- Las personas cambian: *ego* → *sē*, *tū* → *ille*; *hic, nunc* → *ille, tum*.
- César, *BG* 1, 1: perfecto pasivo, genitivo partitivo, ablativo de limitación, superlativo + genitivo.
- Catulo 5: subjuntivos exhortativos, genitivo de precio, gerundivo con dativo agente.
:::
