# 6. L'imparfait et le futur

Deux autres temps se forment sur le même radical que le présent : l'imparfait, pour ce qui était en cours ou se répétait, et le futur. Pour les deux premières conjugaisons, les deux se font avec une syllabe contenant un **b**. *Sum* et *possum* ont leurs propres formes.

## L'imparfait : *-ba-*

L'imparfait ajoute **-ba-** au radical du présent, puis les terminaisons personnelles (avec *-m* à la première personne).

| Personne | amāre | monēre |
|---|---|---|
| 1re sg. | amā**bam** | monē**bam** |
| 2e sg. | amā**bās** | monē**bās** |
| 3e sg. | amā**bat** | monē**bat** |
| 1re pl. | amā**bāmus** | monē**bāmus** |
| 2e pl. | amā**bātis** | monē**bātis** |
| 3e pl. | amā**bant** | monē**bant** |

L'imparfait décrit une action en cours ou répétée dans le passé, comme l'imparfait français : *ambulābam* « je marchais », « j'avais l'habitude de marcher ». Il plante le décor : *Puerī in agrīs labōrābant* « les garçons travaillaient dans les champs ».

## Le futur : *-bō, -bis, -bit*

Les deux premières conjugaisons forment leur futur avec **-b-** et les voyelles *ō, i, i, i, i, u* :

| Personne | amāre | monēre |
|---|---|---|
| 1re sg. | amā**bō** | monē**bō** |
| 2e sg. | amā**bis** | monē**bis** |
| 3e sg. | amā**bit** | monē**bit** |
| 1re pl. | amā**bimus** | monē**bimus** |
| 2e pl. | amā**bitis** | monē**bitis** |
| 3e pl. | amā**bunt** | monē**bunt** |

Apprenez les voyelles comme une comptine : *bō, bis, bit, bimus, bitis, bunt*. Attention : les troisième et quatrième conjugaisons forment leur futur autrement (leçon 8).

## *Sum* et *possum*

*Sum* a le radical *er-* aux deux temps : imparfait *eram*, futur *erō*. *Possum* place *pot-* devant.

| Personne | Imparfait de sum | Futur de sum | Imparfait de possum | Futur de possum |
|---|---|---|---|---|
| 1re sg. | eram | erō | poteram | poterō |
| 2e sg. | erās | eris | poterās | poteris |
| 3e sg. | erat | erit | poterat | poterit |
| 1re pl. | erāmus | erimus | poterāmus | poterimus |
| 2e pl. | erātis | eritis | poterātis | poteritis |
| 3e pl. | erant | erunt | poterant | poterunt |

## Les mots du temps

| Latin | Sens |
|---|---|
| *nunc* | maintenant |
| *tum* | alors, à ce moment-là |
| *iam* | déjà, désormais |
| *mox* | bientôt |
| *crās* | demain |
| *herī* | hier |
| *diū* | longtemps |

*Herī in forō erāmus ; crās in agrīs labōrābimus.* Hier nous étions au forum ; demain nous travaillerons dans les champs.

::: exercise translate
Traduisez.

- *Ōlim agricolae in agrīs labōrābant.* → {{Autrefois les paysans travaillaient dans les champs. / Jadis les paysans travaillaient dans les champs.}}
- *Crās amīcōs vidēbimus.* → {{Demain nous verrons nos amis. / Demain nous verrons les amis.}}
- *Puer laetus nōn erat.* → {{Le garçon n'était pas joyeux. / L'enfant n'était pas heureux.}}
- *Mox poterit cantāre.* → {{Bientôt il pourra chanter. / Bientôt elle pourra chanter.}}
:::

::: summary
- Imparfait, 1re et 2e conjugaisons : radical + *-bam, -bās, -bat, -bāmus, -bātis, -bant* : action en cours ou répétée dans le passé.
- Futur, 1re et 2e conjugaisons : radical + *-bō, -bis, -bit, -bimus, -bitis, -bunt*.
- *Sum* : *eram…* et *erō, eris, erit, erimus, eritis, erunt* ; *possum* : *poteram…*, *poterō…*.
:::
