# 11. Le système du parfait : parfait, plus-que-parfait, futur antérieur

Jusqu'ici, tous les temps venaient du radical du présent. Le passé des actions achevées, « j'aimai », « j'ai aimé », « j'avais aimé », « j'aurai aimé », vient d'un second radical, le **radical du parfait**, donné par le troisième temps primitif. Une fois qu'on le connaît, les trois temps sont parfaitement réguliers, dans les quatre conjugaisons.

## Les temps primitifs

Un verbe latin s'apprend avec quatre temps primitifs : présent, infinitif, parfait, supin (ou participe parfait).

| Présent | Infinitif | Parfait | Supin | Radical du parfait |
|---|---|---|---|---|
| amō | amāre | amāvī | amātum | amāv- |
| moneō | monēre | monuī | monitum | monu- |
| regō | regere | rēxī | rēctum | rēx- |
| capiō | capere | cēpī | captum | cēp- |
| audiō | audīre | audīvī | audītum | audīv- |
| sum | esse | fuī | futūrus | fu- |

Les première et quatrième conjugaisons sont surtout régulières (*-āvī*, *-īvī*). La deuxième a souvent *-uī*. La troisième s'apprend verbe par verbe : en *-sī* (*scrīpsī*, *dīxī* = *dīc-sī*), avec une voyelle longue (*vēnī*, *lēgī*, *fēcī*), avec redoublement (*dedī*, *cucurrī*). Le radical du parfait est le parfait sans son *-ī*.

## Le parfait

Le parfait a ses propres terminaisons, les mêmes pour tous les verbes :

| Personne | Terminaison | amāre | regere |
|---|---|---|---|
| 1re sg. | -ī | amāv**ī** | rēx**ī** |
| 2e sg. | -istī | amāv**istī** | rēx**istī** |
| 3e sg. | -it | amāv**it** | rēx**it** |
| 1re pl. | -imus | amāv**imus** | rēx**imus** |
| 2e pl. | -istis | amāv**istis** | rēx**istis** |
| 3e pl. | -ērunt | amāv**ērunt** | rēx**ērunt** |

Le parfait exprime une action passée achevée, « j'aimai », ou son résultat présent, « j'ai aimé » : *Vēnī, vīdī, vīcī*, « je suis venu, j'ai vu, j'ai vaincu ». Opposez-le à l'imparfait : *Caesar scrībēbat* (écrivait), *Caesar scrīpsit* (écrivit, a écrit).

## Le plus-que-parfait et le futur antérieur

Tous deux ajoutent les formes de *sum* au radical du parfait, avec de petites modifications :

| Personne | Plus-que-parfait (radical + *eram*) | Futur antérieur (radical + *erō*) |
|---|---|---|
| 1re sg. | amāv**eram** j'avais aimé | amāv**erō** j'aurai aimé |
| 2e sg. | amāv**erās** | amāv**eris** |
| 3e sg. | amāv**erat** | amāv**erit** |
| 1re pl. | amāv**erāmus** | amāv**erimus** |
| 2e pl. | amāv**erātis** | amāv**eritis** |
| 3e pl. | amāv**erant** | amāv**erint** |

La troisième personne du pluriel du futur antérieur est *-erint*, non *-erunt*. Le latin l'emploie là où le français met souvent un présent ou un futur : *Sī vēneris, gaudēbō*, « si tu viens (seras venu), je me réjouirai ».

::: summary
- Quatre temps primitifs : *amō, amāre, amāvī, amātum* ; le radical du parfait est le troisième sans *-ī*.
- Parfait : *-ī, -istī, -it, -imus, -istis, -ērunt* : action achevée (« je fis », « j'ai fait »).
- Plus-que-parfait : radical + *-eram…* ; futur antérieur : radical + *-erō, -eris, -erit, -erimus, -eritis, -erint*.
- Les parfaits de la troisième conjugaison s'apprennent : *rēxī, dīxī, vēnī, lēgī, fēcī, cēpī, dedī*.
:::
