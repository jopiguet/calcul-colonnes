# 2. Souffle ou claquement : les éjectives

Le géorgien a trois sortes de p, de t et de k. Le français ne distingue pas les deux que voici : l'aspirée, avec un souffle, et l'éjective, dite gorge fermée. Cette leçon donne ces lettres, et le nom du pays.

## Aspirées et éjectives

| Aspirée | Son | Éjective | Son |
|---|---|---|---|
| ფ | p | პ | p' |
| თ | t | ტ | t' |
| ქ | k | კ | k' |
| | | ყ | q' |

- Les aspirées se disent avec un souffle, comme le *p* de l'anglais *pin* : ფ *p*, თ *t*, ქ *k*.
- Les éjectives se disent gorge fermée, puis relâchée : un claquement bref et dur, sans souffle. La translittération les marque d'une apostrophe : პ *p'*, ტ *t'*, კ *k'*.
- ყ *q'* est une éjective faite plus en arrière, à la luette.
- ჰ *h* est un *h* soufflé, rare, au début de quelques mots.
- L'apostrophe compte : ქარი *kari* est « vent », კარი *k'ari* « porte ». Tapez-la ' ou ’.

:::

## Des mots, et le pays

| Géorgien | Translittération | Sens |
|---|---|---|
| საქართველო | *sakartvelo* | Géorgie |
| ქალაქი | *kalaki* | ville |
| პური | *p'uri* | pain |
| ყველი | *q'veli* | fromage |
| ფული | *puli* | argent |
| თავი | *tavi* | tête |
| კარი | *k'ari* | porte |

- Les Géorgiens appellent leur pays საქართველო *Sakartvelo*, « pays des Kartvèles », et leur langue ქართული *kartuli*. Le nom « Géorgie » est venu de l'extérieur, par le persan et l'arabe.
- Le pain cuit souvent dans un four rond en terre, le თონე *tone*.

::: summary
- Aspirées ფ p, თ t, ქ k (avec souffle) ; éjectives პ p', ტ t', კ k', ყ q' (gorge fermée, sans souffle) ; ჰ h.
- L'apostrophe distingue les mots : ქარი vent, კარი porte.
- საქართველო Géorgie, ქალაქი ville, პური pain, ყველი fromage, ფული argent, თავი tête, კარი porte.
