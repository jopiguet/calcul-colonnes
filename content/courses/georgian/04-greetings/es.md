# 4. Victoria: los saludos

El «hola» georgiano desea la victoria. Esta lección da los saludos, sí y no, y cómo decir el nombre, con dos rasgos de la gramática: no hay género, y hay un «sí» de cortesía.

## Hola y gracias

| Georgiano | Transliteración | Significado |
|---|---|---|
| გამარჯობა | *gamarjoba* | hola |
| გაგიმარჯოს | *gagimarjos* | hola (la respuesta) |
| მადლობა | *madloba* | gracias |
| ბოდიში | *bodishi* | perdón |
| ნახვამდის | *nakhvamdis* | adiós |

- გამარჯობა *gamarjoba* viene de la palabra para la victoria, გამარჯვება *gamarjveba*; la respuesta, გაგიმარჯოს *gagimarjos*, significa «que tengas la victoria».
- ნახვამდის *nakhvamdis* es «hasta vernos»: ნახვა «el ver», -მდის «hasta».

::: exercise greet
¿Qué significa?

- გამარჯობა → ((hola* / adiós / gracias))
- მადლობა → ((gracias* / perdón / hola))
- ბოდიში → ((perdón* / gracias / adiós))
- ნახვამდის → ((adiós* / hola / perdón))
:::

## Sí, no, y su nombre

| Georgiano | Transliteración | Significado |
|---|---|---|
| კი | *k'i* | sí |
| დიახ | *diakh* | sí (cortés) |
| არა | *ara* | no |
| რა გქვია? | *ra gkvia?* | ¿cómo te llamas? |
| მე მქვია ნინო. | *me mkvia Nino.* | me llamo Nino. |

- კი *k'i* es el sí de cada día; დიახ *diakh* se dice a los mayores y a los desconocidos.
- El georgiano no tiene género gramatical: ის *is* es «él», «ella» y «ello».
- La capital, თბილისი *Tbilisi*, toma su nombre de თბილი *tbili*, «cálido», por sus fuentes termales.

::: exercise yesno
¿Qué significa?

- კი → ((sí* / no / perdón))
- არა → ((no* / sí / gracias))
- დიახ → ((sí, con cortesía* / no, con cortesía / hola))
- გაგიმარჯოს → ((hola, como respuesta* / adiós / perdón))
:::
