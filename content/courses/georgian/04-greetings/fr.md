# 4. Victoire : les salutations

Le « bonjour » géorgien souhaite la victoire. Cette leçon donne les salutations, oui et non, et comment dire son nom, avec deux traits de la grammaire : pas de genre, et un « oui » de politesse.

## Bonjour et merci

| Géorgien | Translittération | Sens |
|---|---|---|
| გამარჯობა | *gamarjoba* | bonjour |
| გაგიმარჯოს | *gagimarjos* | bonjour (la réponse) |
| მადლობა | *madloba* | merci |
| ბოდიში | *bodishi* | pardon |
| ნახვამდის | *nakhvamdis* | au revoir |

- გამარჯობა *gamarjoba* vient du mot pour la victoire, გამარჯვება *gamarjveba* ; la réponse, გაგიმარჯოს *gagimarjos*, veut dire « sois victorieux ».
- ნახვამდის *nakhvamdis*, c'est « jusqu'à se revoir » : ნახვა « le fait de voir », -მდის « jusqu'à ».

::: exercise greet
Que veut dire ce mot ?

- გამარჯობა → ((bonjour* / au revoir / merci))
- მადლობა → ((merci* / pardon / bonjour))
- ბოდიში → ((pardon* / merci / au revoir))
- ნახვამდის → ((au revoir* / bonjour / pardon))
:::

## Oui, non, et votre nom

| Géorgien | Translittération | Sens |
|---|---|---|
| კი | *k'i* | oui |
| დიახ | *diakh* | oui (poli) |
| არა | *ara* | non |
| რა გქვია? | *ra gkvia?* | comment t'appelles-tu ? |
| მე მქვია ნინო. | *me mkvia Nino.* | je m'appelle Nino. |

- კი *k'i* est le oui de tous les jours ; დიახ *diakh* se dit aux aînés et aux inconnus.
- Le géorgien n'a pas de genre grammatical : ის *is* est « il », « elle » et « cela ».
- La capitale, თბილისი *Tbilissi*, tire son nom de თბილი *tbili*, « chaud », pour ses sources chaudes.

::: exercise yesno
Que veut dire ce mot ?

- კი → ((oui* / non / pardon))
- არა → ((non* / oui / merci))
- დიახ → ((oui, poliment* / non, poliment / bonjour))
- გაგიმარჯოს → ((bonjour, en réponse* / au revoir / pardon))
:::

::: summary
- გამარჯობა bonjour, « victoire » ; la réponse გაგიმარჯოს ; მადლობა merci ; ბოდიში pardon ; ნახვამდის au revoir.
- კი oui, დიახ oui (poli), არა non ; რა გქვია? — მე მქვია…
- Pas de genre : ის il, elle, cela. თბილისი, de თბილი « chaud ».
:::
